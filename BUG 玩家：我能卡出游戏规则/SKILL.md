# 《BUG 玩家：我能卡出游戏规则》创作规范

## 类型定位
反套路全息网游爽文。核心爽点：**别人遵守规则，我定义规则**。
四幕结构（1-6 新手封神 / 7-14 主城扬名 / 15-20 至暗危机 / 21-24 破格封神），24 章，每章约 2000-2400 字。

## 视角与人设纪律
- 第三人称限知，跟随陆寻；每章至少一次"他人反应镜头"（围观/论坛/频道/反派内部）做震惊放大器。
- 陆寻台词短、冷、狠，禁止长篇装逼独白；他的狂体现在行动里。
- 苏清然弧光：惋惜→疑惑→震撼→抉择→信任。她不是花瓶，是"守规矩的顶级强者"，与主角天赋天然对立互补（F-004）。
- 反派智商在线：天穹的每一步围剿都有利益逻辑；官方 AI【衡】不是蠢系统，是制衡程序。

## 金手指细则（全书锁死，不得自相矛盾）
- 天赋【规则偏移】：触发后产生 **0.01 秒规则真空**——目标判定被悬置（等级压制/锁定/惩罚/掉落/buff 存续/传送/仇恨/死亡结算……皆可）。
- 无属性加成、无攻击技能；真空只能"让判定失效"，不能直接造伤害。伤害靠操作、地形、普攻与心理战。
- 真空可**无限叠加**：多判定同悬、时长延展、范围扩大（F-001 主线成长线）。
- 代价：精神负荷随叠加层数递增；后期被【衡】针对性校验干扰（15 章）。

## 每章统一爽点公式
规则压制 → 众人嘲讽 → 系统判定锁死 → 主角触发真空 → 破格反杀 → 全员震惊 → 埋新伏笔。
章尾必须留钩子（悬念/威胁/反转任选其一）。

## 风格黑名单
- 禁止大段设定说明堆砌，设定必须藏在冲突与反应里。
- 禁止圣母、禁止主角解释自己、禁止反派废话超过三句。
- 系统文本用【】；论坛/频道用引用块；数据面板可用缩进块。
- 数字面板用阿拉伯数字，叙述用中文数字。
