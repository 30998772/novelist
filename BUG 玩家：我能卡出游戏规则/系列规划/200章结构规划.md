## 第一部：废稿封神（001-047）

### 第一幕：觉醒（001-012）
- 核心：废稿天赋的真面目
- 节奏：快速升级，密集爽点
- 关键人物：陆寻、苏清然、陈胖、赵擎

### 第二幕：扬名（013-024）
- 核心：天穹对决，特例单位
- 节奏：压迫→反击→封神
- 关键人物：白慕鸿、【衡】

### 第三幕：扩张（025-036）
- 核心：深层探索，感情线发展，创世者真相
- 节奏：探索→日常互动→真相揭示
- 关键人物：叶霜（记忆）、沈墨（残留）、苏清然
- 结构调整：前6章（025-030）聚焦深层探索与NPC觉醒，后6章（031-036）聚焦感情线与真相揭示

### 第四幕：抉择（037-047）
- 核心：NPC生存权，规则编写，苏清然反叛
- 节奏：冲突→抉择→新秩序
- 关键人物：赵铁山、林风

## 第二部：深渊回响（048-098）

### 第一幕：探索（048-059）
- 核心：深层全面开放，新职业，感情线日常
- 节奏：探索→日常互动→战争阴云
- 关键人物：苏清然（057章日常互动）、白慕鸿（058章阴谋）

### 第二幕：觉醒（060-072）
- 核心：NPC起义，陆寻重大失败，低谷段
- 节奏：战争→失败→崩溃→重生种子
- 关键人物：叶霜、赵擎（071章抉择）

### 第三幕：重建（073-084）
- 核心：从废墟中站起，白慕鸿退场
- 节奏：重建→白慕鸿过去→理念之争→对决→结局
- 关键人物：白慕鸿（080章过去揭示，081-084章退场）

### 第四幕：真相（085-098）
- 核心：创世者真相，维护者使命，全球投票
- 节奏：揭秘→使命→现实反应→全球投票→告别
- 关键人物：沈墨（完整揭露）、陈胖（093章高光）

## 第三部：规则之上（099-133）

### 第一幕：新秩序（099-114）
- 核心：维护者日常，人性流失，陈胖守护
- 节奏：日常→人性流失渐进→陈胖守护→苏清然坚持
- 关键人物：陈胖（113章高光）、苏清然、赵铁山（109章NPC视角）

### 第二幕：制衡（115-125）
- 核心：【衡】反扑，陆寻证明自己
- 节奏：制衡→证明→觉醒→认可
- 关键人物：【衡】

### 第三幕：真相（126-133）
- 核心：世界本质，补天决定
- 节奏：真相→恐惧→考验→补天→失去能力
- 关键人物：陆寻、苏清然

## 第四部：特例永恒（134-153）

### 第一幕：普通人的守护（134-140）
- 核心：陆寻失去能力后的日常，灰色光点威胁
- 节奏：日常→威胁具象化→团结→准备→出发
- 关键人物：全员

### 第二幕：最终考验（141-148）
- 核心：裂缝修复，众人力量，苏清然沉睡与苏醒
- 节奏：对抗→安抚→团队高光→代价→守候→苏醒
- 关键人物：苏清然（143章决定，148章苏醒）

### 第三幕：特例永恒（149-153）
- 核心：归来，传承，新时代，永恒
- 节奏：归来→传承→新时代→永恒→尾声
- 关键人物：全员

## 关键成长线

### 陆寻
- 第一部：卡规则 → 写规则 → 成为特例单位
- 第二部：维护者 → 重大失败 → 重生 → 击败白慕鸿
- 第三部：维护者 → 失去人性 → 被拉回 → 补天 → 成为普通人
- 第四部：普通人 → 用"人"的方式守护世界 → 传奇落幕

### 苏清然
- 第一部：秩序回响 → 日常互动 → 公开反叛天穹
- 第二部：日常互动 → 骂醒陆寻 → 陪伴 → 规则共鸣进化
- 第三部：守护"人"而非"规则" → 将陆寻拉回
- 第四部：主动守护陆寻 → 沉睡 → 苏醒 → 永恒守护者

### 陈胖
- 第一部：忠诚损友 → 陆寻被众人疏远时独留
- 第二部：安慰陆寻 → 【铁胃】破解护符封印（高光）
- 第三部：不离不弃守护陆寻（高光）
- 第四部：用【铁胃】吞噬规则碎片（高光）

### 【衡】
- 第一部：监控者 → 承认陆寻
- 第二部：制衡程序 → 选择立场
- 第三部：启动校准协议 → 认可陆寻 → 永恒伙伴
- 第四部：见证者 → 永恒伙伴

### NPC群体
- 第一部：程序 → 有意识
- 第二部：有意识 → 起义 → 牺牲
- 第三部：重生 → 独立文明
- 第四部：永恒生命
