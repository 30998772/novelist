# 《BUG 玩家：我能卡出游戏规则》创作资料库

## 项目概述

《BUG 玩家：我能卡出游戏规则》是一部游戏题材网文，讲述拥有"规则偏移"天赋的玩家陆寻在全沉浸VR网游中发现系统漏洞，一步步卡出游戏规则、最终揭示世界真相的故事。

- 正传：24章×4000字≈9.6万字
- 结构：觉醒→试炼→破格→真相

## 核心设定

1. **规则偏移天赋**：0.01秒判定真空，可悬置系统判断
2. **叠加机制**：真空可叠加，但消耗精神力
3. **世界真相**：游戏是真实平行世界的投影
4. **特例单位**：主角最终被定义为无法封禁/修复/定义的存在
