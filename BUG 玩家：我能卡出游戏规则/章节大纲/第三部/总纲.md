# 第三部：规则之上（099-133章）

## 基本信息

| 项目 | 数值 |
|------|------|
| 章节范围 | 099-133 |
| 总章数 | 35章（新增113章"陈胖的守护"） |
| 字数目标 | ~12.25万字 |
| 核心主题 | 成为维护者后的挑战，面对【衡】的最终制衡，守护世界的代价，以及"规则之上"的真相 |

## 修改要点

1. **删除多世界体系**：不再引入"其他虚拟世界""多世界联盟""高维存在"等设定。所有冲突集中在《寰宇神域》内部。
2. **格局收缩**：最终战不是打"高维存在"，而是守护这个世界的人和规则。
3. **【衡】的角色强化**：作为"制衡程序"，它成为第三部真正的对手——不是敌人，而是必须跨越的考验。
4. **陆寻的代价**：成为维护者后，他逐渐失去"人性"，需要在"规则"与"人"之间做出最终选择。
5. **标题风格统一**：取消"角色：事件"格式。
6. **人性冲突加深**：新增106章"非人的温度"（陆寻第一次情感麻木）、107章"唤醒失败"（苏清然尝试各种方式唤醒他），让"人性流失"有渐进过程。
7. **陈胖高光深化**：新增113章"陈胖的守护"，在陆寻失去人性后，陈胖用"不离不弃"的方式守护他——不是用超能力，而是用"人"的方式。这是对"普通人的力量"主题的具象化。
8. **叶霜视角新增**：新增109章"银甲的守望"，以叶霜视角展开NPC文明重建的剧情线；新增111章"铁与银的对话"（赵铁山×叶霜），让NPC阵营有更多自主行动。
9. **制衡段扩展**：新增119章"失控的边缘"（陆寻证明自己过程中的内心挣扎），让"向【衡】证明"的内心戏更充分。
10. **使命段深化**：新增128章"恐惧"（陆寻对失去能力的恐惧+苏清然的承诺），让"补天"决定更有情感重量。
11. **编号调整**：第二部新增至51章，第三部编号顺延为099-133（35章），第四部编号顺延为134-153。

## 三幕结构

### 第一幕：新秩序（099-114章）

| 章号 | 标题 | 核心内容 |
|------|------|----------|
| 099 | 维护者的第一天 | 重建世界规则的日常；陆寻感受到"维护者"身份的重量 |
| 100 | 规则的裂缝 | 世界边缘出现异常——不是"其他世界"，而是世界本身的退化 |
| 101 | 退化的根源 | 创世者离开后，世界底层规则正在缓慢崩解 |
| 102 | 陆寻的应对 | 用规则偏移建立"规则锚点"，暂时稳定世界 |
| 103 | 苏清然的配合 | 秩序回响稳定规则锚点；两人配合日渐默契 |
| 104 | NPC的贡献 | 有意识的NPC成为"规则节点"，帮助稳定世界 |
| 105 | 【衡】的警告 | 制衡程序提醒：规则锚点只是延缓，不是解决 |
| 106 | 陆寻的困境 | 他越使用规则力量，越感受到"人性"在流失——开始用"效率"衡量一切 |
| 107 | 非人的温度 | **新增**：苏清然在维护任务中受伤，陆寻第一反应是计算"修复效率最优解"而非关心她；他看着她的伤口，心里浮现的是数据而非心疼——**他第一次意识到自己"感受不到温度了"**。章末他试图假装关心，但苏清然已经看到了他眼中的冷漠 |
| 108 | 唤醒失败 | **新增**：苏清然尝试各种方式唤醒陆寻——做他爱吃的菜、讲陈胖的笑话、提起叶霜的牺牲——但陆寻始终以冷静的逻辑回应。她在他面前崩溃大哭，他只是递了纸巾，问"哭能解决问题吗？"。**她第一次感到：他正在变成他们曾经对抗的东西** |
| 109 | 铁匠的注视 | **NPC视角章（赵铁山）**：赵铁山在自治城治安官任上被【衡】选为"规则节点"（双重身份：治安官管秩序，节点管规则稳定），见证陆寻从"维护者"变成"规则机器"；回忆叶霜的牺牲，思考NPC重生后的意义 |
| 110 | 银甲的守望 | **NPC视角章（叶霜）**：叶霜以"规则残影"形态回归后，在重建NPC文明的过程中发现——陆寻正在变成他们曾经害怕的存在；她决定"我们不能再让一个人独自承担所有" |
| 111 | 铁与银的对话 | **新增**：赵铁山×叶霜对话——赵铁山回忆叶霜曾救过自己的场景，提出"我们欠他的"；叶霜提出NPC分担世界维护的方案；两人达成共识：**不是等陆寻来保护他们，而是他们也要保护陆寻** |
| 112 | 裂痕加深 | 苏清然试图用过去的回忆（069章废墟、陈胖的安慰、叶霜的牺牲）唤醒陆寻的情感，但陆寻的反应让她绝望；**叶霜带着NPC们来到陆寻面前——"你不是一个人在守"**；陆寻的回答是"不需要，你们帮不上忙" |
| 113 | 陈胖的守护 | **新增·陈胖高光**：陈胖意识到陆寻正在失去人性，决定用"普通人的方式"守护他。他每天给陆寻带饭、讲笑话、坐在他身边——不是因为有用，而是因为"你以前也是这样对我的"。陆寻的反应依然冷淡，但陈胖不在乎。**苏清然看到这一幕，意识到：守护不一定需要超能力，有时候只需要一个朋友的不离不弃。这是"普通人的力量"主题的第一次具象化** |
| 114 | 最后的温柔 | **新增**：苏清然在陆寻面前最后一次尝试——她不再试图唤醒，而是像往常一样陪他工作、吃饭、散步，用"日常"对抗"规则化"。陆寻依然冷淡，但章末有一个细节：**他接过她递来的水杯时，手指微微颤抖了一下**——人性的火种尚未完全熄灭 |

### 第二幕：制衡（115-125章）

| 章号 | 标题 | 核心内容 |
|------|------|----------|
| 115 | 【衡】的反扑 | 制衡程序启动"校准协议"，试图削弱陆寻的权限 |
| 116 | 规则之战 | 陆寻与【衡】在规则层面的对决——不是战斗，而是理念的碰撞 |
| 117 | 【衡】的真相 | 它不是敌人，是在执行创世者最后的命令："当维护者失控时，制衡他" |
| 118 | 陆寻的证明 | 他必须向【衡】证明自己"没有失控" |
| 119 | 失控的边缘 | **新增**：陆寻在证明过程中，越努力证明自己"清醒"，越发现自己已经站在失控边缘——他的逻辑开始自洽地走向极端。**他意识到：如果继续这样下去，【衡】是对的** |
| 120 | 苏清然的抉择 | 她必须在陆寻和【衡】之间选择——她选择"人"而非"规则" |
| 121 | 守护者的代价 | 苏清然用秩序回响稳定陆寻，自己承受规则反噬 |
| 122 | 陆寻的觉醒 | 他意识到自己正在变成"规则本身"——这正是创世者担心的 |
| 123 | 创世者的遗言 | 沈墨留下的最后信息："规则是工具，不是信仰。记住你是一个人。" |
| 124 | 陆寻的选择 | 他选择"人"而非"规则"——放弃部分维护者权限 |
| 125 | 【衡】的认可 | 制衡程序承认陆寻，停止校准协议 |

### 第三幕：真相（126-133章）

| 章号 | 标题 | 核心内容 |
|------|------|----------|
| 126 | 世界的本质 | 寰宇神域是创世者沈墨留下的"礼物"——用来证明"规则与人可以共存"。沈墨现实世界的详细故事——曾是顶尖游戏程序员，因目睹现实世界中规则对弱者的压迫，决心创造一个"规则与人平衡"的世界；他耗尽心血创造《寰宇神域》，却在完成前病逝，留下未完成的遗愿 |
| 127 | 两个人的使命 | 陆寻的使命是守护"规则与人共存"的可能性；苏清然的使命是守护"人"——让陆寻不至于迷失 |
| 128 | 恐惧 | **新增**：陆寻在"补天"决定前夜，罕见地表现出恐惧——他害怕失去能力后无法保护苏清然、无法守护世界。苏清然说："你守护世界不需要超能力，需要的是'人'。我陪你"。**这是陆寻第一次在苏清然面前示弱** |
| 129 | 最后的考验 | 世界底层的规则崩解加速，必须有人"补天" |
| 130 | 补天者 | 陆寻决定用自己的规则偏移"补天"——但代价是失去所有能力 |
| 131 | 苏清然的反对 | "你不能用命去换"——两人最激烈的冲突 |
| 132 | 和解 | 陆寻说"我不是用命去换，我是用能力去换"；苏清然说"我陪你" |
| 133 | 规则之上 | 陆寻完成"补天"，失去规则偏移能力，但世界得救；第四部开启 |
