# 《BUG 玩家：我能卡出游戏规则》总纲

一句话：全民全息游戏时代，少年抽到全服唯一的"废稿"天赋，却发现它能卡掉游戏的一切规则——别人在规则里玩，他把规则当玩具。

## 核心逻辑
规则压制 → 众人嘲讽 → 判定锁死 → 触发真空 → 破格反杀 → 全员震惊 → 埋新伏笔。

## 四幕
1. 第 1-6 章 新手封神（觉醒日→SSS+→卡惩罚→胜苏清然→论坛质疑→热修照卡）
2. 第 7-14 章 主城扬名（岚风城→赵擎挑衅→buff 清零反杀→成名→坠星崖→职业碎片→封杀令→单刷 BOSS）
3. 第 15-20 章 至暗危机（【衡】监控→围杀→死亡不掉落→猜忌疏远→苏清然抉择→全域修正倒计时）
4. 第 21-24 章 破格封神（冻结全城 3 秒→天穹溃败→揭世界真相→特例单位+深层地图伏笔）

## 关键设定存档
- 天赋触发：意念锁定目标判定瞬间 → 0.01 秒规则真空（该判定悬置失效）。
- 真空不能造伤害，只能让"判定失效"；伤害靠操作与普攻。
- 叠加层数越高精神负荷越大；冻结全城 3 秒是当前极限（021）。
- 【衡】的格式化台词风格：【警告。】【记录。】【校准协议·启动。】
