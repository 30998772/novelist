# 第064章 创世者的第七位

深层边缘有一座被地图划去的旧档案层。织律者公会的舆图上，它标着"无法进入"四个字，旁边还补了一笔：塌方，勿近。

这层档案原本埋得比深层还深，是上次规则风暴之后，地壳一样的岩层被掀开一角，白芒从裂缝里漏出来，深层的开拓队这才报了警。陆寻来，一半是查那道白芒，一半是手里的徽记在抖。自上而下，它抖得越来越厉害，像一段卡了很多年的线，终于等到了要接话的人。

他和苏清然沿着下层通道走了大半夜，通道两侧的墙壁越来越老，老到后来连材质都辨不出来了，触手是一层低温玻璃般的微凉，指尖按上去，墙会无声地陷。尽头没有门，只有一道渗着淡光的缝隙。

苏清然把定规之钥悬在掌心，光晕贴着缝隙描了一圈，读出一行字。光晕很稳，像在替整个档案层盖章。"记忆层。"她念出那个名字，眉尖轻轻拧起来，"谁会把记忆锁在这种地方。共7格。"

缝隙自己滑开了。

灰白色的光从里面流出来，安静得像整一层时间都被黏在了这儿。屋内并排嵌着7只银匣，6只有光，1只沉在暗里。最暗那只的匣沿，铸着一行小字：创世者的第七位。

第一只银匣弹开的瞬间，整间档案室都被火光染红了。

【编号001·林渊。残影7秒。】

燃烧的规则之海。黑色火浪一叠压着一叠，浪尖上全是正在熄灭的字。林渊站在海面上，腰间只剩半截断刀，断口烧得发红，他还握得很稳。他回头，对着看不见的方向笑了一下，笑得像终于放下了什么拿了多年的东西，眉梢是松的。然后整片海倒卷着退下去，一退到底，退得干干净净——他把火海整个劈进了自己脚下，换身后那个世界一分清净。

【编号002·楚瑶。残影19秒。】

第二只匣子里下着雪。楚瑶蹲在一群NPC中间，牵着一只冰凉的小手，指尖在地上一笔一画地写。写的是极寻常的字：一个名字。她写一个字，停一停，等身后的人跟着念一遍；写到最后一个笔画，地上的字忽然亮起来，浮到半空，又烙进每个旁观者的小臂。从今往后，NPC也能把自己的名字写进这个世界了。那群NPC起初只是看着，后来有个小姑娘试着也蜷起手指，在她写过的字上一笔一划地描。楚瑶没有拦，反把自己那只手又摊开些，把最宽的笔画让给她。雪落在她发间，她没有掸。她抬头，笑出一口白牙，把那只小手放进自己掌心，握稳了，才松开。

【编号003·周铮。残影4秒。】

第三只匣子的画面剧烈晃动，像有人扛着一台坏掉的记录仪在跑。门槛。半截刀鞘撞在门槛上，碎成两片。周铮背对镜头，用肩膀抵住一扇正在往里塌的门，门后有什么东西一下一下撞过来，每撞一下，他就往下矮一截。门缝里挤着半只手，正拼命往外推。有人喊他的名字，他只低低应了一声，像哄，也像道别。他始终没有回头，只有一声压得极低的叹息。画面碎在那里，只有4秒。

第四只匣子里没有画面。

【编号004·沈墨。残影：无。】

匣底躺着一只停了的老怀表，表壳的划痕磨得发亮，像揣着它的人摸过千百回。表盖内侧刻着一行小字：规则要是没人看管，会自己长出牙来。指针停在0点整。后来陆寻在创世记录里查到，那恰好是沈墨按下确认键、把自己编进世界的那一秒。

004是最特殊的一位。他是创世者本人，也是唯一一个没有给自己留下任何残影的人——沈墨把所有人的结局都录进了这套编号，唯独漏了自己。005怕规则反噬，003怕自己退半步，而004怕的，是这座世界里再没有一个人愿意替它守着看。从那一秒起，他就把自己整个活成了世界的一部分，只剩下这只停了的表，供后来的人认领。

【编号005·佚名。残影10分钟。】

第五只匣子的影像最长，内容却最单调。白墙，一张桌，一支不见底的笔。佚名一直在写。从写满一页纸，写到纸上再没有空白，她便悬着手在空气里一笔一画地填，一个字都不肯漏。她写的不是规则——她在把规则的每一道缝隙都填满，写到没有缝，就没有什么东西能再钻出来。到后来，她开始写自己：姓名、记忆、害怕的事、喜欢的人。她想趁还认得出自己的时候，把这一身空白全占满，一分都不留给反噬。

她开头说的其实不是那一句。最初的两三句是完整的，语气也温和：别怕，规则会吃人，是因为总有人把缝留得太宽。再往后，句子就开始卷了。第十遍她还是叮嘱，第一百遍时，就只剩那五个字横在画面中央，横了整整400多遍，像要把最后一点清醒反复磨亮：

"不要完全相信规则。"

最后一帧，才冒出半句没写完的："如果你听到这些，说明我已经……"

苏清然忽然说："画面最后半段，角度不对。"

"嗯？"

"005的残影里，还压着第二道视角。"苏清然指尖把那道虚影放大到片尾，"观测台上，一直有个人在看。她在崩解成光之前，那人转身就走了，从头到尾，没有伸手。"

"他看得最清，退得也最远。"陆寻看着虚影消失的方向，"见过神的下场，又没有伸手拦住的人，心里多半已经拿定了一个主意。这样的人，最先被记住，也最难被劝动。"

【编号006·叶霜。残影31秒。】

第六只匣子里只有一座碑。叶霜蹲在碑前，一下一下刻自己的名字，刻得很慢，像怕白费一个笔画。刻完，她直起身，腕上绷着一根断在半空的光线，像一句话只说到一半。她回头，隔着不知多少年的光阴，朝看的人轻轻笑了一下，像在说：认路的人，跟着罢。

碑没有立在必经之路上，它立在任何人都能绕过去的地方，像是只给想停下来的人看的。

六段残影放尽，档案室里静了很久，久到能听见灰落下来的声音。

【提示：检测到残留权限印记。来源：特例单位记忆索引，共6份。】

【警告：印记处于休眠状态，请勿尝试激活或追溯。】

苏清然把光晕逐格收拢，声音放轻了些："特例单位，拥有规则豁免与改写资格的候选者。沈墨建这套编号的时候，001到006，每一个都是他的尝试——他想找一种存在：既能理解规则，又不被规则同化。"

"001把规则劈开了。"陆寻说，"002把笔递给了别人。003把自己钉在门口。005想把规则写绝，写到没有缝，结果自己先漏成了光。"

"可细看，她们都在替没人记住的东西留坐标。"苏清然垂着眼，"002把名字还给NPC，006把自己的名字刻给世界，001劈的、003挡的，也都是别人来时的路。这大概就是沈墨选人的标准——各人各认一条，谁也替不了谁。"

"那004呢。"

"004就是沈墨。"陆寻说，"他希望有人能管住规则，又知道自己管不住自己的怕，最后连自己也写了进去。他活成了规则，是想让后来的人，不必再成为规则。"

"可005，她最后不还是成了。"苏清然的目光落回第五只匣子上，声音压得极低，"她把全部的自己填进规则的缝隙，最后只剩下那400多遍重复，和半句没说完的。"

"成了，但没成完。"陆寻说，"她把不肯信的，和没能信的，都留在了这套编号里。也在等一个能听懂的人来领。"

档案层里那片极淡的光，一圈一圈暗下去。

就在这时，那只停了不知多少年的怀表，咔地，响了一声。

指针从0点整，往前爬了一格。

苏清然屏住呼吸："它在走。"

"在倒数。"陆寻说。

他走到第七只空匣前面。匣子是空的，匣沿的灰尘却被人从正中间擦开一道新鲜的划痕——他们不是头一批来这里的人。暗红的地面上，拖过半截表链的痕迹，和4号匣底那只老怀表的链痕，一模一样。

苏清然蹲下去，指尖描过那道划痕，又点开匣侧的状态栏。

编号：未交付。资格：已激活。最近访问：3个月前。

访问记录指向的方向，隔着很长一段路，是天穹。

"3个月前……正好是天穹第一次往深层派探路队的日子。"苏清然的声音低下去。

"第七位还活着。"她说。

"而且已经醒了。"陆寻说，"他来看过这6个人的结局，看完就走了。"

"他也会是特例单位。"

"会。"陆寻低头，看着那只又咔地响了一声的怀表，"但他见过005的下场，见过004的归零。他还在往前走，说明他要的不止是一个名号。"

怀表又咔了一格，像一个很老的人，站在0点的钟下，数着下一格。

七只匣子里，六只有光，一只空着。空的那只压在尽头，正等着某个人，亲手把他的名字放进去。

"你说，等他真把自己的名字放进去那天，会是改写世界，还是吞掉世界。"苏清然问。

陆寻没有立刻回答。他看了那只空匣很久，久到连匣沿的灰都重新落定了，才说：

"那要看我们给不给他，非写不可的理由。"

他把怀表放回4号匣底，表链垂落，在灰上拖出新的痕迹，细细的，和新旧两道表链印，渐渐并成同一格。

门在他们身后合拢。档案层的冷光收成一线，7只匣子一起沉进暗里。

第七位还没来。

但陆寻已经知道，朝着他来的那个人，腰边或者口袋里，一定也揣着一只和创世者一模一样的怀表。

他抬手把7号匣的盖子轻轻合拢，落下一层薄灰。

"名字不是刻上去的。"他说，"是他自己，走进去的。"
