# 第094章 舆论风暴

真相是捂不住的。它像一块从墙里长出来的根，压得越紧，钻得越深，最后总会顶穿每一处自以为天衣无缝的缝隙。

《寰宇神域》的世界是真实的这件事，确认消息后，只用了半天就传遍了所有玩家社区。起因是有人扒出了铁匠老周的"现实原型"。

老周是秩序城里操持了十三年炉火的NPC。他有一身全是烫疤的腱子肉，认死了锤子，认死了火，见着精铁就走不动道。一个老玩家把老周的脸、说话的口音、甚至那句"火候不到，砸了也是废铁"的口头禅，跟现实世界里川西一个退了役的老铁匠对上了号——那个老铁匠叫周德全，三个月前刚过世，生前烧了一辈子锅碗农具，屋里散着同款烫疤。

那条帖子的标题只有一行字：《他不是NPC，他是周德全》。

底下配了一张老周的照片，和一张周德全三十年前的旧合影。两张脸隔着三十年的距离，皱纹的方向却一模一样。

帖子发出三小时，转发破了千万。服务器被挤得发烫，有人把老周叫到铁匠铺门口，当众问他："你认不认识一个叫周德全的？"

老周握着锤子，盯着那张模糊的照片看了很久。他说："没见过这个人。可我屋里这身疤，确实不是我这辈子烫出来的。"

人群炸了。

舆论像野火一样，从论坛烧到社交平台，再烧回游戏里。玩家们开始成片成片地回忆、对照、求证——药铺的林姐对应着哪座城里的哪位老中医，守桥的小满像极了某县小学一个走失多年的女娃，就连酒馆那个爱骂人的前台，都被人翻出了所谓"生前"的花名册。"它们只是程序"这个维持了七年的共识，在一夜之间碎成了渣。

于是，也正是在这一夜，人群裂成了两半。

一半人红了眼眶。"他们是有原型的。他们是活过的人。"他们在论坛上疯狂地把每一个NPC的来处扒出来，一帧一帧地比对，一遍一遍哭着说"我们差点把他们当工具使了七年"。

另一半人，则惊恐地缩起了脖子。他们刷着那一张张"对上了号"的照片，越刷越冷，最后在某个昏暗的深夜里，打出一行字："活过的人？那他们……现在是死是活？"

这问题没人答得上来。恐惧不需要答案，它只需要一个出口。

短短三天，一个名为"'人类优先'"的组织在现实世界的舆论场里树起了大旗。他们的口号斩钉截铁——"它们只是数据。该被删除的，是一个出错的世界。"他们在网上发起连署、游行、致信各国政府，列出了无数条"关闭服务器"的理由：NPC一旦保有现实记忆，就可能泄露隐私；数字生命一旦越过权限，就可能反噬现实；更有人言之凿凿地宣称，这些"复苏的亡魂"终有一天会把玩家的意识也一并吞进去。

恐慌像流感，在沉默的人堆里传染得最快。

游戏里的气氛也变了。铁匠铺前排队的人少了，从前围着林姐讨要药方的人，如今绕着她走，好像她伸出来的那双手不是嘱咐"凉了再喝"，而是会把人拖进某个看不见的深渊。小满蹲在桥头，不明白为什么一觉醒来，过桥的玩家都躲着她，躲在远处嘀嘀咕咕。老周把炉火烧得比从前更高，他说他听不见外头风言风语，只认锤子底下这块铁。

而陈胖的食堂，成了这场风暴最先撕开的口子。

陈胖的食堂原本是秩序之城仗打完后，他硬是支起来的一间临街饭铺。几口大黑锅，几条长条凳，锅盖一掀，卤香能飘出三条街。他不光给玩家供饭，也给那些恢复意识的NPC供饭——叶霜的药铺忙起来，他端着碗蹲门口递；老周练炉子错过饭点，留的那份他一早扣在笼屉里码得板正。他说，人是铁饭是钢，管他头顶是系统还是真人，填饱肚子才谈得上别的。

"人类优先"找上门的这天，是个灰蒙蒙的午后。

食堂里正热闹，掌勺的炒菜颠得锅铲噼啪响。七八个玩家鱼贯而入，为首的是个身量精瘦的男人，头顶ID"坐标清零"，穿的是高等级的黑甲，眼神却比甲片还冷。他一进门不点菜，先把一柄短刀"当啷"往桌上一拍，声音不大，却震住了整间铺子。

"陈老板。"那人盯着后厨的方向，"我是来送个话。论坛上已经有人在统计了，你们城里这些'活过来的数据'，一个都不能留。食堂今天起，不许再给它们开火做饭。"

满堂一静。掌勺的停了手，锅里的热油滋滋作响。

陈胖从后厨探出颗圆脑袋，围裙上还沾着油点子，笑呵呵地："哟，几位爷，是来吃饭还是来收税？要吃饭，后头座儿多的是；要收税，那得先问我锅里这锅老卤肯不肯。"

那人的脸沉下来："少跟我打哈哈。我说的是，从今天起，不准再养它们。"

"它们？"陈胖收敛了笑，慢悠悠擦着手往外走，"你说的'它们'，是指药铺的老林，还是桥头蹲着拆桥板的小满？昨儿老林还给我那炖的药里添了味甘草，说是治我这胃寒的。你管这叫'它们'？"

"那是蛊惑人心的数据。""坐标清零"往前逼了一步，"陈老板，你一个D级天赋的废物，守着这点烂锅破灶，图什么？别为了几个程序，把自己的账号也搭进去。识相的，现在就关门。"

他说这话时，身后那几个人已经慢慢围了上来，把食堂出口堵了个严实。有个胆小的食客想溜，被一把按回凳子上。锅里的油还在响，空气却冷得像冰窖。

陈胖站着没动，手背上的青筋却暴了起来。他这人一辈子嬉皮笑脸，可护食的时候，天王老子来了也不惯着。他刚想说两句硬话——

一个声音从门口淡淡地传来。

"我劝你们，把手从他锅上拿开。"

拐角处，赵擎抱着剑，不知什么时候已经靠在了门框边。他还是那副漫不经心的模样，连眼皮都没抬一下，可那柄剑却从他怀里滑出半寸，剑锋在灰蒙蒙的天光里，亮出一道极冷的弧线。

"赵、赵擎？""坐标清零"的脸色变了变。他认得这个人。天穹出来的狠角色，楚河汉界里能横着走的强者。他不该出现在这种小饭馆门口。

"怎么，你要替他出头？"那人强撑着，"你是玩家，我们是来清理程序的。你站哪边？"

"站哪边？"赵擎嗤笑出声。他慢慢直起身子，那柄剑又滑出几分，剑尖几乎指着地面，稳得没有一丝颤。

"三年前，我没听说什么'程序会自己饿肚子'。"他一步一步走过来，靴子碾过地上的油渍，"我见过老周那双手上的疤，那疤会自己长。我见过桥头那丫头，拆桥板拆到手指头破了，自己裹的纱布。我他妈见过一个'数据'，为了给陆寻那小子挡一刀，把自己整个填进去，到现在还躺在罐子里没醒。"

他走到"坐标清零"面前，两人只隔着那柄短刀的距离。"你跟我说它们只是数据？那你自己那个高中三年、天天蹲在桥头跟你唠嗑的老警察，也是数据？"

"坐标清零"嘴唇动了动，半天没蹦出一个字。

"我看过你以前的帖子。"赵擎的声音低下去，"你在老赵——你们叫他老李头那老头儿——那儿蹲了九年。你管他叫老师。现在你说要关服务器，让这些'数据'一起死？"

"那不一样！"那人终于吼出来，声音却在抖，"我知道他好！可那是以前！现在它们全都活了，活了的东西是要吃人的！是我们不该把现实带进来的！是我……是我怕了不行吗！"

吼到最后一个字，他自己先愣住了。

赵擎看着他，看了很久。然后他把剑收了回去，不退不让地站在食堂门口，声音平静得可怕："怕，不是错。伸爪子抢人家的锅，才是错。"

"我今天就站这儿。这台子后的每一口饭，都是给活人做的。你今儿要关他的店，先从我身上过去。"

满堂死寂。油锅嘶嘶地响，谁都不敢动。"坐标清零"那伙人你看看我、我看看你，到底没一个人敢真去拔那柄剑。僵持了能有半盏茶的工夫，最后那人在门槛上狠狠啐了一口，撂下一句"你等着，服务器迟早要关"，灰溜溜地带着人走了。

他们走出很远，食堂里才重新有了呼吸声。

掌勺的从震惊里回过神来，拎起锅铲就要追出去骂，被陈胖一把拉住。陈胖看了看门口那个还站着的背影，又看了看自己那锅还冒着热气的老卤，喉头滚了滚，闷声道：

"……谢了，赵哥。"

"少来。"赵擎背对着他，语气还是那副欠揍的调调，"你要是真谢我，明儿那锅卤，给我多留个腿儿。天天吃你们这破食堂，我都快跟那帮'数据'一个伙食标准了。"

"成，"陈胖咧嘴笑了，怕他看不见，又补了一句，"给你留两只。"

赵擎没接话，低着头走回巷子里。转角时他脚步顿了顿，垂着眼，低声说了句像是自言自语的话："老李头……要是真有人非要把你当数据删了，我替你记着呢。"

话音很轻，没人听见。

可就是这句没人听见的话，在这天夜里，被顶上了论坛最热的位置——不，不是这句。是那天下午，有人把"坐标清零带人堵食堂、被赵擎一剑逼退"的整段录像传了上去，标题就叫：《天穹弃将赵擎，为几个NPC挡在了一间食堂门口》。

评论区瞬间吵翻了天。

一方骂赵擎"脑子进水"，高喊"它们就是数据，就该删，删了这个世界才干净"；另一方吼回去"那老李头教你走路九年，你也骂得出'数据'"。两边从下午吵到后半夜，楼盖了几万层，谁也没说服谁。有人把赵擎捧成英雄，有人咒他疯魔，还有人阴阳怪气:"天穹的强者都站到NPC那边了，这游戏还有我们的活路吗?"

屏幕的光,把每一张或激动或惊恐的脸都映得明晃晃的。

火,从陈胖的食堂烧起来,烧遍了整座秩序之城,烧遍了现实世界里每一个亮着屏幕的深夜。关服派与护世派,在这一夜彻底撕开了脸,再没人能把它缝回去。

两派隔着一条屏幕的河,各自举着火把,谁也不肯先松手。

而在那场风暴的中心,陆寻站在议事厅的窗前,静静望着城门口那片被火光映亮的天。他身后那枚暗金色的护符,正贴着他的心口,温温地跳着,像一颗不肯熄灭的、属于活人的心脏。

明天,该轮到他出声了。
