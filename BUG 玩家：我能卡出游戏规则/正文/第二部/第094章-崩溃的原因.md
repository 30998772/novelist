# 第094章 崩溃的原因

崩溃的原因

陆寻接受了使命，但他需要更多的信息。

"【衡】。"他说，"告诉我，为什么规则网络会崩溃？"

"因为沈墨离开后，这个世界失去了核心。"【衡】说，"规则网络需要一个核心来维持运转，而沈墨就是那个核心。当核心消失后，规则网络就开始退化。就像一颗心脏停止跳动后，身体的各个器官就会逐渐衰竭。"

"那为什么NPC的觉醒会导致崩溃？"苏清然问。

"NPC的觉醒不是崩溃的原因，而是症状。"【衡】说，"规则网络退化，导致NPC开始产生自主意识。他们觉醒了，但同时也加速了规则网络的退化。"

陆寻皱眉："为什么？"

"因为NPC的觉醒打破了原有的平衡。"【衡】说，"NPC原本是规则网络的一部分，是被动的数据流。但当他们产生自主意识后，他们就开始脱离规则网络的控制。他们不再是被动的数据，而是主动的生命。这导致规则网络的稳定性下降——就像一条河流突然失去了河床的约束，开始四处泛滥。"

"所以……NPC的觉醒是双刃剑？"陈胖问。

"是的。"【衡】说，"NPC觉醒让他们获得了真正的生命，但同时也加速了世界的崩溃。"

房间里陷入了沉默。

"那我们该怎么办？"苏清然问，"如果NPC继续觉醒，世界就会崩溃。但如果阻止他们觉醒，他们就无法成为真正的生命。"

"这就是为什么需要陆寻。"【衡】说，"陆寻可以修复规则网络，让NPC在保持自主意识的同时，重新融入规则网络。创造一种新的平衡——NPC既拥有自主意识，又与规则网络和谐共存。"

"怎么做？"陆寻问。

"用创世之笔，重新编写规则。"【衡】说，"你需要创造一种新的规则，让NPC既能保持自主意识，又能与规则网络共存。这是一项前所未有的工作——沈墨当初也没有做到。"

陆寻沉默了。

这听起来很简单，但实际上……这几乎是不可能的任务。

规则是这个世界的基础，任何错误的修改都可能导致世界崩溃。一个错误的符号，一条错误的代码，都可能引发连锁反应，导致整个规则网络的崩塌。

"但你必须尝试。"【衡】说，"因为你是唯一的希望。"

陆寻点了点头。

"好。"他说，"我这就开始。"
