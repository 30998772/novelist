# 第078章 创世者工坊的秘密

战争的第十二天，陆寻收到了一条神秘的消息。

那条消息没有经过任何通讯系统，直接出现在他的意识中，就好像有人在他的脑海里写下了一行字。

陆寻警觉地睁开眼。能绕过所有通讯频道、直接把信息写进他意识里的存在，他只想到一个。可这一次，消息的格式又是标准的系统提示，字正腔圆，不似【衡】惯于玩弄措辞的风格。

【系统提示：检测到隐藏区域解锁。创世者工坊已开放。坐标已标记至您的地图。】

"创世者工坊。"陆寻皱眉。

【创世者工坊：沈墨在创建这个世界时使用的工作室。其中包含修改世界基础规则的工具。警告：该区域危险等级为SSS，建议谨慎进入。】

"沈墨。"陆寻默念着这个名字。第四位传承者，也是把"织律者"三个字刻进规则里的那个人。关于他的记录极少，少到陆寻一度怀疑这个名字本身就是个代号。

陆寻的眼睛亮了起来。

修改世界基础规则的工具：如果能得到它，或许就能彻底结束这场战争。不靠战斗，不靠牺牲，靠修改规则本身。他闭上眼，把那条消息在意识深处又过了一遍，确认不是幻觉——坐标、权限、警告，一个字一个字的，像是有人专门留给他看的一把钥匙。窗外的风灌进来，吹得桌上那张战报纸角直掀。

"苏清然，陈胖。"他召集了核心成员，"我要去一个地方。"

"去哪儿。"陈胖问。他的黑眼圈比之前更重了，显然已经好几天没有睡好觉了。

"创世者工坊。"陆寻说，"沈墨的工作室。"

苏清然皱眉："现在就走。战争还没结束，天穹公会随时可能发动新一轮的进攻。"

"正因为战争还没结束，我才要去。"陆寻说，"只有得到创世者工坊的力量，才能真正结束这一切。靠战斗，靠牺牲，永远无法真正结束战争。"

苏清然盯着他看了几秒，忽然道："如果工坊里有结束战争的办法，为什么沈墨自己不用。"

这个问题让帐篷里安静了一瞬。

"所以我要亲自去看看答案。"陆寻说。

陈胖犹豫了一下："但是陆寻，这边的战斗怎么办。我们群龙无首的话。"

"你来。"陆寻说，"我相信你。"

陈胖愣住了："我。"

"你是我见过最聪明的战术家。"陆寻说，"你对数据的敏感度，对战局的判断力，比任何人都强。这场战斗交给你，我放心。"

陈胖的眼眶微微泛红，但他很快掩饰了过去。他深吸一口气，挺直了腰板。

陆寻难得地多说了几句："真空锚点还剩七个能用，B线的伤兵不要排第一班。还有，要是天穹放终焉之火，就把人撤进三号区，别心疼工事。"

"知道了知道了，你什么时候变得这么啰嗦。"陈胖摆摆手，声音却有些发哽。

"好。"他说，"我会守住的。"

陆寻点了点头，然后看向苏清然："你跟我一起去。"

苏清然点头："好。"

两人消失在了夜色中。

创世者工坊位于游戏世界的最深处，一个从未被玩家发现的隐藏区域。它藏在数字之海的最底层，被无数的防火墙和数据加密保护着，像一枚沉在最深海底、几百年没人碰过的锈锚。

路上并不太平。第三层防火墙是一道活体规则墙，会主动撕咬一切靠近的数据，锋利的丝线贴着他们的衣角擦过去，留下一条条焦黑的印子；第五层是记忆迷宫，闯入者会看见自己最不愿回想的画面。陆寻靠规则偏移硬生生卡掉两道关卡，苏清然则用规则同化安抚那些躁动的防火墙程序，像驯服一群恶犬——指尖贴着丝线一寸一寸顺过去，直到那些发烫的敌意一圈一圈地软下来。

记忆迷宫里，陆寻看见的是新手村的那条泥路。雨夜，昏黄的路灯，一个卖药水的NPC朝他用力挥手。画面只持续了一瞬，就被他亲手掐灭了。撕开幻象的时候，他的指尖不易察觉地抖了一下。

苏清然什么都没问，只是走过来，与他并肩。

最后一段路，两人是踩着一段废弃的旧版本地形走过的。脚下的山川还是许多年前的样子，边缘处不断剥落成光屑，坠入无尽的黑暗深处。

陆寻和苏清然穿过重重障碍，终于来到了工坊的入口。

那是一扇巨大的金属门，高约十米，宽约五米，上面刻满了复杂的符文。那些符文在黑暗中散发着微弱的光芒，明暗交替，一起一伏，像一扇门在均匀地呼吸。锈迹从门轴一路爬到门心，又在符文的纹路边缘干裂卷起——这扇门，不知道在这片黑暗里站了多少年。

"这些符文，"苏清然伸手触碰，指尖刚沾上，那圈符文就像受了惊，齐齐亮了一下，"是规则的具现化。每一条符文都代表着一条规则：重力、时间、空间、生命、死亡，它们交织在一起，形成了这扇门。门上的锈和灰，是年月替它们盖的被子。"

"门在筛选来访者。"她收回手，"它刚才读了我的权限。"

"结果。"

"我们被允许进入。"她顿了顿，"但门说，上一位访客，已经是很多年前了。"

"能打开吗。"陆寻问。

"能。"苏清然闭上眼睛，规则同化的力量在她体内涌动。

她伸出手，轻轻触碰金属门。

嗡。

金属门上的符文开始发光，然后缓缓打开。门轴发出沉重的摩擦声，听声音就知道，这扇门已经很久没有开过了。

一股沉寂了不知多少年的空气从门缝里涌出来，带着金属与旧纸张混合的味道。

门后，是一个巨大的空间。

无数的机器、屏幕、工具整齐地排列着，像一座沉睡的实验室。空气中的尘埃被那道门推开的光惊起，在光柱里缓缓浮沉。空气中弥漫着一股古老的气息，那是时间的味道，是历史的味道，混着金属、机油和干涸墨水的旧气。

苏清然的脚步声在这里格外清晰，一步一声，都被空旷的空间接住、放大。她走过一排排沉默的机器，那些蒙尘的屏幕依次亮起微光，像沉睡的哨兵认出了来人，一盏接一盏地睁眼，却没有一个惊动这片沉寂。

工坊深处有一张积灰的工作台，上面摆着半杯早已凝固的茶、几页写满涂改痕迹的草稿纸，还有一枚磨得发亮的六面骰子。椅背上还搭着一件外套，落满了灰，轮廓却依然挺括，像是主人只是起身去倒个水，随时还会回来。草稿纸上的字迹潦草而用力，有几处甚至划破了纸背，笔尖把整张纸都戳得坑坑洼洼，能想见那个人写这些字的时候，眉头拧得有多紧。

苏清然拿起其中一页，轻声念出上面的一行小字："规则应当公平，否则宁可不写。"

落款处只有一个编号：004。

"六面骰。"她把那枚骰子托在掌心。六个面上各刻着一个编号，001到006，唯独没有007。

"传承者的名录。"陆寻的声音压得很低。

骰子底部的棱上还刻着一行极小的字：掷出我的人，已经不在场了。

在这时【衡】开口："沈墨离开之前，把工坊的权限拆成了三份。一份交给了那扇门，一份封进了这支骰子。至于第三份。"

它停住了。

"在哪里。"

"如果我能说，你们就不会是第一批活着走进来的访客了。"

"这就是创世者工坊。"陆寻走进去，四处张望。

他的目光被一个巨大的屏幕吸引。

屏幕从地面一直立到屋顶，上面滚动着无数的数据和代码，那是这个世界的底层结构。那些字迹密密麻麻，像一整片倒悬的星河，光看久了都会晕。陆寻从未见过如此复杂的数据。每一条代码都是一条河流，无数条河流汇聚在一起，形成了这个世界，而这片星河，此刻正对着他一个人静静地淌。

有几条河流明显在"发烧"：战争留下的规则创口还没有愈合，代码在那里打着旋，泛起一圈圈浑浊的浪，发出细密的杂音。陆寻甚至不用靠近，光凭意识就能定位到每一处伤口对应的现实坐标——那一处的光亮，是和别处不一样的、泛着焦黑的暗红。

"这是，"陆寻瞪大了眼睛。

"世界的源代码。"苏清然走到他身边，"沈墨就是用这些代码，创造了整个寰宇神域。重力、时间、空间、生命、死亡，所有的规则，都在这里。"

陆寻盯着屏幕，眼中闪烁着复杂的光芒。

他下意识地想用规则偏移去碰其中一条支流，指尖刚起势就被苏清然按住了手腕。

"在这里，每一次试探都是真刀真枪。"她摇头。

"如果能修改这些代码，"他低声说，"就能改变这个世界的规则。"

"但是你必须小心。"苏清然说，"任何错误的修改，都可能导致世界崩溃。这个世界是精密的，每一条规则都相互关联，牵一发而动全身。"

陆寻点了点头。

他开始在工坊中搜索，寻找可以修改世界的工具。

最终，他在一个角落里发现了一个古老的装置。

那是一个巨大的机器，高约三米，整体形状是一枚巨大的笔尖。机器的表面布满了锈迹和划痕，但它的核心部分却散发着微弱的光芒。那是创世之光，是创造世界的力量。

"创世之笔。"苏清然的声音放得很轻，像怕惊着什么，"传说中，沈墨就是用这支笔，创造了这个世界。它不是普通的工具，是创造规则的工具。"她顿了顿，"握住它的人，握住的就不再是一支笔，是整个世界的笔山墨海。"

陆寻伸出手，握住了那支笔。

笔身冰凉，重得超出预期，比他想象中沉了不知多少倍，总之悬着一整片大陆的重量。那一瞬间他握住的不只是工具，更是一段沉甸甸的历史——指尖触到笔杆上那些细密的划痕，像是无数双手曾在这里短暂停留，又一一松开。

一股强大的力量涌入他的体内。那是创世的力量，是改变规则的力量。他的脑海中瞬间涌入了无数的信息，每一条规则的结构，每一个节点的位置，每一条代码的含义。



【衡】的声音头一回带上了一丝近似于紧张的东西："放下它，或者做好觉悟。这支笔每写下一个字，都要以世界的基础架构为墨。你们脚下这个世界，经不起几次挥霍。"

陆寻的手没有松开。

"我感觉到了。"陆寻说，"我能感觉到这个世界的每一条规则，每一个节点。它们交织成一张巨大的网，形成了这个世界。"

"还有你的精神负荷。"苏清然说，"已经接近极限了。要是现在动笔。"

"我知道。"陆寻打断她，"但是我没有选择。"

苏清然看着他，忽然想起白慕鸿转述过的一句话：这个人从不解释自己，但他的每一步都踩在自己说过的话上。

她没有再劝。她只是走到他身侧半步的位置站定。从今往后，他写下的每一个字，都有她来守。

他闭上眼睛，握紧创世之笔。笔尖悬在半空，映出他眼底跳动的光。

"这场战争，必须由我来结束。"
