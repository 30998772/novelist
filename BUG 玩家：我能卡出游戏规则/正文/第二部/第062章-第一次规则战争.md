# 第062章 第一次规则战争

第一次规则战争

灾难发生在三天后。

深层边缘的一片区域突然爆发了大规模的"规则风暴"——表层规则和深层规则同时失控，形成了一个巨大的混乱区域。

风暴的范围覆盖了数十个地图，数百名玩家和NPC被困其中。

风暴所过之处，地形被撕成流动的数据碎片，天空像坏掉的屏幕一样闪烁。连时间都变得忽快忽慢，有人在频道里喊了一句什么，声音拖长了三秒才落进耳朵。被困的玩家发出最后的位置信号，然后成片成片地失联。

【警报：深层第4-19区检测到规则风暴】

【警报：风暴等级持续上升，当前评级：灾难级】

【请所有深层玩家立即撤离】

消息传回表层，整个服务器都慌了。

主城的传送阵前排起了长队，全是等待消息的玩家和NPC。有人举着自制的牌子，上面写着"救救我哥哥"；有NPC抱着孩子站在角落里，一动不动地盯着公告板。队伍里没有人喧哗，只有偶尔响起的、压抑的啜泣。

「风暴中心好像是天穹的地盘？」

「天穹最近在深层搞什么秘密工程，该不会是他们搞出来的吧」

「别乱说，没有证据」

「可我表弟就在17区，到现在联系不上！」

「祈祷吧。听说连系统救援都进不去」

"这怎么办？谁去救人？"

"玩家的救援队根本进不去，规则风暴太强了！"

"NPC呢？他们不是对规则更敏感吗？"

"NPC的秩序之城也受到了影响，他们自顾不暇！"

"陆寻呢？他不是维护者吗？这种事他不管？"

陆寻当然在管。

但他现在面临一个两难的选择——

如果他用规则偏移暂停规则风暴，可以暂时稳定局面，但无法根除问题。风暴会在暂停结束后重新爆发，而且会更加剧烈。

如果他用规则修改来调整规则参数，可以让风暴平息，但需要消耗大量精神力。以他现在的能力，最多只能处理一个区域的风暴。

但风暴有数十个区域。

更糟的是，每拖延一分钟，被困者的数据流失就多一分，救援窗口正以肉眼可见的速度关闭。

秩序之城那边传来的消息同样糟糕：风暴撕开了城市外围的三道屏障，烬不得不把一半的青壮调去修补城墙。NPC的自救和玩家的自救，在同一场灾难里撞了个满怀。

陈胖抓着通讯器嘶吼着协调各支救援队的方位，嗓子已经哑了。

"苏清然。"陆寻看向身边的搭档，"你能预测风暴的走向吗？"

苏清然闭上眼睛，全力运转天赋："可以。风暴的核心在……那里。"她指向深渊深处的一个方向，"如果能摧毁核心，整个风暴就会瓦解。"

"核心在哪里？"

"在……天穹的秘密基地附近。"

陆寻的瞳孔猛地收缩。天穹的基地？

难道这场风暴……是人为的？

"走。"陆寻没有犹豫，"去核心区域。"

通往核心区域的路，是从风暴的缝隙里硬蹚出来的。

苏清然在前方可视化开路，金色的视野里，每一次风暴的喘息都提前三秒显现；陆寻跟在她身后半步，用规则偏移在致命的间隙里撕开一条条仅容一人通过的通道。

途中，他们从崩塌的哨卡下拖出了四名被困玩家、两名NPC向导。其中一个NPC向导怀里还死死护着队伍的名单。

"往回走，跟着铜哨的频率走。"陆寻把向导的铜哨塞回他手里，"别停。"

那名NPC向导重重点头，搀起同伴，一步一步退出了风暴的边界。

当他们赶到风暴核心时，眼前的景象让每个人都被惊得呆立当场——

天穹的基地已经被规则风暴彻底摧毁。而在废墟的中央，秦烈正站在一个巨大的装置前，脸上带着疯狂的笑容。

"陆寻！"秦烈看到他，大笑起来，"你来得正好！看看我的杰作！"

"你做了什么？"陆寻的声音冰冷。

"我释放了规则能量。"秦烈的眼中闪烁着疯狂的光芒，"深层的原始规则能量！我把它们全部释放出来了！"

"你疯了！"苏清然喊道，"这种能量会毁灭一切！"

"毁灭？"秦烈笑了，"不，这是重生！旧的规则会被摧毁，新的规则会诞生！而我……将成为新世界的神！"

陆寻明白了。秦烈抽取了大量规则能量，然后故意释放出来，制造了这场规则风暴。他的目的是摧毁现有的规则体系，然后用规则核重新编写世界。

而他自己，则成为新世界的"创世者"。

废墟四周，横七竖八倒着不少NPC和玩家的身影——都是被抽干能量后丢弃的躯壳。基地原本的守卫一个都不见了，只有那台巨大的抽取装置还在轰鸣，像一头不知疲倦的怪物。

"秦烈。"陆寻一字一顿，"这些人呢？"

"什么人？"秦烈环顾四周，像是才注意到那些倒下的身影，随即嗤笑，"哦，他们啊。新时代不需要那么多人口，总要有人做出牺牲。"

苏清然蹲下身，探了探一名倒下NPC的鼻息，抬起头时眼眶通红："还有气。他们都还有气。"

"那就还来得及。"陆寻说。

"你不会成功的。"陆寻说，"你没有编写规则的能力。"

"我不需要。"秦烈抬起手，露出掌心的一颗发光的球体——规则核，"我有这个！规则核里储存着足够的能量，只要用它来重写规则——"

"那不是重写。"陆寻打断他，"那是毁灭。"

秦烈的笑容僵住了。

"规则核的能量是混乱的。"陆寻继续说，"用它来重写规则，只会创造一个更加混乱的世界。你不是在创造，你是在毁灭。"

秦烈的脸色变得阴沉："你懂什么？你只不过是个运气好的玩家而已！"

"我不懂？"秦烈的声音陡然拔高，"我在表层跪了三年！副本进不去，任务轮不到，连摆个摊都要被大公会收保护费！是谁定的这些规矩？是你们！是你们这些既得利益者！"

他的眼睛赤红："规则偏移、传承印记，凭什么都在你身上？我只是拿回本该属于我的东西！"

陆寻静静听完。

"所以你要让所有人为你的三年陪葬？"

秦烈没有回答。他只是笑着，一步步后退，退到那台装置的控制台前。

"陪葬？"他轻轻抚摸着控制台，像抚摸什么珍宝，"不，这是分娩的阵痛。"

"我懂规则。"陆寻向前走了一步，"而你，什么都不懂。"

秦烈的脸上闪过一丝愤怒，但随即变成了疯狂的笑意：

"就算你说得对又怎样？风暴已经开始了，没有人能阻止！"

他猛地将规则核抛向空中。核体爆裂，释放出更加恐怖的能量。整个风暴的规模瞬间扩大了数倍，仿佛要吞噬整个深层。

大地开始成片剥落，露出下面翻滚的原始数据海。远处，秩序之城的轮廓在混乱中若隐若现，城墙上那些由意志编织的光丝，正在一根一根地熄灭。

"撑住。"陆寻低声说。不知道是说给秩序之城听，还是说给自己听。

"陆寻！"苏清然喊道，"风暴失控了！"

陆寻看着眼前不断扩张的混乱区域，深吸一口气。

"规则偏移——修改！"

他的天赋全力发动，试图修改风暴的核心规则。无数参数在他的意识里奔流，那核心庞大得像一头狂暴的巨兽，精神力以惊人的速度流逝，鼻腔里涌上铁锈味，视野边缘开始发黑。

这是他离极限最近的一次。

快了。再给我三秒。

但就在他即将成功的瞬间——

另一股力量介入了。

一个模糊的身影出现在风暴中心，伸出一只手，轻轻一握——

整个风暴……静止了。

悬浮的碎石停在半空，翻涌的数据凝固成琥珀般的纹理，连声音都被冻结。那不是暂停，也不是修改。那只手握住的，是整片区域所有规则的"开关"。

在场每一个人都目瞪口呆。

秦烈的笑容彻底僵在脸上。他比谁都清楚这意味着什么——他赌上一切释放出来的力量，在这个人面前脆弱得像个笑话。

那个身影缓缓转过身，露出一张苍白而俊美的面孔。

"好久不见，陆寻。"

陆寻的瞳孔猛地收缩："你……是第七位？"

那人微微一笑："你可以叫我……霜华。"
