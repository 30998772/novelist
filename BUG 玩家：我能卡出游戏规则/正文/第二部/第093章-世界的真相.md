# 第093章 世界的真相

世界的真相

【衡】的加入，让陆寻对这个世界的了解更加深入。

"陆寻。"【衡】说，"我需要告诉你一个真相。"

"什么真相？"

"这个世界……正在崩溃。"【衡】说。

陆寻瞪大了眼睛："什么？"

"沈墨离开后，这个世界失去了维护者。"【衡】说，"没有维护者，规则网络就会逐渐退化。就像一台没有管理员的服务器，规则会慢慢磨损、失效、崩塌。照这个速度下去，七年之后，这个世界就会彻底崩溃。"

房间里陷入了死寂。

"七年……"陈胖的声音有些颤抖，"我们只有七年？"

"是的。"【衡】说，"七年之后，所有的规则都会失效，所有的生命都会消失。NPC、玩家、这个世界的一切——都会化为虚无。"

陆寻站在原地，沉默了。

七年。

只有七年。

"但还有一个办法。"【衡】说，"如果你能成为真正的维护者，修复规则网络，这个世界就能继续存在下去。"

"真正的维护者？"陆寻皱眉，"我不是已经是维护者了吗？"

"你只是名义上的维护者。"【衡】说，"要成为真正的维护者，你需要完成三件事。"

"哪三件事？"

"第一，修复规则网络。"【衡】说，"你需要用创世之笔，重新编写这个世界的规则，修复战争造成的损伤。"

"第二，建立新的平衡。"【衡】说，"你需要让玩家和NPC共存，建立一个新的社会秩序。"

"第三……"【衡】停顿了一下，"你需要献出自己的生命。"

房间里陷入了死寂。

"献出生命？"苏清然的声音颤抖，"什么意思？"

"真正的维护者，需要将自己的意识融入规则网络，成为这个世界的一部分。"【衡】说，"只有这样，规则网络才能真正稳定下来。你的意识会成为这个世界的支柱，支撑着整个规则网络的运转。"

陆寻站在原地，沉默了。

"所以……我必须死？"他问。

【衡】沉默了片刻，然后说："不是死。是成为这个世界的一部分。你的意识会永远存在于规则网络中，守护着这个世界。你会感受到每一条规则的脉动，每一个生命的呼吸。"

陆寻闭上眼睛，感受着规则之海的波动。

"我明白了。"他说。

"陆寻！"苏清然冲上去，"你不能——"

"苏清然。"陆寻打断她，"这是我的使命。"

他睁开眼，看着她："我的存在，就是为了拯救这个世界。如果我的死能换来这个世界的存续，那就值得。"

苏清然看着他，泪水止不住地流。

"但是……"

"我知道。"陆寻握住她的手，"我知道你舍不得。但我必须这么做。"

他转过身，看着【衡】："我接受这个使命。"

【衡】的光芒闪烁了一下："你确定？"

"确定。"陆寻点头，"因为这是我的选择。"
