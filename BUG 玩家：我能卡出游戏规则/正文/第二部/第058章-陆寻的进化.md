# 第058章 陆寻的进化

陆寻的进化

从第二层深渊回来之后，陆寻的变化是显而易见的。

最明显的是他的眼睛。以前，陆寻的眼睛是普通的黑色。但现在，他的瞳孔深处偶尔会闪过一丝银色的光芒——那是与原始规则建立连接的标志。

"你的眼睛……"苏清然有些担忧地看着他。

"我知道。"陆寻说，"这是代价的一部分。与规则对话会改变人的……本质。但我能控制。"

他没有说谎。回到表层之后，他确实能感觉到自己与普通人类之间的距离在拉大。他的思维方式变得更加"逻辑化"，情感波动变得更加微弱。有时候，他甚至能"看到"周围人的规则结构——他们的天赋、属性、状态，全都以规则的形式呈现在他眼前。

这种感觉很奇怪，但并不让他排斥。

因为与此同时，他的能力也获得了质的飞跃。

【规则偏移升级】

【新特性解锁：规则修改】

【描述：你现在可以暂时修改规则，而非仅仅暂停规则】

【修改范围：单条规则的参数调整】

【修改持续时间：最长10秒】

【冷却时间：24小时】

陆寻看着系统提示，眼中闪过一丝光芒。

从"暂停"到"修改"，这不仅仅是字面上的变化。以前，规则偏移只能在0.01秒的真空内暂停规则，让规则暂时失效。但现在，他可以直接修改规则的参数——改变规则的触发条件、影响范围、生效时间等等。

这意味着，他不再只是一个"防御者"，而是变成了一个"调制者"。

"让我试试。"陆寻看向陈胖，"陈胖，你的天赋是什么？"

"暴击强化啊，怎么了？"

"触发条件是什么？"

"每次攻击都有10%的几率触发双倍伤害。"

陆寻点了点头，然后伸出手，指向陈胖。

"规则偏移——修改！"

一瞬间，0.01秒的规则真空出现。在这极短的时间内，陆寻将自己的意志注入陈胖的天赋规则中——

【规则修改：暴击强化】

【原触发条件：10%几率】

【新触发条件：100%几率】

【修改持续时间：10秒】

【冷却时间：24小时】

"去打一下试试。"陆寻说。

陈胖一脸懵逼地拿起武器，对着旁边的石头砍了一刀——

轰！

石头瞬间碎裂，碎屑飞溅。

"我靠！"陈胖瞪大眼睛，"双倍伤害？我刚才刀刀都是暴击？"

"是的。"陆寻说，"我修改了你的天赋触发条件，让你在10秒内必定暴击。"

"这也太变态了吧？"陈胖兴奋地跳了起来，"老陆，你这天赋简直就是外挂啊！"

"不是外挂。"陆寻摇了摇头，"修改规则是有代价的。每修改一次，都会消耗我的精神力。如果频繁使用，我会……"

他没有说完，但所有人都明白他的意思。修改规则不是没有成本的，只是成本从"生命力"变成了"精神力"。

"够用了。"苏清然走上前，"在关键时刻，10秒的修改能力足以改变战局。"

陆寻点了点头。

他看向远方，目光深远。

从暂停到修改，这只是第一步。如果他继续进化，也许有一天能做到更多——比如，永久修改规则。或者，编写全新的规则。

但这些都是以后的事。

现在，他需要先解决眼前的问题。

"走吧。"陆寻转身，"回公会，有事要商量。"
