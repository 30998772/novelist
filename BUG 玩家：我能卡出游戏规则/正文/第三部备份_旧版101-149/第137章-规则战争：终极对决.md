# 第137章 规则战争

三天后，追捕"虚无"的行动正式开始。

这三天里，联盟表面上风平浪静：重建按部就班，巡逻照常轮值，论坛上的热闹也一如往常。只有极少数核心层知道，一张针对"虚无"的大网正在无声张开。

出发前的动员会上，陆寻只说了一句话："这次的目标，是'虚无'。"

台下安静了一瞬，随即爆发出整齐的应和声。没有人问为什么——上一次联盟保卫战的伤口还没愈合，每个人都憋着一口气。

「追捕行动直播已开启，五十人精锐小队集结完毕！」

「目标是入侵者领袖'虚无'，一百二十七个兄弟的血债！」

「血债血偿！」

「陆神亲自带队，这波稳了！」

「楼上的，稳不稳不知道，但这次联盟是真上下一心了」

「听说连NPC军团都主动递交了随行申请」

陆寻亲自带队，带领联盟最精锐的五十名成员，在寰宇神域的各个角落搜索"虚无"的踪迹。赵擎负责情报收集，白慕鸿负责技术支援，陈胖负责直播和舆论引导。

对此陈胖的评价是："让我一个搞笑担当去搞舆论战？行吧，反正我的嘴皮子比剑快。"事实证明这话不假：行动开始当天，联盟的志愿频道就涌进了上万名响应者。

他还顺手发了个"全民找虚无"的悬赏帖，置顶加精，赏格高得吓人。三天里线索箱被塞进十几万条消息，九成九是废话，剩下的是恶作剧。陈胖气得跳脚，陆寻却让人全部归档："废话也是数据，至少能帮我们排除。"

但"虚无"就像是蒸发了一样，完全找不到任何线索。

三天时间，队伍翻遍了七座主城、二十几条秘境链路，问讯记录堆成了小山。所有的线索到了某个节点就齐齐断裂，干净得像被人用尺子裁过。

可越干净，越说明对方够专业。

"要么是有人给他递了详细路线，"陆寻在沙盘前站定，"要么他自己就是地图大师。两种可能，都够麻烦。"

频道里安静了几秒。

"还有一种。"霜华的声音幽幽响起，"他压根就没打算藏一辈子。"

"老大，我已经扫描了寰宇神域90%的区域，没有发现任何规则侵蚀的痕迹。"白慕鸿的声音从通讯频道传来，"他可能已经离开了寰宇神域。"

"不可能。"陆寻说，"他的天赋是规则侵蚀，这种天赋需要持续吸收其他世界的规则能量才能维持。如果他离开了寰宇神域，他的天赋就会逐渐衰弱。"

"所以他还藏在某块我们没照到的阴影里。"赵擎把地图调了出来，"可我们连阴影在哪都找不到……"

"换个思路。"陆寻打断他，"别找他在哪，找他在吃什么。"

"那他会去哪里？"

"一个规则能量丰富，但又不容易被发现的地方。"陆寻说。

他的脑海中闪过一个念头，随即越来越清晰。

"苏清然，"他通过规则通道联系古老世界的意志，"帮我检查一下古老世界的边境区域，看看有没有异常的规则波动。"

"好。"那声音回答得很干脆。

片刻之后，苏清然的声音传来："陆寻，古老世界的边境区域确实有异常。我检测到了微弱的规则侵蚀痕迹，方向是……东北方。"

通道那头能听见她翻动检测面板的轻响，还有刻意压着的疲惫。他没问她的同步率，她也知道他不会问。

两个人默契地跳过了所有危险的话题。

"你们那边怎么样？"他终究还是没完全绕开。

"死不了。"她说得干脆，"你也是。"

"苏清然。"

"嗯？"

"谢谢。"

"……跟那个世界学的？"她轻笑一声，切断了通讯。

频道安静下来后，陆寻盯着地图看了很久。她的声音比三天前轻了，笑声却比三天前用力，那种刻意吊起来的轻快，他在审核会前夜的档案室里听她用过。他把这点发现压回心底，像收起一件不能示人的证物。

"果然。"陆寻的目光冷了下来，指尖在地图上重重一点。

"虚无"没有离开寰宇神域，而是潜入了古老世界的边境区域。那里规则密度极高，而且远离联盟的监控范围，是藏身的绝佳地点。

但这也意味着，"虚无"的目标可能不只是寰宇神域——他可能想要侵蚀古老世界的规则。

如果让他在规则海洋深处站稳脚跟，就等于在心脏旁边埋了一颗雷。以古老世界刚刚新生的脆弱状态，根本经不起第二次大规模侵蚀。

"我们必须尽快找到他。"陆寻说，"如果让他接触到古老世界的核心规则，后果不堪设想。"

他带领队伍向东北方急行军，同时通过规则通道与古老世界的意志保持联系。

边境地带的规则密度一路飙升，队伍里的普通成员很快就被甩在了后面，最后只剩十二个顶尖强者跟着他踏进了规则海洋的浅层。他们当中，有当初跟着他从特例单位审核会走出来的老面孔，也有在多世界联盟里崭露头角的新血。没有人抱怨路途艰险，队伍安静得只剩风声。

越往深处走，光线就越暗，脚下的丝线却越来越亮，像行走在倒悬的星空之下。

有队员伸手碰了碰身边的丝线，整条手臂的汗毛瞬间竖了起来："这玩意儿……在呼吸？"

"它们都是活的规则。"陆寻头也不回地说，"别乱碰。"

队伍里最年轻的队员咽了口唾沫，小声问："陆神，我们真要在这种地方打仗？"

"到了就知道了。"

"……哦。"少年把已经涌到嘴边的第二句话咽了回去。

"你能确定他的具体位置吗？"陆寻问。

"很难。"那声音说，"规则侵蚀的痕迹太微弱了，我无法精确定位。但可以确定的是，他正在向核心规则的方向移动。"

"多快？"

"按照他目前的速度，大约七天后就会到达核心规则区域。"

七天。

七天里要横穿上万层规则区，咬住一个擅长藏匿的家伙，再打一场硬仗。任何一个环节出错，都是万劫不复。更何况，没人能保证"虚无"会乖乖等在终点等他去抓。

陆寻握紧了拳头。理论上，七天足够他追上"虚无"。但问题是，他现在只有39%的规则之心稳定性，如果与"虚无"发生战斗，规则之心很可能会崩溃。

白慕鸿连夜重跑了一遍推演：以他当前状态正面硬撼"虚无"，胜率百分之十一，心脏崩溃概率百分之六十四。报告发过来时，末尾罕见地附了一句话："建议三思。"

陆寻回了两个字："已思。"

"你在担心什么？"古老世界的意志察觉到了他的迟疑。

"我的规则之心。"陆寻没有隐瞒。对一个能感知自己躯体每一寸波动的存在隐瞒，毫无意义。

"我知道。"那声音说，"你的心脏已经接近崩溃的临界点。如果继续高强度使用规则能力，后果会很严重。"

"我知道。"陆寻说，"但'虚无'不会因为我心脏不好就放过这个世界。而且这一战躲不掉：他在暗，我们在明，拖得越久，他对古老世界的侵蚀就越深。等他把边境啃完，下一个就是核心。"

那声音沉默着，像是在重新评估眼前这个人类的固执程度。

"你有选择。"那声音说，"我可以帮你。"

"怎么帮？"

"我可以暂时接管你的心脏。"那声音说，"用我的规则力量来稳定你的规则之心，让你可以在不消耗自身稳定性的情况下使用规则能力。"

陆寻沉默了。

"这意味着什么？"他问。

"这意味着，在你使用规则能力的时候，消耗的不是你的心脏，而是我的规则力量。"那声音说，"这对我的新生是一个负担，但我愿意承受。"

"风险呢？"

"有。"它答得诚实，"我们的规则频率不同，强行并线可能出现排斥。排斥发生时，我们两个都会受伤。"

"为什么还要做？"陆寻问。

"因为你给了我新生。"那声音说，"而且……我不想看到你为了保护我而牺牲自己。"

陆寻沉默了很久。被一个世界当成同伴的感觉，陌生，却不坏。

最终，他点了点头。

"好。谢谢你。"

"不用谢。"那声音顿了顿，补上一句生硬的玩笑，"朋友之间，不讲代价。"

古老世界的意志开始调动规则力量，通过规则通道将能量输送到陆寻的体内。陆寻能感觉到，自己的规则之心被一股温暖的力量包裹，稳定性停止了下降。

那股力量浩瀚、厚重，带着大地般的沉稳。与规则之心的锋锐截然不同，却又莫名合拍，像两条并行了万年的河终于交汇。

他想起刚才那句"跟那个世界学的"。原来不只她在学，这片海也在学。

【系统提示：外部规则能量注入】

【规则之心稳定性：39%→45%】

【效果：规则能力使用时不再消耗规则之心稳定性】

【提示：「同律」状态已建立：宿主与永恒帝国规则频率暂时同步】

同律——规则频率的临时同步。这意味着从现在起，他的每一次出手背后，都站着一整个世界的重量。

陆寻活动了一下手指，感受着体内涌动的全新力量，目光一点点变得锐利。

他望向东北方那片光暗交界的深处。

远处，规则海洋的光流缓缓涌动，像是在为即将到来的大战蓄力。这场跨越两个世界的猎杀，从这一刻起，攻守易形。

"虚无，这一次，你跑不掉了。"
