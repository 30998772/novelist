# 第041章 规则之战

深层BOSS战

三天后。

陆寻正在创世核心前尝试与沈墨的残留意志对话，系统突然弹出了红色警告：

"警告：深层数据海检测到异常能量波动。"

"警告：规则侵蚀率突破临界值。"

"警告：创世级威胁正在苏醒。"

三条警告排成一列，红色的字迹倒映在陆寻的瞳孔里。徽记的震动从胸口一路蔓延到指尖，像是在替谁发抖。

陆寻猛地睁开眼。远处，数据之海的深处传来一声震耳欲聋的咆哮。那声音不是任何生物发出的，而是规则本身在尖叫。

"那是什么。"陈胖惊恐地喊道。

霜华的脸色变了："是核心守护者，沈墨创造的最后防线。"

"核心守护者。"

"当规则网络崩溃时，创世残留会自动激活，成为新的维护者。"霜华说，"而核心守护者的使命，就是保护创世残留，或者说，保护"维护者"的候选人。"

"那它怎么会变成怪物。"

"因为它也被规则侵蚀了。"霜华的声音变得沉重，"沈墨死后，没有人维护规则网络，核心守护者长期暴露在规则侵蚀中，已经失去了理智。它现在只是一头被规则驱动的怪物。"

"那就杀了它。"烬的声音冷得像铁。

"杀不了。"霜华摇头，"它没有要害之外的实体，你们砍中的只是数据投影。"

"投影也分主次。"烬眯起眼，"它每走一步，脚下乱码最浓的那条线就是数据主干。顺着找，能摸到真身。"

"就算摸到也没用。"霜华说，"能伤到它的力量，这片深层数据海里只有一个人有。"

远处的咆哮声越来越近。大地在震动，数据碎片如暴雨般倾泻而下。一个巨大的身影从黑暗中浮现：那是一个由无数规则碎片构成的人形生物，身高超过五十米，身上散发着令人窒息的压迫感。

它的"皮肤"由无数条高速滚动的代码构成，每走一步，脚下就有一片地面被解析成乱码。烬带着NPC战士退开半里，刀已出鞘，握刀的手背青筋暴起。

"核心守护者·形态一——数据巨像。"霜华低声说，"小心，它的攻击力足以一击摧毁整个营地。"

营地后方传来撤离的号角声。NPC战士们押着伤员向岩壁后的通道转移，没有谁回头多看一眼那尊正在逼近的庞然大物。

"能打吗。"赵擎问。

"不能。"霜华摇头，"它的规则抗性极高，普通攻击根本无法伤到它。只有创世残留的力量，或者说织律者的力量，才能对它造成伤害。"

在场每个人的目光都转向了陆寻。

陆寻深吸一口气，握紧拳头。织律者徽记的光芒在他身上流转，完整的织律者徽记的力量汇聚于一点。

"我来试试。"

他向前迈出一步，身体瞬间化作一道金光，冲向那头巨大的怪物。

"织律者·规则之链。"

无数金色的锁链从他手中射出，缠上了数据巨像的身体。锁链接触到怪物的瞬间，发出刺耳的金属碰撞声，那是规则与规则之间的对抗。

数据巨像发出一声怒吼，挥动巨臂砸向陆寻。陆寻用规则偏移躲过了那一击，但巨像的力量余波还是将他震飞了出去，他在半空翻滚了两圈才卸掉那股巨力。

"寻哥。"陈胖惊呼。

赵擎拖着战锤冲上来，把陆寻从碎石里拽起来："寻哥，别硬扛，这玩意儿一巴掌能拍死一个营的人。"

"知道。"陆寻抹掉嘴角的血，目光死死锁着巨像胸口的暗红色光点。

陆寻在空中稳住身形，肋骨发闷。数据巨像的力量远超他的想象，即使有织律者的力量，他也只能勉强抵挡。

"霜华。"他喊道，"弱点在哪。"

"胸口。"霜华说，"那里是规则侵蚀的核心。如果你能击碎它，就能暂时瘫痪它的行动。"

陆寻点头，再次冲向巨像。但这一次，他改变了策略：不再正面硬抗，而是利用规则偏移的0.01秒真空，不断在巨像的攻击缝隙中穿梭。

每一次规则偏移，都能暂时"挂起"巨像身上的一条规则。虽然只有0.01秒，但累积起来，巨像的行动开始变得迟缓。

"有效。"陈胖兴奋地喊道。

金色的细痕在巨像身上越缠越多，像一张正在收紧的网。每一次挂起都短暂得可怜，可陆寻的节奏没有一丝混乱：偏移，借力，换位，再偏移。他的呼吸渐渐沉重，精神力如退潮般往下掉。

【叮。律痕·初阶剩余维持时间：17秒。】

十七秒。陆寻把数字在心里又过了一遍。巨像的拳头擦着他的耳侧砸空，气浪掀得他踉跄半步，皮肤被乱刮的数据流割出细小的血口，痛感真实得不像在游戏里。

但就在这时，远处突然传来一阵骚动。白慕鸿带着他的人出现了，他身上散发着诡异的银光，眼中闪烁着疯狂的光芒。

"陆寻。"白慕鸿大喊，"别以为只有你能对付它。"

他挥手，身后的五十个人同时冲向巨像。他们的身上都散发着银光，那是白慕鸿赋予他们的"规则复制"。

"白慕鸿，你疯了。"霜华怒喝，"你的人根本挡不住它。"

事实很快证明她说得对。复制来的银光在巨像的规则面前脆弱得可笑，第一批冲锋的玩家连它的膝盖都没摸到，就被一道横扫的数据波掀飞出去，惨叫声此起彼伏。

有玩家一边逃一边开着直播，弹幕和营地频道彻底炸了：

「卧槽那是什么东西。五十米的BOSS。」

「策划呢。策划出来挨打。这玩意儿是给人打的。」

「别骂了，快跑。BOSS的仇恨转移了——」

"那又怎样。"白慕鸿冷笑，"只要我能拿到核心守护者的核心，拿到里面创世级的力量，我就不用死。"

他冲向巨像，银光爆发。他的规则复制在这一刻达到了极限：他同时复制了三种规则能力，速度、力量、防御。

"白慕鸿·规则复制·三重奏。"

他的身体化作一道银色的流星，直接撞向巨像的胸口。

轰——！

巨大的冲击波扩散开来，数据碎片被吹得四散。白慕鸿的攻击确实命中了巨像的胸口，但没有造成任何伤害。

巨像的胸甲上连一道白痕都没留下，反而泛起一圈涟漪，把那道银色的冲击尽数吞了进去。战场上安静了一瞬，随后是更加疯狂的咆哮。

"不可能，这不可能。"白慕鸿的表情彻底僵住。

巨像低头看向他，眼中闪烁着冰冷的光芒。然后，它伸出一只手，直接捏住了白慕鸿的身体。

"啊——！"

白慕鸿惨叫一声。他的铠甲在巨像的力量下碎裂，身上的银光也迅速暗淡。规则复制的力量正在被巨像吸收。

那些被夺走的银色光流顺着巨像的手臂向上蔓延，它的躯体以肉眼可见的速度变得更加凝实。它在进食。

"会长。"他的人惊呼，想要上前救援，但被巨像的另一只手横扫出去，撞在远处的岩壁上，生死不知。

陆寻看到这一幕，做出了决定。

"霜华，带陈胖他们撤退。"

"你呢。"

"我来拖住它。"

"你会死的！"

"不会。"陆寻的声音平静而坚定，"我是创世残留，它不会杀我。它的使命是保护我，即使失去了理智，这个本能还在。"

霜华咬了咬牙，最终点头。她挥手释放出一道冰霜之墙，掩护陈胖他们撤退。

"寻哥，你可得活着啊。"陈胖被赵擎拖着往后跑，还在声嘶力竭地喊，"我还欠你一顿火锅呢。"

冰墙之后，脚步声和喊声渐渐远去。

陆寻独自面对巨像，织律者徽记的光芒在他身上燃烧到极致。

"来吧。"他低声说，"让我看看，创世者留下的"保险"到底有多强。"

他冲向巨像，金色的光芒与银灰色的规则碎片碰撞在一起。整个数据之海都在颤抖，灰色的海面翻起一层层代码浪。

巨像的每一拳都砸得空间嗡嗡作响，陆寻的身影在指缝与拳风的间隙里穿行，金色轨迹在灰暗的海面上拖出一道道残影。他默默数着自己的次数：律痕·初阶，今日第三次。三十秒内，他可以续接巨像自身的"守护规则"，把它压在原地。

在战斗的间隙，陆寻瞥了一眼被巨像捏在手中的白慕鸿。那个曾经不可一世的天穹会长，此刻已经奄奄一息，眼中满是恐惧和不甘。

"救……救我……"白慕鸿微弱地喊道。

陆寻沉默了一秒。

然后，他做了一个决定。

他用规则偏移创造了0.01秒的规则真空，在那0.01秒内，他将白慕鸿从巨像的手中"偷"了出来。

那0.01秒里，捏住白慕鸿的五根手指的"抓取规则"同时失效，惯性把他抛向了陆寻张开的手。真空闭合的瞬间，巨像困惑地摊开空空的手掌，缓缓转过头。

白慕鸿落在地上，大口喘息。他看向陆寻，眼中满是不可置信。

"你……为什么救我。"

"因为你死了，天穹会更乱。"陆寻说，"现在，滚回表层去。下次再来深层，我不会管你。"

白慕鸿挣扎着站起身，带着他的人仓皇逃离。

远处传来冰墙碎裂的脆响。陆寻活动了一下发麻的手腕，掌心的血口在数据流里微微发亮。巨像沉重的呼吸声近在咫尺，每一口都卷着灰热的乱码气味。

陆寻转身面对巨像，金色的光芒在他身上燃烧。

"现在，只剩我们了。"
