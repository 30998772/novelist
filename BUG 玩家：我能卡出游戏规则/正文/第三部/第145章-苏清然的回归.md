# 第145章 苏清然的回归

苏清然的回归

庆典结束后的第二天。

陆寻站在联盟总部的天台上，看着远方的天际线。

苏清然走到他身边，两人就这样静静地站着，什么都没有说。

"你有什么打算？"苏清然终于开口。

"继续当仲裁者。"陆寻说，"维护多世界联盟的秩序，确保所有世界和平共处。"

"听起来很累。"苏清然微笑。

"是挺累的。"陆寻也笑了。

两人相视一笑，然后一起看向远方。

太阳缓缓升起，金色的光芒洒在大地上，温暖而柔和。

这是一个新的开始。

一个新的时代。

一个多世界和平共处的时代。

"陆寻。"苏清然突然说。

"嗯？"

"谢谢你。"苏清然说，"谢谢你一直保护着我，保护着联盟，保护着所有世界。"

陆寻摇了摇头："这是我应该做的。"

"不。"苏清然说，"这不是你应该做的。这是你选择做的。你本可以不管这一切，你本可以只做一个普通的玩家，过普通的生活。但你选择了承担这一切，选择了保护所有人。"

陆寻沉默了。

苏清然继续说道："你是一个英雄，陆寻。一个真正的英雄。"

"我不是英雄。"陆寻说，"我只是做了一个正确的选择。"

"正确的选择就是英雄的行为。"苏清然说。

陆寻看了看苏清然，嘴角微微上扬。

"谢谢你，苏清然。"他说，"谢谢你一直在我身边。"

苏清然笑了："这是我应该做的。"

两人再次相视一笑，什么都没有说。

但一切都尽在不言中。

远方的天际线上，太阳越升越高，金色的光芒照亮了整个世界。

一个新的时代，正式开始了。

而陆寻和苏清然，将携手走过这个时代的每一个瞬间。

陆寻看着眼前的系统提示，目光平静。

他知道，这只是开始。

在规则之上，还有更高的存在。

在多世界之外，还有更广阔的空间。

但无论未来会面对什么，他都不会退缩。

因为他不是一个人在战斗。

他有伙伴，有朋友，有苏清然。

这就够了。

他转身看向苏清然，伸出了手。

"走吧。"他说，"新的时代在等着我们。"

苏清然握住了他的手，两人一起走向远方。

身后，联盟总部的旗帜在风中飘扬。

多世界联盟的旗帜。

和平的旗帜。

希望的旗帜。
