# 第128章 苏清然的配合

陆寻与古老世界意志对话的同时，寰宇神域这边的情况正在急剧恶化。

联盟总部的指挥中心里，数十个全息屏幕闪烁着刺眼的红光。

每一块屏幕上都滚动着密密麻麻的规则监测曲线，其中三条已经变成刺目的猩红，正以肉眼可见的速度向警戒上限爬升。分析员们的手指在操作界面上翻飞，没人说闲话，只有键盘敲击声和低频警报声交织在一起。

"苏清然，情况不妙！"白慕鸿的声音从分析组传来，带着罕见的焦虑，"古老世界的规则压制强度又提升了12%！按照这个速度，我们撑不过两个小时！"

"具体点。"苏清然说。

"古老世界的外层规则正在整体向内收缩，挤压效应传导过来，就是我们全境的规则压力上升。主城防御阵法的承载上限是标准值的四倍，现在已经三点二倍了。"白慕鸿飞快地念出一串数字，"另外，驻各世界观察员回报，至少五个小型世界出现了同样的压力波动。它不只冲我们来。"

"它是想把整片海的水位都抬起来。"她的声音冷了下来。

苏清然站到指挥台前，目光扫过所有屏幕上的数据。她的脸色很不好看。

"启动秩序回响的全域防御模式。"她下达了命令。

"可是那样会消耗大量能量——"白慕鸿试图反驳。

"执行。"苏清然的声音不容置疑。

白慕鸿还想争辩，可对上她的眼神，还是把后半句咽了回去。他太清楚这个女人的脾气：她认定的事，十头龙也拉不回来。

她转身看向通讯频道中陈胖和赵擎的影像："你们两个，组织联盟所有成员准备撤离核心区域。如果规则压制继续增强，那里会首先崩溃。"

陈胖的脸色变了变："撤离？核心区可是有三十多万玩家和NPC，还有联盟总部整套规则设施……"

"设施可以重建，人不行。"苏清然说，"按预案第七条执行，NPC的迁徙优先级与玩家相同。"

赵擎已经在调兵遣将："苏姐放心，一小时之内清空核心区。"

"明白！"两人同时回答。

通讯切断前的最后一瞬，苏清然的视线在频道列表上停了半秒。陆寻的下一次报平安时间是一分四十秒之后，而频道里安静得能听见电流的嘶声。

苏清然深吸一口气，做出了一个决定。

她要进入古老世界。

陈胖似乎看穿了她的想法，声音一下子提高了八度："苏清然，你不会是想——"

指挥中心里的警报声好像都顿了一拍。

"那边是什么地方？规则密度外界四十七倍！你进去能撑几分钟？"陈胖几乎吼了出来。

"陆寻需要我。"苏清然打断他的话，"他的规则潜行可以让他在规则海洋中自由移动，但那个世界的意志太强大了。我必须用秩序回响帮他稳定对话环境。"

"可是你的身体——"

"秩序回响可以保护我。"苏清然说，"但如果我不去，陆寻可能会被那个世界的意志吞噬。你觉得哪个风险更大？"

陈胖沉默了。

赵擎的声音从另一端传来："苏姐，让我们跟你一起去。"

"不用。"苏清然摇头，"你们留在这里指挥联盟。记住，如果我失败了，立刻启动最终防御方案。不要犹豫。"

"苏姐——"

苏清然关闭了通讯频道，将全部注意力集中在秩序回响上。

这件规则神器发出柔和的银色光芒，仿佛在回应她的意志。她曾经用它稳定过无数混乱的规则，创造过无数秩序的奇迹。但这一次，她要用它做一件前所未有的事——在规则海洋中开辟一条通道。

【系统提示：秩序回响启动】

【效果：规则稳定场】

【范围：半径500米】

【能量消耗：每分钟3%】

【警告：宿主与定规之钥同步率87%，超出安全阈值】

【提示：过度使用将加速「同化」进程】

苏清然看都没看那行小字，挥手关掉了警告。同化的代价她比谁都清楚，手腕上偶尔浮现又隐去的银色纹路就是证明。但有些账，不能只算自己这一头。

苏清然感觉到一股巨大的力量从秩序回响中涌出，包裹住她的身体。周围的规则开始变得稳定，不再像之前那样混乱。

她深吸一口气，调动全部力量，在虚空中撕开了一道裂缝。

裂缝只有一掌宽，边缘不断痉挛着想要愈合，像一道不肯听话的伤口。她咬牙把秩序回响的力量灌进去，一寸一寸将它撑开、加固、锚定。

那是连接寰宇神域与古老世界的规则通道。

指挥中心爆发出一阵压抑的惊呼。屏幕上，一条横跨两个世界的银色光带缓缓亮起，像在惊涛骇浪上架起了一座看不见的桥。这一幕同时被联盟的公共频道转播了出去：

「卧槽，苏神要亲自下场了！」

「规则密度47倍的地图，这是人能进的吗？」

「怕什么，陆神都在里面待半天了！」

「给秩序回响充能的队列已排起，每人每天捐一次规则之力，速来！」

"苏清然！"陈胖的声音最后一次从通讯频道传来，充满了担忧。

"通道我给你盯着！稳定场波动一旦超过百分之十，我立马拽你回来！"他大声说，嗓音有点发颤，"还有……你们俩都得给我完好无损地回来！"

"帮我看好这里。"苏清然头也不回地踏入了通道。

当她睁开眼睛时，发现自己已经置身于规则海洋之中。

无数发光的规则丝线在她周围穿梭，每一条都蕴含着足以毁灭一个世界的力量。但秩序回响的稳定场形成了一个银色的保护罩，将她包裹在其中，隔绝了外界的规则压力。

即便隔着保护罩，她依然感到了那股沉甸甸的压迫。这里的每一条丝线都比寰宇神域的规则粗壮数十倍，光是看上一眼，意识就像被一只巨手按进了水里。

她终于真切体会到陆寻独自承受的是什么。

她定了定神，操纵稳定场向陆寻所在的位置移动。

在规则海洋里移动不是走路，更像逆着瀑布往上爬。每前进一段，就要用秩序回响重新校准一次方向——这里的丝线始终在流动，上一刻的坐标到下一刻就可能偏出数十层之遥。护罩表面不时撞上漂浮的规则碎屑，激起一圈圈细密的银纹，发出玻璃器皿轻碰般的脆响。

越往下，丝线就越亮、越粗，压迫感也层层递增。她的呼吸渐渐变重，指尖因为持续输出力量而微微发麻，却始终没有放慢速度。

她感知到了陆寻的位置，开始向他靠近。

距离不算远，可在规则海洋里，"不远"是个陷阱般的词汇。她每前进一段，就要用秩序回响重新校准一次方向：这里的丝线始终在流动，上一刻的坐标到下一刻就可能偏出数里之遥。

越靠近陆寻所在的深度，丝线就越亮、越粗，压迫感也随之层层递增。

当她出现在陆寻身边时，正好看到了那个古老意志投来的审视。

"有趣。"那意志的声音在整个规则海洋中回荡，"你选择信任她。"

陆寻没有回答那意志的话，而是转头看向苏清然："你不该来。"

"我知道。"苏清然微笑，"但我选择来了。"

"通道撑不了太久，别浪费。"陆寻的目光落在她护罩边缘已经开始发暗的银光上，"同步率呢？"

"百分之八十九。"她答得很平静。

陆寻的眼神沉了沉。过了九十，同化就不可逆。她在拿自己当耗材。

"回去。"他说。

"说完正事再赶我。"苏清然把秩序回响往他身侧一送，银光稳稳嵌进他的规则场边缘，"你的心跳频率从踏进这片海起就没正常过。别以为隔着频道，我就看不出你在硬撑。"

陆寻没再劝。他知道她的脾气，和自己是同一种人。

她开始调动秩序回响的力量，在陆寻周围创造了一个规则稳定的区域。这个区域就像是规则海洋中的一座孤岛，银色的光芒将外界的规则波动隔绝在外。

银色光纹以她为圆心层层铺开，所过之处，躁动的丝线一根根安静下来，像被无形的手抚平的鬃毛。陆寻感觉到肩头那股持续不断的重压骤然一轻，连呼吸都顺畅了几分。

这就是定规之钥的力量。不攻击，不改写，只是让规则暂时"守秩序"。

"现在，你可以专心了。"苏清然说。

"能撑多久？"

"钉固状态一次二十秒，间歇十秒，我可以循环。"苏清然报出数字，"够你说完一段话就续上。"

陆寻点了点头，重新将注意力转向世界的深处。

光罩之外，那道意志的注视变得更加清晰。它没有催促，也没有阻拦，只是安静地看着这两个渺小的外来者在自己的躯体里筑起小小的阵地，像看着两粒沙子在海边堆城堡。

"继续。"他对那意志说，"你说你是创世者的第一件作品，那为什么你会变成现在这样？"

苏清然悄悄向他靠近了半步。她注意到，随着这个问题出口，整片规则海洋的蠕动都慢了下来，千万条丝线的震颤频率整齐划一，像某个庞大的生物屏住了呼吸。

它在回忆。而回忆显然不是一件愉快的事。

苏清然忽然压低声音："它也有委屈。"

"嗯。"陆寻不动声色。

"那你打算怎么跟一个受了委屈的世界讲道理？"

"先听完它的委屈。"陆寻说，"再告诉它，委屈不能成为压垮别人的理由。"

那意志沉默了片刻，然后缓缓开口："因为创世者放弃了我。"
