# 第141章 古老世界的崩溃

古老世界的崩溃

陆寻陷入了深度昏迷。

联盟总部的医疗室内，他躺在一张白色的床上，身上连接着各种监测设备。苏清然坐在床边，握着他冰冷的手，眼眶微红。

"他的情况怎么样？"陈胖的声音从身后传来。

苏清然摇了摇头："规则之心稳定性降到了3%，几乎已经停止了跳动。我的秩序回响正在尝试修复，但效果很微弱。"

"那怎么办？"陈胖的声音里充满了焦虑。

"我不知道。"苏清然的声音带着一丝颤抖，"我从来没有见过这种情况。规则之心是融合了多世界规则精华的核心，如果它崩溃了，陆寻就会……"

她没有说完，但所有人都明白那个未说完的词意味着什么。

死亡。

联盟总部的气氛变得异常沉重。陆寻是联盟的灵魂，如果他倒下了，整个联盟都会失去方向。

但更糟糕的消息还在后面。

白慕鸿的声音突然从通讯频道传来，带着惊恐："不好了！古老世界开始崩溃了！"

"什么？"苏清然的瞳孔骤缩。

"规则层面的崩溃！"白慕鸿说，"陆寻在与虚无战斗时，将规则真空扩展到了极限。这个操作虽然消灭了虚无，但也对古老世界的规则体系造成了巨大的冲击。现在，古老世界的核心规则正在解体！"

苏清然的心中一沉。

她立刻调动秩序回响，感知古老世界的状况。当她"看到"那里的景象时，脸色变得惨白。

古老世界的规则海洋正在崩溃。

那些原本交织缠绕的规则丝线开始断裂，无数规则碎片在空中飘散，化作虚无。整个世界就像一座正在倒塌的大厦，每一块砖石都在脱落。

"不能让它崩溃。"苏清然说，"如果古老世界的规则体系彻底解体，那些规则碎片会冲击整个多世界体系，包括寰宇神域。"

"那怎么办？"赵擎问。

苏清然深吸一口气，做出了一个决定。

"我要用秩序回响稳定古老世界的核心规则。"

"什么？"陈胖的声音提高了八度，"苏清然，你疯了吗？你的秩序回响能量才刚恢复到60%，怎么可能稳定一整个世界？"

"我必须试试。"苏清然说，"如果古老世界崩溃了，后果不堪设想。"

"可是你的身体——"

"我没事。"苏清然打断他的话，"你们照顾好陆寻，这里交给我。"

她转身走出医疗室，来到了联盟总部的指挥中心。

她闭上眼睛，开始调动秩序回响的力量。

【系统提示：秩序回响启动】

【效果：规则稳定场——全域扩展】

【能量消耗：每分钟5%】

苏清然感觉到一股巨大的力量从秩序回响中涌出，穿越空间，直奔古老世界而去。她必须用这股力量去稳定古老世界正在崩溃的核心规则，阻止灾难的发生。

但这需要付出巨大的代价。

秩序回响的能量正在以惊人的速度消耗，她的身体也承受着巨大的负荷。但她没有停下，因为她知道，如果她停下来，一切都完了。

"苏清然！"陈胖的声音从通讯频道传来，"你的秩序回响能量已经降到40%了！继续下去你会——"

"我知道。"苏清然的声音平静，"但我不能停。"

她咬紧牙关，继续输出秩序回响的能量。

古老的规则海洋在她的力量下逐渐稳定，崩溃的速度开始放缓。但距离完全稳定，还需要很长时间。

而她的时间，已经不多了。
