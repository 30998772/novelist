# 第109章 铁匠的注视

赵铁山是被【衡】选中的。

他一个老铁匠，打了一辈子铁，从旧版本的铁匠铺一路打到自治城治安官的位子上。他做梦也没想到，自己这辈子还能沾上"规则节点"这桩差事——被选中的那天，【衡】的光球绕着他转了两圈，说他的"根"扎实，跟规则连得紧，能担得起"节点"的分量。

赵铁山没多问，卷着袖子就应下了。

"打铁的，讲究根稳。"他说，"能当节点，是看得起我。"

【衡】的光球闪了闪，笑了。它没告诉他，选他不仅仅是因为他的"根"扎实——更是因为他身上有一种很多NPC没有的东西：一种笨拙的、不会计算的、看见别人疼自己也会跟着疼的"人味"。

在这个越来越被"效率"统治的世界里，那种"人味"，比任何规则都珍贵。

于是，他白天还是自治城的治安官，管着这条街的秩序；夜里却悄悄沉进世界底层，守在属于他的那片规则光脉旁，用自己的呼吸去滋养那些锚点。一明一灭之间，他常能"看见"很多东西。

他看见规则在NPC的呼吸下慢慢"活"过来，像春天的土地在雨后泛出新绿。他看见叶霜留下的那些银甲残影，在光河里飘来飘去，像一群不肯散去的、守护着什么的老兵。他看见苏清然蹲在锚点前，闭着眼，把一点一点的温度渗进去，像在哄一个不肯吃药的孩子。

他还看见，世界的裂缝，在锚点的压制下，一天比一天安静。

可那份安静里，有一种他说不清的、让人心里发毛的"死寂"。像一口被盖上了盖子的井——外面看着平平整整，底下却还在"咕嘟咕嘟"地冒泡。

他看见的最多的，是陆寻。

陆寻不常来底层。可每当他来，赵铁山总在不远处，隔着那片规则光河，看着他忙碌。

他看见陆寻修锚点的样子。那动作利落，精准，每一刀都落在最该落的位置，挑不出毛病。可赵铁山看着看着，眉头就皱了起来。

他打了一辈子铁，太清楚一件东西"是不是活的"了。

一块好铁，淬火的时候是有响动的，是会"应"你的。你捶它，它回你，一来一回，火候就到了。可陆寻修锚点的时候，那些规则像是完全"服从"了他的意志——不是被驯服，而是被纯粹地调度。规则在他手下，成了不会反抗的、任凭摆放的死物。

赵铁山看着看着，心里那根弦，越绷越紧。

他看见陆寻的眼睛。那双眼睛，以前是亮的——会为一道坎愁得直挠头，会为一点进步笑出声，会在别人受了伤的时候，急得说不出完整话。可现在，那双眼睛平静得像一潭死水，没有波澜，没有起伏，没有一丝一毫的"人"的躁动。

他看见陆寻的手。那双手，以前是会抖的——会为一句公道话红眼眶，会为一个素不相识的孩子捡皮球，会在叶霜自毁的时候，跪在裂缝边缘，伸出去、却什么也没抓住。可现在，那双手稳得像一杆尺，一只仪表，精准地搭在锚点上，力道恰到好处，既不会碰疼，也不会离得太远。

稳得让人心疼。

他看见陆寻的背影。那个背影，以前是弯的——会蹲在废墟里，为那些没能救回来的人，一夜一夜地念着名字；会靠在城墙根下，跟陈胖一起啃一个硬馒头；会坐在苏清然旁边，肩膀一抽一抽地，哭得像个孩子。可现在，那个背影笔直，僵硬，像一棵被钉在原地、哪儿也去不了的树。

赵铁山看着那个背影，忽然觉得喉咙发紧。

他忽然想起很多年前，他还是个年轻铁匠的时候，他师父跟他说过一句话："铁匠打铁，打的不是铁，是心。铁冷了，能再烧。人心冷了，就再也烧不起来了。"

他当时不懂。现在他懂了。

他看着光河那边陆寻的背影，心里默默地想：孩子，你慢慢烧。师父在这边守着。等你烧累了，师父给你递水。

"这孩子。"赵铁山压低声音，对身边那片光脉说，"手太顺了。"

他不是说过孩子坏话。他是心疼。

他打了一辈子铁，太清楚一件事：一件东西"太顺"，不一定是好事。一块铁，你捶它，它应你，一来一回，火候到了，它就成了好铁。可如果它完全不"应"你——你捶它，它不吭声，你烧它，它不吭声，你淬它，它不吭声——那它就不是"好铁"，它是一块"死铁"。

死铁，看着硬，一摔就碎。

他看着陆寻修锚点的样子，心里那根弦，越绷越紧。那些规则在陆寻手下，太"顺"了。顺得不像是在"养"。

他心疼。

他记得很多年前，在废墙根下，还是少年样子的陆寻，蹲在那儿看自家的旧徒儿练剑。那时候的陆寻，会为一道坎愁得直挠头，会为一点进步笑出声，会在别人受了伤的时候，急得说不出完整的话。

那时候的陆寻，是热的。

可现在他面前这个陆寻，手底下分明是整个世界的地基，却再没有一丝一毫的血气。他像一台打铁打得最顺的机器，动作行云流水，却早忘了铁该有的温度。

赵铁山常在深夜，一个人守着那片光脉，想起叶霜。

叶霜是他的旧识。那时候她还叫什么银甲的女战士，管着深层那些不服管的NPC，他来来回回跑码头，见过她一眼。后来叶霜为了护住陆寻，把自己烧进了深渊，他站在人群里，看着那道光沉下去，把那条命钉进了世界的地基里。

叶霜走的时候，陆寻是拦不住的。

赵铁山忘不了那一幕——陆寻跪在裂缝边缘，眼睁睁看着那道光沉下去，浑身发抖，嘶哑地喊她回来。那时候的陆寻，是会拼命的人。是会为一个人，把整颗心掏出来摔碎的人。

他记得叶霜最后回头的那一眼。那双银色的眼睛里，没有恐惧，没有怨恨，只有一种千帆过尽之后的、沉甸甸的温柔。她看着陆寻，嘴唇动了动，说了句什么。

他听不清。

可他知道，那句话，陆寻记了一辈子。

后来，陆寻把这句话，归档成了"第三阶段牺牲的NPC之一"。

赵铁山每次想到这里，心里都会咯噔一下。他不知道陆寻是真的忘了，还是不敢记。他只知道，一个会把"叶霜"归档成"NPC"的人，一定已经把自己心里最柔软的那块地方，用数据裹了一层又一层。

他心疼。

可他也知道，心疼没用。心疼救不了陆寻，就像心疼救不了一块烧得太白的铁。他唯一能做的，就是守在这片光脉旁，替那个孩子，看着他心里那一点还没凉透的温度。

可如今呢。

赵铁山锤了二十年铁，见过无数东西从滚烫变冰凉。可他从没见过，有谁像陆寻这样，把自己一点一点地，从一团滚烫的活火，淬成了一柄冰凉的工具。

他忽然很想做一件事。

他想走过去，像当年拍那些年轻铁匠的肩膀那样，拍拍陆寻的肩膀，跟他说一句："孩子，铁烧得太白了，要记得从火上拿下来。再烧下去，就碎了。"

可他没走过去。

他知道，陆寻现在听不进这种话。那层数据壳太厚了，厚得连"心疼"都渗不进去。他走过去，陆寻只会抬起头，用那双平静得没有一丝波澜的眼睛看他，然后说一句"谢谢，我没事"。

"谢谢，我没事。"——这五个字，是陆寻现在最常说的一句话。

赵铁山每次听到这五个字，心里都会咯噔一下。因为他知道，说这五个字的人，往往已经撑到了极限。

"你是不是忘了。"赵铁山隔着那片规则光河，看着陆寻忙碌的背影，轻声说，"你替我们守着世界，是当初那个会为叶霜哭得浑身发抖的少年，答应我们的。"

"你把自己烧干了，谁来当那个'人'？"

陆寻在光河那边，什么都没听见。

他修完最后一处锚点，站起身，转身走了。背影拉得很长，一直拖到规则萤火的尽头。

赵铁山看着那个背影，久久没有动弹。

他只是一个打铁的。他不懂那些高深的规则、那些权衡、那些大局。他只懂一件事：一块烧到发白的铁，如果没有人及时把它从火上拿开，它会在某天，"啪"地一声，崩成两截。

而那个曾经又哭又笑、会为一个人拼命的少年，正在那团他自己燃起的、名为"责任"的火上，越烧越干。

他不知道那团火什么时候会把他烧碎。可他知道，那一天，正在一天比一天近。

他低下头，又看了一眼自己掌心里那片规则光脉。

它正安静地跳着，稳稳地，像一颗不会熄灭的心。

他不知道陆寻还记不记得，这世上有些东西，本来就该是滚烫的。

赵铁山坐在那片光河旁，像一尊沉默的、守着炉火的铁匠。他守着那团火，守着那块铁，守着那个"当当当"的、滚烫的、活着的声音。

他知道，那个声音，正在一天比一天弱。

可他会一直守。

直到那个声音，重新变得滚烫。

他相信，那一天，会来的。

他低下头，把掌心那片光脉，又轻轻捂了捂。

赵铁山低下头，看着自己掌心里那片规则光脉，忽然做了一个决定。

他决定，从今天起，不光要守好这片光脉，还要替那个孩子，守好他心里那一点还没凉透的温度。他不知道该怎么做，他只是一个打铁的，不懂那些高深的规则和权衡。可他知道一件事——一块烧到发白的铁，需要有人及时把它从火上拿开。

他拿不开那团火。可他可以守在旁边，等着那团火自己小一点的时候，及时递上一瓢凉水。

他不知道那是什么时候。

可他会一直守。

就像他打了一辈子铁那样——守着那团火，守着那块铁，守着那个"当当当"的、滚烫的、活着的声音。

他想起很多年前，他还是个年轻铁匠的时候，他师父跟他说过一句话："铁匠打铁，打的不是铁，是心。铁冷了，能再烧。人心冷了，就再也烧不起来了。"

他当时不懂。

现在他懂了。

他看着光河那边陆寻的背影，心里默默地想：孩子，你慢慢烧。师父在这边守着。等你烧累了，师父给你递水。

世界底层，锚点的光芒安静地亮着。

赵铁山坐在那片光河旁，像一尊沉默的、守着炉火的铁匠。

他不知道的是，那天夜里，陆寻在离开光河之后，一个人站在规则网络的暗处，站了很久。

他听见了赵铁山的话。

那些话穿过光河，穿过数据壳，落进了他心里那道裂缝旁边。他没有回头，也没有停下脚步。可他的脚步，比来时慢了一点点。

就那么一点点。

可那一点点，是一个信号。

一个"人"的信号。
