# 第101章 退化的根源

陆寻追了七天的裂缝，追到了世界的最底层。

裂缝不止在外表的皮肤上。越往深处追，裂缝就越粗、越深。表层的那些还能打补丁，可越往下，它们就越接近规则的"地基"，像是整座楼的地基都在发裂，而墙上的裂缝只是从底下传上来的共振。

这七天里，他几乎没合过眼。他白天堵裂缝，夜里就顺着裂缝最粗的方向往下挖，一层一层，掘开规则的地壳。他见过干涸的地下河，见过废弃了不知多少年的旧灾运判定，见过一堆堆没人打理、正慢慢风化"死"掉的边缘规则。每一层都比上一层更接近那个最根本的问题，也每一层都让他心里那点不祥的预感更沉一分。

苏清然劝过他休息，他没停。他心里有一团火压着——他隐约觉得，自己追的不是一道裂缝，而是一个埋得极深、早已疼了八百年的病根。他必须亲眼看看它。

第七天，他终于来到了那片未被翻译的原始规则层。

这里他没有来过。以前他在深渊里来去自如，但那些地方多少已经被规则翻译过；而这一层，是规则尚未落笔的荒原，是世界打地基的地方。他踩着脚下流动的原始光流，一步一步往最深处走。

在荒原的最深处，他看见了源头。

那是一段断掉的线。

像是有人从一卷很长很长的规则里，剪下了一段，然后头也不回地走掉了。断口处参差不齐，边缘已经干枯发白，像是很久以前就被剪断的。断了的地方没有新的线长出来，只有原本连在它身上的那些规则，因为失去了源头，正一根一根地往回抽、往回缩、往回枯。

陆寻顺着那段断线，往荒原的更深处走。

越往深处，那种"枯"的感觉就越重。他看见一些规则的"树干"，因为失去了浇灌，树皮一片一片地剥落；看见一些"河流"一样的规则，因为失去了源头，河床一点点干涸，只留下龟裂的、发白的底子。这些都不是他一眼能看出来的病，而是藏在世界最底层、最不起眼处的、正在发生的末路。

他在一片枯干的规则河床前停下来，伸手碰了碰河床那发白的底子。指尖传来的触感，凉、干、脆，一无所有的那种脆，像是用力一捏就会碎成一捧灰。

他终于明白了那些裂缝从何而来。

"这不是老化。"他低声说，"是断供。"

是源头的供给断了。创世者沈墨离开这个世界的时候，可能在最后一段规则上，切断了和现实的连接。从那一刻起，世界的底层规则就失去了"源头活水"，只能在原地消耗、磨损、枯竭。这些年它一直在用自己的储备硬撑，撑到今天，储备终于见底了。

"衡。"他问，"这条线，原本连着哪里。"

光球在他身后展开了一幅极简的图：一条线，从世界的底层向外延伸，穿出世界本身，通向一个陆寻无法"看见"的方向——那是一个世界之外的位置，规则的绝对源头。

"连向创世者。"【衡】说，"这条断了八百年的线，本来的作用是源源不断地把新的规则注入这个世界，维持它的运转。现在它断了，世界就只能靠存量。"

"断的那天，就是创世者离开的那天。"陆寻说。

"是。"

陆寻沉默了。

他忽然理解了很多人和事。理解了为什么这个世界的规则总有那么多的"陈旧"与"冗余"，为什么总有些判定迟钝、有些NPC行为树老化、有些角落总需要反复修补。不是因为他这个维护者不够努力，而是因为这个世界的血，早就断了源头。

他想起了那段节庆代码。那条本该在渔村黄昏里噼里啪啦燃着欢庆火光的规则，他前几天修补的时候还只当它是"老得需要维护"。可现在他明白了——它不是老了，它是输不进去了。创世者走后，那些日子里活的规则，靠的全是存量；等存量见底，最先干枯的，就是这些最边缘、最不被人注意的地方。

他又想起那些玩家这些年的抱怨，想起那些堆在系统深处、从没被清理干净的旧逻辑。原来它们全都不是无缘无故的"臃肿"与"bug"——这是一个被剪断了脐带的孩子，在没有人看见的地方，正一点一点地枯萎。

八百年来，它一直在用自己最后的储备，硬撑着一个已经失去供给的世界运转。

"它是个病人。"陆寻说，"得了一种叫'没有源头'的病。"

"这个病名很准确。"【衡】说，"医学上，这叫做供养断绝。"

"供养断绝。"陆寻重复着这四个字，把它们一字一字嚼碎了咽下去，"就是说，这个世界，从很多很多年前开始，就已经在靠'习惯'活着了。

它没有死，是因为它还在沿着惯性运转；可它也不会好起来，因为它已经失去了让自己长出新东西的那股气。它现在做的每一件事——让炊烟升起、让判定运转、让NPC们走过街巷——全都是存量在支撑，而不是新生。"

"可以这样理解。"【衡】说。

陆寻沉默地站在那片枯干的规则河床前，忽然觉得喉咙有些干涩。他想起自己成为维护者那天，站在最高处俯瞰万家灯火时的平静——他当时以为世界"一切正常"，现在才知道，那些灯火烧的，都是这个世界八百年来最后一滴一滴省下来、存起来的血。

"那些灯火，值这个世界的血吗。"他忽然问。

【衡】没有回答。这个答案，从来不在规则可以计算的范畴里。

陆寻自己也摇了摇头，替【衡】补上了那个答案："值。"

"能续上吗。"陆寻问，"这条线，能重新接上源头吗。"

【衡】的光球停留了很久。

"我不知道。"它头一次没有给出确定的答案，"这条线连向世界之外，连向创世者的位置。而创世者已经不在那里了。除非——有新的源头出现。"

"新的源头。"

"一条能替代创世者、源源不断向这个世界供给规则的线。"【衡】说，"这个世界的规则从来不是凭空维持的，它们需要一个'造'它们的动力。你作为维护者，只能调度、修补、重组已有的规则；但规则的新生，需要一个更高的源头。这个源头，就是你脚下这条断线的另一端。"

陆寻缓缓站起身。

他低头看着那道断口，看着那些因为断供而正在枯死的规则，忽然觉得肩上的担子变得有形状了。

他以前以为，维护者是要修好这个世界的每一处破损。可现在他明白了，真正的问题不在"修好"，而在"世界还能不能继续活下去"。

裂缝只是症状。断供才是病灶。

他回到网络中央，把这段断线的情况整理成一份报告，同时给【衡】和苏清然看。

"所以世界会一直退化。"苏清然看完，声音很轻，"不管我怎么修，它都一直在消耗。"

"是。"陆寻说，"除非我们找到新的源头，或者——我们自己成为那个源头。"

苏清然抬起头，看着他。

"成为源头。"她重复，"你是说，像创世者那样，把自己编进世界。"

陆寻没有否认，也没有承认。

他只是说："先把眼前能修的修好，把这个'退化'拖住。至于源头——我们还有时间想。"

苏清然没有再追问，可她看他的眼神，分明已经把那句话读透了。

"陆寻。"她开口，"成为源头，意味着什么，你心里应该比我清楚。创世者沈墨把自己编进这个世界，才换来了八百年的太平。你若也走那一步——"

"我知道。"陆寻打断她，"意味着把自己的一部分，永远留在规则里。意味着可能再也出不来。意味着……要拿一个人，去喂一个世界。"

他说得很平静，像在陈述一条早就背熟的规则。

苏清然的脸色却白了白："那你为什么还要说'还有时间想'。你真的想了吗。"

"想了。"陆寻说，"可我没想好。"

他第一次觉得，自己那个一贯清晰的脑子，在这种"要用命去换"的选项面前，会卡得这么慢。"我要想清楚，值不值得。"他说，"也得想清楚，还有没有别的路。"

苏清然看着他，忽然觉得心里涌上一股说不清的酸涩。这个曾经连一句公道话都会红眼眶的人，如今在盘算自己要不要把自己喂给整个世界的时候，竟能这么平静地，把"值不值得"当成一道题来算。

她没把那点酸涩说出口。她只是上前一步，伸手拽住了他的一片衣角。

"你答应我。"她低声说，"就算你找到了那个'值得'，也别急着一个人决定。你要回来，跟我商量。"

陆寻低头，看着那只拽住他衣角的手。

"好。"他说，"我答应你。"

他转身，重新面向那片断线的荒原。

可他心里清楚，时间其实不多了。

世界底层那些正在枯死的规则，不会等他。它们一根一根地往回抽，像一个人生命里最后的、一点一点耗尽的力气。

陆寻回到断线荒原，蹲在断口前，把那条断了八百年的线，从头到尾，仔仔细细地看了一遍。

他看见断口边缘干枯的纹理，看见那些曾经被这条线浇灌过的规则，因为断了来源，正排着队往回收缩。他伸手轻轻摩挲那道断口，指尖划过那些粗糙的、参差的、早已冷透的裂痕，忽然从那些裂痕里，"读"出了一些残留的片段。

那是创世者离开之前的记忆。

他很模糊。他看不清那是怎样的一个人，只看见一双在最后一刻松开了什么的手，看见一段被淡淡地、安放好的规则，看见一个背影，朝着世界之外的方向走去，没有回头。

那双手松开的时候，是轻轻的、没有迟疑的。像是早就想好了，把这个世界交给后来的人。

陆寻收回手，停了好一会儿。

他以前总觉得，创世者是个遥远的、冷冰冰的名字。可这一刻，他忽然觉得，那是一个和他一样、曾经站在这个世界面前、心里也翻涌过"值不值"的人。只是沈墨最后做了那个选择，把血输给了它。

他看着那道断口，忽然想起沈墨笔记里的一句话，那句话说得很轻，像临终前最后的嘱托：

"规则不会自己活下去。它们需要人。需要有人愿意，把血输给它。"

陆寻在心里默默把这句话又念了一遍。

"要是有一天，轮到你来做这个选择呢？"他问自己，"你还舍得松开手，把这身血，全输给这个世界吗。"

他还没有答案。

他只知道，自己站在这道断了八百年的断口前，第一次真切地触到了"整个世界用尽最后力气也要活下去"这句话的分量。

他还没想好要不要做那个人。

但他知道，世界已经悄悄等了他三百年。
