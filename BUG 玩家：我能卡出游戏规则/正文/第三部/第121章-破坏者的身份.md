# 第121章 破坏者的身份

破坏者的身份

永恒帝国的代表离开后，陆寻开始调查这个世界的背景。他通过共鸣网络，收集了关于永恒帝国的信息。

【永恒帝国信息扫描中...】
【世界名称：永恒帝国】
【世界状态：完整】
【世界历史：约10000年】
【规则体系：古代规则体系】
【世界内生命体数量：约5.2亿】
【世界实力评估：极高】

陆寻看着这些信息，皱起了眉头。一万年的历史——这意味着永恒帝国是多世界体系中最古老的世界之一。古代规则体系——这意味着它的规则体系比其他世界要古老得多，也强大得多。五亿两千万的生命体——这意味着它的人口比寰宇神域还要多。极高——这意味着它的实力远超其他世界。

"这个世界...很不寻常。"

苏清然点头："一万年的历史...这意味着它可能见证过多世界体系的创建过程。"

"对。它可能知道一些我们不知道的事情。"

他继续调查，发现了更多关于永恒帝国的信息。永恒帝国的统治者自称"永恒之王"，它拥有强大的规则之力，能够操控多种规则。更重要的是，永恒之王声称自己是创世者的第一件作品——多世界体系中第一个被创造出来的世界。

"第一个被创造出来的世界？这意味着什么？"

"这意味着它可能拥有创世者留下的特殊力量。也意味着它可能知道创世者的真正意图。"

陆寻点头。他决定亲自前往永恒帝国，与永恒之王对话。

"你确定？永恒帝国可能很危险。"

"我知道。但我必须去。如果永恒帝国真的拥有创世者留下的特殊力量，我需要了解它。"

苏清然沉默了片刻，然后说："那我和你一起去。"

"不。你留在这里，维持联盟的稳定。如果我出了什么事，联盟需要你。"

苏清然想要反驳，但她知道陆寻说的是对的。"小心。"

"我会的。"

他转身，朝永恒帝国的方向飞去。永恒帝国位于规则维度的最深处，被重重壁垒保护着。陆寻花了三天时间才到达那里。当永恒帝国出现在他面前时，他被震撼了。那是一个由金色和白色构成的世界——金色的宫殿、白色的城墙、闪烁的光芒。整个世界都散发着一种古老而强大的气息。

"这就是永恒帝国。"

他降落在永恒帝国的边境，立刻被一群士兵包围。"你是谁？为什么闯入永恒帝国？"

"我是寰宇神域的维护者。我来见永恒之王。"

士兵们面面相觑。"维护者？你有什么资格见永恒之王？"

"我有重要的事情要和他谈。关于多世界的未来。"

士兵们犹豫了片刻，然后说："你在这里等着，我去通报。"

一个小时后，领头的士兵回来了。"永恒之王愿意见你。跟我来。"

陆寻跟着士兵走进了永恒帝国。永恒帝国的内部比外面看起来要宏伟得多——金色的走廊、巨大的雕像、闪烁的水晶灯。每一个细节都彰显着永恒帝国的富饶和强大。

陆寻被带到了一座巨大的宫殿前。宫殿的大门缓缓打开，露出了里面的景象。一个身影坐在宫殿的中央——那是一个由金色光芒构成的存在，拥有人类的形态，但全身都散发着古老而强大的气息。

"你就是永恒之王？"

"对。我就是永恒帝国的统治者，多世界体系中第一个被创造出来的世界。"

陆寻看着永恒之王，感受着它身上的力量。那种力量...比他想象的要强大得多。

"你来这里做什么？"

"我来邀请你加入联盟。"

永恒之王笑了："联盟？那个由弱小世界组成的联盟？"

"联盟不是由弱小世界组成的。联盟是由愿意和平共处的世界组成的。"

"和平共处？在多世界体系中，和平共处是不存在的。只有强者才能生存。"

陆寻沉默了。他知道，永恒之王的观念来自于它的经历——作为最古老的世界，它见证过多世界体系的兴衰。在它看来，只有强者才能生存，弱者只能被淘汰。

"你说得不对。"

"哦？那你说说看，什么是对的？"

"和平共处是对的。多世界体系之所以衰败，正是因为各个世界之间互相争斗。如果它们能够和平共处，多世界体系就不会衰败。"

永恒之王沉默了。"你的想法...很天真。"

"不是天真。是信念。我相信，只要坚持正确的道路，就能创造一个和平的世界。"

永恒之王看着陆寻，眼中闪过一丝复杂的神色。"你和创世者...很像。"

"创世者？你见过创世者？"

"当然。我是他创造的第一个世界。我见过他，也听过他的话。"

"他说了什么？"

"他说...他创造多世界体系的目的，是让所有生命都能和平共处。但他失败了。各个世界之间互相争斗，导致多世界体系衰败。创世者试图阻止，但失败了。于是，他把自己的力量分散到所有世界中，然后消失。"

陆寻沉默了。这和他在创世者档案中看到的信息一致。"所以，你拒绝加入联盟，是因为你不相信和平共处是可能的？"

"对。和平共处只是创世者的幻想。在多世界体系中，只有强者才能生存。"

陆寻摇头："你错了。和平共处不是幻想。它是我们必须实现的目标。如果我们不实现它，多世界体系就会彻底衰败。"

永恒之王沉默了。"你说的话...让我想起了创世者。他也说过类似的话。"

"那你觉得，他说得对吗？"

永恒之王沉默了很久。"我不知道。但我知道一件事。"

"什么？"

"如果你真的能实现和平共处，我会加入联盟。"

陆寻的眼睛亮了起来："你确定？"

"确定。但你必须证明给我看。"

"我会证明的。你等着。"

他转身，准备离开永恒帝国。"等等。"

"什么？"

"创世者在消失之前，留下了一件东西。他说，这件东西会在关键时刻帮助多世界体系。"

"什么东西？"

"规则之心。创世者把自己的核心力量凝聚成了一颗心脏，藏在了规则维度的最深处。他说，当多世界体系面临毁灭时，规则之心会拯救它。"

陆寻的瞳孔猛地收缩。规则之心——创世者的核心力量。如果他能找到规则之心，就能阻止创世者的计划，也能拯救多世界体系。"你知道规则之心在哪里吗？"

"不知道。但我知道，它在规则维度的最深处。你需要自己去找。"

陆寻点头："谢谢你。"

他转身，离开了永恒帝国。他现在有两个目标：一，证明和平共处是可能的，让永恒帝国加入联盟。二，找到规则之心，阻止创世者的计划。这两个目标都很困难。但他不会放弃。为了寰宇神域，为了联盟，为了所有生命的未来。
