# 人物档案

## 陆寻（主角）
- 18 岁，高三应届生。冷静、寡言、行动派。被嘲讽时不辩解，用结果说话。
- 天赋【规则偏移】：觉醒日显示为「废稿·无效果」，全服唯一。
- 面板真实信息（仅陆寻可见）：`【规则偏移】——判定真空 0.01s。可叠加？（未验证）`
- **成长线（详细）**：
  - 第一部（001-050）：单点卡判定 → 叠加悬置 → 冻结岚风城3秒（极限）→ 首次编写规则
  - 第二部（051-100）：深层规则操控 → 与原始规则意志对话 → 修复规则网络 → 成为"维护者"
  - 第三部（101-150）：世界维护者 → 多世界规则协调 → 击败古老世界 → 成为"仲裁者"
  - 第四部（151-200）：仲裁者 → 高维存在对话 → 规则重构 → 规则之父

## 苏清然（女主）
- 同班第一，18 岁。天赋 S 级【秩序回响】：强化一切"合规"技能效果，必中类技能自带判定加成。
- 职业预备选手（天穹青训挂名），守规矩的顶级强者。
- 弧光：惋惜 → 疑惑 → 震撼 → 公开反公会抉择 → 无条件信任 → 牺牲与重生 → 规则之母。
- 暗线：她的天赋是系统正统规则的"代言人"，能隐约看见规则纹理；与主角天赋同源对立（F-004）。
- **天赋进化**：S级【秩序回响】→ 规则可视化 → 规则共鸣（035章）→ 定规之钥（051章后）→ 规则创造（166章）→ 规则之母（终章）。
- **代价**：每次大规模使用秩序回响都会对意识造成损伤，过度使用会被规则同化（编号005的前车之鉴）。
