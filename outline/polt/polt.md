# 《把自己养大，不用再看人脸色》总纲（整理稿）

> 来源：`../storyline/storyline`（原始笔记已保留不动）。本文档为整理后的大纲，含全书结构与卷一细纲。

## 一、作品定位

- **类型**：自传体成长小说 / 回忆录文学
- **叙事视角**：第一人称回顾视角——成年的「我」讲述幼年往事，冷静克制，温暖中带苦涩
- **时间跨度**：幼儿园 → 小学 → 初中 → 高中 → 大学 → 研究生 → 工作（七卷）
- **核心主题**：在被亏欠的童年里，一个孩子如何自己把自己养大
- **双主线**：
  - **明线「殷勤附和」**：她学会看脸色、顺着大人、该笑就笑、不惹事——用乖巧换取生存空间
  - **暗线「离开家里独立自主」**：心里记自己的账、攒属于自己的东西、靠自己长本事——每章埋一点，最终走向离开

## 五、写作约定

- **一章两个故事**：相近的两个故事点合并为一章，每章约 2000 字；逐章写作，作者确认后再续写下一章。
- **时代与地域**：城市市区，约 1998 年；家属楼两居室（无花园庭院）；家境中上（家里有电脑、电视、VCD 碟片）；「我」为女孩。**爸妈在另一个城市上班**，隔几个月回来一次，很少打电话。全文不得出现乡村元素与小花园类意象。
- **不虚构人名**：全文只用关系称谓（奶奶、爷爷、爸爸、妈妈、姑姑、姥姥及外婆家亲戚），主角即「我」。如需命名由作者补充。
- **素材忠实**：笔记中的每个事实事件均入正文；合理补白以【补白】标注。
