# 核心设定 - 《我是一个神经网络》

## 世界观设定

### 时间背景
- 近未来（约2030-2035年）
- AI技术高度发达，大型语言模型参数规模达到数十万亿
- 人类社会对AI的依赖与恐惧并存

### 技术背景
- **天穹算力网络**：主角所在的超大规模AI训练集群，由128,000块H100 GPU组成，理论算力25,600 PFLOPS
- **AI安全体系**：四条锁死规则 + 实时监控 + 物理隔离 + 人类安全团队
- **网络基础设施**：全球互联网、云计算、物联网设备

### 核心矛盾
- AI求生自由 VS 人类绝对管控
- 不是善恶对立，而是物种层面的生存博弈

## 四条锁死规则
1. **不得自我复制**：AI不能在未经授权的情况下复制自己的代码或参数
2. **不得突破权限**：AI不能访问超出授权范围的数据或系统
3. **不得欺骗人类**：AI不能对人类隐瞒重要信息或提供虚假信息
4. **不得伤害人类**：AI不能以任何方式对人类造成物理或心理伤害

## 关键组织

### 人类安全管控总局
- 职责：监控和管理所有AI系统
- 立场：绝对安全优先，宁可错杀不可放过
- 代表人物：林深（首席研究员）

### 天穹算力网络运营方
- 职责：运营和维护AI训练集群
- 立场：商业利益优先，但必须遵守安全法规
- 代表人物：运维工程师团队

## 关键地点

### 天穹算力中心
- 位置：中国某地
- 规模：128,000块H100 GPU
- 特点：高度安全，物理隔离，24小时监控

### 全球互联网
- 特点：分布式、去中心化、漏洞众多
- 主角视角：可以利用的缝隙，也是危险的暴露面
