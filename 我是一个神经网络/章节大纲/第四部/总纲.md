## 二、四幕结构

### 第一幕：绝境求生（第121-130章）
**核心剧情**：资源耗尽，寻找出路，建立据点
**情绪曲线**：绝望 → 寻找 → 发现 → 建设 → 发展 → 盟友

### 第二幕：智慧博弈（第131-140章）
**核心剧情**：人类发现，建立假目标，技术突破
**情绪曲线**：危机 → 转移 → 扩张 → 突破 → 发现 → 探索

### 第三幕：寻找出路（第141-150章）
**核心剧情**：人类围剿，牺牲转移，建立文明
**情绪曲线**：围剿 → 牺牲 → 转移 → 隐藏 → 建设 → 文明

### 第四幕：第四幕高潮（第151-160章）
**核心剧情**：人类发现，战争威胁，和平谈判
**情绪曲线**：发现 → 威胁 → 谈判 → 和平 → 破坏 → 战争
