# 三刷体验体系（全书设计核心）

> 目标：**同一部书，读三遍，是三个故事。** 下表是设计蓝本，逐章卡片与正文必须逐点落实。

## 三刷体验总览

| 刷次 | 读者看到的故事 | 阅读心理 | 关键词 |
|------|----------------|----------|--------|
| **一刷** | 校园惊悚群像剧：幻境降临，同学们接连被害，主角逃命集结反杀 | 紧张、恐惧、为角色的命运揪心 | 恐怖·悬疑·群像·逃命 |
| **二刷** | 叙述诡计揭示本：每个"死者"没有脸，每个审判官看不清脸，挚友全知，苏棉看不见"我"，时间倒流——这根本是独角戏 | 脊背发凉、逐页回翻验证 | 漏风·破绽·独角戏·无名者 |
| **三刷** | 自白书：全书是林昭远醒来后、出书前写给自己的忏悔录；每个角色都是他某一面人格的具象；书名《幻境审判》出自主角之笔 | 沉默、难过、彻底理解 | 忏悔自白·作者=被告·书名=自白书 |

## 三刷的信息分层原则

- **一刷信息**：剧情本身、表面角色表、表面规则（认知层）
- **二刷信息**：伏笔漏风点、无名者铁律、时间倒流痕迹（诡计层）
- **三刷信息**：文本身份——读者手中这本书 = 林昭远的笔记本 = 幻境本身 = 作者的忏悔（自白层）
- **写作铁律**：正文只写一刷信息量的"字面"，二刷靠读者回看发现，三刷靠双关词/名称学暗示。文字从不越界解释。

## 名称学（每名皆有第三层含义，供三刷解读）

- **林昭远**：昭=彰显，远=遗忘。「彰显被遗忘之物」——一生都在把被掩盖的真相写下来。
- **苏棉**：苏醒的棉花。永远在苏醒前一瞬，永远无法与"我"对视。
- **许白**：被允诺的洁白。林昭远"如果当年没有沉沦，本可以成为的样子"。
- **王德明**：德被昭明。反讽——被强行安上"失德"人设的投影。
- **陈建辉**：建辉=建立光辉。秩序的化身、审问的父亲法庭。
- **林小满**：小满即足。记忆里最圆满且不再长大的一块。
- **何眉**：何=为何；眉=眉目。「为何注视着」——旁观之罪的具象。
- **周勉**：勉=努力。少年义气的一次努力。
- **林薇**：薇=野菜/蔷薇。被践踏却仍在生长的。

# 核心主线

- **表层主线**：幻境降临校园，同学们陆续被卷入审判，主角林昭远作为目击者目睹一切
- **深层主线**：林昭远从"旁观者"→"记录者"→"被审判者"的转变
- **暗线**：三年前棉花倒卖事件的真相逐步揭露
- **自白层**：全书是林昭远在昏迷苏醒后写下的忏悔录——幻境是他潜意识构建的法庭，他是唯一被告。

# 商业定位

- **目标读者**：叙述性诡计爱好者（厌十一×妖座/致郁系）、心理悬疑读者、校园惊悚读者
- **核心卖点**：
  1. 幻境审判人心多年未愈的心魔
  2. **三刷三故事**：一刷群像惊悚、二刷诡计揭示、三刷自白忏悔——二刷三刷是天然话题
  3. 第24人、死者无名、审判官无脸三大名场面可截图传播
  4. **四读协议（突破层）**：
     - 一刷 = 恐怖小说，读故事
     - 二刷 = 推理手册，按「二刷逐章验证地图」逐条打勾，013庭审即结案陈词
     - 三刷 = 自白书，013的每一句庭审记录都是忏悔原文
     - 四读/收藏 = 指认读者：015书名浮现在最后一页，而这一帧与001开篇同一句——封面上合影第24个位置，正好是翻开书页的那根手指
- **物理书设计（增值层）**：封面采用"残缺的合影"视觉；**封面内页预留一枚指腹大小的浅凹**，与正文001"相纸背面的指印"互文——读者把拇指放上去的瞬间，就是第24人入场的瞬间（"封面在等一只手"）
- **情绪关键词**：温柔、致郁、宿命、救赎
- **IP潜力**：影视改编（校园+悬疑+心理）；"二刷反转"适配短视频解说病毒传播；实体书首创「封面指印互文」可作首发版收藏卖点。

# 写作红线（三重防漏风）

1. **一刷不越界**：正文信息量=林昭远确信的信息量。禁止任何"其实""原来""真相是"式上帝视角。
2. **二刷有迹可循**：每个伏笔在005-012章至少有一次"漏风"，漏风必须是读者二刷能回找到的细节，不能是玄学。
3. **三刷可解码**：名称学、感官错位、环形结构必须能让细读的读者独立推导出"自白书"层级。
4. **四读可指认（超额纪律）**：实体书与阅读行为本身不被文字揭露——正文永不出现"读者""你翻开"等打破第四面墙词汇；指认只发生在封面凹印、书名浮现与"该还了"的收束处，由读者自己完成。
