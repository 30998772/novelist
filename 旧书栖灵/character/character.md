# 《旧书栖灵》人物档案

## 主角

### 陆栖
- 二十六岁，南枝文献馆管理员。名字取「鸟歇于木」——他自己要到很久以后才懂这个名字的分量
- 自幼能看见书灵：小时候说漏嘴被当成怪孩子，从此学会闭嘴；习惯一个人、习惯把温柔藏在动作里而不是话里
- 弧线：藏起能力的孤单者 → 被小灵们需要的守护者 → 学会目送离别的人 → 与自己的能力与孤单和解的人（ch35）
- 习惯细节：说话轻、走路轻；随身带软毛刷和棉线（修书用）；冬天手冷，捧着搪瓷杯取暖

### 顾松年
- 七十岁上下，老馆长，守馆四十年。知道馆里的「老规矩」（留灯、晒书），也隐约知道陆栖能看见什么，从不多问
- 功能：人间线的温度来源；档案与往事的钥匙（ch18 揭露阿棠生平）；后期把馆务交给陆栖

## 贯穿长线

### 诗灵·阿棠
- 民国末藏书楼主的独女，爱诗的女学生，十九岁病逝；手抄诗集《未刊诗草》想送给学堂的孩子们，未及付印
- 魂栖书中六十年：透明身影，只有黄昏才显形；不敢靠近人，怕自己散掉
- 推进线：ch1 初遇 → ch6「困在这里六十年」→ ch12 碎片自述 → ch18 完整揭露（得知名字）→ ch25 被读懂（执念落地）→ ch26 随风远行，留下无题最后一首诗 → ch34/36 以晚风的方式年年回来
