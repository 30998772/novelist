# 《旧书栖灵》创作资料库 -- 夏目

## 项目概述

《旧书栖灵》是一部夏目式治愈小说，讲述能看见书灵的青年陆栖在小城文献馆工作，用一个又一个温柔的单元故事接住旧书里的孤单与遗憾的故事。

- 系列：6部、410章、约150万字
- 第一部：60章×3500字≈24万字（陆栖27→42岁）
- 结构：10卷×6章
- 全系列时间跨度：约48年（陆栖27岁→75岁）

## 核心卖点

1. **纯治愈设定**：无反派、无争斗、无虐心
2. **书灵世界观**：独特的旧书精灵设定
3. **单元剧结构**：每章独立故事，新鲜不枯燥
4. **贯穿长线**：诗灵阿棠的故事串联全书
5. **温柔余韵**：每章结尾用余韵收束
