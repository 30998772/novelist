# 《旧书栖灵》创作资料库

## 项目概述

《旧书栖灵》是一部夏目式治愈小说，讲述能看见书灵的青年陆栖在小城文献馆工作，用一个又一个温柔的单元故事接住旧书里的孤单与遗憾的故事。

- 正传：36章×2000字=7.2万字
- 结构：6卷×6章

## 内容说明

### 设定
- **世界观设定/**：书灵、栖息地、显形条件、三大铁律
- **角色设定/**：主要角色和各书灵的详细档案

### 章节大纲
- **总纲.md**：全书定位、分卷主题、伏笔登记表
- **逐章卡片.md**：36章的POV、场景、目标、冲突、钩子

### 正文
- 已完成36章正文

## 核心卖点

1. **纯治愈设定**：无反派、无争斗、无虐心
2. **书灵世界观**：独特的旧书精灵设定
3. **单元剧结构**：每章独立故事，新鲜不枯燥
4. **贯穿长线**：诗灵阿棠的故事串联全书
5. **温柔余韵**：每章结尾用余韵收束
