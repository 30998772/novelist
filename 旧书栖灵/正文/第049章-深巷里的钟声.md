# 第049章 深巷里的钟声

陆栖第一次听见钟声，是在入职南枝文献馆的第三个月。

那天夜里他加班整理一批民国旧刊，忙到快十一点才收拾东西准备走。楼梯口的马灯还亮着，火苗很稳，铜铃铛在灯光下泛着淡淡的金色。他正要关灯，忽然听见一声低沉的钟鸣——

当——

声音从楼下传来，沉闷、悠长，像一个人在很远很远的地方喊了一声，隔了很久才传过来。他停住脚步，侧耳听了一会儿，钟声没有再响。他以为自己听错了，关了灯，摸黑下楼。

走到一楼大厅的时候，他看见了那座钟。

是一座老式的座钟，木壳，铜面，摆在大厅角落的条案上。钟面已经发黄，指针停在十二点零三分的位置，一动不动。他白天经过无数次，从来没留意过这座钟。此刻他走近了看，钟摆是歪的，悬在那里，像一条晒干了的鱼。木壳上的漆剥落了大半，露出底下灰白色的木质，像老人脸上的斑。铜面上有一道浅浅的划痕，从十二点的位置一直划到六点，像一道细细的伤疤。

他伸手碰了碰钟面。凉的。冰冰凉凉的，像碰到了冬天的铁门把手。

他正要松手，忽然听见极轻的一声——嗒。

不是钟声，是什么东西落在木壳上的声音。像一滴水落在老木头上面，闷闷的，小小的。他低头看，钟面上什么都没有。他把手缩回来，盯着那座钟看了一会儿，转身走了。

走出文献馆的大门，他回头看了一眼。二楼的灯已经灭了，整栋楼黑黢黢的，只有门廊下那盏路灯还亮着，昏黄的光照在青石板上。他想了想，又走回去，推开虚掩的门，走到那座钟前面。

"是你在响吗？"他轻声问。

没有人回答。钟摆还是歪的，指针还是停在十二点零三分。他站了一会儿，把手贴在木壳上，感觉到一阵极轻极轻的震动，像心跳，又像呼吸。他收回手，转身走了。

第二天他去问顾松年。

"大厅条案上那座座钟，还能走吗？"

顾松年正在喝茶，听了这话，手里的搪瓷杯顿了顿。"那座钟啊，"他说，"放了有四十年了吧。我来的时候它就不走了。"

"谁放的？"

"不知道。我来的时候它就在那儿了。以前的人也没提过。倒是有一年台风天，馆里进水，我把那座钟搬出来过一回。沉得很，两个人才抬得动。搬出来的时候我看见钟摆底下刻着一行字，太小了，没看清。后来水退了又搬回去，就再也没动过。"

陆栖回到大厅，站在那座钟前面，仔仔细细地看了一遍。钟的底座刻着一行小字，字迹模糊，他凑近了才看清："永记钟表行，民国二十三年制。"

民国二十三年，一九三四年。这座钟九十多岁了。

他又蹲下来看钟摆的底部。果然有一行更小的字，刻得很浅，像是用指甲划的："等我回来。"三个字，歪歪扭扭的，最后一笔拖得很长，像一个人写到一半忽然哭了出来。

他盯着那三个字看了很久。月光从天窗落下来，照在那三个字上面，字迹泛着微微的银光，像一个很久以前的愿望，还在发光。

晚上他躺在床上翻来覆去睡不着。那三个字一直在他脑子里转——等我回来。谁写的？等谁回来？那个人回来了没有？他想到那道划痕，从十二点到六点，半圈，像一个人走了半辈子的路，忽然停住了。他又想到自己——他在这栋楼里，是不是也在等什么？等那些看不见的邻居开口说一句话？等那盏马灯的火苗跳一下？等那本蓝布封皮的书翻开一页？

他不知道。他只知道，他愿意等。

第二天，他去找了巷口的裁缝铺老陈。老陈在南枝巷住了六十多年，什么事都知道。

"文献馆大厅里那座钟？"老陈放下手里的剪刀，想了想，"哦，你说那个大家伙啊。我小时候就见过。听我爷爷说，那是民国年间永记钟表行的老师傅做的。老师傅姓周，手艺很好，整条巷子的钟表都找他修。后来他儿子出去当兵，说打完仗就回来。老师傅就做了这座钟，说要等儿子回来。"

"等到了吗？"

老陈摇了摇头。"没有。他儿子走了就没回来。老师傅等了二十年，走了。钟还在那儿。后来文献馆收了这栋楼，钟就一直摆在大厅里。"

陆栖沉默了一会儿。"那道划痕呢？钟面上那道。"

"什么划痕？"老陈不明白，"我只知道那钟面上以前有幅画，画的是个小人儿，站在门口，好像在等人。后来不知道怎么的，画就花了，只剩一道印子。"

陆栖回到文献馆，又去看那座钟。他凑近了铜面，在光线下仔细辨认。果然，那道划痕不是划痕，是一幅画的残影——一个极小极小的人影，站在一扇门前面，歪着头，像是在往远处看。人影只有指甲盖那么大，线条模糊，可他还是看出来了，那是一个孩子的姿态。

他在钟前面站了很久。

那天夜里，他又加班。

十一点的时候，他正在二楼整理书目，忽然又听见了那声钟鸣——

当——

比昨天更清晰一些，也更近一些。他放下笔，循着声音走下楼。大厅里黑着灯，月光从天窗落下来，照在条案上。那座钟还是老样子，一动不动。可他分明听见了声音，不是从钟里发出来的，是从钟的旁边——从空气里，从木壳和铜面之间的缝隙里，从那些剥落的漆皮底下。

他走近了。

月光下，他看见钟面上有一团淡淡的光，像一小团雾。光很薄，几乎透明，在月光里微微地颤，像一只受了惊的蝴蝶。他蹲下来，和那团光平视。

"是你。"他说。

光颤了一下，缩了缩，像是被他吓到了。

"别怕，"他说，"我不是坏人。我是这儿的管理员。"

光又颤了一下，慢慢地，不那么抖了。它在钟面上游移了一圈，最后停在那道浅浅的划痕上面，像一个人用手指摸着自己脸上的伤疤。

"你一直在走？"他问。

光没有回答。可他感觉到一阵极轻极轻的震动，像齿轮在努力转动，像发条在拼命拧紧，又像一个老人在深深地吸气，准备说一句等了很久的话。

当——

钟声响了。很轻，很闷，像隔了一层厚棉被。可在这安静的夜里，这声闷响却传得很远，穿过大厅，穿过走廊，穿过天井，一直传到巷子外面去。

陆栖没有动。他看着那团光慢慢亮起来，从淡白色变成暖黄色，像一盏被点亮的小灯。光在钟面上画了一个圈，然后慢慢地、慢慢地往钟的内部渗进去。他看见齿轮上泛起了一层极淡的金色，像生锈的铁器被什么东西温柔地擦过。

"你一直在等。"他说。不是问，是陈述。

光没有回答。可他感觉到空气里弥漫开一股暖意，像冬天的炉火，像夏天的晚风，像一个人终于被理解时的释然。

他站起来，走回二楼。坐在书桌前，翻开笔记本，写了一行字：

"大厅座钟灵。守时。等了四十年，仍在走。"

从那以后，每到夜里十一点，钟声会准时响起。当——，当——，当——，一共三声，沉闷、悠长，像一个人在很深很深的夜里，轻轻地叹了一口气。

陆栖加班的时候，总会在十一点停下来，听那三声钟响。有时候他会在心里跟着数：一、二、三。数完了，他笑一笑，继续干活。有几次他会在钟响的时候走到大厅，站在钟前面，和那团光一起沉默。光在他身边绕一圈，像是在说晚安，然后慢慢地落回钟面上。

有一次他忘了加班，夜里在家里听见了钟声。声音从很远的地方传来，穿过巷子，穿过窗户，落在他的枕头上。他睁开眼，听见当——当——当——三声，然后一切归于寂静。他想，那座钟是怕他听不见，特意穿过半条巷子来告诉他：我在走。你放心。

他翻了个身，又睡着了。

那年冬天特别冷。十二月的一个深夜，文献馆的暖气管冻裂了，热水淌了一地。陆栖半夜接到电话，裹上棉袄赶过来。进门的时候他看见大厅里一片狼藉，地上全是水，条案的腿泡在水里，那座钟摇摇欲坠。

他冲过去，把钟抱起来。

钟很沉，沉得像一个成年人的体重。他把它抱到干燥的地方，用袖子擦干木壳上的水。铜面凉得刺骨，他的手指贴上去，感觉像是贴在冰块上。木壳泡了水，颜色变深了，像哭过的眼睛。

"没事了，"他轻声说，"没事了。"

那团光从钟面上浮了出来，比以前亮了一些。它在他手边绕了一圈，像一只关切的小鸟，然后慢慢地落回钟面上。他感觉到指尖传来一阵微弱的暖意，很轻很轻，像一个老人在用尽最后一点力气握住他的手。

他把钟抱到自己的办公室，放在暖气旁边。那天夜里他在办公室睡了一晚，守着那座钟。夜里他醒了几次，每次醒来都看一眼钟面——光还在，安安静静的，像一只闭着眼睛睡觉的小动物。

第二天早上他醒来，看见钟面上的那团光已经安安静静地融了回去。钟摆微微地晃了一下，指针从十二点零三分的位置，往前走了一格——十二点零四分。

他盯着那根指针看了很久。

四十年了，它往前走了一格。

后来他把钟搬回了大厅。条案换了新的，钟摆在那上面，端端正正的。他每天早上经过的时候，都会看一眼指针——十二点零四分，十二点零五分，十二点零六分。

它在走。

很慢很慢地走，一天走一格，像一个拄着拐杖的老人，一步一步地往前挪。走得慢，可从来没有停。

巷子里的邻居们也渐渐注意到了。裁缝铺老陈路过的时候探头看了一眼："哟，这钟在走了？"卖豆腐的张婶说："我说最近夜里怎么老听见钟声，原来是它在响。"连巷口小卖部的老板娘都说："这钟走了几十年都没走，现在忽然走了，怕是成精了。"

陆栖听了，只是笑笑，不说话。

那年除夕，文献馆放假。陆栖锁门之前，走到大厅，站在那座钟前面。外面的鞭炮声噼里啪啦地响，烟花在天上炸开，五颜六色的光从天窗落进来，照在钟面上。

指针指向十二点零八分。

"新年快乐。"他轻声说。

钟面上的那团光亮了一下，暖黄色的，像一盏被风吹动的小灯。他听见极轻的一声嗒，像齿轮咬合的声音，又像一个人在说"你也是"。

他笑了笑，转身走了。

走出文献馆的大门，回头看了一眼。二楼的灯灭了，可大厅的窗口透出一点微弱的光，暖黄色的，一闪一闪的，像一颗很老很老的星星。

巷子里的风很冷，他裹紧了棉袄，往家的方向走。走了一段路，他忽然听见身后传来钟声——

当——当——当——

三声，沉闷、悠长，在除夕的夜空里飘得很远。他停下脚步，站在巷口，回头望去。文献馆的轮廓在烟花的光影里安安静静地立着，像一个守着什么的人。

他听完了三声钟响，笑了笑，转身继续走。

那座钟走了四十年，等了四十年，终于等到了一个人，愿意在深夜里蹲下来，听它说话。它往前走了一格，又一格，像在说：谢谢你听见了我。

陆栖走在回家的路上，巷子两旁的门缝里透出暖黄的灯光，有人在包饺子，有人在看春晚，鞭炮声此起彼伏。他想，这栋楼里有那么多看不见的邻居，它们各自守着各自的位置，等了那么久。他能做的，不过是每天来看看它们，换一盏灯，泡一杯茶，在它们需要的时候伸一把手。

不，它们大部分都不说话。它们只是在那里，安安静静地在那里。这就够了。

他回到家，推开门，屋里很暗。他没有开灯，在黑暗中站了一会儿，然后走到窗边，拉开窗帘。巷子尽头，文献馆的灯光已经看不见了，只有夜空中的烟花还在绽放，一朵一朵的，亮了又灭，灭了又亮。

他想，那座钟现在在想什么呢。它走了四十年，终于往前走了一格。它是不是也像他一样，在这样一个夜里，安安静静地站着，想着一些很远很远的事。

他不知道。他只知道，明天早上六点，他会准时到馆，打开大门，看见那座钟安安静静地立在条案上，指针比昨天多走了一格。

这就够了。

他拉上窗帘，上床睡觉。夜里他又听见了钟声，很远很远的，像从梦里传来的。当——当——当——

三声。

他睡得很安稳。
