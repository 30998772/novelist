# 第054章 陆栖的笔记本

陆栖有一个笔记本。

不是什么贵重的本子，就是最普通的那种，封面是深蓝色的硬纸板，内页是泛黄的横线纸。他在县城的文具店里买的，花了三块五。本子的边角已经磨毛了，封面上沾着几块茶渍，纸页翻得多了，变得软软的，像一件穿旧了的衣裳。

这个笔记本他用了二十年。

第一页写着一行字："南枝文献馆住户名录。"字迹很小，一笔一画，像在完成一件很重要的事。下面是一行一行的名字——不是人的名字，是书灵的名字。

他给每一个他见过的书灵都取了名字。

绘本区那团绒毛，他叫它"小棉"。因为它软软的，白白的，像一团小棉花。小棉怕冷，冬天的时候会缩成一团，抖抖索索的。他每次经过，都会在心里说一句："小棉，别怕，我在。"

工具书区那位戴圆框眼镜的字典灵，他叫它"老先生"。因为它总是端端正正地站在书架上，手里拿着一本小册子，像一个老师在备课。老先生最讲究，书架上的灰稍厚一点，它就皱眉头。他每次除尘，都会把老先生的书架刷得干干净净。

楼梯上那位看不见脚步声的主人，他叫它"足音"。因为它每天准时上楼、坐下、翻页、下楼，脚步声嗒嗒嗒嗒的，像一座上了发条的老钟。足音从来不在白天出现，只在夜里十一点以后才出来。他每次加班，都会在十一点停下来，听那三声脚步。

大厅那座座钟的灵，他叫它"老钟"。老钟等了四十年，终于往前走了一格。它现在每天走一格，很慢很慢，像一个拄着拐杖的老人。他每天经过的时候，都会看一眼指针，数一数它走了几格。

那张车票的灵，他叫它"明远"。因为它等的那个叫陆明远的人，终于回来了。明远现在不等了，它安安静静地待在书页里，像一个完成了心愿的人，终于可以安心了。

《未刊诗草》里的那个影子，他叫她"小诗"。小诗胆小，不敢见人。他每次经过，都会放轻脚步，怕吓着她。小诗抱着那册看不见的书，一页一页地翻，翻得很慢，像在品味什么。

他把这些名字一个一个地记在笔记本上，每一个名字后面都跟着一段记录。记录写得很详细，什么脾气，什么忌讳，什么时候出现，什么时候消失，他都记得清清楚楚。

"小棉。怕冷。冬天缩成一团。需加温。"

"老先生。圆框眼镜。讲究。书架灰厚则皱眉。需勤除尘。"

"足音。夜间出现。嗒嗒嗒嗒。准时。需保持安静。"

"老钟。守时。等了四十年。一天走一格。需观察。"

"明远。已归。不再等。安。"

"小诗。胆小。抱书翻页。勿扰。"

除了这些常住的邻居，他还记过一些偶尔出现的。有一年夏天，他在三楼库房发现了一窝刚出生的猫崽，母猫瘦得脱形。他去巷口买了两条小鱼回来喂它们。从那以后，那只狸花猫见了他就蹭裤脚。他在笔记本上写了一行字："狸花猫。三楼库房。需喂食。"后来猫崽长大了，一只一只地被领养走了，只剩母猫还留在馆里。他每天给它留一碗鱼饭，它每天准时来吃。他走的时候，母猫会跟着他走到门口，蹲在门槛上看着他走远。他每次回头，都能看见母猫的眼睛在暮色里闪着光。

他还记过一个特殊的邻居。有一年秋天，他在整理一批旧报纸的时候，发现了一只蝴蝶。蝴蝶很小，翅膀是淡黄色的，停在报纸上一动不动。他凑近了看，蝴蝶的翅膀已经干了，脆得像一片薄纸。可它还是停在那里，翅膀微微地张着，像在等什么。他用手指轻轻碰了碰蝴蝶的翅膀，翅膀碎了，变成了一小片一小片的碎片，落在报纸上。他在笔记本上写了一行字："黄蝶。旧报纸间。已逝。安息。"

他还记过一些特别的事。

有一年冬天，暖气管冻裂了，热水淌了一地。他半夜赶到馆里，把那座座钟抱到干燥的地方。那天夜里他在办公室睡了一晚，守着那座钟。第二天早上，钟面上的那团光已经安安静静地融了回去，钟摆微微地晃了一下，指针往前走了一格。他在笔记本上写了一行字：老钟。冻裂夜。我守了它一夜。它走了一格。

有一年夏天，下了一场大雨，天井里积了半尺深的水。他把书从一楼搬到二楼，搬了一整个下午。搬完的时候，他已经累得站不住了，靠在墙上喘气。可他看见那些书灵都安安静静地待在书页里，没有一个被淋湿。他在笔记本上写了一行字：大雨天。书灵无恙。安。

有一年秋天，一个老太太来馆里查资料。她要查的是她丈夫年轻时写的一篇文章。她找了很久，找了一整个下午，最后在一本旧期刊里找到了。她捧着那本期刊，哭了。他站在旁边，不知道该说什么。他递给她一杯茶，她接过来，喝了一口，说：谢谢你。他摇了摇头，说：不用谢。老太太走的时候，他看见期刊里有一团淡淡的光，像一个人在笑。他在笔记本上写了一行字：旧期刊灵。有人来找它的主人了。安。

他还记过一些关于自己的事。

一九九八年。入职南枝文献馆。二十七岁。

二〇〇八年。在这里十年了。见过二十七个书灵。

二〇一八年。在这里二十年了。见过四十一个书灵。

二〇二八年。在这里三十年了。我老了。书灵们还是老样子。

他写得很慢，一笔一画，像在完成一件很重要的事。因为他知道，这些名字，这些记录，有一天会变成很珍贵的东西。这些东西不是写给自己的，是写给以后的人的。以后的人看见这些记录，就会知道，这栋楼里曾经住着这么一些看不见的邻居，它们等了那么久，守了那么久，终于被一个人看见了。

他翻到笔记本的中间部分，看见了一段话。那是他十年前写的：

"今天是我在南枝文献馆的第十年。十年里，我见过二十七个书灵。有的胆小，有的胆大；有的安静，有的活泼；有的等了很久，有的已经不等了。它们都是好的。它们只是在那里，安安静静地在那里，等我来看看它们，和它们说说话。"



他还记过一些关于这条巷子的事。

巷口的裁缝铺老陈，做了四十年的裁缝。他的手艺很好，整条巷子的人都找他。他从来不多收钱，说都是街坊邻居，收什么钱。

卖豆腐的张婶，做了三十年的豆腐。每天凌晨三点起床，磨豆子，煮豆浆，点豆腐。她的豆腐做得好，白白嫩嫩的。

小卖部的老板娘，开了二十多年的小卖部。她人好，谁家缺个盐少个醋的，她都赊着。

理发店的老王，剪了五十年的头发。他说他还能剪十年。

这些人都在巷子里住了一辈子。他们不知道那些看不见的邻居，可他们守着自己的位置，一天一天地过日子。他们也是这条巷子的一部分，也是这栋楼的一部分。

他看见了另一段话，是五年前写的：

"今天是我在这里的第十五年。小棉还是怕冷，老先生还是讲究，足音还是准时，老钟还在走。小诗还是胆小，可她偶尔会从书页里探出头来，怯怯地看我一眼。我朝她笑一笑，她就飞快地缩回去。我知道她在笑。"

他翻到笔记本的最后几页。

最后一页写着一段话，是他五年前写的。字迹有些颤抖，像写字的人手在抖。那段话是这样写的：

这个笔记本是给以后的人看的。以后的人翻开它，就会知道这栋楼里曾经住着一些看不见的邻居。它们不是鬼，不是妖，只是书里住久了的一点灵性。它们等了那么久，守了那么久，终于被一个人看见了。那个人就是我。我看见了它们，记下了它们，和它们说了话。这就够了。

它们不需要被拯救，不需要被超度，不需要被忘记。它们只需要被看见。看见就够了。

他还在这段话的下面加了一行小字：如果你翻到了这个笔记本，请善待它们。给它们换一盏灯，泡一杯茶，和它们说说话。它们会很开心的。

他还看见了最后几行字，是上个月写的：

"今天是我在这里的第二十年。我老了，头发白了，眼睛花了，走路也慢了。可那些看不见的邻居还是老样子。小棉还是软软的，老先生还是端端正正的，足音还是嗒嗒嗒嗒的，老钟还在走，小诗还在翻书。它们不老。它们只是等。"



他每天晚上都会翻开笔记本，看一会儿。不是为了记什么新东西，只是为了看看那些老朋友。他看看小棉的名字，想起它缩成一团的样子，笑一笑。他看看老先生的名字，想起它皱眉头的样子，笑一笑。他看看足音的名字，想起它嗒嗒嗒嗒的脚步声，笑一笑。他看看老钟的名字，想起它一天走一格的样子，笑一笑。他看看明远的名字，想起那个老人拎着木箱子走进来的样子，笑一笑。他看看小诗的名字，想起她怯怯地看他一眼又飞快缩回去的样子，笑一笑。

他想，这个笔记本就是他的朋友。他和它说了二十年的话，它从来不说累，从来不说烦，只是安安静静地待在那里，等他翻开它，等他写下几行字，等他合上它，放在桌上。它陪着他度过了二十年的夜晚，二十年的黄昏，二十年的清晨。

他想，也许有一天，他会在笔记本上写下最后一行字。那行字会写什么呢？也许会写：今天是我在这里的最后一天。我走了。请替我照顾它们。也许会写：谢谢你们。也许什么都不写，只是合上本子，放在桌上，让它安安静静地待在那里。

他把笔记本合上，放在膝盖上。

窗外的月光照进来，落在笔记本的封面上。深蓝色的硬纸板在月光下显得格外深沉，像一片夜空。他想，这个笔记本就是他的星空。每一个名字都是一颗星，每一段记录都是一道光。他把它们记下来，放在本子里，放在月光下，放在一个安安静静的角落里。

他想，有一天他不在了，这个笔记本会留在文献馆里。以后的人翻开它，就会看见那些名字，那些记录，那些他和看不见的邻居们相处的日子。以后的人会知道，这栋楼里曾经有一个人，每天早上六点开门，换一盏灯，泡一杯茶，和一些看不见的邻居说说话。

这就够了。

他把笔记本放在桌上，走到窗边。窗外的月亮很亮，圆圆的，像一个大大的句号。他想，他的一生大概就是这样的——在一个安安静静的地方，和一些安安静静地邻居，过一些安安静静的日子。没有大起大落，没有惊天动地，只是每天开门，关门，除尘，浇花，换茶，听那些看不见的邻居说说话。

他觉得这样很好。

他拉上窗帘，上床睡觉。睡得很安稳。

笔记本放在桌上，安安静静的。月光照在封面上，深蓝色的硬纸板在月光下泛着淡淡的银光，像一片正在做梦的夜空。
