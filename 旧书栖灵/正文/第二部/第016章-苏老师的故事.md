# 第十六章 苏老师的故事

入秋越深，太阳就越懒。等到上午九点半，日光才勉强爬过对街的屋脊，落进南枝文献馆二楼的窗台，像一封迟到了、却不肯缺席的信。

每逢周二和周四，苏晚晴总是头一个到。她拎一只洗得发白的绿帆布包，里面装着老花镜、放大镜、一沓便签，还有一小罐润喉的枇杷膏——那是站在讲台上的人留下的习惯，嗓子里总像还留着半堂课。进了门，她先把窗户支开一条缝透气，再把当天要理的旧书一摞摞码好，动作不快，却没有一步是多余的。

苏晚背地里管她叫“编外馆员”，当面则规规矩矩喊苏老师。

这天早上，苏晚往借阅卡上誊书目，把“借阅”写成了“藉阅”。苏晚晴路过，俯身瞧了瞧，用铅笔尖在那个字底下轻轻一点：“这个字，穿错衣裳了。”苏晚吐吐舌头，撕了卡片重写。苏晚晴从口袋里摸出一颗桂花糖搁在她手边：“改对了，有奖。”苏晚剥糖纸的手快得像抢答。

上午的活儿是给三楼的旧报纸换夹子。褪色的棉线一茬茬断在夹口里，苏晚晴戴上顶针，用新线一匝一匝缠好，顺手翻了翻一份三十年前的晚报，忽然乐了：“你瞧这版广告，一副老花镜卖八毛钱，还送擦镜布。”陆栖探头看了一眼，两个人对着那张泛黄的纸笑了好一阵。笑声不高，飘在空荡荡的报库里有种奇怪的暖意。

闲下来的时候，苏晚晴教苏晚给旧书“体检”：一看，看书脊直不直、书角圆不圆；二摸，摸纸页潮不潮、韧不韧；三闻，闻有没有霉味和虫屑气。“书跟人一样，会自己说不舒服，就看你听不听得见。”苏晚把这句抄进小本子，笔迹圆圆的，一笔一画都很用力。

学得快不如上手快。苏晚抱来一摞待检的书，学着苏晚晴的样子，一本一本地看脊、摸页、闻味。检到第三本，她忽然咦了一声，把书凑到鼻子底下又嗅了一遍：“这本有点潮，纸边都软了。”

苏晚晴接过去翻了两页，点点头：“好耳朵。前几天下雨，它八成是在靠窗的架子上挨了潮气。”她把书抽出来搁在一边，“先隔离，晾两天再归架。你看，它不会说话，可它会把不舒服写在脸上——就看你肯不肯低头细看。”

苏晚把这本书单独放在通风的窗台上，摆的时候特意把书口朝下，扇开一点点缝。“这样它透气。”她小声解释，像在照顾一个感冒的病人。

午后，陆栖在修复室补一册民国的县志。虫蛀的洞眼有黄豆大，要先裁了皮纸补上，再用纸捻订回原样。所谓纸捻，就是把宣纸裁成细条，搓成细细的纸钉，穿进书脊的针眼里去——老辈修书不用金属钉，怕锈伤了纸。苏晚晴坐在旁边的竹椅上帮他搓，手掌在桌面上轻轻一滚，一根匀称的纸捻就出来了。她年轻时在学校图书馆帮过忙，一上手就想起来了。

“您以前常干这个？”陆栖问。

“帮着装订过一柜子的作业本。”苏晚晴把搓好的纸捻排成一排，笑了笑，“修书跟教书其实是一回事，都急不得。书破了要一页一页补，学生慢，也得一天一天等。”

陆栖手里的竹起子顿了顿：“等？”
“我教过一个学生，叫周大成。”她挑了张厚薄合适的纸条，慢悠悠地讲起来，“一九九三年我头一年上岗，他在初二。作文从来写不满三行，写春天就一句‘春天来了’，写母亲也一句‘我妈妈很辛苦’。办公室里有人说，这孩子怕是教不出来了。”

“那您怎么办？”

“我没让他重写过一篇。”她说，“我只是每次都在他本子上画一样东西。头一回，画一颗种子。第二回，种子边上冒了个芽。第三回，芽上多了片叶子。全班都知道我在他本子上种东西，他自己也知道。”

窗外的槐树落下一片叶，贴在玻璃上，又被风揭走了。

“初三最后一篇作文，他还是写得慢，字也歪。”苏晚晴把声音放轻了，“可他写足了满满一页，写他家楼下的梧桐，像量身高那样一年一年地量。最后一句是：‘今年它高过我爸爸了，我也快了。’”

修复室里静了一会儿。糨糊的气味淡淡的，混着旧纸的味道，暖烘烘的。

“后来呢？”陆栖问。

“后来他毕业，我换了学校，音讯就断了。”苏晚晴把最后一根纸捻放进盒子，拍了拍手上的纸屑，“直到前年教师节，有个中年男人堵在校门口，手里攥着一个塑料皮的笔记本，说是我的学生。我愣了半天没敢认——他比讲台下坐着的那些孩子，足足高出两个头。”

“他在开公交车，十九路，一开十一年。”苏晚晴说，“那个本子他天天写，一天一行。给我看的那页上写着：‘今天路过母校，梧桐比我高了。’底下还有一行小字：‘苏老师，芽我接着画呢。’”


“那个本子我翻了半天，”她接着说，“从第一页到最后一页，一天一行，没有断过。有几天写的是‘今天下雨’‘今天很累’，也照写。我跟他说，这就叫日子。日子不是天天都有大事，日子是小事摞着小事，你肯记，它就不算白过。”

陆栖想起自己那本记录馆里精灵的笔记本，也是这样一天一行地写着。有的日子只写了“无事”，有的日子写“三楼窗台来了新客人”。原来不知不觉间，他也把日子过成了别人口中值得的样子。

陆栖低下头继续手上的活儿。糨糊涂得很匀，皮纸覆上去，鬃刷一遍一遍刷实。他想起馆里的那些灵——它们在书页间一等就是几十年，等的无非也是这样一句话：你种下的东西，后来长大了。

“教书的人，是不是格外懂等待？”他问。

“懂，也没办法不懂。”苏晚晴笑了，眼角的纹路里都是笑意，“种子埋下去，你要是天天扒开土看，芽就死了。你能做的就是浇水、松土，把剩下的事交给时间。有人问我，退休了舍不舍得讲台。我说舍的不是讲台，是看着一个慢孩子慢慢亮起来的那个过程。那个急不来，也不该急。”

她摘下老花镜，用绒布擦了擦，又戴上：“所以后来再有人问我，什么叫等待，我就告诉他——”

她看向陆栖，一字一字地说：“等待不是什么都不做，是相信会来。”
窗外起了点风，院里老槐树的叶子哗啦啦响过一阵，像许多人在小声鼓掌。

歇茶的工夫，苏晚抱着借阅簿上来，顺势在门边坐下：“苏老师，您教了多少年书呀？”

“三十二年。”苏晚晴掰着手指数了数，自己也笑了，“数出来吓一跳。头一年站上讲台，粉笔灰呛得直咳嗽；最后一年站上讲台，居然舍不得那股灰了。”

“最调皮的学生呢？后来怎么样了？”

“最调皮的那个，把我的自行车气门芯拔过两回。”苏晚晴眼睛弯起来，“上个月他们消防队来学校做安全讲座，主讲教官就是他。他在台上说，小时候气门芯都拔，现在专门给人堵漏洞。台下笑倒一片，我在底下，眼泪都快笑出来了。”

满屋子人都笑了。茶凉到一半，苏晚晴忽然想起一件事：“上回我说起那本有葱姜味的书——老聚香园的菜谱，有眉目了吗？”

“还不算有。”陆栖给她续上热水，“它的心思我大体明白了，只是还没遇上一个合适的人。”

“如今的年轻人……”她叹了半口气，又把后半口气笑掉了，“也不能一概而论。总有肯学的，只是缘分未到。缘分这个东西，我们当老师的顶相信——你把种子埋下去，说不定哪天就从哪条墙缝里发出芽来。”

黄昏时分，阿棠从善本库里飘出来，循着说话声在窗边悬了半晌，这才慢悠悠地接口：“苏老师这句话，我可以作证。”

苏晚晴自然看不见她，只觉得窗口掠过一缕很淡的桂花香，忍不住深吸一口气：“奇怪，这个节气了，哪儿来的桂花？”

“隔一条街的老邻居。”阿棠冲她眨眨眼，可惜对方看不见。她转向陆栖，声音放轻了，“等过六十年的人，听见这话，比谁都明白。信送到了，诗也送出去了——你看，只要信着，东西总会到的。”

陆栖朝窗边微微颔首，算是应了。
临走时，苏晚晴从帆布包里取出一个布包，一层层打开，是三本卷了角的作文本。“家里翻出来的，头一届学生的。扔了可惜，搁在床底下，迟早霉掉。文献馆既收旧东西，不如收它们。往后我再陆续寻些来——教案、点名册、学生写的贺年卡，都还有。”

“您放心。”陆栖双手接过，像接一件很重的轻东西，“会给它们编号，一页也不会少。”

“不急。”她把布包的系带仔细卷好，递过来，“放在你们这儿，我踏实。教书的人最知道，好东西要放在能被翻到的地方，才算活着。”

下楼的时候，她经过天井，在水缸边站了站。缸里养的铜钱草入了深秋，边缘卷了一圈黄，根须在水里悠悠地晃。她伸手指碰了碰水面：“下周四我带一包自己晒的陈皮来，泡茶化痰，比枇杷膏省事。”说完自己先摆摆手，“瞧我，什么都想管。你们别嫌烦就好。”

“不嫌。”陆栖替她推开院门，“苏老师，慢走。”

她的身影出了院门，一步一步，不疾不徐。巷口的路灯次第亮起来，把她裹进一团团暖黄的光晕里，又一团团地放开。

陆栖回到楼上，把三本作文本摆上桌。封皮颜色深浅不一，最旧的那本，蓝底已经褪成了灰。翻开第一页，扉页上是苏晚晴清秀的钢笔字：某届某班，作文本。再往后翻，纸页间的字迹深深浅浅，有工整的，有潦草的。翻到中间某一页，空白处果然卧着一颗铅笔画的小芽，两瓣叶子，笨笨地朝着光。

他抽出一张空白登记卡，一笔一划地填：捐赠人，苏晚晴；品目，作文本三册。写到备注栏，笔尖悬了一会儿。他想了想，在空白处画了一株小小的芽。

画得并不比周大成当年好多少。

儿童阅览室方向传来一阵极轻的窸窣，大约是雪团又在绒毯里翻了个身。修复室窗台上，那本晾干的旧菜谱安安静静地躺着，书缝间偶尔透出一丝若有似无的葱姜气，像有人在梦里咂了咂嘴，梦见了一口烧热的锅。

陆栖把登记卡插好，关了台灯。

暮色从窗缝渗进来，一点一点漫过桌面。卡片角落里那株铅笔的小芽浸在暗处，安安静静，等它自己的季节。
