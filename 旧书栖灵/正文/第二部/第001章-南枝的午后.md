# 第一章 南枝的午后

初秋的午后，阳光从南枝文献馆的天井里斜斜地照进来，把地上的青砖照得发亮。空气里浮动着细小的灰尘，在光线里慢慢旋转，像是微缩的星系。

陆栖站在二楼的书架前，手里拿着一块半干半湿的棉布，正仔仔细细地擦拭着书脊。他穿着一件洗得发白的深色外套，袖口挽到小臂，左胸口别着工牌，透明卡套里夹着一小片纸角——那是很久以前的事了，久到他自己都快忘了那是怎么来的。

他今年二十七岁。在南枝文献馆工作的第四年。

顾松年退休之后，这座文献馆就只剩下他一个人守着了。说"一个人"也不太准确——二楼的善本库里住着阿棠，儿童阅览室里住着雪团，三楼的旧报纸堆里偶尔还能见到纸屑灵那个薄如蝉翼的小家伙。但要说"人"的话，确实只有他一个。

"值得被留下的东西，就值得被修好。"

他自言自语，把棉布叠好放进工具箱里。这句话是顾松年教他的，他记了四年，也说了四年。

书架上的灰尘已经被他擦掉了一层。初秋的午后容易起灰，尤其是这种老旧的木质书架，缝隙里藏着不知道多少年的尘埃。他从书架的最高层开始擦，一层一层往下，直到擦到和他胸口齐平的那一层。

窗外传来几声鸟叫，清脆得很。南枝文献馆的院子里种着一棵老槐树，树冠伸到了二楼的窗边，每到初秋就结满了一串串淡黄色的槐花。那些花没什么香气，但有一种干净的味道，像是被阳光晒过的旧床单。

陆栖的手指无意间碰到了一本塞在角落里的旧书。

书很薄，封皮是暗红色的，边角已经磨损得看不出原来的样子。书脊上没有书名，只有几个模糊的烫金字迹，像是被人用手指反复摩挲过，已经磨平了大半。他把书抽出来，翻了翻——里面是一封信，用毛笔写的，字迹娟秀，墨色已经褪成了浅褐色。

信纸的边缘已经泛黄发脆，像秋天的落叶一样薄。陆栖小心翼翼地捧着它，生怕一用力就把纸弄碎了。信上的内容他没有细看，只是瞥见了开头几个字："见字如面，展信安好。"

他的手指停住了。

不是因为信的内容，而是因为他感受到了一种微弱的、温暖的气息，从书页间透出来，像是冬天里呵出的一口热气。那种气息很熟悉，和阿棠身上的桂花香不一样，和雪团身上的奶香也不一样。它更古老，更沉静，像是一个老人坐在摇椅上，慢慢地摇着，慢慢地讲着一个很长很长的故事。

书灵。

他太熟悉这种感觉了。在这座文献馆里工作了四年，他已经习惯了与它们共处。有些灵安静得像影子，有些灵活泼得像孩子，有些灵甚至会在你经过的时候，轻轻地碰一下你的手指，像是在说"嘿，看看我"。

但这本书里的灵不一样。

它的气息很淡，淡到几乎察觉不到，像是一个人在很远很远的地方喊你的名字，声音被风散了，只剩下一点点余音。它不是活跃的，也不是微弱的——它是安静的，安静得像是在等待什么。

陆栖把书合上，放回书架。他用手指轻轻抚过那本暗红色的封面，像是在安抚一个睡着的孩子。

他没有急着处理它。顾松年教过他：有些灵需要时间，急不得。你把书放回去，过几天再来看，如果它还在那里，就说明它准备好了。有些灵会等你准备好，有些灵会等一个对的人，有些灵甚至不知道自己在等什么——它们只是安安静静地待在书页间，等着某一天被谁翻开。

他继续往下擦书架，手上的动作很轻很稳。阳光从窗户照进来，把他的影子投在书架上，影子的边缘模糊得像水墨画。

大约过了半个小时，阿棠从善本库里飘了出来。她穿着一身民国时期的学生装，梳着两条麻花辫，身上带着淡淡的桂花香。她飘到陆栖身边，歪着头看他擦书架。

"又在干活？"她问，声音轻柔得像是风。

"嗯。"陆栖头也不抬。

"刚才你摸的那本书，"阿棠说，"里面有个老朋友。"

陆栖的手停了一下："你认识它？"

"不认识。"阿棠摇摇头，"但它身上的味道很熟悉，像是很久很久以前的那种味道。比我的年纪还大。"

陆栖沉默了一会儿。阿棠是一九三几年的灵，比她年纪还大的，至少得是民国初年甚至更早的。

"它在等什么？"陆栖问。

阿棠飘起来，在书架间转了一圈，又飘回来："不知道。但它等得很耐心，一点都不急。"

陆栖点了点头。他相信阿棠的直觉——这个桂花香的灵虽然平时看起来大大咧咧的，但对同类的气息特别敏感。

下午三点左右，文献馆的大门被人推开了。

那扇铁门很重，推开的时候发出"吱呀"一声，像是老人的叹息。陆栖从书架间探出头，看见一个年轻男人站在门口。那人穿着一件浅灰色的风衣，肩上背着一个黑色的双肩包，手里拿着一叠文件。他正仰着头，打量着门楣上那四个褪色的大字。

"南枝文献馆……"他轻声念出来，声音里带着一点意外，"比我想象的要老。"

他走进院子，脚步踩在青砖上，发出清脆的回声。院子里的槐树落了几片叶子，飘到他的肩上，他伸手拈起来，看了一眼，又轻轻放下。

陆栖走下楼梯，站在大厅里看着他。

那人转过头来，看见了陆栖，微微一愣，然后露出一个礼貌的微笑："你好，我是沈洄，城市规划局的。我们之前联系过的，关于老城区历史建筑的调研。"

陆栖点了点头。他记得这通电话——上周，规划局的人打来，说要派人来文献馆做一次历史建筑的记录和测绘。当时他没太在意，以为又是那种拍几张照片就走的人。

"请进。"他说。

沈洄走进大厅，目光在书架之间逡巡。他的表情很认真，像是在看一幢需要测量的建筑，而不是一屋子旧书。他掏出手机，对着大厅拍了一张照片，又对着墙壁上挂着的一幅老照片拍了一张。

"这里比我想象的保存得要好，"他说，"这些书架看起来都有年头了，但结构还很完整。"

"都是实木的，"陆栖说，"老顾——顾松年在的时候，每年都会做维护。他懂木头，知道怎么保养。"

"顾松年？"沈洄掏出笔记本，"就是在这里工作了四十年的那位老馆长？"

"嗯。"

"我听同事提起过他，说他是南枝文献馆的活化石。"沈洄笑了笑，"可惜他退休了，我想见见他都没机会。"

陆栖没有接话。他不太擅长和陌生人聊天，尤其是这种一见面就问东问西的类型。他转身往楼梯走："你想看哪里？"

"都看看吧。"沈洄跟上来，"一楼二楼三楼都看一遍，我拍些照片，做一下记录。"

他们走上二楼。楼梯是木头的，踩上去会发出轻微的"咯吱"声。沈洄一边走一边拍照，时不时地在笔记本上记些什么。他注意到二楼的走廊很长，两边都是紧闭的房门，门上挂着各种各样的牌子——"古籍修复室"、"善本库房"、"档案室"……

"这些房间……都能进去看吗？"沈洄问。

"有些可以，有些不行。"陆栖说。

他们经过一排书架的时候，沈洄的脚步慢了下来。他偏过头，好像在听什么。

"怎么了？"陆栖问。

"没什么。"沈洄摇摇头，"可能是我听错了，我好像听到了……翻书的声音。"

陆栖心里一动，面上却不动声色："可能是风吧。这里窗户多，风大的时候会有响声。"

沈洄没有追问，继续往前走。但他的脚步明显慢了下来，目光在那些书架之间多停留了几秒。

陆栖注意到了——刚才经过那排书架的时候，阿棠的气息波动了一下。那个桂花香的灵大概是对这个新来的陌生人有些好奇。她平时很少对生人感兴趣，今天不知道怎么了。

他们走到三楼的库房，沈洄看见那堆积如山的旧报纸，眼睛亮了起来。

"这些报纸保存得真好，"他蹲下来，翻开一份报纸的牛皮纸包装，"上世纪五六十年代的报纸，在别的地方早就找不到了。你们是怎么保存的？"

"恒温恒湿，"陆栖说，"这间库房做过改造，温度和湿度都控制得很好。老顾花了很多心思。"

"看得出来。"沈洄站起身，环顾四周，"这里每一样东西都被照顾得很好，能感觉到……有人在认真地对待它们。"

陆栖看了他一眼。这个年轻人说话的方式很特别，不像是在说客套话，而是真的在感受这个地方。

沈洄拍了很多照片。他拍书架，拍报纸，拍墙壁上褪色的标语，拍窗户上斑驳的光影。他拍得很认真，每一张都要调整角度，等光线最好的时候才按下快门。

"你不嫌烦吗？"陆栖问。

"不烦。"沈洄说，"记录这些东西是我的工作。而且……"他停了一下，看着手里的相机屏幕，"你不觉得这些东西很美吗？时间留下来的东西，都有它自己的美。"

陆栖看着他的侧脸。夕阳的光从窗户照进来，把他的轮廓照得很柔和。这个年轻人和他之前见过的那些来调研的人不太一样——那些人通常来了就走，拍几张照片就完成任务了。但沈洄不一样，他看这些东西的眼神里，有一种认真的光。

像是在看一个值得被记住的故事。

下午四点半，沈洄收拾好东西，准备离开。

"谢谢你的配合，"他伸出手，"改天我再来，有些细节需要二次确认。"

陆栖握了握他的手。沈洄的手掌干燥温热，握得很有力。

"不客气。"

沈洄转身往大门走。他走了几步，突然停下来，回头看了一眼——

"对了，"他说，"你们这里还招人吗？我……有点想多来几次。"

陆栖看着他，没有说话。

沈洄笑了笑，转身推开了那扇沉重的铁门。夕阳的光从门缝里照进来，把他的影子拉得很长。他走出院子，脚步声渐渐远去，最后消失在巷子的尽头。

陆栖站在大厅里，看着那扇门慢慢合上。

他突然想起了什么，快步走上二楼，走到下午他发现那本旧书的书架前——

书架上空空的。

那本暗红色封皮的旧书不见了。

陆栖愣了一下，目光在书架上扫了一遍，确认不是被碰歪了掉到别处。没有，它就是不在了。他伸手摸了摸那个空出来的位置，指尖碰到的只有冰凉的木头和细碎的灰尘。

他轻轻叹了口气。

"……大概是跟着他走了。"

他转过身，看见阿棠从书页间探出半个身子，歪着头看着他，眼神里带着一点担忧。

"别看了，"他对阿棠说，"那个人不是坏人。"

阿棠眨了眨眼睛，嘴巴动了动，像是想说什么，但最后还是飘回了书里。桂花香在空气中停留了几秒，然后也散了。

陆栖站在书架前，目光落在那片空出来的位置上。初秋的阳光从窗户照进来，把灰尘照得闪闪发亮。他想，那本书里的灵，大概是找到了什么它想要找的东西。

又或者，是那个叫沈洄的年轻人身上，带着什么它熟悉的味道。

他摇了摇头，拿起棉布，继续擦书架。

南枝文献馆的午后，和每一天一样安静。院子里的老槐树在晚风里轻轻摇晃，几片枯黄的叶子落下来，贴在青砖地面上，像是被时光遗忘的书签。

阿棠从善本库里飘了出来，在走廊里慢慢走着。她的身影在夕阳里变成淡金色，半透明的，像一片被光照透的旧书页。她经过陆栖身边的时候，停了一下，看了看他正在擦的那排书架，又看了看窗外渐渐暗下来的天空。

"今天好像有什么不一样。"她说。

陆栖没有回答。他只是继续擦着书架，把每一道缝隙里的灰尘都清理干净。

但有什么东西，在那片安静里，悄悄地动了一下。

像是一个很长很长的故事，刚刚翻开了第一页。
