# 第010章 雨天的借读册

梅雨季一来，小城就泡在了水里。

天井里的青石板缝里冒出蘑菇来，白生生的一小簇一小簇，像从地底探出来的手指头。文献馆的屋檐淌着水帘，滴在台阶上溅起的水珠打湿了陆栖的裤脚。

这种天气出门是种折磨，可待在馆里，听雨打瓦檐的声音，闻着旧纸和潮气混在一起的味道，倒有种说不出的安心。

天上像是漏了个窟窿，雨从早下到晚，从晚下到天亮，没完没了。巷子里的青石板被洗得发亮，踩上去鞋底打滑，走路的人撑着伞，伞面上的水汇成小瀑布。

雨下下停停，停停下下。天井排水口日夜咕嘟着，青石板缝里冒蘑菇，馆里的除湿机嗡嗡响成一片背景音。这种天气，连书页翻起来都是闷的。

陆栖每天上班第一件事是开窗通风，第二件事是关窗防雨，第三件事还是开窗。如此反复，一天能折腾十几个来回。

书也跟着遭罪。有几册民国画报的纸页受了潮，灵们闷在里面哼哼唧唧地抱怨，声音像被棉花塞住了嘴。

文献馆最怕这个。顾松年带着陆栖把除湿机全开上，一天三遍地查库房。

除湿机是前年才买的，噪音大，开起来像拖拉机。馆里一共三台，库房两台、借阅室一台，二十四小时连轴转。水箱满了就倒，倒完再接上，一天能接七八桶水，足够浇天井里那棵老槐树了。

陆栖倒水的时候想，这楼和人一样，潮了就容易出毛病。这天下午，陆栖在借阅室旧柜里发现了一册蓝布封面的公共借阅簿——民国年间的老物件，布面受潮发乌，隐隐透出一股闷闷的潮气。

它是个很老的灵了。蓝布册子，方方正正，像个端坐的老先生。陆栖把它请到干燥的桌面上摊开，又垫了两层吸潮纸，它才慢慢缓过神来。

蓝布的面子已经发乌了，边角磨损得起了毛，可翻开内页，纸张还是硬朗的，一行一行的借阅记录排列得整整齐齐，像列队的士兵。几十年的墨迹有深有浅，有的端正，有的潦草，有的用力过猛把纸都戳出了坑。

这册子当年是馆里的公共借阅登记本。从民国二十六年到解放后，几百个人在上面签过名：穿长衫的教员、扎辫子的女学生、拉黄包车的车夫、纺织厂的下夜班工人……每一笔借阅记录背后，都是一个人捧着书回家的温度。

陆栖一页一页翻过去，指尖隔着薄薄的棉手套，感受纸面上凹凸不平的字迹。有的字写得轻，像随手一划就走了；有的写得重，像要把什么刻进纸里。几十年的墨迹有深有浅，有的端正，有的潦草，有的用力过猛把纸都戳出了坑。；有的端端正正一笔一画，有的潦草得几乎认不出——那是赶时间的人留下的，急着把书借走，急着回家去读。

"我记得他们每一个。"蓝布册子灵说。它的声音潮乎乎的，像雨天的青石板，"张先生的手总是凉的，他借书都在冬天。李家小姐还书的时候哭过，眼泪滴在第四十七页。有个小徒弟偷了他的东家的《三国》来看，怕被发现，三天就看完了，看得眼睛都直了……"

它絮絮地讲，讲了几百个人的痕迹：油渍、泪痕、压平的折角、被小孩涂鸦的书角。

它记得最清楚的，是那些最微不足道的细节：某一页的角被折过两次，方向相反——借书人先折了个角当书签，后来又折了回去，大概是觉得折角会损伤纸页；某一页的边沿沾了一点墨，是借书人做笔记时不小心蹭上的；某一页的纸比别的厚一些，夹了一张薄薄的信纸，上面写着"此书甚好，推荐一读"。

讲到兴起处，它会用声音描出那个人的样子："张先生借书从来不用手——他用书签，而且是竹制的，可讲究了。""李家小姐每次来都穿旗袍，不同颜色的，我记得有月白的、有藕荷的。"

"这条油渍是米汤。"它指着某一页，语气里带着一点得意，"别以为我看不出来。那是巷口卖粥的孙家老三，他一边喝粥一边看，看得舍不得撒手。后来他自己跟我讲过——那年他十七岁，看完这本书就下了决心要去考学徒。"

"还有这个折角，"它翻到另一页，声音软下来，"是个姑娘折的。她借书那天在登记栏里写名字写了两遍，第一遍写错了。我猜她那天心不在焉得很——多半是要见什么人了。"

"还有雨痕。这条最长，从页眉一直洇到页脚。

水渍已经干成了浅褐色的地图，边缘模糊，像一幅没画完的水墨画。陆栖拿手电照着看，水渍中间隐约能看出字迹的轮廓——那一页的借阅记录被雨水洇掉了大半，只剩下日期和半个名字，像一个被水冲散的故事。"它指着一册借书记录旁边的水渍，"那是个中学生，暴雨天把书揣在怀里护着跑回来的。书淋了点雨，人大概也淋了。第二天他还书的时候连声道歉，我说不碍事，他就笑，说'值当'。"

陆栖听得入了神。一册薄薄的旧簿子，在他眼前忽然活了过来：几百个名字不再是褪色的墨迹，而是一张一张有温度的脸，捧着同一本书，走在各自的人生里。

他想，这栋楼里装着的不只是书，是无数个平行的人生。借书的人走了自己的路，书留在了原地，可书里记着他们的手指、他们的叹息、他们翻过某一页时停顿的那一秒。

这就是文献馆存在的意义——不只是保存纸，是保存人。每一本书里都住着一个人的影子，每一次翻阅都是一次重逢。借阅簿记录的不只是谁借了什么书，更是一个人和另一本书相遇的证据。

"可是现在没人翻我了。"它的声音低下去，"他们都走了。连记得他们的人，也没有了。"

窗外的雨又大了些，打在瓦上哗哗作响，像几百个人同时翻书的声音。蓝布册子灵在雨声里沉默着，蓝布面子被馆里的灯光照出深深浅浅的纹路，像一张写满了皱纹的脸。

窗外的雨忽然大了一阵，砸在瓦上噼里啪啦响。蓝布册子灵在雨声里沉默着，像一个人在组织语言。

"我想有人再把我温柔地翻一遍。不是查档案那种翻法。是……像他们当年等我那样。"

那天晚上，陆栖没有用白手套，也没有按修复规程来。他就着一盏台灯，坐在借阅室里，把这册蓝布簿子从头到尾、一页一页地翻。

他把自己坐的那张旧藤椅挪到桌边，藤条吱呀响了一声，像在给他让座。台灯的光圈刚好罩住摊开的簿子，四周的借阅室暗下来，满墙的旧书架在暗处沉默着，像一群安静的听众。

翻得很慢。

每翻到一条借阅记录，他就停下来，轻声念一遍那个名字，然后凭着自己的本事，猜一段这个人借书那天的事："陈守义，借《饮冰室文集》，三月十二，这天该是开学不久，先生备课要用的吧。""王秀珍，借《啼笑因缘》，六月里，天热，她大概是摇着蒲扇看的。"

有些猜测大概不对。但蓝布册子灵听着，潮气一点一点褪下去，布面渐渐透出温润的光泽。

每念完一个名字，它就轻轻"嗯"一声，像老师批改作业时的点头。有时候它会补充一句："不对，他那天穿的是棉袍，不是长衫。""她不是一个人来的，还带着她妹妹。"

念到最后，陆栖嗓子有点哑了，可他舍不得停。一册旧簿子在他面前铺开的，是一座城的半部日常史。那些名字不再是纸上的墨迹，而是一个个活生生的人——他们借过书，读过书，爱过书，最后把书还了回来。还回来的不只是书，还有一段段人生的痕迹。

翻到中间，陆栖念到一个熟悉的名字："顾松年，借《营造法式》，一九六二年九月——"

蓝布册子灵笑出了声："是他。那时候他还是个小徒弟，天天来抄书里的图样，抄完蹲在我边上描摹。手抖得厉害，我说小伙子你稳着点，他说师父等着用。"

蓝布册子灵看着那行字，看了很久很久。

它没有说话。陆栖能感觉到它的目光落在那行字上，一笔一画地看，像一个等了很久的人终于听到了敲门声。

窗外的雨不知什么时候小了，只剩檐下滴滴答答的水声，像在替它数着读完那行字的时间。

那天之后，蓝布册子灵就在借阅室的旧柜里安了家，身体重新变得干爽挺括。

后来陆栖有回路过，撞见来查老账的年轻馆员正跟它较劲，每翻一页都平平整整，一点不卡，年轻人翻得满头雾水，嘀咕了句"这几十年的老簿子，状态怎么比新本子还乖"。
