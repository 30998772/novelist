
# 《旧书栖灵》系列总规划

## 系列一句话

能看见旧书之灵的青年陆栖，在小城文献馆用一生的时间，接住一个又一个被遗忘的灵魂——从学会接纳，到学会完成，到学会守望，到学会放手，到学会传承，到学会相信：晚风年年都来，旧书常明不灭。

---

## 系列定位

| 项目 | 说明 |
|------|------|
| 类型 | 温暖治愈系单元叙事长篇 |
| 总字数 | ~150万字 |
| 每部体量 | ~25万字（约70章×3500字） |
| 核心基调 | 温暖、安静、治愈。没有鬼怪，只有遗憾；没有恐惧，只有等待；没有死亡，只有完成 |
| 叙事方式 | 单元故事+主线推进，每个灵是一个单元，灵与灵之间形成回声 |
| 时间跨度 | 全系列横跨约四十年（陆栖27岁→约67岁） |

# 第一部：旧书栖灵

**副标题：** 晚风与旧书页
**已完稿：** 60章 × 3500字 ≈ 24万字

## 本部定位

陆栖入职南枝文献馆，从一个觉得自己是"没人要的旧书"的沉默青年，逐渐在这里找到了存在的意义。他遇见了旧书里的灵，学会了倾听它们的故事，帮助它们完成执念。最终，困在馆中六十年的诗灵阿棠读完了自己的一生，随风圆满而去。

**时间结构：**
- 第一段（001-036）：入职第一年，从初遇到阿棠远行
- 第二段（037-060）：数年后，陆栖独立守馆，日常延续，时间蒙太奇

## 本部主题

- **被看见**：每一个灵都在等一个能看见它们的人
- **被记住**：你做过的每一件小事，都会被记住
- **温柔从不徒劳**：你给出去的善意，终将以另一种方式回来

## 核心冲突

陆栖的内心冲突——害怕被当成异类 vs 渴望被需要。外部冲突极弱，没有反派，只有等待与完成。

## 主要人物弧光

- **陆栖**：从"没人要的旧书"→被需要的守夜人
- **阿棠（诗灵）**：从透明→被读懂→化光远行
- **顾松年**：从师父→交棒
- **雪团**：从怕冷→学会照顾别人

## 本部结尾（陆栖42岁）

阿棠远行。顾松年退休交棒。陆栖开始独立守馆，写诗集记录遇见的每一个灵。新的小日记本灵出现。晚风年年都来。

# 第二部：晚风不散场

**副标题：** 从一个人守到一群人守

## 本部定位

阿棠远行后，陆栖从"接住灵的人"变成"守着灵的人"。文献馆来了新馆长、新住户、新灵，老街面临改造，灯笼灵面临无处可去的困境。陆栖要学会的不再是"完成"，而是"陪伴"——有些灵不需要远行，它们只是需要一个安稳的家。

## 本部主题

- **陪伴**：不是所有执念都需要完成，有些只需要被陪伴
- **延续**：一个人的守变成了众人的守
- **日常即是永恒**：最好的结局不是远行，是每天都在

## 核心冲突

表层：老街改造带来的存废之争，灯笼灵的去留。
深层：陆栖从"完成者"到"守望者"的角色转变——他习惯了"送走"，却不知道怎么"留下"。

## 本部结构

## 新角色

- **新馆长林越**：三十出头，有想法但不信灵，被陆栖慢慢感化
- **陆栖的学徒苏晚**：二十二岁，能隐约感知灵的存在，像当年的陆栖；**个人暗线**：祖父是旧书店老板"拾遗斋"，书店倒闭时书被当废品卖掉，她至今记得祖父坐在空书架前的背影——"被遗忘"是她最深的恐惧；母亲有精神疾病史，她一直害怕自己也会"不正常"
- **沈念**：沈明远的后人，为完成太爷爷传记来到文献馆，带来关键线索（照片、信件、钥匙）
- **日记本灵"小禾"**：喜欢图书馆的小孩子，叽叽喳喳，活泼可爱

老街保住了，灯笼灵留在原处。苏晚开始独立守馆。沈念完成了太爷爷的传记。陆栖在天井里看着满院灯火，说："这栋楼的灯，不会灭。"

## 与第一部的呼应

- 第一部结尾：阿棠远行，陆栖许诺"灯永远不会灭"

# 第三部：纸页有回声

**副标题：** 每一页都记得你

## 本部定位

陆栖发现阿棠诗集里夹着的旧纸，引出一段被遗忘的往事——文献馆的前身"南枝楼"里，曾住过一个叫沈明远的人（阿棠的兄长）。他是捐楼建馆的人，却从没有人记得他。陆栖开始追溯文献馆的前世今生，发现这栋楼里的每一个角落都藏着回声——过去与现在互相映照，旧人与新人彼此呼应。

## 本部主题

- **回声**：你说过的话、做过的事，墙壁都记着
- **被遗忘的人**：捐楼的人、修书的人、守夜的人，他们不该被忘记
- **过去与现在**：旧时光不是死的，它活在每一个当下的选择里

## 核心冲突

表层：追溯南枝楼的历史，寻找沈明远的故事。
深层：陆栖面对"守馆人也会被遗忘"的恐惧——顾松年退休后，还有人记得他吗？他自己老了以后呢？

沈明远的灵看见文献馆依然灯火通明，安然消散。陆栖在档案室里翻到顾松年年轻时的笔记，第一页写着："这栋楼值得守。"他合上笔记，轻声说："值得。"

# 第四部：春泥护花

**副标题：** 执念终有归处

## 本部定位

这一部聚焦"完成"本身——不是所有的灵都能被完成，不是所有的执念都有答案。有些灵等了太久，已经忘了自己在等什么；有些灵的执念太深，完成反而是一种艰难的选择。陆栖要学会的不是"帮它们完成"，而是"陪它们面对完成"。

## 本部主题

- **完成的代价**：完成了就要走了，走了就真的不在了
- **执念的重量**：有些执念是翅膀，有些执念是锁链
- **放手也是温柔**：你不必替它完成，你只需要让它知道可以完成

## 核心冲突

表层：几个"难以完成"的灵——它们的执念太深或太复杂，不能简单地"读懂"就解决。
深层：陆栖面对阿棠走后的空洞——他帮灵完成了那么多，自己的执念呢？他有没有想完成的事？

## 本部结构

| 卷三 | 完成的那天 | 25-36 | 一个即将完成的灵的最后时光 |
| 卷四 | 陆栖的执念 | 37-48 | 陆栖面对自己的内心——他想完成什么？ |
| 卷五 | 春泥护花 | 49-60 | 所有的完成都是为了下一朵花开 |
| 卷六 | 归处 | 61-70 | 每个灵都找到了自己的归处，无论走还是留 |

- **小苏（苏晚的成长）**：从学徒变成了能独立守馆的人

陆栖终于明白：他想完成的事，就是"让这栋楼一直亮着"。这不是一个可以"完成"的执念，而是一个可以一直做下去的事。他笑了。

# 第五部：灯火暖人

**副标题：** 灯亮着就有人回来

## 本部定位

陆栖进入中年，文献馆迎来了一次真正的危机——不是拆迁，不是资金，而是"没有年轻人愿意来了"。老读者一个个离去，新读者寥寥无几，灵们也渐渐变淡。陆栖开始意识到：守馆不只是守着一栋楼，而是守着一种"人与旧物之间的情感连接"。他决定走出去，让文献馆的灯照亮更多的人。

## 本部主题

- **走出去**：守不一定是守在原地，也可以是把光带到更远的地方
- **连接**：人和书、人和灵、人和人之间的连接，比任何东西都重要
- **灯火暖人**：你点一盏灯，路过的人就暖了一程

## 核心冲突

表层：文献馆的存续危机——读者减少、经费紧张、年轻人不来。
深层：陆栖从"守馆人"到"传播者"的转变——他要把文献馆的精神带到馆外去。

## 具体障碍（让"走出去"不容易）

1. **陆栖的身体危机**：六十二岁时被诊断为早期帕金森，手开始发抖——一个修书的人，手不稳了。他不得不面对"我能做多久"的恐惧。
2. **社区的冷遇**：陆栖第一次去社区讲旧书故事，只有三个听众，其中一个还是来蹭暖气的。"旧书有什么用？网上什么查不到？"——这是他第一次感受到"被时代抛弃"。
3. **与苏晚的理念分歧**：苏晚想用短视频、直播等新媒体推广文献馆，陆栖觉得"那样不对，书是要一页一页读的"。两代人第一次因为"什么是对的"而争执。

陆栖七十五岁。

又是一个春天。

他照常六点推开门，木门框发出那声轻响。天井里的老槐树已经要三个人才能合抱，树冠遮了半个天。他走到二楼古籍区，摸了摸那本蓝布封皮的诗集。

"早。"他说。

窗台上的小马灯还亮着。茶杯里的茉莉花茶冒着热气。楼梯上的嗒嗒声准时响起。

他走到大厅，翻开那本自己写了一辈子的笔记本。第一页是四十多年前的字迹，歪歪扭扭的："二楼里间，《未刊诗草》。住户一名，黄昏出没。胆小，勿扰。"

他翻到中间某一页，那里有一个名字，旁边画了一个小小的墨点。四十多年前他写下这个名字时，手是抖的——墨点灵，他没能帮到的第一个灵。

他拿起笔，在那个名字旁边写下一行小字："墨点灵，我后来帮到了很多灵。你走的那天，是我不够勇敢。现在够了。"

最后一页是昨天写的："今日无事。晚风照旧。"

他合上笔记本，走到天井里。

晚风来了。

风从巷口吹过来，暖暖的，轻轻的，裹着春天的气息——青草的、泥土的、花开的。风中还有一丝若有若无的桂花香。

他闭上眼，让那风在脸上停了一会儿。

他想，晚风年年都来。四十多年前是这样，四十多年后也会是这样。他不在了，风还会来。楼不在了，风还会来。只要有人记得这栋楼，记得这些旧书，记得那些看不见的邻居——晚风就年年都来。

他睁开眼，看了看天井里的老槐树。树上停着几只麻雀，叽叽喳喳的，像一群小孩子在吵架。他笑了笑，转身走进大厅。

苏晚——不，现在应该叫苏馆长了——正在给一个年轻女孩介绍馆藏。那女孩的眼睛亮亮的，她说："这本书好像在呼吸。"

陆栖停下脚步，笑了。

他想起很多年前，也有一个人说过一模一样的话。

大厅里安安静静的。书架整整齐齐。茶杯冒着热气。绿台灯亮着暖黄色的光。

他坐下来，拿起笔，在笔记本上写下今天的第一行字：

"晚风年年都来。"

```
  - 暗线推进：面对一个和自己很像的灵（被当成异类的小女孩灵）——他想起墨点灵
  - 暗线回响：在整理沈明远档案时发现一封未寄出的信，信中沈明远写道"吾生最大之憾，非未能守楼，乃未能护一诗魂"——陆栖在笔记本上写下："墨点灵，我也不是一护住。"

第四部（52-60岁）：
  - 暗线高潮：陆栖面对自己的"完成"——他帮了那么多灵，自己的执念是什么？
  - 暗线回响：面对一个和自己当年一样犹豫的年轻馆员，陆栖说："犹豫不是错，但别让犹豫变成来不及。"——这是墨点灵教他的
  - 暗线收束：他终于明白，他的执念不是"完成"，而是"让灯一直亮着"

第五部（60-68岁）：
  - 暗线收束：陆栖开始写回忆录，记录每个灵的故事
  - 暗线收束：他终于放下对"被需要"的恐惧

第六部（68-75岁）：
  - 暗线终章：在笔记本上写下"墨点灵，我后来帮到了很多灵。你走的那天，是我不够勇敢。现在够了。"
  - 暗线终章：陆栖终于学会"目送"——不只是目送灵，也目送自己老去
```

```
雪团（外貌永远不变：一团白绒绒）
  一部：怕冷怕生，只会把绒毯推给人

  三部：第一次离开保护册，短途走到天井又回来

  五部：会安慰更胆小的新灵："慢慢来，我以前也这样。"

  一部：说话结巴，被人认真听完就红了眼眶
```

### 客串写作要领
1. 老灵客串不为凑热闹，每次出场要么**推动剧情**（提供线索），要么**映衬成长**（对比新老），要么**暖场余韵**
2. 新老灵同框必有一次**互动细节**（递东西、让位置、学样子），体现"邻居"关系
3. 心理成长靠小事累积，忌突然"性格大变"；每部每灵至多推进一格
4. 外貌变化只在关键节点用，且必须呼应该灵"最在意的东西"

## 单元公式变体设计（防审美疲劳）

> 410章同一种"执念→理解→释然"模式必然疲劳。每部引入不同变体：

| 类型 | 占比 | 描述 | 示例 |
|------|------|------|------|
| A类·经典型 | 35% | 灵的执念→被理解→释然/远行 | 情书灵、乐谱灵、家书灵 |
| B类·陪伴型 | 20% | 灵不需要完成，只需要被陪伴 | 雪团、纸屑灵、小禾 |
| C类·解谜型 | 15% | 灵的执念是一个谜题，需要推理 | 照片关联、车票线索、批注对话 |
| D类·代价型 | 15% | 帮助灵需要陆栖付出代价或面对艰难选择 | 陆栖必须在"帮灵"和"保护秘密"之间选择 |
| E类·群像型 | 10% | 多个灵的故事交织，或人与灵的群像 | 馆庆、四季流转、灯火满堂 |
| F类·遗憾型 | 5% | 不是所有灵都能被完成——有些只能被记住 | 墨点灵（第一部）、忘了等什么的灵（第四部） |

**各部变体分布：**
- 第一部：A类为主（60%），建立基调
- 第二部：A类50% + B类25% + E类25%，引入陪伴和群像
- 第三部：A类40% + C类30% + D类30%，增加解谜和代价
- 第四部：A类30% + B类30% + D类25% + F类15%，引入遗憾
- 第五部：A类30% + B类30% + E类25% + D类15%，群像与传承
- 第六部：A类25% + B类35% + E类25% + F类15%，陪伴与闭环

## 写作原则（全系列适用）

### 不变的底线

1. **没有反派**：所有冲突来自等待、遗忘、误解，不来自恶意
2. **没有死亡**：灵的远行不是死亡，是完成
3. **没有黑暗结局**：每一部结尾都是温暖的、有希望的
4. **不恐怖**：灵是温暖的存在，不是鬼怪

### 每部必须有的元素

1. **至少一个完整的灵的故事**（有来历、有执念、有完成或留下）
2. **至少一个日常场景**（晒书日、泡茶、换灯、说"我走了"）
3. **至少一次晚风**：每一部结尾都要有晚风
4. **至少一句经典语录**：能被读者记住的话

### 情感节奏

每部的情感曲线：
```
平静 → 小波动 → 深入 → 触及核心 → 温暖收束
```

永远不要让读者感到绝望。即使是最悲伤的场景，也要留一盏灯。
