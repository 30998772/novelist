1. **规则偏移天赋**：0.01秒判定真空，可悬置系统判断
2. **叠加机制**：真空可叠加，但消耗精神力
3. **世界真相**：游戏是真实平行世界的投影
4. **特例单位**：主角最终被定义为无法封禁/修复/定义的存在
