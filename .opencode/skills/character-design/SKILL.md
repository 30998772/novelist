# 人物塑造

创建和维护 `characters.md` 中的人物档案。

## 人物档案模板

每个主要角色一份：

```
## <姓名>
- 基本信息：年龄 / 身份 / 所属阵营
- 外貌特征：2~3 个正文可反复调用的辨识点（不要写满一页外貌清单）
- 性格：核心特质 + 一个明显缺陷（缺陷推动剧情）
- 欲望 vs 恐惧：他最想要什么 / 最怕失去或暴露什么
- 背景故事：塑造其行为模式的关键经历（3 条以内）
- 语言特征：口头禅、句式习惯、用词档次——保证对话可辨识
- 成长弧线：从什么状态 → 经历什么转变 → 到什么状态
- 人物关系：<名字>（关系 + 当前张力）
```

配角可精简为：身份、与主角关系、功能、语言特征。

## 设计原则

- **动机自洽**：反派不作恶而作恶；每个行动都能用「欲望—恐惧」解释。
- **弧线绑定主线**：人物的内在转变节点应落在大纲的幕转折点上。
- **功能性检查**：无法删掉也不影响故事的角色考虑合并或删除。
- **一致性铁律**：已确立的性格、能力、口癖不得擅自更改；剧情需要人物做出反常行为时，必须铺垫动机或向用户说明理由并获确认。

## 关系网

主要角色 ≥4 人时，在 `characters.md` 末尾维护一张关系表：
`A ↔ B：表面关系 / 真实关系 / 当前张力`

## 衔接

- 新角色进入主线时，在 `outline.md` 对应章节卡片标注登场章。
- 人物言行的历史记录以各章正文为准，发现矛盾提示调用 `continuity-check`。
