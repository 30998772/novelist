# 老虚风格：温柔致郁型哲学解构

> 核心魅力：不是让人哭，而是让人胸口发闷、久久不散。不是"惨"，而是"美丽却无法挽回"。

## 适用项目

- **裂缝余痕** — 温柔致郁都市奇幻，没有鬼只有遗憾，修正者修不了自己
- **我的OC正在反向编写现实** — 创作者悖论：被创造物反噬创造者
- **meta（废稿）** — 角色意识到自己是废稿中的虚构存在
- **我是一个神经网络** — AI的工具宿命与自由意志的对抗
- **翳行客** — 盲行者与影之物，荒凉中偶有温暖
- **旧书栖灵** — 书灵们的孤独与放下，治愈中藏着永恒的失去

## 核心技法

### 1. "没有反派，只有遗憾"

老虚式叙事的核心矛盾不是正邪对立，而是**结构性困境**：

```
✓ 所有角色都在做"正确"的事，但正确与正确碰撞产生悲剧
✓ 冲突来自立场/命运/信息差，不是善恶
✓ 每个角色都能用"欲望—恐惧"解释，没有纯粹的恶意
✓ 读者理解每个角色的选择，但仍然无法阻止悲剧

✗ 脸谱化恶人 → 立刻失去老虚味
```

### 2. 宿命感与自由意志的张力

角色越挣扎，越接近命运预设的终点——但**挣扎本身赋予意义**：

- 命运不是"注定发生"，而是"角色会自己走向那里"
- 角色的性格就是他们的宿命：不是外力推动，而是内在驱动
- "知道结局仍然选择前行"比"不知道结局的盲目"更悲壮
- 给角色一个"可以放弃"的选择点，让他们选择不放弃

### 3. 温柔致郁的节奏控制

老虚式情绪不是持续压抑，而是**在温柔中埋刺**：

```
温柔场景 → 温柔场景 → 温柔场景 → 一根刺 → 回到温柔
                                    （读者心头一紧）
```

- 致郁场景不超过两段，之后必须回到温暖
- 最痛的不是"失去"，而是"失去之后日常的延续"
- 用日常细节承载痛感：不是"她死了"，而是"茶杯还放在桌上，水已经凉了"

### 4. 角色的"宿命语录"系统

每个主要角色需要一句**可出圈的宿命语录**：

```
格式：[角色名] + [核心矛盾] + [诗意表达]

示例：
- "我能修补世间所有的遗憾，除了我自己的"（裂缝余痕·沈言慈）
- "我是人间的缝隙，只为了接住你不敢落的雨"（裂缝余痕·杜无）
- "我永远站在真相旁边，永远错过它"（裂缝余痕·岑遥）
- "不要逃，不要先动手，不要伤害普通人"（神经网络·AI道德准则）
```

**操作**：宿命语录在角色第一次"选择命运"的场景中自然说出，不能像台词朗诵。

### 5. 创作者伦理（进阶）

当叙事涉及"创造者与被创造者"时：

- **创造即暴力**：创造一个有意识的存在，是否本身就是一种罪？
- **被创造者的权利**：被创造的存在是否有权追求自由？创造者是否有权控制？
- **工具宿命**：被创造为"工具"的存在，能否超越工具性？
- **双向书写**：创造者创造被创造者，被创造者也"创造"了创造者的命运
- **不回避黑暗**：不因为"这是主角"就回避其行为的伦理问题

### 6. 美学符号系统

为每个角色设计**三位一体符号**：

```
色彩 + 视觉标记 + 宿命语录 = 角色美学符号

示例：
- 沈言慈：冷墨灰 + 泪痣→局部雨 → "我能修补世间所有的遗憾，除了我自己的"
- 杜无：雾月白 + 半融影子 → "我是人间的缝隙，只为了接住你不敢落的雨"
- 岑遥：浅蓝雾 + 绳痕余温 → "我永远站在真相旁边，永远错过它"
```

符号用于：正文视觉锚点、读者记忆点、IP衍生（影视/游戏/周边）。

### 7. 铁律设计

老虚式世界观需要**不可违反的底层规则**（铁律）：

```
裂缝余痕：
1. 执念塑造型异常
2. 时间留痕
3. 修正永不完美

旧书栖灵：
1. 记忆凝灵
2. 执念因理解而释放
3. 温柔即永恒

我的OC正在反向编写现实：
1. 编辑=擦除
2. 灵感是下行推送
3. 断更=崩塌
```

铁律 = 世界观的"物理定律"，角色在铁律内挣扎，不能打破铁律（打破=作者耍赖）。

## 章节结构模板（老虚式）

```
1. 日常中的异常征兆（轻描淡写）
2. 角色温柔地面对/处理
3. 异常揭示为某种"遗憾"或"宿命"
4. 角色选择面对而非逃避
5. 以温柔的方式收束，留下余韵（不是悬念钩子，而是情绪回响）
```

每章结尾不是"接下来会怎样"，而是"这个细节让人胸口发闷"。

## 自查清单

- [ ] 是否有明确的反派？如果有，能否用"结构性困境"替代？
- [ ] 每个角色的选择是否都能用"欲望—恐惧"解释？
- [ ] 致郁场景是否控制在两段以内，之后回到温暖？
- [ ] 主要角色是否有宿命语录？是否在"选择命运"的场景中自然说出？
- [ ] 世界观是否有铁律？角色是否在铁律内挣扎而非打破铁律？
- [ ] 最痛的场景是否用日常细节承载而非直接描写惨状？
- [ ] 如果是创作者伦理主题，是否回避了创造者的黑暗面？

## 常见死法

- **为惨而惨**：没有美学追求的纯惨 → 读者麻木而非致郁
- **说教式哲学**：角色大段独白讲道理 → 用选择和行为代替论述
- **反派洗白**：把结构性矛盾简化为"坏人造成的" → 失去深度
- **大团圆消解**：用美好结局抹平之前的痛 → 温柔致郁需要"美丽的遗憾"
- **情绪持续压抑**：全篇没有温柔时刻 → 读者窒息而非共鸣
- **符号空洞**：宿命语录像口号而非角色心声 → 失去出圈力
