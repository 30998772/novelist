# 世界观构建

搭建小说的世界观，产出和维护 `worldbuilding.md`。

## 设定范围清单

按题材选用需要的模块：

| 模块 | 内容 |
|------|------|
| 地理 | 大地图、重要地点、地点间的距离与交通方式 |
| 历史 | 影响当下格局的大事件时间轴（只写有用的，别写百科全书） |
| 社会 | 政体、阶层、法律、习俗、货币与经济 |
| 力量体系 | 等级划分、修炼/施法/科技原理、晋升条件 |
| 势力 | 主要组织的目标、资源、相互关系 |
| 日常 | 饮食、服饰、通讯方式——正文质感来自这里 |

## 力量体系三原则

1. **代价与限制先于能力**：先回答"使用它的代价是什么、什么情况下失效"，再谈威力。无代价的力量会杀死悬念。
2. **规则透明**：读者理解规则后才能为角色的巧计喝彩；不要关键时刻临时加新规则救场。
3. **等级差距可感知**：越级挑战必须有合理机制支撑（道具、环境、牺牲），且不可滥用。

## 写作纪律

- 设定为故事服务：只详细展开主线会用到的部分，其余保持一句话占位。
- 每条会影响剧情的硬设定标注「硬约束」，正文不得违反；软氛围类设定可灵活。
- 世界观与既有章节冲突时，以已发布正文的描写为准，更新设定文件并向用户说明差异。

## 衔接

- 完成关键设定后，将影响主线的部分同步摘要进 `outline.md`；涉及时间线的记入 `timeline.md`。
