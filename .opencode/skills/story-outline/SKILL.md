# 大纲设计

搭建小说的整体结构与章节细纲，产出和维护 `章节大纲/` 文件夹。

## 结构方法

按篇幅选择骨架：

- **短篇**：起承转合四段式。
- **中长篇**：三幕式——第一幕（建置，约25%）/ 第二幕（对抗，约50%，中点必须有重大转折）/ 第三幕（解决，约25%）。
- **超长连载**：先定「总主线」，再拆「卷」（每卷一个阶段性大高潮），卷内拆章。

## 文件结构

```
章节大纲/
├── 总纲.md      # 全书总览、多部定位、主线逻辑、暗线总表、伏笔总表
├── 第一部/
│   ├── 总纲.md    # 第一部总览、伏笔登记
│   └── 逐章卡片.md # 第一部逐章大纲
├── 第二部/
│   ├── 总纲.md    # 第二部总览、伏笔登记
│   └── 逐章卡片.md # 第二部逐章大纲
├── 第三部/
│   ├── 总纲.md    # 第三部总览、伏笔登记
│   └── 逐章卡片.md # 第三部逐章大纲
└── 第四部/
    ├── 总纲.md    # 第四部总览、伏笔登记
    └── 逐章卡片.md # 第四部逐章大纲
```

对于单部作品，可以只保留第一部文件夹结构。

## 总纲模板

`章节大纲/总纲.md` 包含：

- 一句话概括
- 正传定位（体量、基调、核心）
- 多部总览表（每部定位、核心冲突、结尾钩子）
- 核心主线（表层+深层）
- 结构逻辑（每部定位+结尾钩子）
- 三大核心主角
- 核心世界观（三大铁律+核心概念）
- 暗线总表（伏笔埋设/回收追踪）
- 商业定位

`章节大纲/第X部/总纲.md` 包含：

- 本部定位（体量、基调、核心）
- 本部主线（表层+深层）
- 本部结构逻辑（每章定位+结尾钩子）
- 本部核心冲突
- 本部伏笔登记

## 章节卡片模板

`章节大纲/第X部/逐章卡片.md` 中每一章用此格式登记：

```
### 第NNN章 <暂定标题>
- POV：视点人物
- 场景：地点 / 时间
- 本章目标：这一章推动什么（剧情/关系/信息）
- 冲突：谁和谁的矛盾，卡在哪
- 转折/钩子：章末留什么
- 伏笔：埋下 [F-编号] 或回收 [F-编号]
- 状态：未写 / 已写 / 已修改
```

## 规划原则

- 每章至少完成一件事：推进剧情、揭示信息或改变人物关系，三者占其一方可成章。
- 伏笔必须登记进 `章节大纲/总纲.md` 伏笔总表（编号 F-001 格式），标注预计回收位置；只埋不收的伏笔是债务。每部伏笔登记在本部总纲中。
- 高潮前安排低谷；连续三章同类型事件 = 节奏拖沓预警。
- 大纲服务于写作而非束缚：正文偏离大纲时，回来更新大纲而不是放任不管。

## 与其他 skill 的衔接

- 构思阶段 → 先由 `story-brainstorm` 定核心概念
- 人物线交织复杂时 → 提示调用 `character-design` 补档案
