# 一致性检查

交叉核对全部创作文件，找出矛盾并维护 `章节大纲/总纲.md` 伏笔总表。

## 检查范围与顺序

1. **人物一致性**：逐章比对正文中的言行 vs `设定/角色设定/` 档案——性格、能力上限、口癖、称谓、年龄。
2. **设定一致性**：正文描写 vs `设定/世界观设定/` 硬约束——力量体系规则、地理距离、社会制度。
3. **时间线**：抽取每章的日期/时长线索，排成事件轴，找"三天走了半个月路程""角色同时出现在两地"类冲突。
4. **伏笔账本**：对照 `章节大纲/总纲.md` 伏笔总表逐条核验：
   - 已到预计回收章却未回收的伏笔 → 逾期预警
   - 正文中新出现但未登记的铺垫 → 补登记
   - 回收时是否与埋设时的细节吻合

## 执行方式

- 用 Grep 工具按人名、地名、设定关键词全文检索，不要凭记忆抽查。
- 章节数多时分批检查（每次 ≤10 章），汇总后统一报告。

## 报告格式

```
🔴 矛盾：第012章 vs 设定/角色设定/xxx — 描述差异 + 引用原文位置
🟡 逾期伏笔：F-007 预计第015章回收，现已第018章
🟢 良好：本次检查通过的项目简列
```

只报告，不擅自改正文；修复方案列出选项由用户决定。

## 收尾

- 经用户确认的修正同步写入相关文件；
- 更新 `章节大纲/总纲.md` 伏笔总表的伏笔状态为「已回收 / 已删除 / 已改期」。
