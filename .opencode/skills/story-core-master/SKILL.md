# 故事核心掌控法

> 核心永远是人。世界观、设定、剧情、反转、诡计，全部服务于两件事：
> 人在极端处境下的选择，以及这个选择带来的情感冲击。
>
> 读者会忘记设定、招式、剧情细节。但不会忘记那个让他心疼、发冷、落泪的人。

## 一、作品类型识别

### 四问定类型

先问四个问题：

1. 这个故事最让你记住的，是一个人、一段关系、一个画面，还是一个道理？
2. 主角最大的敌人是谁？
3. 最高光片段是因为什么成立？
4. 把核心元素删掉，故事还成立吗？

### 类型坐标

| 类型 | 核心问题 | 关键特征 | 代表作品 |
|------|----------|----------|----------|
| 主题驱动 | 人如何面对世界/命运？ | 人物是命题的载体 | 钢炼、小圆、诡秘之主 |
| 关系驱动 | 人如何面对他人？ | 关系就是一切 | 魔道、天官、Clannad |
| 向内探寻 | 人如何面对自己？ | 敌人是自己 | 物语、小樱、声之形 |
| 世界观察 | 人如何理解世界？ | 人物是观察视角 | 虫师、奇诺、芙莉莲 |
| 悬疑驱动 | 世界藏了什么？ | 靠释放信息驱动 | 海猫、命运石之门、巨人 |
| 情绪驱动 | 想让人感到什么？ | 情绪本身是内容 | 鬼灭、四月谎言、夏目 |
| 人物魅力 | 想让人爱上谁？ | 人设大于剧情 | 文豪野犬、银魂、JOJO |
| 氛围驱动 | 看见什么，感受到什么？ | 情节淡，余韵深 | 夏目、虫师、奇诺 |
| 群像剧 | 每个人都如何活着？ | 没有绝对主角 | 无头骑士、Baccano |
| 日常型 | 生活的温度在哪里？ | 无大事，有温度 | 轻音、悠哉日常大王 |
| 燃系战斗 | 为什么而战？ | 战斗承载信念与情感 | 天元突破、灵能百分百 |

### 复合结构确认

绝大多数名作都是复合型。确定：主类型是什么，副类型是什么。

- 犬夜叉 = 关系驱动 + 向内探寻 + 宿命主题
- 柯南 = 悬疑驱动 + 关系驱动 + 陪伴感
- 鬼灭 = 情绪驱动 + 人物魅力 + 战斗燃系
- 钢炼 = 主题驱动 + 群像 + 关系驱动

## 二、作品成色判断

### 六维评分（每项 0-10 分）

| 维度 | 判断核心问题 |
|------|-------------|
| 人物不可替代性 | 换一个人，故事还成立吗？ |
| 关系张力 | 有没有明明在乎却互相伤害、靠近就失去？ |
| 情绪落点 | 有没有一个瞬间让你停住、屏息、想重读？ |
| 设定根基 | 一句话"这个世界里，人最容易失去什么"能否答出？ |
| 核心痛感 | 能不能用一句话说出最痛的地方？ |
| 作者冲动 | 有没有一处"这个只有我写得出来"的内容？ |

### 总分评估

| 总分 | 判断 | 行动 |
|------|------|------|
| 10-18 | 未成型 | 不要改文字，先找核心的人 |
| 19-30 | 有东西但温吞 | 选定一个方向加力 |
| 31-42 | 不错但有短板 | 补最弱的一项 |
| 43-55 | 成熟 | 可以拿出手 |
| 56-60 | 经典潜质 | 进入精修 |

## 三、自己故事的启动

### 第一步：找到"非写不可"的东西

问自己：

- 我能写出一个只有我懂的人吗？
- 我脑海里有没有一个反复出现的画面？
- 有没有一句非说不可的话？

只要有其一，就可以开始。

### 第二步：用一句话说清核心

- "我想写一个被世界误解，却被一个人始终相信的人。"
- "我想写一个不得不杀死自己最好的朋友的人。"
- "我想写一个明知会失去，还是选择伸出手的人。"

这句话就是你的核。

### 第三步：确定最根本的敌人

是这个世界？某个具体的人？他自己？某个无法改变的过去？

### 第四步：写出一个关键场景

选出这个故事里，如果只能留一个画面，你会留什么。把它写出来。哪怕三百字。这就是故事的第一块砖。

## 四、初稿修正（已有稿子/AI稿子）

### 第一步：降维

不要在文字层面找问题。先问：这个故事想让读者对谁，产生什么感觉？

### 第二步：找"最接近"的一处

在已有稿子里，找出已经有那么一点味道的段落。哪怕只有两句。

### 第三步：把感觉翻译成一句话

- "他每一次笑，都是在告别。"
- "她越温柔，他越像被按进水里。"
- "不是不救，是救了之后，她再也不会记得他。"

### 第四步：只重写关键场景

不要推翻全文。只选一个场景，让它"准"。让 AI 出三个版本，你来选、来改。改到你心里"咯噔一下"，就对了。

### 第五步：反向修订全篇

用这个"准了"的场景当标尺：

- 前面在往这里推吗？
- 后面是从这里长出来的吗？
- 不是的地方，删或改。

## 五、终极判断

不是设定小、文笔嫩、剧情简单导致平庸，而是连作者自己都不在乎。

没有作者冲动，没有"非写不可的人"，没有一处让自己也心虚或心疼的真相，这样的故事，再工整也只是文字。

## 自查清单

- [ ] 这个故事的核心是什么？（一句话）
- [ ] 主角是谁？他最大的敌人是谁？
- [ ] 最高光片段是因为什么成立？
- [ ] 用六维评分：每项几分？总分多少？
- [ ] 如果只能留一个画面，留哪个？
- [ ] 这个故事里，有没有一处"只有我写得出来"的内容？
