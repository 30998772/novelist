# 类型匹配规则

> 不同书籍类型对应的推荐平台优先级。

## 匹配原则

1. **类型优先**：先按书籍类型筛选平台
2. **风格次之**：再按风格匹配（爽文/治愈/悬疑等）
3. **篇幅参考**：长篇优先付费平台，短篇优先社区/免费平台
4. **读者匹配**：考虑平台核心读者群与目标读者的重合度
