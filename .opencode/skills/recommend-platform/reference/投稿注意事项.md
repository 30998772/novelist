# 投稿注意事项

> 投稿前必须检查的事项和常见问题。

## 一、投稿前检查清单

### 稿件状态

- [ ] 全书/指定章节已完稿
- [ ] 已通读检查错别字
- [ ] 已检查标点符号规范
- [ ] 已确认无AI痕迹（降AI处理完成）
- [ ] 已确认无逻辑矛盾
- [ ] 已确认人设一致

### 格式要求

- [ ] 确认目标平台的格式要求（字数/格式/文件类型）
- [ ] 确认是否需要大纲/简介/人设稿
- [ ] 确认是否需要样章（通常3-5章）
- [ ] 确认文件命名规范

### 投稿材料

- [ ] 正文稿件（按平台要求格式）
- [ ] 作品简介/大纲
- [ ] 作者简介
- [ ] 联系方式

## 二、常见退稿原因

| 原因 | 说明 | 解决方案 |
|------|------|----------|
| 类型不符 | 与平台定位不匹配 | 重新选择平台 |
| 质量不足 | 文笔/逻辑/节奏有问题 | 润色修改后重投 |
| 篇幅不符 | 太短或太长 | 调整篇幅或选择其他平台 |
| 同质化严重 | 与平台已有作品太像 | 强化差异化卖点 |
| AI痕迹明显 | 被识别为AI生成 | 降AI处理后重投 |
| 格式不规范 | 未按要求排版 | 按平台要求重新排版 |

## 三、投稿时间建议

### 文学期刊

- 一般每月/每季度征稿
- 避开节假日（编辑休息）
- 提前1-2个月投稿

### 网文平台

- 随时可投
- 建议存稿10-20章后再发
- 保持稳定更新频率

### 比赛/征文

- 提前关注征稿启事
- 不要最后一天投稿
- 准备好备用方案

## 四、被退稿后的处理

1. **不要立即重投同一平台**：至少间隔1-2个月
2. **分析退稿原因**：如有反馈，认真分析
3. **修改后重投**：针对性修改后重新投稿
4. **尝试其他平台**：不要只盯着一个平台
5. **保持记录**：在 `推荐投递平台.md` 登记退稿记录

## 五、多平台投稿策略

### 可同时投稿

- 文学期刊 + 网文平台（不同平台可同时投）
- 国内平台 + 海外平台
- 短篇投期刊 + 长篇投网文

### 不可同时投稿

- 同一平台的不同编辑
- 竞争对手关系的平台（需确认）

### 独家要求

- 部分平台要求独家发布
- 投稿前确认是否接受一稿多投
- 签约后通常要求独家

## 六、稿费税务

### 国内稿费

- 稿费收入需缴纳个人所得税
- 税率：稿费×(1-20%)×20%×(1-30%)
- 平台通常代扣代缴

### 海外稿费

- 需要关注外汇管理规定
- 部分平台支持PayPal/Wise等
- 确认税务合规
