# 投稿注意事项

> 投稿前必须检查的事项和常见问题。

## 一、投稿前检查清单

### 稿件状态

- [ ] 全书/指定章节已完稿
- [ ] 已通读检查错别字
- [ ] 已检查标点符号规范
- [ ] 已确认无AI痕迹（降AI处理完成）
- [ ] 已确认无逻辑矛盾
- [ ] 已确认人设一致

### 格式要求

- [ ] 确认目标平台的格式要求（字数/格式/文件类型）
- [ ] 确认是否需要大纲/简介/人设稿
- [ ] 确认是否需要样章（通常3-5章）
- [ ] 确认文件命名规范

### 投稿材料

- [ ] 正文稿件（按平台要求格式）
- [ ] 作品简介/大纲
- [ ] 作者简介
- [ ] 联系方式

## 二、常见退稿原因

| 原因 | 说明 | 解决方案 |
|------|------|----------|
| 类型不符 | 与平台定位不匹配 | 重新选择平台 |
| 质量不足 | 文笔/逻辑/节奏有问题 | 润色修改后重投 |
| 篇幅不符 | 太短或太长 | 调整篇幅或选择其他平台 |
| 同质化严重 | 与平台已有作品太像 | 强化差异化卖点 |
| AI痕迹明显 | 被识别为AI生成 | 降AI处理后重投 |
| 格式不规范 | 未按要求排版 | 按平台要求重新排版 |

## 三、各平台投稿要点

### 起点中文网

- 需要存稿10-20章后再发
- 保持稳定更新频率（日更/隔日更）
- 前3章决定签约，需精心打磨
- 签约后要求独家发布
- 付费阅读分成

### 晋江文学城

- 女频核心，治愈/言情/耽美友好
- 前3章+文案决定曝光
- 保持稳定更新
- 签约后要求独家
- 付费阅读分成

### 番茄小说

- 免费阅读，流量大
- 门槛相对较低
- 广告分成模式
- 适合新人试水

### 飞卢小说

- 同人/系统文聚集地
- 爽文节奏要快
- 前3章必须有爽点
- 付费阅读分成

### 刺猬猫

- 二次元/轻小说向
- 年轻读者为主
- 设定/人设要鲜明
- 付费阅读分成

### 豆瓣阅读

- 文艺向核心平台
- 适合有文学性的类型小说
- 付费阅读分成
- 适合中短篇

### LOFTER

- 社区平台，短篇友好
- 适合试读/人设/宣发
- 打赏/约稿模式
- 不适合长篇连载

## 四、被退稿后的处理

1. **不要立即重投同一平台**：至少间隔1-2个月
2. **分析退稿原因**：如有反馈，认真分析
3. **修改后重投**：针对性修改后重新投稿
4. **尝试其他平台**：不要只盯着一个平台
5. **保持记录**：在 `推荐投递平台.md` 登记退稿记录

## 五、多平台投稿策略

### 可同时投稿

- 不同平台可同时投（如起点+番茄）
- 短篇投LOFTER+长篇投起点

### 独家要求

- 起点/晋江签约后要求独家
- 番茄免费模式无独家要求
- 投稿前确认是否接受一稿多投

## 六、收益模式说明

| 模式 | 说明 | 代表平台 |
|------|------|----------|
| 付费阅读分成 | 读者付费，作者按比例分成 | 起点、晋江、飞卢、刺猬猫 |
| 广告分成 | 免费阅读，广告收入分成 | 番茄、七猫 |
| 打赏/约稿 | 读者打赏或约稿 | LOFTER |
