# 情感戏写作

## 情绪公式：压抑蓄力 → 导火索 → 宣泄 → 余波

- 先压后放：宣泄前的隐忍越充分，爆发越有力
- 导火索要小而具体（一碗打翻的面），引爆的是积攒已久的大情绪
- 宣泄后必须有余波：沉默、下意识的小动作；不要戛然而止

## 催泪技法

- 用具体物件承载情感：旧毛衣、没发出去的消息
- 克制比嚎啕有力：写"她把眼泪憋回去，继续摆碗筷"
- 错位催泪：葬礼上没人哭，反而是整理遗物时被一双拖鞋击溃
- 让读者先于角色意识到失去，角色最后知道

## 告白与关系推进节拍

- 靠近—退缩—再靠近的三步舞：每次推进配一次代价或恐惧
- 台词宁笨拙勿华丽：真话往往说得磕绊
- 身体语言先于语言：先写手在抖，再说出口的话

## 冲突戏（争吵/决裂）

- 双方都必须"有理"：各自站在自己的伤口上说话
- 最狠的话戳的是对方真正的软肋（需前期铺垫）
- 吵完留裂缝，不当场缝合，给后续和解蓄力

## 红线

- 禁止报菜名式写情绪（"她感到悲伤、愤怒和不舍"）
- 情绪转折要有过程，禁止一键黑化/一键原谅
- 配角之死不许沦为主角成长的纯工具，给足其自身的重量

## 自查

- [ ] 把这段拿掉，读者会想念吗？
- [ ] 全段最重的那句话，落在具体细节上了吗？
- [ ] 宣泄之后，有没有留一口"余味"的静场？
