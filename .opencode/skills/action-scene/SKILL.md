# 打斗戏写作

## 清晰第一

- 读者随时能回答：谁在哪、朝哪动、想干什么
- 空间分层：先立地标（柱子、悬崖、楼梯），招式围绕地标走
- 每次攻防交换后重新定位一次双方位置

## 节拍结构：攻防有来回，代价在累积

1. 试探（互相摸底牌）
2. 交手升级（各自亮一手）
3. 危机（主角落入下风，付出真实代价）
4. 翻盘（用之前埋的能力/智谋/环境，禁止空降新能力）
5. 定格（一锤定音的一击，慢镜头）

## 燃感来源

- 翻盘手段必须提前铺垫（契诃夫之枪）：前文出现的弱点、道具、规则在此回收
- 代价可见：断刀、吐血、耗尽——赢得越惨越燃
- 旁观者反应做放大器：配角的惊呼、敌人的动摇衬托强度
- 关键一击用短句 + 分行制造速度感

## 能力体系纪律

- 战斗中遵守已定规则；临时加设定必须先付代价
- 强弱靠"限制与消耗"体现，不是数值喊话
- 越强的能力限制越狠

## 红线

- 禁流水账招式罗列（"一拳接着一脚又躲开"，无画面无立场）
- 同类招式换着写，同一个拟声词不连用三次
- 主角光环救场每卷不超过一次，且要付代价

- [ ] 这场赢靠的是铺垫内的东西吗？
- [ ] 打完之后，主角失去了什么 / 得到了什么？
