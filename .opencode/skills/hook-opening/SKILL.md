# 开篇与钩子

## 开篇三要素（前 500 字内完成）

1. 一个具体的人物在做一件具体的事（拒绝天气开场、梦境开场、设定说明书开场）
2. 一个反常信号：哪里不对劲
3. 一个问题钩子：让读者想问"然后呢 / 为什么"

## 黄金三章标准（网文）

- **第一章**：主角登场 + 核心冲突露头 + 金手指/卖点亮相，结尾必留钩子
- **第二章**：卖点第一次兑现（小爽点），冲突升级
- **第三章**：第一个小高潮落地，读者明白"这本书爽在哪"
- 三章读完，读者应能回答：主角是谁、想要什么、阻碍是什么、看点是什么

## 开篇常见死法

- 大段世界观设定先行（设定应随事件带出）
- 模板化开场三连：主角醒来、穿越晕倒、被退婚
- 出场人物超过 5 个，读者记不住
- 抒情散文式开头，迟迟不进事件
- 冲突与主角无关（先写别人出事）

## 章末钩子类型轮换

- 悬念型：新危机、异常细节、一句话炸雷
- 反转型：上一刻的认知被推翻
- 情绪型：宣泄落点、意难平
- 期待型：预告即将到来的对决/重逢

相邻两章不用同型钩子；钩子必须在下一章前 1/3 兑现或推进，不许无限吊。

## 开篇体检清单

- [ ] 第一段出现人物或事件了吗？
- [ ] 前 300 字能否删掉一半而不伤故事？若能 → 还不够凝练
- [ ] 读完第一章，是否产生一个明确想知道答案的问题？
- [ ] 卖点是否在前三章亮相，而不是憋到第十章？
