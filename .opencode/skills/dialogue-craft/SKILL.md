# 对话写作

## 对话三重功能（每句至少占其一）

1. **推进情节**：透露新信息、做出决定、引发冲突
2. **塑造人物**：语气、用词、思维方式即人设
3. **制造张力**：分歧、试探、言外之意

三者皆无的寒暄客套直接删除。

## 潜台词技法

- 人物很少直接说出真正想要的东西：让"说的"和"想要的"错位
- 用回避、转移话题、答非所问传递情绪
- 关键信息让读者比在场角色先一步听懂，张力自生
- 例：「吃饭了吗。」「你倒是关心这个。」——冲突不必明说

## 角色声纹区分（口吻指纹）

每个重要角色固定四件套：

- **句长习惯**：长句绕 / 短句砸
- **高频词与口头禅**
- **称呼方式**：对不同人怎么叫
- **回避什么**：绝口不提的事最显性格

检验法：遮住名字读对话，能猜出是谁说的才算过关；猜不出就回炉。

## 技术规范

- "说"字标签能省则省，用动作 beat 代替：他放下杯子。「随你。」
- 连续对话超过 3 个回合要插入动作或环境，防止"乒乓球实录"
- 对话里别塞设定说明（info dump）；必要信息拆碎了借冲突带出
- 方言、术语、敬语体系前后一致
- 单人单次发言一般不超过 3 行；长篇大论须被打断或有听者反应

## 自查清单

- [ ] 删掉全部对话剧情还能成立吗？若是，说明对话没起作用
- [ ] 有没有人在"替作者说话"（作者代言人腔）？
- [ ] 吵架、告白等重头戏里，是否至少有一句让人记住的台词？
- [ ] 情绪最激烈处，是否反而用了最短的话？
