# 对话写作

## 对话三重功能（每句至少占其一）

1. **推进情节**：透露新信息、做出决定、引发冲突
2. **塑造人物**：语气、用词、思维方式即人设
3. **制造张力**：分歧、试探、言外之意

三者皆无的寒暄客套直接删除。

## 潜台词技法

- 人物很少直接说出真正想要的东西：让"说的"和"想要的"错位
- 用回避、转移话题、答非所问传递情绪
- 关键信息让读者比在场角色先一步听懂，张力自生
- 例：「吃饭了吗。」「你倒是关心这个。」——冲突不必明说

## 角色声纹区分（口吻指纹）

每个重要角色固定四件套：

- **句长习惯**：长句绕 / 短句砸
- **高频词与口头禅**
- **称呼方式**：对不同人怎么叫
- **回避什么**：绝口不提的事最显性格

检验法：遮住名字读对话，能猜出是谁说的才算过关；猜不出就回炉。

## 技术规范

- "说"字标签能省则省，用动作 beat 代替：他放下杯子。「随你。」
- 连续对话超过 3 个回合要插入动作或环境，防止"乒乓球实录"
- 对话里别塞设定说明（info dump）；必要信息拆碎了借冲突带出
- 方言、术语、敬语体系前后一致
- 单人单次发言一般不超过 3 行；长篇大论须被打断或有听者反应

## 乒乓体的判定与治法

乒乓体 = 连续多行独立引语，**无归属、无动作、无环境**，读起来像会议记录。

**判定**：连续 ≥8 行引语且中间无叙述行为真乒乓。5–8 行通常是正常对话密度，不要动。

**必须排除「被引用的文本」**：日记正文、书页摘录、信件、契约、账目、单据——这些本身就该一行一句连着排，不是乒乓。判据：这些行不是「谁在说什么」，而是「纸上写着什么」，且上下文有"她翻开本子""那一页上写着""引语如下"这类引入。

```python
import re
Q  = re.compile(r'^["“].{1,30}["”]?[。？]?$')          # 纯引语行
TAG = re.compile(r'(说|道|问|答|喊|叫|笑|想|念|回头|站起来|看了看|摇了摇头)')
QUOTE_CTX = re.compile(r'(翻开|那一页|写着|摘|抄|信上|纸上|如下|原话|我的记录)')

L = [l.strip() for l in open(path, encoding='utf-8') if l.strip()]
i = 0
while i < len(L):
    if Q.match(L[i]):
        j = i
        while j < len(L) and Q.match(L[j]): j += 1
        n, quoted = j - i, False
        # 往前 8 行找一次引入，之后整段按引文处理
        if n >= 8:
            back = '\n'.join(L[max(0, i-8):i])
            quoted = bool(QUOTE_CTX.search(back))
            if not quoted and any(TAG.search(x) for x in L[i:j]):
                quoted = True          # 有归属标签，多半是正常对话
        if n >= 8 and not quoted:
            print(path, '第%d行 连续%d行' % (i+1, n))
        i = j
    else:
        i += 1
```

**「有归属标签」也是排除信号**：一段连续引语里只要有一行带「某某说」，通常就是正常对话被拆行了，不该算乒乓。反过来，整段一个标签都没有、又没有任何叙述插入，才是真正的乒乓。

```python
def pingpong(path, run=8):
    L = [l.strip() for l in open(path, encoding='utf-8') if l.strip()]
    c = r = 0
    for l in L:
        c = c + 1 if l.startswith('"') else 0
        if c >= run: r += 1
        if c == run: print(path, L.index(l) - run + 1)
    return r
```

**治法：合并，不是加标签。** 给每句加「他问」「她答」会让章更长。正确做法是把一问一答压进一段有归属的叙述：

```
- "为什么。"
- "你攥完它湿了，说明它留住了你手心的水。"
- "那它跟土一样？"
- "它跟土不一样。它跟一样东西一样。"
+ 方知远说石头也是留水的。苏念问那它跟土一样？
+ 他说不一样，它跟一样东西一样——什么，他没说。
```

**保留镜像对白。** 两人对镜头的短句（「你凉得比土快」「我凉手」）是刻意风格，不是病。判据：镜像句有内在逻辑与信息增量；乒乓句只是把叙述拆成了问和答。镜像不要合并，它的力量来自对称。
