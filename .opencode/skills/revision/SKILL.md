# 修改润色

按三个层次由重到轻审改，产出结构化意见后再动手。

## 审稿流程

1. **先诊断，后动刀**：通读目标章节，输出问题清单（位置 + 层级 + 问题 + 建议），等用户确认范围再改。
2. 用户明确说"直接改"时可跳过确认，但结构性大改（删场景、改结局、调时间线）仍须先说明方案。

## 三层检查

### 结构层（最优先）
- 本章是否推进了至少一件事？不推进 → 建议删除或合并
- 场景顺序是否符合因果与信息揭示节奏
- 开头是否入戏太慢（前三段必须出现钩子或冲突）；结尾钩子是否有力度

### 场景层
- 节奏：连续对话超过一页 → 插动作/环境节拍；描写堆砌 → 砍一半
- 视角：是否越出了本章 POV 人物的感知
- 信息：角色"不该知道"的信息是否提前泄露

### 文字层
- 删除冗余：「地」字副词、重复形容、解释性旁白
- 对话标签多样化但不过火；连续对白超过 4 轮无动作插入需处理
- 替换 AI 腔套话（参照 `chapter-drafting` 的禁用清单）
- 朗读测试：拗口的长句拆短

## 输出格式

```
【结构】第N段：问题 → 建议
【场景】第M段：问题 → 建议
【文字】原句 → 改句（理由）
```

## 红线

- 不擅自改变情节走向和人物性格——那是用户的决定。
- 改完在 `章节大纲/第X部/总纲.md` 将章节状态标为「已修改」，涉及伏笔变动同步 `章节大纲/总纲.md` 伏笔总表。

## 铁律：改稿之前

**这三条都出过事故，不要跳过。**

### 1. 先落回滚点，再动第一行

备份要**精简**：只留 `00_原稿`、`01_当前版本回滚点`、`02_脚本` 三份。多留几份「以防万一」的回滚点，一周后就分不清哪个是当前状态了。每完成一小批就覆盖回滚点——不要攒到最后。

### 2. 脚本绝不能先删后写

写批量脚本时，**先写全部新文件并验证，再删旧文件**。写反了就是整章丢失。

```python
# 错：删完才写，中途报错就全没了
for f in files: os.remove(f)
for f in files: open(f,'w').write(...)

# 对：写临时名 → 全部成功 → 才替换
tmp = []
for f in files:
    t = f + '.new'
    open(t,'w',encoding='utf-8').write(render(f))
    tmp.append((t, f))
for t, f in tmp: os.replace(t, f)
```

改写脚本跑完**立刻校验文件数**（`len(glob) == 期望章节数`），不等下一步。

### 3. 长度指标先确认口径

**唯一口径：总字符（含标点，不含空白）** `len(re.sub(r'\s','',t))`，要求 3200-3800。

不要再用汉字数 `len(re.findall(r'[\u4e00-\u9fff]', t))`——那是纯汉字，
与本口径差约 20%，会让同一章在两个标准下得出相反结论（3500 汉字 ≈ 4300 总字符）。

若某个项目沿用了汉字口径的历史统计，改口径时需重跑全部字数基线。

## 改完必跑

```python
import re, glob
bad = []
for f in glob.glob('正文/*/*.md'):
    t = open(f, encoding='utf-8').read()
    if re.search(r'\n{3,}', t): bad.append((f, '连续空行'))
    if '**' in t: bad.append((f, '正文加粗'))
    if '\ufffd' in t: bad.append((f, '坏字'))
    if not t.endswith('\n'): bad.append((f, '缺尾换行'))
    if t.count('"') % 2: bad.append((f, '引号不成对'))
    if not re.match(r'^# 第\d+章 .+', t): bad.append((f, '标题异常'))
print(bad or 'OK')
```

**引号不成对要逐行查**：整文件统计只能告诉你有问题，得逐行找出行号。注意引号可能跨行开合（书信、引文块），那种情况整文件计数是奇数但其实合法——看具体行。

## 拆分/合并章节

- **切分点必须先在原稿里核实。** 按印象切会切掉一半内容，而且新章常常结尾断在半句。
- 拆完立即校验：编号连续、无重号、每章都有结尾句。
- 拆完同步：`章节大纲/第X部/逐章卡片.md`、`章节大纲/总纲.md`、全书章节编号。**这三样不同步是拆章后最常见的遗留问题。**
- 原稿是基准：拆章前后的内容总量应当与原稿对得上。明显少了，说明切丢了。
