# 文风定制

分析、定义、模仿文风，并为项目产出可执行的《文风指南》。

## 能做什么

1. **文风分析**：给一段文字或一部作品，拆解其风格要素，输出「文风画像」
2. **文风定制**：与用户确认目标文风后，产出 `设定/文风指南.md`
3. **文风模仿**：参照样本文本提炼特征，应用到新写的文字上
4. **文风校对**：对照既定指南检查正文是否跑偏，指出偏离段落并改写

## 文风六要素（分析框架）

- **句式节奏**：长短句比例、段落密度、标点习惯（逗号连绵还是句号利落）
- **词汇色彩**：书面/口语、雅/俗、古风/现代、术语密度
- **叙述温度**：冷峻克制 ↔ 热烈抒情；作者跳出来评论的多少
- **意象偏好**：常用比喻类型、感官侧重（视觉/听觉/触觉）
- **幽默感**：正经/反讽/自嘲/冷幽默及其出现频率
- **信息方式**：直陈多还是留白多；解释欲强弱

## 工作流程

1. 分析样本 → 输出「文风画像」表格：六要素逐项评级 + 原文例句佐证
2. 与用户确认目标文风（拿不准时给 3 种候选，如"冷峻硬朗""轻快吐槽""绵密抒情"，各附 200 字试写样品）
3. 定稿写入 `设定/文风指南.md`，必须包含：
   - 一段正面示例（目标文风的示范段落）
   - 禁用清单（不符合该文风的词句模式）
   - 句式配方（长短句比例、段落行数、标点偏好）
4. 之后写章、改稿时对照该指南执行

## 文风模仿守则

- 只学特征不抄句子：提取句长分布、用词倾向、描写角度；禁止复用原文连续 7 字以上
- 求"神似"而非"形似"：优先还原叙述姿态与情绪浓度，其次才是词藻
- 先给试写样品让用户确认，再批量应用
- 模仿对象是受版权保护的作品时，只用于学习练习，产出的正文须为原创表达

## 常见文风配方速查

| 目标文风 | 句式 | 用词 | 禁忌 |
| --- | --- | --- | --- |
| 冷峻硬朗 | 短句为主，动词驱动 | 具体名词，少形容词 | 滥比喻、直抒胸臆 |
| 绵密抒情 | 长短交错，善铺陈 | 感官形容词丰富 | 信息过密、节奏拖沓 |
| 轻快吐槽 | 口语化，节奏跳脱 | 自嘲反讽适量 | 过度玩梗、油腻 |
| 古典雅致 | 四六句穿插 | 文言虚词点缀 | 现代词汇穿帮 |
| 悬疑冷峻 | 客观白描，信息克制 | 名词准确，少评价 | 解释过多 |

## 写完后

向用户汇报画像结论或指南路径；若建立了 `设定/文风指南.md`，提醒后续所有章节写作都应参照它。
