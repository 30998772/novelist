# 节奏控制

## 张力曲线原则

- 连续高压会让读者麻木：大冲突后必须有缓冲段（反应—消化—决定）
- 连续低压会流失读者：舒缓段里埋小钩子（异样、暗流、未接的电话）
- 每 3~5 章一个小高潮，每卷一个大高潮；高潮前压低、压久，释放才爽

## 场景节拍：场景—反应单元

- **场景（外部）**：目标 → 冲突 → 挫折/惨胜
- **反应（内部）**：情绪反应 → 权衡挣扎 → 新决定
- 快节奏章：砍短反应段；慢节奏章：扩写反应段
- 大场面之间必须穿插反应单元，否则情绪无处落脚

## 快慢工具箱

加速：
- 场景切到冲突爆发前一秒，跳过路程与铺垫
- 用对话交锋代替心理描写
- 时间跳跃："三天后"
- 短句、短段、删环境描写

减速：
- 特写关键道具与微表情
- 展开内心权衡与回忆闪回
- 插入环境细节烘托
- 长句、分段放缓

## 注水自查（拖沓诊断）

- [ ] 这一章删掉，主线受损吗？不受损 = 注水
- [ ] 是否在重复读者已知的信息？
- [ ] 对话是否同义反复（吵了一个回合但立场没变化）？
- [ ] 反应段篇幅是否超过了事件段？

## 太赶自查（仓促诊断）

- [ ] 重要转折前有铺垫镜头吗？读者来得及担心吗？
- [ ] 高潮戏给了足够篇幅展开吗？
- [ ] 情绪重大转变之间有过渡吗？

诊断结论按"加速/减速工具箱"给出具体修改位置清单，而不是笼统评语。
