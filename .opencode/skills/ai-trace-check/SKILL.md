# AI痕迹检测 Skill

逐章扫描正文，识别并消除AI生成痕迹。执行前必读 `reference/` 下的知识库文件。

## 工作流程

### 第一步：加载知识库

读取以下 reference 文件获取检测规则：

| 文件 | 内容 |
|------|------|
| `reference/高频词清单.md` | 问题词汇 + 替换方案 |
| `reference/AI腔句式.md` | 典型AI句式 + 修改方案 |
| `reference/标点规范.md` | 标点使用上限 + 修改规则 |
| `reference/重复类型.md` | 重复内容分类 + 检测方法 |
| `reference/替换方案.md` | 按场景分类的替换素材库 |
| `reference/各书特殊规则.md` | 每本书的专属禁用词和规范 |

### 第二步：读取本书 SKILL.md

获取当前书目的：
- 类型定位与风格
- 文风黑名单
- 字数要求

### 第三步：逐章扫描

对指定章节执行全量检查：

```
1. 高频词扫描 → 统计每个问题词出现次数和位置
2. AI腔句式 → 标记所有命中项
3. 破折号密度 → 总数、每万字密度
4. 重复内容 → 段落/对话/描写/反应重复
5. 标点统计 → 省略号、感叹号数量
6. 句长检查 → 超80字长句标记
```

### 第四步：输出扫描报告

```markdown
## AI痕迹扫描报告 — chXXX

### 高频词统计
| 词汇 | 出现次数 | 每万字密度 | 目标 | 状态 |
|------|----------|------------|------|------|
| XX | X次 | X次/万字 | ≤X次/万字 | ✅/⚠️ |

### AI腔句式
| 位置 | 问题句式 | 建议修改 |
|------|----------|----------|
| 第X段 | XXX | XXX |

### 破折号
| 指标 | 数值 | 目标 | 状态 |
|------|------|------|------|
| 总数 | X处 | — | — |
| 密度 | X处/万字 | ≤12处/万字 | ✅/⚠️ |

### 重复内容
| 位置 | 问题 | 类型 |
|------|------|------|
| 第X段 | XXX | 段落重复 |

### 标点
| 符号 | 数量 | 目标 | 状态 |
|------|------|------|------|
| …… | X处 | ≤8处/万字 | ✅/⚠️ |
| ！ | X处 | ≤10处/万字 | ✅/⚠️ |
```

### 第五步：执行修改

- 只改措辞，不改情节、不改人设、不改钩子
- 修改后重新统计确认达标
- 无法确定的标记【待确认】

### 第六步：登记记录

更新 `书名/修改记录.md`。

## 纪律

- 先读 reference 知识库，再执行检测
- 只动文风，不动情节
- 数据要准，修改后重新计数
- 逐章交付，每章汇报统计对比
- 保持原文风格特色
- 新发现的AI痕迹模式，追加到 reference 知识库
