# 标点规范

> 中文小说标点使用上限与修改规则。

## 一、标点使用上限

| 标点 | 上限 | 说明 |
|------|------|------|
| 省略号（……） | ≤8处/万字 | AI过度使用省略号渲染情绪 |
| 感叹号（！） | ≤10处/万字 | AI过度使用感叹号表达激动 |
| 问号（？） | ≤12处/万字 | AI过度使用问号表达疑惑 |
| 破折号（——） | ≤12处/万字 | AI过度使用破折号做补充说明 |
| 顿号（、） | 不限 | 相对自然 |
| 逗号（，） | 不限 | 但单句不超过80字 |
| 句号（。） | 不限 | 相对自然 |

## 二、省略号修改规则

### 问题用法

| 问题用法 | 修改方案 |
|----------|----------|
| 他……不知道该说什么。 | 他不知道该说什么。/他张了张嘴，没说话。 |
| 这……这不可能！ | 这不可能！/不可能。 |
| 她的眼神里，有太多太多…… | 删除省略号，用句号或具体描写 |
| 他想说什么，但最终还是…… | 他想说什么，但最终没说。 |

### 保留用法

| 保留用法 | 说明 |
|----------|------|
| 对话中的犹豫/停顿 | "我……我不确定。" |
| 声音渐弱/消失 | "救命……" |
| 章尾悬念钩子 | 适合用省略号制造悬念 |

## 三、感叹号修改规则

### 问题用法

| 问题用法 | 修改方案 |
|----------|----------|
| 这不可能！！！ | 这不可能！（最多一个） |
| 快跑！！！ | 快跑！（最多一个） |
| 他居然赢了！！！ | 他居然赢了！/他赢了。 |
| 好厉害啊！！！ | 好厉害啊。/厉害。 |

### 保留用法

| 保留用法 | 说明 |
|----------|------|
| 真正的惊呼 | "小心！" |
| 章尾强烈钩子 | 适合用感叹号制造冲击 |
| 系统提示 | 【警告！】 |

## 四、破折号修改规则

### 问题用法

| 问题用法 | 修改方案 |
|----------|----------|
| 他——那个传说中的男人——走了过来。 | 他走了过来。/那个传说中的男人走了过来。 |
| 这就是命运——不可违抗的命运。 | 这就是不可违抗的命运。/这就是命运，不可违抗。 |
| 她笑了——那种笑让人不安。 | 她笑了，那种笑让人不安。 |

### 保留用法

| 保留用法 | 说明 |
|----------|------|
| 系统文本【】内 | 【规则偏移——触发！】 |
| 章尾悬念钩子 | 适合用破折号制造悬念 |
| 剧情关键节奏点 | 重要的补充说明 |
| 对话中的打断 | "你听我——" |

## 五、句长规范

### 问题句式

| 问题 | 上限 | 修改方案 |
|------|------|----------|
| 单句超过80字 | 80字 | 拆成两个短句 |
| 连续3个以上逗号 | 3个 | 在适当位置用句号断开 |

### 示例

```
❌ 他跑了很久，穿过走廊，拐过弯，推开大门，冲进雨里，才发现自己已经迷路了。
✅ 他跑了很久，穿过走廊，拐过弯，推开大门，冲进雨里。他发现自己迷路了。
```

## 六、双逗号长句检测

### 检测规则

- 统计每个句号之间的逗号数量
- 如果连续出现4个以上逗号，标记为双逗号长句
- 如果单句超过80字，标记为超长句

### 修改方案

- 在语义完整处用句号断开
- 保持每句80字以内
- 连续逗号不超过3个

## 七、特殊标点规范

### 系统文本【】

- 仅限游戏/系统类小说使用
- 保持【】内标点简洁
- 不在【】内使用省略号

### 引用块（>）

- 用于论坛帖子、频道消息、公告等
- 保持引用块内格式统一
- 不在引用块内使用破折号

### 缩进块

- 用于数据面板、属性列表
- 保持格式统一
- 数字用阿拉伯数字
