# 高频词清单

> 持续积累，发现新问题词随时追加。

## 一、程度副词（过度渲染）

| 问题词 | 出现频率 | 替换方案 | 备注 |
|--------|----------|----------|------|
| 仿佛 | 极高 | 像、好似、犹如、像极了、活像、恍若、直接删掉改白描 | AI最爱用的比喻词 |
| 犹如 | 高 | 像、活像、好似、仿若 | 与"仿佛"同病 |
| 宛如 | 高 | 像、好像、好似 | 同上 |
| 似乎 | 高 | 像是、仿佛、大概、看样子 | 减少使用 |
| 好似 | 中 | 像、活像、仿佛 | 同系列 |
| 恍若 | 中 | 像、好像、仿佛 | 文艺腔过重 |
| 恍如 | 中 | 像、好像 | 同上 |
| 宛若 | 中 | 像、好像、如同 | 同上 |
| 犹似 | 低 | 像、好像 | 古风残余 |
| 仿若 | 低 | 像、好像 | 同上 |
