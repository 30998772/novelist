# 重复类型清单

> 重复内容的分类、检测方法和修改方案。

## 一、段落重复

### 检测方法

- 逐段对比，标记相似度超过70%的段落
- 特别关注：连续重复、间隔重复（隔几章后重复出现）

### 常见类型

| 类型 | 表现 | 修改方案 |
|------|------|----------|
| 战斗场景重复 | 相同的打斗描写出现多次 | 改写第二次为不同角度/节奏 |
| 心理描写重复 | 相同的内心独白出现多次 | 改写或删除重复部分 |
| 环境描写重复 | 相同的场景描写出现多次 | 改写或精简 |
| 反应重复 | 相同的震惊/反应出现多次 | 改写为不同反应 |

### 示例

```
❌ 第5章：他的拳头砸在墙上，鲜血顺着指缝流下。
   第12章：他的拳头砸在墙上，鲜血顺着指缝流下。

✅ 第5章：他的拳头砸在墙上，鲜血顺着指缝流下。
   第12章：他一拳砸在墙上，骨节发白。
```

## 二、对话重复

### 检测方法

- 逐句对比所有对话
- 标记完全相同或高度相似的对话

### 常见类型

| 类型 | 表现 | 修改方案 |
|------|------|----------|
| 相同台词 | 同一角色说相同的话 | 删除或改写 |
| 相似回应 | 不同角色用相同方式回应 | 改写为不同风格 |
| 重复问答 | 相同的问答出现多次 | 删除或合并 |

### 示例

```
❌ A："你确定？"
   B："你确定？"

✅ A："你确定？"
   B："确定。"
```

## 三、描写重复

### 检测方法

- 标记所有描写类语句
- 对比相似描写，标记重复

### 常见类型

| 类型 | 表现 | 修改方案 |
|------|------|----------|
| 外貌重复 | 相同的外貌描写出现多次 | 只在首次出场详写，后续简写 |
| 表情重复 | 相同的表情描写出现多次 | 改写为不同表情 |
| 动作重复 | 相同的动作描写出现多次 | 改写为不同动作 |
| 场景重复 | 相同的场景描写出现多次 | 改写或精简 |

### 示例

```
❌ 她的眼睛像星星一样亮。
   她的眼睛像星星一样亮。

✅ 她的眼睛很亮。
   她的眼睛在笑。
```

## 四、反应重复

### 检测方法

- 标记所有角色反应描写
- 对比相似反应，标记重复

### 常见类型

| 类型 | 表现 | 修改方案 |
|------|------|----------|
| 震惊反应 | 多人用相同方式表达震惊 | 改写为不同反应模式 |
| 愤怒反应 | 相同的愤怒描写出现多次 | 改写或精简 |
| 悲伤反应 | 相同的悲伤描写出现多次 | 改写或精简 |
| 围观反应 | 旁观者用相同方式反应 | 改写为不同视角 |

### 示例

```
❌ 所有人都惊呆了。
   所有人都惊呆了。
   所有人都惊呆了。

✅ 围观的人愣住了。
   有人倒吸一口冷气。
   没人说话。
```

## 五、句式重复

### 检测方法

- 统计句式结构
- 标记连续出现的相同句式

### 常见类型

| 类型 | 表现 | 修改方案 |
|------|------|----------|
| 排比重复 | 连续使用相同句式 | 打散排比 |
| 转折重复 | 连续使用相同转折词 | 换用不同转折词 |
| 问句重复 | 连续使用相同问句模式 | 改写为陈述句 |

### 示例

```
❌ 他跑了。她哭了。天暗了。
✅ 他跑了。她没追，只是站在原地，看着天暗下来。
```

## 六、跨章重复

### 检测方法

- 对比相邻章节
- 标记重复出现的内容

### 常见类型

| 类型 | 表现 | 修改方案 |
|------|------|----------|
| 开头重复 | 相邻章节用相同方式开头 | 改写开头 |
| 结尾重复 | 相邻章节用相同方式结尾 | 改写结尾 |
| 过渡重复 | 相邻章节用相同方式过渡 | 改写过渡 |

### 示例

```
❌ 第5章开头：阳光透过窗户洒进来。
   第6章开头：阳光透过窗户洒进来。

✅ 第5章开头：阳光透过窗户洒进来。
   第6章开头：雨停了。
```
