# 书名与简介

## 书名四路数

- **悬念钩子型**：名词短语自带谜团（《消失的第十三层》式）
- **高概念型**：一句话卖点直接当书名，题材关键词前置
- **意象情绪型**：取核心意象营造气质，适合文艺向
- **主角宣言型**：带"我"的第一人称态度句

要求：好读好记好搜索（3~8 字最佳）、避生僻字、起名后在目标平台检索一遍防撞名。

## 简介公式（120~250 字）

1. **钩子首句**：反常设定或困境（一句话，独立成段）
2. **主角与赌注**：谁、想要什么、失败会怎样
3. **卖点展示**：本书最独特的 1~2 个看点，可含一句高光台词
4. **收尾**：留一个悬念或一句狠话

禁忌：剧透关键反转；罗列设定；用"这是一个关于……的故事"套话开头。

## 简介文体

- 短句为主，多分段（手机阅读友好）
- 至少一行独立成段的"炸点句"
- 人名最多出现 2 个，其余一律用身份代称（神秘女人、老刑警）

## 章节标题

- 有信息量或有趣味至少占其一：忌裸编号（正文文件命名除外）
- 台词体 / 悬念体 / 反差体轮换使用
- 长度 ≤12 字为宜

## 交付流程

1. 问清作品定位、平台、目标读者
2. 书名给 ≥5 个候选并分型呈现；简介给 ≥2 版不同侧重（如一版重悬念、一版重情绪）
3. 附一句 15 字内 tagline 供宣传位使用
4. 用户选定后登记进项目 README 或推荐平台档案
