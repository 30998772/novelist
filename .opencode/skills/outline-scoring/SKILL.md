# 大纲质量评分系统

> 对故事大纲进行量化评估，找出短板，指导优化方向。

## 评分维度（100分制）

| 维度 | 满分 | 评估要点 |
|------|------|----------|
| **题材创意** | 15 | 概念新颖度、差异化程度、市场稀缺性、高概念吸引力 |
| **世界观构建** | 15 | 设定自洽性、规则清晰度、硬约束明确性、扩展潜力 |
| **人物塑造** | 15 | 主角弧光完整性、对手/配角立体度、关系网密度、成长节点设计 |
| **情节节奏** | 15 | 结构合理性、爽点密度与多样性、伏笔回收率、节奏曲线 |
| **文笔质量** | 15 | 语言风格独特性、叙述技巧、画面感、对话质量 |
| **结构完整度** | 10 | 逐章卡片完成度、伏笔登记表、时间线一致性、结局闭环 |
| **风格纪律** | 10 | 风格规则明确性、禁忌清单、执行一致性、AI痕迹防控 |
| **IP潜力** | 5 | 改编可能性、出圈元素、商业化空间、系列扩展性 |

## 评分标准

### 题材创意（15分）

| 分数 | 标准 |
|------|------|
| 14-15 | 概念极其新颖，市场上几乎没有对标作品，高概念一句话就能吸引人 |
| 11-13 | 有明确差异化卖点，在同类作品中有独特角度 |
| 8-10 | 题材本身有市场，但差异化不足 |
| 5-7 | 题材老套，缺乏独特卖点 |
| 0-4 | 题材与已有作品高度雷同 |

### 世界观构建（15分）

| 分数 | 标准 |
|------|------|
| 14-15 | 世界观完全自洽，有明确的铁律/硬约束，规则透明，无逻辑漏洞 |
| 11-13 | 世界观完整，有基本规则，存在少量可修复的矛盾 |
| 8-10 | 世界观框架存在，但规则不够清晰或存在明显漏洞 |
| 5-7 | 世界观模糊，规则随意，"临时加规则救场"频繁 |
| 0-4 | 没有明确的世界观，设定随写随丢 |

### 人物塑造（15分）

| 分数 | 标准 |
|------|------|
| 14-15 | 主角弧光完整（起点→转变→终点），对手有独立逻辑，配角有高光时刻 |
| 11-13 | 主角有成长线，对手有基本动机，主要配角有辨识度 |
| 8-10 | 主角有目标但弧线不清晰，对手工具化 |
| 5-7 | 主角被动反应多于主动选择，对手降智 |
| 0-4 | 角色功能化，没有独立人格 |

### 情节节奏（15分）

| 分数 | 标准 |
|------|------|
| 14-15 | 每章有独立爽点/悬念，节奏曲线起伏合理，无注水段 |
| 11-13 | 整体节奏良好，偶有拖沓但不影响追读 |
| 8-10 | 节奏时快时慢，部分章节信息密度不足 |
| 5-7 | 节奏失控，大段铺垫或大段高潮 |
| 0-4 | 没有节奏意识，平铺直叙 |

### 文笔质量（15分）

| 分数 | 标准 |
|------|------|
| 14-15 | 有独特语言风格，叙述技巧成熟，画面感强，对话有辨识度 |
| 11-13 | 文笔流畅，有基本技巧，无明显语病 |
| 8-10 | 文笔中规中矩，缺乏特色但不出错 |
| 5-7 | 文笔有明显问题（AI腔、解释过多、节奏拖沓） |
| 0-4 | 文笔与题材严重不匹配，或AI痕迹极重 |

### 结构完整度（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 所有分部有逐章卡片，伏笔登记表完整，时间线无矛盾，结局闭环 |
| 7-8 | 主要分部有逐章卡片，伏笔有登记但存在少量遗漏 |
| 5-6 | 只有总纲没有逐章卡片，或伏笔管理混乱 |
| 3-4 | 结构不完整，多部待规划，时间线矛盾 |
| 0-2 | 只有概念没有大纲 |

### 风格纪律（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 有明确风格指南+禁忌清单，执行规则可验证，AI痕迹防控到位 |
| 7-8 | 有风格描述和基本禁忌，但执行标准不够量化 |
| 5-6 | 有风格意识但缺乏具体规则 |
| 3-4 | 风格规则模糊，或规则与实际执行严重脱节 |
| 0-2 | 没有风格管理，AI腔/套路化严重 |

### IP潜力（5分）

| 分数 | 标准 |
|------|------|
| 5 | 有明确改编路径（影视/游戏/周边），有出圈元素设计 |
| 4 | 改编可能性高，有视觉化/符号化设计 |
| 3 | 有一定改编潜力但缺乏特别设计 |
| 2 | 改编难度大，或缺乏差异化视觉元素 |
| 1 | 几乎没有改编可能性 |

## 评级标准

| 分数 | 等级 | 含义 |
|------|------|------|
| 95-100 | S | 极优，可直接开写 |
| 90-94 | A | 优秀，小修后开写 |
| 80-89 | B | 良好，需要针对性优化 |
| 70-79 | C | 及格，需要较大改动 |
| 60-69 | D | 问题较多，需要重构 |
| <60 | F | 不建议继续，重新构思 |

## 评分流程

1. **收集材料**：读取总纲、逐章卡片、角色档案、伏笔登记表、风格指南
2. **逐维评估**：按8个维度逐一打分，每项给出具体依据
3. **汇总总分**：计算总分，确定等级
4. **诊断短板**：找出扣分最多的维度，分析原因
5. **优化建议**：针对每个短板给出具体可执行的优化方案
6. **目标分数**：设定优化后的目标分数及达成路径

## 常见扣分项速查

| 问题 | 扣分维度 | 典型扣分 |
|------|----------|----------|
| 金手指无代价/无边界 | 世界观 | -3~5 |
| 反派工具化/降智 | 人物 | -3~5 |
| 只有总纲没有逐章卡片 | 结构 | -4~6 |
| 伏笔不登记/不回收 | 结构 | -2~4 |
| 风格规则与实际脱节 | 风格 | -4~6 |
| 时间线矛盾 | 结构 | -2~3 |
| 对手出场太少 | 人物 | -2~4 |
| 爽点类型重复 | 节奏 | -2~4 |
| 结局不闭环 | 结构 | -2~3 |
| AI腔/金句结尾 | 文笔 | -3~5 |

## 自查清单（评分前必检）

- [ ] 是否读取了所有分部总纲？
- [ ] 是否读取了逐章卡片（至少前40章）？
- [ ] 是否检查了伏笔登记表的完整性？
- [ ] 是否检查了角色档案的出场计划？
- [ ] 是否检查了时间线的一致性？
- [ ] 是否检查了风格指南与正文的匹配度？
- [ ] 是否检查了世界观设定的自洽性？
