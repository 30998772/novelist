# 写得像个人（反复读工程）

AI 写长篇最常见的失败不是"不好看"，是**复读**：把一个句式复制一百遍，段落短到没有呼吸，叙事变成流水账。读者说"这什么玩意儿"，指的就是这个。本 skill 负责把它拆掉。

## 一、六条硬规则（违反即返工）

1. **禁止自我复述。** 正文里不得出现"她今日数的是""她数过这个数两回""第一回是…第二回是…""她把这个记下来"这类句子超过 **2 次/章**。人物要记账，就让她**动手**（把三张纸压在一起、认印不认字、画三个数），不要让她口述。
2. **禁止逐行加粗。** 正文**不用 `**`**，不用 `---` 以外的排版符。段落按语义合并，一段 60–180 字。
3. **对话占比按体裁分档。** 一章里如果全是叙述，通常说明在编——但**散文体例外**：

   | 体裁 | 占比 | 判废线 |
   |---|---|---|
   | 散文体 / 文学向（含独白章） | 10%–25% | <8% |
   | 标准章回小说 | 25%–40% | 全章 <6 处 |
   | 对话体（审讯、谈判、群戏） | 40%–60% | >65% 判乒乓 |

   **判据**：这一章的主要推进手段是"叙述"还是"人物交锋"。
   散文体里"台词是承重墙"依然成立，但叙述同样承重——不要把 25% 当成散文体的下限。
4. **每章至少 3 个非数字的具体细节。** 物件的声音/重量/温度、人的小动作、身体反应（抖、攥、喉结、指甲）。没有细节的章＝提纲扩写。
5. **每章至少 1 处潜台词。** 人物说 A，意思是 B；或人物答非所问。信息不靠台词直给。
6. **章末钩子是物证或动作，不是交代。** 禁止用"她把这一笔记在心里"这类总结句收尾；钩子要落在**一张纸、一只手、一句话**上。

## 二、反复读的四个具体手法

| 症状 | 药方 |
|---|---|
| 同一句式反复 | 第二次出现时改载体：让数字出现在纸上/物件上/别人嘴里 |
| 场景像报表 | 加一件不属于账目的东西：一只鞋、饭的气味、井绳、灯芯的花 |
| 情绪被说明 | 删掉情绪词，改成身体反应与不合常理的动作 |
| 结尾升华 | 停在最硬的那个事实上（印、笔画、断绳、空白批文） |
| 模板总结句 | 「这就是X——不只是A，还传承一种B：C」「X不只是记录故事，还传递力量」——同章出现两次即为复发，改成一件具体发生的事 |
| 万能情绪套语 | 「心里涌起一种…」「眼睛里闪着光」——见下节 |
| 焊接章 | 见下节 |
| 批量替换疤 | 见下节 |

## 三、动作：把"叙述"降格为"场景"

同一件事，两种写法：

- 差：她把凭据收进袖口，记下了这件事。
- 好：她把那张纸摊在几上，两枚印并在一处，缺角对缺角——是同一枚。签契书的人比她早一天就知道她要进门。

**原则：凡能变成纸、印、墨、绳、伤的位置，一律不要写成心理活动。**

## 四、检测（写完必跑）

```python
import re, collections
t = open(path, encoding='utf-8').read()
sents = [s.strip() for s in re.split(r'[。\n]', t) if s.strip()]
c = collections.Counter(sents)
dup_ratio = sum(v-1 for v in c.values() if v > 1) / max(len(sents), 1)
uniq_ratio = len(c) / max(len(sents), 1)
print('唯一句占比', round(uniq_ratio, 2), '重复率', round(dup_ratio, 2))
print([ (v, k[:20]) for k, v in c.most_common(5) ])
```

**判废线**（任一命中即重写，不要修辞润色，要重写）：

- 唯一句占比 **< 0.55**
- 单一短句（如"她数了。""二十息。"）重复 **> 8 次**
- 段均字数 **< 35**
- `**` 出现在正文
- 全章对话少于 6 处

## 五、返工方式

**不要在复读稿上打磨。** 复读稿的句子没有信息，润色只是把废话写得更长。正确做法：**回到章节表，只留事件与钩子，用场景重写。** 一次一章，写完跑检测，通过再写下一章。

## 六、四种复发型的识别与治法

这四种不是靠读出来的，是**同形句在全书换位置复制**。必须用脚本定位。

### 1. 模板总结句

句式：`这就是X——不只是A，还…一种B：C` / `X的力量——它不只是A，还B`

检测：

```python
import re, glob, collections
PATS = [r'这就是[^\n。]{0,10}——不只是', r'[^。\n]{0,20}的力量——它不只是',
        r'心里涌起一种', r'眼睛里闪着光', r'那是.{0,12}的歌。', r'没有尽头']
for d in 部列表:
    for f in glob.glob(f'正文/{d}/*.md'):
        t = open(f, encoding='utf-8').read()
        for p in PATS:
            for m in re.finditer(p, t):
                print(f, m.group(0))
```

治法：**摘要句要换成一件发生过的事，不是换一套漂亮词。**
反例：「有读者留言说，他回去以后在自己社区建了一个小小的守护队。」
正例：「社区工作者参加完课程后说，'我以前觉得社区工作就是处理琐碎的事。'」

### 2. 万能情绪套语

「心里涌起一种深深的感动/满足感/温暖的感觉」——这类句子的共同点是**作者没写他到底感受到了什么**。

治法：改成身体反应或不合常理的动作，一处一个，不要复用。

- 差：她心里涌起一种深深的感动。
- 好：她看了很久，然后把那一页翻过去，又翻回来。

删的时候注意：**一章一次的独立说法不是模板，留着**（「心里涌起一种熟悉的期待」只出现一次，读起来是自然的）。只有当它在不同章反复出现、且措辞高度雷同时，才是病。

### 3. 焊接章

**一章里塞了同一段剧情的两个版本**：前 N 行是 AI 摘要版，后 M 行是人写的真章。判断依据——前半有「总结全篇成果」的排比名单（"他来了，他做了A，他做了B，他做了C"）、`风里带着……`、`那些X交织在一起，变成了一首永恒的歌`，后半有一个具体的、未完成的动作或物件。

治法：**整段删掉前半，保留后半**。不要「合并」，两段是同一件事，写两遍就是冗余。

> 实例：`第三部/052 陆栖的写作`、`第三部/051 陆栖独自在旧书区`、`第三部/054 苏晚的册子` 都有此病。

### 4. 批量替换留下的疤

曾用正则批量改人名/称谓，误伤后留下的句子：**主语来自一句、谓语来自另一句**，拼在一起语法通顺但语义荒谬。

最常见的一族是**处所短语后被塞进光杆人称**——「站在书架前她看着那盏灯」。正确写法是「她站在书架前，看着……」或拆成两句。这类疤可以精确检出：

```python
import re, glob
# 处所动词 + 处所 + 光杆人称 + 看着（中间不能有别的动词）
pat = re.compile(r'(?:站在|坐在|跪在|在)[^，。！？—]{1,4}[她他](?=看着)')
neg = re.compile(r'(?:站在|坐在|跪在|在)[^，。！？—]{0,4}(?:听不|念给|看不|看得|看见了)')
for f in glob.glob('正文/*/*.md'):
    for i, l in enumerate(open(f, encoding='utf-8'), 1):
        if pat.search(l) and not neg.search(l):
            print(f, i, l.strip())
```

**收紧要点**：必须要求 `(?=看着)` 正向断言，否则「在她听不见」「念给她听的」全是误报。实测误报率 0。

**另一族**（谓语来自别处）正则抓不到，只能靠读，因为法理上未必不通：
- 「林越打量着她，她把腰又弯了一点。」——「弯腰」和「打量」不是同一个人的动作
- 「陆栖在那儿她看着那本书。」

判断这两类的口诀：**一句话里如果出现两个不相干的动词，读一遍，问自己「这两个动作是同一个人做的吗」**。答不上来就是疤。

治法：把多余的分句删掉，或补上缺失的动词。「在台灯下她看着那棵树天气」这种三处缝合的，直接重写整句。
