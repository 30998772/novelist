# 故事构思

帮助用户从零开始构思一部小说的核心概念。

## 工作流程

1. **了解偏好**（若用户未说明，先问清）：
   - 想写什么类型？（玄幻 / 都市 / 科幻 / 悬疑 / 言情 / 历史…）
   - 篇幅预期？（短篇 / 30万字网文 / 百万字长篇连载）
   - 目标读者与平台？（起点 / 晋江 / 传统出版 / 自娱）
   - 有没有特别想写的元素、意象或"爽点"？

2. **发散构思**：给出 **3 个方向明显不同** 的方案，每个方案包含：
   - 一句话高概念（logline）：主角 + 核心冲突 + 独特卖点
   - 类型定位与对标作品
   - 核心冲突（外部 + 内部）
   - 2~3 个亮点/名场面设想
   - 风险提示（该方向的常见坑）

3. **对比呈现**：用表格对比三个方案的卖点、难度、市场空间。

4. **收敛定稿**：用户选定后（可混搭），将确定的概念写入新项目文件夹。

## 构思检查清单

一个合格的高概念应能回答：

- [ ] 主角是谁？他想要什么？为什么得不到？
- [ ] 如果失败，主角会失去什么？（赌注）
- [ ] 这个故事和同类作品的差异点是什么？
- [ ] 用一句话讲给别人听，对方会想看吗？

## 新项目文件夹结构

构思完成后，建议创建以下结构：

```
项目名/
├── 设定/
│   ├── 世界观设定/
│   └── 角色设定/
├── 章节大纲/
│   ├── 总纲.md
│   ├── 第一部/
│   │   ├── 总纲.md
│   │   └── 逐章卡片.md
│   └── 第二部/
│       ├── 总纲.md
│       └── 逐章卡片.md
├── 正文/
│   ├── 第一部/
│   └── 第二部/
└── 系列规划/
```
