# 修改记录

每次修改（降AI、修bug、润色、结构调整）后，在 `书名/修改记录.md` 中登记，追踪全书修改历程。

## 工作流程

1. **读取现有记录**：如果 `修改记录.md` 已存在，读取最新条目
2. **分析本次修改**：统计修改类型、涉及章节、具体改动
3. **追加记录**：按时间顺序追加，不删除历史记录
4. **如果文件不存在**：创建新文件并写入模板

## 修改类型分类

| 类型 | 标记 | 说明 |
|------|------|------|
| 降AI痕迹 | `降AI` | 削减高频词、破折号、AI腔套话 |
| 重复修复 | `修重复` | 删除重复段落/句子/对话 |
| 逻辑修复 | `修逻辑` | 修复剧情矛盾、人设崩坏、时间线错误 |
| 润色 | `润色` | 提升文笔、节奏、氛围 |
| 结构调整 | `调结构` | 章节合并/拆分、顺序调整 |
| 字数调整 | `调字数` | 扩写/删减至目标字数 |
| 设定修正 | `修正设定` | 修正与SKILL.md冲突的内容 |

## 统计指标模板

降AI类修改建议统计以下指标：

- **高频词**：所有人、仿佛、第一次、不禁、竟然、居然、顿时
- **破折号（——）**：总数、每万字密度
- **AI腔套话**：眼中闪过一丝、嘴角勾起、空气凝固、五味杂陈
- **重复内容**：段落重复、对话重复、描写重复
- **标点硬伤**：省略号数量、感叹号数量
- **字数**：每章字数是否达标

## 纪律

- 每次修改必须登记，无论大小
- 只追加不删除历史记录
- 统计数据要准确，修改后重新计数
- 涉及设定变更时提示调用 `add-setting` 联动更新
- 修改记录是全书质量追踪的唯一依据，不可伪造数据
