# 写作系统能力地图 — Agent 与 Skill 全景

> 本文档展示 `.opencode` 下所有 agent、skill 的功能与调用链路。重启 opencode 后生效。
> 日常使用：**你只需要对 novelist 说中文指令，其余全自动调度。**

---

## 一、整体架构

```
                          ┌─────────────────────────┐
        你说中文指令 ───▶ │   novelist（主 agent）    │
                          └───────────┬─────────────┘
                    解析意图后自动调度 ↓
        ┌──────────────────────────────────────────────────┐
         │                    Skills（25个）                  │
        │  构思规划 · 写作技法 · 场景类型 · 质检修订 · 运营辅助  │
        └──────────────────────────────────────────────────┘
                    需要专项深度处理时派活 ↓
        ┌──────────┬──────────┬──────────┬──────────────────┐
   content-     ai-trace-   craft-     style-      chapter-
   reviser      checker     reviewer   curator     finalizer
   逻辑连贯      AI痕迹       技法审稿    文风守护     一站式终审
```

---

## 二、Agent 一览（6 个）

| Agent | 模式 | 职责 | 触发语示例 |
| --- | --- | --- | --- |
| **novelist** | primary 主力 | 总调度：构思/大纲/人物/写章/改稿，自动调用所有 skill 和子 agent | 默认就是它，直接说话即可 |
| **content-reviser** | subagent | 逻辑矛盾、上下文连贯、人设一致、伏笔追踪、时间线校验 | "查一下逻辑" "查伏笔" |
| **ai-trace-checker** | subagent | AI腔套话、高频词、比喻密度、标点、重复内容、降AI改写 | "降AI" "查AI痕迹" |
| **craft-reviewer** | subagent | 六维技法审稿：节奏/钩子/对话/描写/情感/打斗悬念视角 | "审节奏" "对话生硬" "没画面" |
| **style-curator** | subagent | 文风分析定制、风格模仿、《文风指南》维护、全书风格统一 | "定个文风" "这段文风不对" |
| **chapter-finalizer** | subagent | **一站式终审**：八步流水线检查+直接修改+登记修改记录 | "终审这一章" "写完帮我过一遍" |

### 子 agent 分工边界（互不重叠）

| 维度 | 负责 agent |
| --- | --- |
| 情节逻辑 / 连贯 / 人设 / 伏笔 / 时间线 | content-reviser |
| 语言表层：高频词 / AI腔 / 标点 / 重复 | ai-trace-checker |
| 写作技法：节奏 / 钩子 / 对话 / 描写 / 情感 / 打斗 | craft-reviewer |
| 语言风格定义与统一 | style-curator |
| 全部维度快速过一遍并直接修 | chapter-finalizer |

## 三、Skill 一览（25 个）

### 📚 构思规划类

| Skill | 功能 | 触发语示例 |
| --- | --- | --- |
| `story-brainstorm` | 新书头脑风暴、高概念提炼、3方案对比 | "我想开本新书" |
| `story-outline` | 大纲设计、分卷分章、情节节奏与伏笔布局 | "帮我搭大纲" |
| `character-design` | 角色档案、人物关系网、成长弧线 | "设计个主角" |
| `worldbuilding` | 世界观、力量体系、历史地理势力 | "构建世界观" |

### ✍️ 写作技法类

| Skill | 功能 | 触发语示例 |
| --- | --- | --- |
| `writing-style` | 文风六要素分析、文风指南生成、风格模仿 | "按XX的风格写" |
| `narrative-viewpoint` | 人称选择、POV切换、叙事距离控制 | "视角混乱了" |
| `dialogue-craft` | 对话三重功能、潜台词、角色声纹区分 | "对话太生硬" |
| `scene-description` | 展示而非陈述、五感调度、画面感配方 | "这段没画面" |
| `pacing-control` | 张力曲线、快慢工具箱、注水/仓促诊断 | "节奏太平了" |
| `hook-opening` | 开篇三要素、黄金三章、章末钩子轮换 | "开头不抓人" |
| `dragon-ride-007` | 规则破坏型智斗：系统漏洞利用、meta叙事、创作者悖论 | "写个规则破坏型主角" "智斗博弈" |
| `urobuchi-gen` | 温柔致郁型哲学解构：宿命悲剧、创作者伦理、美学符号 | "写段致郁的" "宿命感" "没有反派只有遗憾" |
| `anime-lightnovel-styles` | 日式ACGN经典风格参考：钢炼/DRRR/夏目/物语 | "钢炼风格" "像夏目那样写" "物语式对话" |
| `outline-scoring` | 大纲质量评分系统：8维量化评估+诊断+优化方案 | "打分" "评估大纲" "大纲太烂" |

### 🎬 场景类型类

| Skill | 功能 | 触发语示例 |
| --- | --- | --- |
| `emotion-scene` | 催泪技法、告白/决裂节拍、情绪公式 | "写段感情戏" |
| `action-scene` | 打斗清晰度、翻盘铺垫、燃感来源 | "写打斗戏" |
| `suspense-twist` | 悬念三级火箭、反转三定律、误导公平性 | "设计个反转" |

### 🔧 质检修订类

| Skill | 功能 | 触发语示例 |
| --- | --- | --- |
| `chapter-drafting` | 章节正文写作主流程（一章一个故事铁律） | "写下一章" |
| `revision` | 改稿润色、精简压缩、编辑提意见 | "帮我改改这章" |
| `continuity-check` | 前后矛盾排查、伏笔回收核对、时间线审查 | "查查有没有矛盾" |
| `ai-trace-check` | AI痕迹检测规则与消除方案 | "这章AI味重" |
| `revision-log` | 修改记录登记维护 | （改稿后自动登记） |

### 📦 运营辅助类

| Skill | 功能 | 触发语示例 |
| --- | --- | --- |
| `title-blurb` | 书名四路数、简介公式、tagline | "起个书名" |
| `recommend-platform` | 按题材风格推荐投稿平台 | "这本书投哪好" |
| `add-setting` | 新素材入库、设定更新归档 | "补充个设定" |

## 四、核心调用链路

### 链路① 开一本新书

```
你："开新书，类型是XX"
novelist
 ├▶ story-brainstorm    出3个方案 → 你选定
 ├▶ story-outline       总纲+分卷+逐章卡片+伏笔表
 ├▶ character-design    角色档案+关系网
 ├▶ worldbuilding       世界观+力量体系
 └▶ hook-opening + chapter-drafting   第一章落地
```

### 链路② 日常连载（最常用）

```
你："继续写下一章"
novelist ▶ chapter-drafting
            读大纲卡片 → 读上章结尾 → 写正文 → 更新卡片状态

你："终审"
novelist ▶ chapter-finalizer（八步流水线）
            衔接→逻辑人设→伏笔→节奏钩子→对话描写→AI痕→文风→字数
            A/B级直接改，C级列方案等你拍板 → 登记修改记录
```

### 链路③ 专项深度审稿

```
content-reviser ◀ "查逻辑/查人设/查伏笔"     内部调用 continuity-check
ai-trace-checker◀ "降AI/查AI痕迹"           内部调用 reference 知识库6件套
craft-reviewer  ◀ "审节奏/审对话"            内部参照 pacing/dialogue 等8个技法skill
style-curator   ◀ "定文风/风格统一"          产出 设定/文风指南.md
```

### 链路④ 改稿与返工

```
你："第5章节奏拖沓，帮我改"
novelist ▶ pacing-control（诊断）→ revision（执行）
         → revision-log（登记）→ 必要时 continuity-check（复核）
```

### 链路⑤ 成书投稿

```
你："写完了想投稿"
novelist ▶ title-blurb（书名+简介+tagline候选）
         → recommend-platform（按类型匹配平台+注意事项）
```

### 链路⑥ 设定变更

```
你："把男主的能力改成XX"
novelist ▶ add-setting（归档新设定）
         → continuity-check（排查已发章节是否受影响）
```
