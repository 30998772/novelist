# novelist 功能分类（按创作流程）

## 1. 构思阶段
- story_brainstorm：找灵感、定题材、讨论核心冲突

## 2. 设计阶段
- story_outline：大纲设计、章节规划、伏笔布局
- character_design：角色创建、人设档案、关系网
- worldbuilding：世界观搭建、力量体系

## 3. 创作阶段
- chapter_drafting：写新章、续写正文
- add_setting：补充素材、新增设定

## 4. 审稿阶段
- continuity_check：排查矛盾、查伏笔、对时间线
- ai_trace_check：检查AI痕迹、文风审查
- pacing_control：审节奏
- hook_opening：审钩子/开头吸引力
- dialogue_craft：审对话
- scene_description：审画面/场景描写
- emotion_scene：情感场景
- action_scene：动作场景
- suspense_twist：悬疑转折
- narrative_viewpoint：叙事视角

## 5. 修改阶段
- revision：修改润色、根据审稿意见改稿
- writing_style：定制文风、风格模仿、文风跑偏修正
- story_core_master：丰满度补强、AI协作磨场景

## 6. 评估阶段
- story_core_master：六维评分、故事核心诊断
- dragon_ride_007：规则破坏型智斗风格
- urobuchi_gen：温柔致郁风格
- anime_lightnovel_styles：ACGN风格参考

## 7. 包装阶段
- title_blurb：起书名、写简介、tagline
- recommend_platform：推荐投稿平台
- revision_log：修改记录登记
