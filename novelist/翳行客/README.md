# 翳行客

> 行走在阴影中的人，终将成为阴影本身。

## 项目概述

- **书名**：翳行客
- **类型**：古风武侠 · 悬疑 · 行旅叙事
- **视角**：第三人称限知视角（跟随主角）
- **基调**：苍凉、沉郁、偶有暖意
- **目标字数**：约210万字（600章 × 3500字）
- **状态**：大纲规划中

## 核心设定

本书讲述一名背负秘密的盲眼行脚商"沈翳"，行走于乱世江湖，以贩售各色奇异货物为掩护，实则追查十五年前灭门惨案的真相。他双眼虽盲，却能通过触觉、听觉、气息感知常人所不能察之物，随身携带的旧木箱中装满了来历不明的"翳物"——每一件都连着一段尘封的往事。
