# 角色档案：沈翳

## 基本信息

| 项目 | 内容 |
|------|------|
| 本名 | 沈昭 |
| 化名 | 沈翳 |
| 年龄 | 25岁（故事开始时） |
| 身份 | 行脚商 / 翳行客 |
| 外貌 | 清瘦，肤色苍白，常穿灰布长衫，背负旧木箱，手持竹杖 |
| 特征 | 双眼紧闭，眼睑处有淡青色翳痕 |

## 性格特质

### 表面
- 沉默寡言，不喜与人深交
- 对货物（翳物）极为珍视，对人则保持距离
- 偶尔展现黑色幽默，话少但一针见血

### 内里
- 极度自责：认为家人的死与自己有关
- 执念深重：追查真相的执念已近乎偏执
- 残存温柔：对弱者有本能的保护欲，但刻意压抑

### 弧光方向
从"为复仇而活"到"为逝者而活"，最终接受"有些真相永远无法完整"，选择带着残缺的真相继续行走。

## 背景故事

### 童年（0-10岁）
沈家是中州书香世家，父亲沈砚是晦朝史官，暗中研究"翳物"的起源。沈昭自幼聪慧，十岁时已通读家中藏书。

### 灭门之夜（10岁）
一夜之间，沈家上下三十七口被杀。沈昭被蒙面人从火中救出，但双眼被施以翳术致盲。醒来时已身在河西荒漠，身边只有一个旧木箱和一封没有署名的信："莫问来处，莫问归途。"

### 流浪期（10-15岁）
在荒漠中几乎饿死，被一位翳行老人收留。学习如何行走、如何交易、如何与翳物共处。老人三年后病逝，留下更多关于翳物的知识。

### 成长期（15-25岁）
独自行走江湖，以行脚商身份掩护，暗中追查灭门真相。逐渐在翳行中小有名气，被称为"翳行客"。同时，他的感官因长期接触翳物而逐渐异变——视觉完全丧失，但获得了"翳感"。

## 能力详解

### 翳感
- **基础感知**：方圆十丈内存在翳物时会产生"嗡鸣感"
- **触觉读取**：触碰翳物可读取碎片化记忆（非主动，有时会强制触发）
- **代价**：每次深度使用后，听觉或触觉会暂时迟钝（持续数小时到数天）

### 武学：无相手
- 专为盲人设计的近身格斗术
- 以听觉判断方位，以触觉感知对手动作
- 核心理念："不看而见，不闻而知"
- 招式名称朴实：探、引、卸、扣、震

### 听风辨位
- 通过脚步声、呼吸声、衣物摩擦声判断对手位置和动作
- 高手可通过气流变化判断暗器轨迹
- 限制：嘈杂环境（战场、市集）中效果大减

## 重要关系

### 苏檀（飞沙镖局少主）
青梅竹马，灭门之夜一同逃出，后被飞沙镖局收养。十年后重逢，成为沈翳最信任的人，但也隐藏着自己的秘密。

### 老烟（神秘老人）
沈翳的师父，翳行前辈，三年前病逝。留下大量关于翳物的笔记，但关键几页被撕去。

### 赵无眠（影阁密探）
亦敌亦友，多次与沈翳交手又合作。掌握着灭门案的部分线索，但交换条件是沈翳帮他寻找特定翳物。

### 沈砚（沈翳之父，已故）
晦朝史官，暗中研究翳物起源，发现了"心翳"的秘密。他的研究笔记是全书最大的悬念线索。
