# 第093章 我值这个数

沉下去的纸，才对得上账。浮着的纸对不上，是因为浮着的纸还在动。她这一日做了三件事。头一件是数。数的是三万四千两这个数。

三万三千九百九十八两八钱，是十一岁到十九岁这一段的价。这一段她算成了二十六两。二十六两和三万三千九百九十八两八钱差得极远。

差得远，是因为这两笔不是同一样东西。二十六两是十一岁那一年她记的数。三万三千九百九十八两八钱是三月初七那一笔的全数减定金。

两个数摆在一处，中间隔着一个定金的法子。定金的法子她昨日已经算过。三万四千两除以一两二钱，是一万八千九百九十九。

这两件事她昨日混在一处了。今日她把它们分开。分开之后，她今日算的是第二件。第二件是：她值多少。她值多少，署里没有一处写着。

名录上没有。采买簿上没有。分命册上没有。三娘手里那三张上也没有。没有写着的，就是没有定过的。没有定过的，她今日定。

今日有了。今日有了，是因为昨日那一页在她袖口里。那一页上有两个数。一个是一两二钱。一个是八两。两个数都是别人给的。

这一张不是署里发的。署里发的纸有数目，用一张要销一次。销一次要记一笔，记一笔要写日子和名字。她不想记这一笔。

她拿的是昨日折成三折那一页的背面。背面是空的。空，是因为正面写了三样。三样不能写在同一面上。同一面上写三样，往后对账的时候要分开看。

分开看的账，最容易漏。漏一处，这一页就作废。作废的一页，是白看一回。白看一回，是三娘白来一趟。三娘白来一趟，就白走了这一趟。

白走的那一趟，她自己记着。她拿炭条。用炭条不用笔。笔要洗，洗笔的水要走一道呈。炭条不用洗。不用洗的东西，才配写她自己的数。

万字是最不值钱的那一格。不值钱，是因为它是最大的一格。最大的一格写着最小的那个数。三万四千两里，最小的那一笔，是那四千。

四千在五位数里，是最小的一笔。最小的一笔，是最不值得写的一笔。不值得写的一笔，写了也是虚。虚的一笔，是万字那一格撑出来的。

三千四百两，是四位数。四位数比五位数窄。窄的那一格，是千字那一格。千字是四位数里最大的一格。最大的一格，和万字那一格一样，是撑出来的。

十字那一格，是这一格里最值钱的一格。因为剩下的四两，比十小。比十小的四两，是这一格里真正的数。真正的那个数，是四。

三娘十二岁那年给的是三十四两。三十四两里，最真的那一个，是四。四是三娘给的。三娘给的这一笔，是她七岁到十二岁那一段的全部。

七岁到十二岁，五年。五年，四两。一年不到一两。一年不到一两的人，在署里算最下等。最下等这一档，是七岁进名录那一档。

七岁进名录没有钱，是空付的。空付的才最下等。她七岁进名录，是最下等。十二岁卖三十四两，是中一等。十九岁进府值多少，是上等。

上等是多少，今日她自己定。这一层她昨日没有算。昨日她只算了定金和全数。今日她算的是三档。三档摆在一处，中间那档是三娘给的。

认了中间那一档，第三档才有根。有了根，第三档才立得住。立得住的第三档，是她自己的。她自己的第三档，是十九岁这一档。

六年是她七岁到十二岁，三娘卖她那一段。六年加十二年，是十八年。加上今年，是十九年。十九年她没有。没有十九年，她拿什么换。

她今日要拿的那一样，是她自己定的那一个数。那一个数，她还没有定。没有定，就还不能拿出去换。不能拿出去换，就还不能定。

今日她要在圈里站住。站住的意思是：她今日不定。今日不定，是因为今日她只算。算够了再定。算够的法子，是把三档都算到能对上的地方。

她写第二个数。第二个数是八两。八两是她母亲的值。八两是三娘十二岁那年记在她名下的。八两比三十四两少二十六两。

记成八两，是因为那年她把母亲的价当成了自己的。当成自己的那五年，在册上只有一行。那一行写的是：永和十一年三月，姜氏，值银八两。

那一行是母亲的。不是她的。她自己的那一行，在名录上。名录上她七岁进名录那一行，写的是价空。价空的意思是没有价。

没有价的意思是：七岁那一年她不值钱。不值钱，是因为没有人买。没有人买，是因为那一行是空付的。空付的意思是：录进去的时候，一文没有。

她十九岁今日要对的那一笔，就是要让她不再是那样的人。不再是那样的人，不是有人给她写一个数。是有一天她自己在纸上写一个数，写完不划。

写完不划，才算数。划了的，等于没有。没有的，等于七岁那一年。七岁那一年她不值钱。今日她要不划。不划的那一个数，是她今日要定的。

她写第三个数。第三个数她写了半日。写了半日，是因为这一个数她试了七回。七回里有五回她划掉了。划掉那五回，是因为她每次都多写了。

多写，就是把别人的算成自己的。把别人的算成自己的，是七岁那一年她做的事。今日不能再做一回。第六回她写的是三万四千两。

画掉的那一格，是撑出来的那一格。撑出来的那一格不是她自己的。不是她自己的，就不能算进她的价。所以第三个数是三千四百两。

三千四百两，是她自己画的圈里最大的一格。最大的一格，也是她最不敢定的那一格。最不敢定的那一格，她今日定下来了。

别人的数，手才抖。七岁那年她没有数，所以那时候她的手一直是抖的。抖了十二年。今日不抖了。今日不抖，是因为她今日第一次有了一个自己的数。

折起来，是因为纸上的三个数不能摊着。摊着的纸，谁走过来都看得见。看得见的数，就成了署里的。成了署里的，就有人要问。

所以要折起来。折起来，是因为折起来的纸看不见里头。看不见的，才是她自己的。她折了三折。折三折，是因为三个数折三层。

这三日她算出来三样。头一样是定金。第二样是全数减定金。第三样是她自己的价。前两样是别人给的。第三样是她自己定的。

写在纸上的东西，只要纸不烂，就一直在。纸烂了才是散。纸烂了也有数。烂到看不见字，才算散。所以她把这一张折好，收进袖口最里头。

收在最里头，是因为最里头不容易被拿出来。不容易被拿出来的，才不容易被人借去对账。借去对账的人，会顺手改一个数。

这一日她没有咳。没有咳，是因为她今日没有折。没有折，是因为她今日一整日没有替人承任何一份。不承，是因为她今日算自己的数。

算自己的数不折。替人算也折。自己算就不折。自己算的这一日，是她这三年里最干净的一日。最干净，是因为这一日她替自己算了一回。

替自己算的人，不欠任何人的。不欠人的一日，是她自己的。这一日她走到东跨院的水缸边。她走到缸边，是因为她要数水。

那个人她数过两次了。两次都是多半桶。多半桶是同一只桶打满了一桶，另半桶是另一只。两只桶不一样，说明打水的人有两只桶。

有两只桶的人，不是自己家的人。自己家的人一只桶。吴门房一只。所以还是那个人。那个人她不去问。不问，是因为这一件她记在心里。

"三娘。"

"哎。"

"您昨日说的那一件，我今日要问。"

"姑娘问。"

"您说您拿您的十九年换那一张。"

"是。"

"我今日问的是：换不换。"

"姑娘是问我要不要换。"

"我是问您换不换。"

"这两句不是一句。"

"是两句。"

"您问我，我答一句是。"

"我问您换不换。"

"我不换。"

这一句她也答得很快。答得快，是因为这一句她已经想了一日。想了一日的答案，是不换。不换，是因为换了，她就没有了。

没有了，她那三张就永远对不上。对不上，那一张白给。白给的这一张，她白跑了一趟。白跑一趟还算轻。重的是：她那一趟，是把自己换出去的。

"三娘，您昨日说来。"

"昨日是昨日。"

"昨日您说来，今日您说不。"

"姑娘。"

"哎。"

"昨日与今日之间，隔着一日。"

"隔着一日。"

"这一日里，您想清楚了一件事。"

三娘这一句她没有答。没有答，是因为这一句答了就是承认。承认她昨日是冲动。冲动的人，是不记账的。不记账的人，是她这三年做过的事里最不该做的一件。

"三娘，您昨日是冲动的。"

"我是。"

"今日呢。"

"今日我不是。"

想清楚了的，就不冲动。

"三娘，您今日不冲动，是想清楚了什么。"

"我想清楚的是：那一趟我来，是要拿一样东西换。"

"换什么。"

"换您把那三张对一遍。"

"我说了要对。"

"您说了要对。"

"您说了要对，您就要拿东西出来。"

"我拿了。"

"您拿了，您就不用拿您的十九年了。"

"您只要拿一样不是您的。"

这一句姜梧说了。说了，是因为这一句是她今日算出来的。算出来这一句的时候她才明白：三娘昨日说的十九年，是虚的。

虚的意思是：三娘知道自己不会真给。知道自己不会真给的，才先说。先说，是为了看她接不接。她接了，三娘就知道她好拿捏。

"三娘，您昨日说十九年，是试我。"

"姑娘。"

"哎。"

"我昨日说的不是试。"

"那是试。"

"不是。"

"三娘，十九年是一个空的人换出来的价。"

"空的人换了以后，就没有了。"

这一句三娘没有答。没有答，是因为这一句她自己也知道。自己知道的事，不用答。不用答的事，就是真的。真的这一句，是这三日她算出来的第二件要紧事。

不回屋，是因为她今日要在外头站一会儿。站一会儿，是因为她今日要走一段路。走路是因为她今日要走到水缸边，再走到门框边。

记在心里的这两处，是她十九年里唯一量过的两处。量过了，就有了自己的数。有了自己的数，她今日才敢说要拿的东西。

踮脚刻的，刻得歪。歪的才刻得下去。正着刻，刻不动。刻不动的，就不刻。不刻的那些年，她记在心里。记在心里的，就是她十九年里最重的那一笔。

最重的那一笔，她今日不去称。称了，就要算出来。算出来，就有了数。有了数，那十九年就成了三万四千两那样的一笔账。

成了账，就要有人担。担的人是她自己。她担得住。担得住是她这三日算出来的一件事。她今日不担，是因为她今日还不给它定价。

不定价的账，是没有对手的账。没有对手的账，讨不出来。讨不出来，就不是她十九年的数。十九年的数，比三万四千两大。

大很多。大到今日她不敢写。她转身要走。要走，是因为她今日要看的东西看完了。看完的东西，要走一段路才能沉下去。

左脚五下，右脚五下。左右一样多，是她走得很正。走得正的人，是心里不慌的人。心里不慌，是因为她今日有了一个自己的数。

有了自己的数，她今日就不慌。不慌的人，走十步是十步。慌的人，走十步是二十步。走的步子不一样，是因为心里装的重量不一样。

最大的一格也不重。重的是那一格底下的八两。八两是她母亲的。八两压在她身上，压了十九年。压了十九年的一个数，才重。

问别人就要问出别的。问出别的，就不是三万四千两了。不是三万四千两的，就不是她今日定的。不是她自己定的，就不算。

值一点是多少，她不知道。不知道的，就不定。不定的，就还是她自己的。这一日她咳了三声。咳了三声，是因为她今日动了自己的数。

动自己的数也要咳。也要咳，是因为动了自己的数，也动了她身上的那份。动了她身上那份，是往里动。往里动的，要咳出来。

三声。三声比昨日少。少，是因为昨日咳的是六十一。六十一减三，是五十八。五十八是她今日咳出来的数。五十八不是折进去的。

是算出来的。算出来的数不用折。不用折的数，咳出来就轻。轻的三声，是她这三月里最轻的三声。最轻的三声，是因为她今日第一次动的是自己的账。
