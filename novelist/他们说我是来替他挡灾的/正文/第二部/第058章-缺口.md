# 第五十八章 缺口

六月廿日，午后，府门里。

署门外的石阶上没有人，木箱上那道新划痕还留着，灰上压着一道浅印。

——

回到府里的时候，是午后。

吴门房在门房里。

"姑娘。"
"哎。"
"您回来了。"

"我回来了。"
"您今日去了很久。"
"一天。"

"我一夜没回。"
"您一夜没回。"
"吴门房，您今日添横了么。"

"我添了。"
"您添了几道。"
"两道。"

"因为您今日走的是正门。"
"我今日走的是正门。"
"您走正门了。"

"我走正门了。"
"最上头那一横，填上了。"
"那一横是今日的。"

"吴门房。"
"哎。"
"我今日在署里坐了一夜。"

"您坐了一夜。"
"我一夜没合眼。"
"您合过一回。"

"合了多久。"
"一小会儿。"
"吴门房，您一夜没睡，还是睡过一回。"

"我一夜没睡。"
"那您怎么知道。"
"因为我一夜没合眼。"

吴门房从门房里取出一只碗，碗里是水。

他把碗放在柜上。

"姑娘。"
"哎。"
"您喝口水。"

"我不渴。"
"您一日没喝水。"
"我喝过。"

"您什么时候喝的。"
"在架阁里。"
"架阁里没有水。"

"那您没喝过。"
"我没喝过。"

姜梧端起那碗水，喝了一口。

水是凉的，碗沿上有一道缺口，缺口是圆的。

"吴门房。"
"哎。"
"您这只碗，缺一块。"

"缺口是圆的。"
"二十年前，裴老夫人院里也有一只这样缺口的碗。"
"一样的。"

"那一年她二十岁。"
"十八。"
"她进府那年，摔了一只碗。"

"从那只碗起，二百四十七口人，一年到头，摔的碗都是这个样。"
"吴门房，我不问那一只。"
"您不问。"

"我问的是：后来还摔吗。"
"一年摔几回。"
"三四回。"

"三娘一只，我一只，陈谷一只，杂役房三只。老夫人自己摔过十一回。"
"为什么十一回。"
"因为她摔得比谁都快。"

姜梧把碗放回柜上。

"吴门房，您今日给了我一样东西。"
"什么东西。"
"水。"

"我一日没喝。"
"您一日没喝。"
"您没问我为什么。"

"我不问。"
"您为什么不问。"
"因为您要是渴了，您自己会问。"

"您不问，是因为您自己会喝。"
"我自己会喝。"
"姑娘，您今日话少。"

"我今日话多。"
"您今日话多。"
"我今日话多，是因为我一夜没睡。"

"您一夜没睡。"
"我一夜没睡。"
"吴门房，我今日在架阁里数了一夜。"

"您数了一夜。"
"我数了一夜。"
"数出什么。"

"数出三样。"
"哪三样。"
"第一样：命格册二十七页里，八页有字，十九页空。"

"第二样：第八页比别处多八格。"
"第三样：多出来的八格里，有两格是满的。"
"两格都是二十四画。"

"二十四画，在一百四十七页里，我找到四个半。"
"那半，在架阁第十四格里。"
"我今早数出来了。"

"您数出来了。"
"我数出来了。"
"那现在是五个。"

"陈先生说不让他翻第八页。"
"他不让我翻。"
"我翻了。"

"您翻了。"
"他怎么知道。"
"他不知道。"姜梧说，"他只说了那句话，说的是我。"

他把册子合上，压了一下。

他把手放在米缸上，盖子一掀一合，掀了三次。

"吴门房。"
"哎。"
"您掀了三回。"

"我掀了三回。"
"三回是您数到三。"
"三是我自己掀的。"

"您为什么掀三回。"
"因为我要把米缸里的米压一压。"
"压三回。"

"吴门房。"
"哎。"
"我今日在架阁里坐了一夜。"

"您坐了一夜。"
"我今日不想说话。"
"您不想说话。"

"我不想说话。"
"那您喝水。"

姜梧端起那碗水，把剩下的半碗喝完。

碗底的缺口有一粒米。

她把那粒米倒在掌心上看。

米是白的，圆的，缺了一角。

"吴门房。"
"哎。"
"今夜的月不圆。"

"月缺了一口。"
"跟那只碗一样。"
"吴门房，我今日在架阁里坐了一夜。"

"您坐了一夜。"
"我坐了一夜。"
"那一夜我在想一件事。"

"什么事。"
"我在想那个掉在档里的手。"
"第二格。"

"第二格里没有手。"姜梧说，"是我心里有的。"
"您心里有的。"
"我心里有的。"

"吴门房，我进府六十七日。"
"我数了六十七天。"
"您数了六十七天。"

"我今日数完了。"
"您数完了。"
"我今日把它记下来。"

"您记在纸上。"
"吴门房，您今日看我，是一眼。"
"三日前你看我，是三眼。"

"我今日不知道您看成几眼。"
"我今日看了一整日。"
"您进门的时候我看了一眼，您出去的时候我又看了一眼。"

"那是两眼。"
"我今日没看第三眼。"
"为什么。"

"因为您在架阁里坐着，您不看人。"
"我不看人。"
"您看格。"

"我看格。"
"看格的时候，您不看门口。"
"我不看门口。"

吴门房不再说话。

他把米缸的盖子盖上，压了一下。

"吴门房。"
"哎。"
"我明日还去。"

"您明日还去。"
"我明日要把那一册抄出来。"
"抄出来我再看一遍。"

"您看了它，它就变了。"
"它不变。"
"它会变。"

"为什么。"
"因为第三格已经填了字。"
"您自己填的。"

"我自己填的。"
"您填的是查原籍的空行。"
"我填的是查原籍的空行。"

"您填了，那一行就动了。"
"它动了。"
"动了的那一行，往后会有人来动第二次。"

"第二次不是您。"
"我算了一遍。"姜梧说，"我明日去的时候，那一册或许已经不在第十四格。"
"我算的是：或许。"

"姑娘。"
"哎。"
"您算的或许里，有几成。"

"七成。"
"剩下三成呢。"
"剩下三成是它还在。"

"它还在，三成。"
"它还在的时候，姑娘您要不要连夜抄。"
"那您今夜就睡不成。"

"我今夜也没打算睡。"

吴门房把碗收了。

"吴门房。"
"哎。"
"这只碗我拿走了。"

"它有缺口。"
"我明日拿它去换。"
"您拿什么换。"

"拿三张纸换。"
"我三张纸换一只碗。"
"那您划算。"

"我不划算。"
"您不划算。"
"吴门房。"

"哎。"
"我把碗留下了。"
"您留它做什么。"

"留着。"
"看缺口。"
"缺口是圆的。"

"缺一口的碗，才装得下水。"
"所以我留下了。"
"您把它留下了。"

"我把它留下了。"

姜梧回东跨院。

她坐下，摊开袖口里那四十三张纸。

四十三张。她没有加。

她拿出今天取档单上抄下来的第三格，摊在最上头。

六个小方框，一个大框，一个点。

点旁边一个记号。

她看了很久。

然后她把取档单折好，收进袖口。

"今天归位的东西有三样。"

她对着桌上那四十三张纸说。

"第一样：命格册。"
"第二样：那块挡板。"
"第三样：我自己。"

三样。

前两样在架阁上，第三样在她身上。

她把三样记在心里。

前两样记在心里，不落纸。

第三样落纸。

落纸的只有一张纸：六个小方框，一个大框，一个点。

这张纸上是她在第六卷第一页第一行写的东西。

她今日把它抄了一遍。

抄的时候她发现了一件事。

她抄的六个小方框，跟第七页那六个不一样。

第七页那六个，大小一样。

她抄的这六个，有两个比别的小。

小的那两个，是"第六十九行"和"第七十三行"。

第六十九行是那个三年前死的。

第七十三行是她。

两个小框，一个死了，一个活着。

她把这一条记在心里，不落纸。

落纸的只有"两个小框"这三个字。

她今日坐在桌前，看了很久。

窗外，日头落进院墙里头去了。

院墙上那两道渗水的白边显出来了。

她数了。

两道。

三样，都记在心里。

落纸的只有那张六个小方框、大方框、一个点的纸。

窗外，井绳在风里撞了一下井沿。

她听着。姜梧把碗收了。

她没有立刻走。

她站在门房门口，看着吴门房把碗倒扣回柜上。

倒扣的时候碗底朝上，缺口转到里侧，看不见。

"吴门房。"
"哎。"
"这只碗，您倒扣多少年了。"

"十九年。"
"十九年前您就在门房。"
"我十九年前进府，进的就是门房。"

"十九年前这只碗是好的。"
"您摔的。"
"我摔的。"

"为什么摔。"

吴门房的手在柜面上按了一下。

"因为那年老夫人嫁进来，府里摆宴。"
"宴上用的碗，一色的。"
"我用错了。"

"您用错了哪一只。"
"我用的那一只，缺口朝上。"
"缺口朝上的碗盛汤，汤漏。"

"汤漏在桌上。"
"汤漏在老夫人的裙子上。"

门房里静了一下。

"老夫人那年十八。"
"她没有骂我。"
"您知道她没有骂您。"

"她把裙子上的汤擦掉了，然后把这只碗拿走了。"
"她拿走了。"
"她拿走了以后，没有再还。"

"没有还。"
"吴门房。"
"哎。"

"那这十九年，您倒扣着它，是为了看缺口，还是为了不看。"

吴门房没有立刻答。

他把柜上那只倒扣的碗转了半圈，转得极慢，转到缺口朝外为止。

"不看。"
"看了它就是一口破碗。"
"不看它就是一只碗。"

姜梧伸出手，指尖在那道圆口上按了一下。

按下去，碗沿的毛刺扎手。

她把手缩回来，在指腹上看见一道红。

红得很浅，一眨眼就没了。

"吴门房。"
"哎。"
"我今日不拿这只碗了。"

"您不拿。"
"我拿去换，我换回来还是一只缺口朝上的碗。"
"那我就不换。"

"您不换。"
"我把它倒扣回去。"
"您倒扣回去。"

姜梧把碗翻过来，重新倒扣在柜上。

扣完她退开一步，看了看。

从她站的地方看，缺口正好朝着柜里。

看不见。

姜梧回东跨院。

她坐下，摊开袖口里那四十三张纸。

四十三张。她没有加。

她拿出今天取档单上抄下来的第三格，摊在最上头。

六个小方框，一个大框，一个点。

点旁边一个记号。

她看了很久。

然后她把取档单折好，收进袖口。

"今天归位的东西有三样。"

她对着桌上那四十三张纸说。

"第一样：命格册。"
"第二样：那块挡板。"
"第三样：我自己。"

三样。

前两样在架阁上，第三样在她身上。

她把三样记在心里。

前两样记在心里，不落纸。

第三样落纸。

落纸的只有一张纸：六个小方框，一个大框，一个点。

这张纸上是她在第六卷第一页第一行写的东西。

她今日把它抄了一遍。

抄的时候她发现了一件事。

她抄的六个小方框，跟第七页那六个不一样。

第七页那六个，大小一样。

她抄的这六个，有两个比别的小。

小的那两个，是"第六十九行"和"第七十三行"。

第六十九行是那个三年前死的。

第七十三行是她。

两个小框，一个死了，一个活着。

她把这一条记在心里，不落纸。

落纸的只有"两个小框"这三个字。

她今日坐在桌前，看了很久。

窗外，日头落进院墙里头去了。

院墙上那两道渗水的白边显出来了。

她数了。

两道。

架阁里坐了一夜。她数出两个小框，一上一下：上头那个圈画得歪，先按的，人死了；下头那个圈画得正，后按的，人还活着。

三样，都记在心里。

落纸的只有那张六个小方框、大方框、一个点的纸。

窗外，井绳在风里撞了一下井沿。

她听着。

她回东跨院的时候，天已经全黑了。

黑得看不见院墙。

她进屋先点灯。

灯点着，屋里亮起来。

亮起来以后她才发现，桌上有一样东西不是她的。

是一只碗。

碗倒扣着。

缺口朝着柜里。

她把碗翻过来看。

碗底有一个记号。

记号很小，是用指甲划的一道。

划得很浅，浅到要对着灯才看得见。

她把碗对着灯举起来。

那道划痕在灯下显出来了。

不是一道。

是两道。

两道并排，一长一短。

长的那道有三划，短的有一划。

三加一，是四。

她把碗放下来。

这只碗不是府里的。

府里的碗她认得。

这只碗的碗沿上有一道烧痕，烧的那一面往外翻。

翻的那一面朝里。

也就是说，这只碗摔过，摔的时候口朝下。

口朝下摔，碗沿不会翻。

碗沿翻了，说明它不是摔的。

是被人把碗口朝下按在硬东西上按裂的。

她把这只碗放回桌上。

放完她把门闩插上。

闩上以后她在门后站着。

站了一会儿，她把窗推开一条缝。

缝很窄。

外头没有人。

她把窗关上。

她没有把这只碗收起来。

收起来就等于她拿了。

拿了就要问是谁放的。

她坐回桌前，把袖口里的纸全部掏出来，摊在桌上。

四十三张。

她没有加。

她把今日那一张摊在最上头。

今日这一张上有一个记号：圈里点一点。

一个记号对应一个人。

那个人今日在这府里坐了一夜。

她把纸压好，压在那只倒扣的碗旁边。

压完她才想起来：这只碗是缺口朝里的。

缺口朝里，看不见。

她把碗转了半圈，转到缺口朝外。

停住。

她看着那道缺口。

圆口。

缺口是圆的。

她今日在署里见过一个圆的东西。

圈里点一点。

那个记号也是圆的。

她把这一条记在心里。

不落纸。

落纸的只有一句：四十三张，加一张空碗。

窗外，井绳在风里撞了一下井沿。

她听着。
