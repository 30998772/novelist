# 第四十章 一个头

六月初十，辰时。

姜梧没有去署里。

她坐在东跨院，把这三日的东西在纸上排开。

她摊开三张纸。

第一张上写着七个数：三十四两、三万四千两、一百四十七、二十四、九、四、十三。

第二张上写着两行：第三格，空的；第七页，封。

第三张上写着两个数：九、六。

她把三张纸并在一处。

她今日要做的是一件很笨的事：把这三张纸上的数，一个一个对。

先对第一张。

三十四两，能对：凭据上一枚印缺角。

三万四千两，能对：姜三娘袖口两道白印。

一百四十七，能对：取用则例她背了九百零八条，加第三卷到第八十一卷，合一千四百四十七。

二十四，能对：第三卷第一页第一行那一行。

九，能对："空"字九画。

四，能对："无"字四画。

十三，能对：圈里点一点，圈九画，点四画。

七个数，七个对上的东西。

她把这七个对上的，记在一张新纸上。

记完，她对第二张。

第三格，空的。能对：没有。

第七页，封。能对：监正亲手封的，令贴在架阁门上。

两个数，一个对得上，一个对不上。

她把这两个记下来。

再对第三张。

九，能对：九个空命格的人。

六，能对：陈谷说的一半——六个名字，两个姓周的姓吕的。

能对上。

她把三张纸对完，又做了一件事。

她把十个数抄在一张新纸上，抄成两行。

第一行五个：三十四，三万四千，一百四十七，二十四，十三。

第二行五个：九，四，九，六，二。

她抄完，把这张纸折成两折，塞进袖口。

然后她出门，往二进去。

裴鹤在案后坐着。案上没有茶碗。案面上还留着那一圈淡淡的印子，印子上有缺口。

"监正。"

"嗯。"

"我今日带了十个数来。"

"十个数。"

"十个能对上的数。"

"能对上。"

"我今日对一遍。"

"你对。"

"第一个：三十四。"

"三十四。"

"我三月初一在罪妇名录上是一个数。"

"是三十四。"

"这三十四两是钦天监采买出的。"

"是公账出的。"

"公账出三十四两，落款是钦天监采买。"

"是。"

"这三十四两不进裴府的账。"

"不进。"

"第一个，对上了。"

"对上了。"

"第二个：三万四千。"

"三万四千。"

"这三千四百是姜三娘十九年抽的一成。"

"是。"

"她袖口上两道白印。"

"是。"

"这三千四百不进裴府的账。"

"不进。"

"第二个，对上了。"

"对上了。"

"第三个数：一百四十七。"

"一百四十七。"

"取用则例的条数。"

"是。"

"我堂上背过九百零八条。"

"是。"

"第三个数，对上了。"

"对上了。"

"第四个数：二十四。"

"二十四。"

"第三卷第一页第一行的画。"

"是。"

"这一行是您自己加的。"

"是。"

"第四个数，对上了。"

"对上了。"

"第五个数：十三。"

"十三。"

"圈加点。"

"是。"

"圈九画，点四画。"

"是。"

"十三也是七加六。"

"是。"

"第五个数，对上了。"

"对上了。"

"第六个数：九。"

"九。"

"空字九画。"

"是。"

"第七个数：四。"

"四。"

"无字四画。"

"是。"

"第八个数：九。"

"九。"

"命格册第七页，六格满。"

"是。"

"第六到第八个数，对上了。"

"对上了。"

"第九个数：六。"

"六。"

"陈谷今日跟我说了一半。"

"一半。"

"他说了一半，说了六个。"

"六个。"

"那六个是死的人。"

"是。"

"第十个数：二。"

"二。"

姜梧抬起眼。

"第十个数，是我自己加的。"

"你自己加的。"

"我自己加的。"

"它跟别的九个不一样。"

"哪儿不一样。"

"别的九个，都能对。"

"是。"

"这一个，对不上。"

"对不上。"

"它对不上，是因为它不在纸上。"

"不在纸上。"

"它不在纸上，是因为它指向您母亲。"

"是。"

"指向您母亲的，就不落纸。"

"不落纸。"

"所以这十个数里，九个能对，一个对不上。"

"九个能对，一个对不上。"

"监正。"

"嗯。"

"这一个对不上的，是您母亲。"

"是我母亲。"

"我今日把它算出来，是因为它跟别的九个不一样。"

"是不一样。"

"别的九个是纸上的。"

"是纸上的。"

"这一个在人身上。"

"在人身上。"

"在人身上的，就不落纸。"

"不落纸。"

"我今日把它记在心里。"

"你记在心里。"

"记在心里，不落纸。"

"不落纸。"

"监正。"

"嗯。"

"我今日这十个数里，九个在纸上，一个在心里。"

"九个在纸上，一个在心里。"

"在纸上的，署里能抄一份。"

"能抄一份。"

"在心里的，署里抄不走。"

"抄不走。"

"抄不走的那个重。"

"重。"

"为什么。"

"因为抄得走的，是官里的。抄不走的，是我的。"

"是。"

"监正。"

"嗯。"

"我明日来。"

"你明日来。"

"我明日带第八个数来。"

"第八个数。"

"第八个数是九。"

"是九。"

"那一个九，是命格册第七页六格满的。"

"是。"

"我明日要问您：那六个坑，跟您那八个坑，有几个是同一处。"

"我不知道。"

"您不知道。"

"我不知道。"

"您不知道，是因为您没有查。"

"没有查。"

"我明日要您查。"

"我查。"

"我走了。"

"你走。"

她把这三张纸对完，发现了一样。

第一张纸上的七个数，都能对上。

第二张纸上的两个数，一个能对上，一个对不上。

第三张纸上的两个数，都能对上。

三个数——第一张七个，第二张两个，第三张两个——合起来十一个。

十一个数里，十个能对上，一个对不上。

对不上的那一个，是第七页。

第七页是监正封的。

她把这个数记在一张纸上。

记完，她看着它。

十一个数里，十个能对，一个不能。

那一个不能的，是她自己封的。

她今日在纸上写下这一句：十个数能对，一个数不能。

不能的那一个，是裴鹤封的。

她写完这一句，看着它。

这是她进府第六十三日。

她今日做的这一件，是把三日的东西对了一遍。

对的结果是：十个能对，一个不能。

能对的那些，都是真的。

不能的那一个，是假的。

假的那一个，是裴鹤六月初七封的。

她今日把这一件记在心里，不落纸。落纸的只有那十个数里能对上的九个。

她拿出一张新纸，在上头画了一个圈。

圈里点一点。

画完，她在圈底下画了一条线。

线底下空着。

这是她身上第三十二张纸。

她把这张纸压在最上头。

然后她把手垂在床沿外头，指尖碰到床板上那道"井"字。

她按着那道字。

"井"字是她进府第一夜摸到的。

她进府六十三日，摸了一百多次。

今日她按着那道字，想的是这六十三日。

六十三日里，她记了三十一张纸。

三十一张纸上，有三十四两、三万四千两、一百四十七、二十四、九、四、十三、九、六、三。

十个数。

十个数她今日对上了。

对上的那十个数，是真的。

对不上的那一件，是裴鹤封的。

她今日把这一件记在心里。

不落纸。

窗外，日头出来了。

院墙上那两道渗水的白边，今日显出来了。

她今日数了。

两道。

这是她今日数的头一样。

她今日在纸上画了一个圈。

这是第二样。

她今日在东跨院坐了半日。

这是第三样。

三样。

她今日把这三样记在心里。

落纸的只有那个圈。

圈里点一点。

圈底下空着。

空着的那一条，是裴鹤封的那一卷。

她今日把这一件记在心里。

不落纸。

她今日靠在床头。

她今日没有点灯。

她今日在黑里坐着。

她今日想的最后一件事，是那十个数。

十个数能对。

一个不能。

那一个，是裴鹤封的。

她今日把这一件记在心里。

不落纸。

她今日睡了。

她在这府里第六十三日。

她今日在纸上画了一个圈。

圈里点一点。

圈底下空着。

她今日看着那一条空。

她今日睡了。

窗外，井绳在风里撞了一下井沿。

她没有听见。

她今日没有数。
