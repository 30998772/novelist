# 《他们说我是来替他挡灾的，我说是来收债的》角色档案

> 模板依据 `character-design`。外貌只写 2~3 个可反复调用的辨识点。

---

## 姜梧

- **基本信息**：十九岁 / 罪妇（买来的）→ 裴府"承灾的人" / 空命格
- **外貌特征**（只用这三个）
  1. **进门时在门框上刻字的那只手**——左手食指有一道新刻痕，第一部最后一章消失
  2. 走路极轻极快，**像随时准备被人换掉**（被买来的人的走法）
  3. 眼睛只看人脸不看人身上的官服——**因为官服是买主的，看官服就是看价钱**
- **性格**：不哭、不闹、不问价。核心特质是**"记"**——她记得每一笔账、每一句话、每一个人的欠她的。
  - 明显缺陷：**她不会求。** 她这辈子只说过一次"求"，对方是市集上卖她的人。她记住了那个"求"字没被答应的声音，从此不再说第二遍。
- **欲望 vs 恐惧**
  - 欲望：**讨回十九年。** 她不认命，她认账——命不能讨，账能讨。
  - 恐惧：**她的命不归她自己。**（空命格 = 她的命是别人随便挪的）
- **背景故事**（3 条以内）
  1. 七岁那年她被从罪妇名录上第一次买卖，记不清自己本姓。**她后来给自己取了个"梧"字——因为她只记得一棵树。**
  2. 十九年前清空她命格的那一夜，她记得一只大人的手按住她的头。**她记住的是那只手有六根手指。**（第五部揭晓：裴老夫人。见 A-5：她也是被人这样"救"过的）
  3. 十八岁被卖进裴府，三十四两。门房要她报生辰，她在门框上刻下自己的八字——**那是她的第一笔账。**
- **语言特征**
  - 极短，且**永远是账目语言**（"多少"、"这一笔"、"抵了"、"划掉"）——因为账目语言不含指向，是唯一不会把灾引进来的话
  - 从不用"我"字开头（"多少"、"能算"、"不必"）
  - 被夸时答"应当的"（护甲）
  - 生气时报数：**"三百四十二笔。"**
- **成长弧线**
  - 起点："我在收债。"（她进府第一天的定位）
  - 转折（第三部）：她发现讨回来的每一分命，都要从**他**身上扣 → 她第一次不敢讨
  - 终点（第五部）：她算清了这笔账该怎么讨——**不是讨十九年，是把"移"改成"消"**。她不认命，她认账。
- **人物关系**
  - 裴鹤（监正 / 买她的人之子 / 全书唯一能改她命数的人）
  - 裴老夫人（当年清空她命格的主谋，第二部揭穿）
  - 姜三娘（卖过她两次的人，全书唯一的"亲人"称呼来源）
  - 沈度（钦天监前任监正，第五部的钥匙）
- **专属符号**：门框上她的生辰八字。**第一部之后它一直在，她每隔一段就去看看有没有被磨掉。**
- **宿命语录**：
  > "你们说我是来挡灾的。我是来收债的。"

## 裴鹤

- **基本信息**：二十六岁 / 钦天监监正（正三品） / 分命八十一
- **外貌特征**（只用这三个）
  1. **右手指节比左手大一号**——常年握笔书符，握符的手比握筷的手大
  2. 看人时**先看对方的命格**（眼睛像在数数）——职业病，也是他最没礼貌的地方
  3. 说话时袖口永远压着腕子——**因为腕上有一道符纸压出来的痕，一圈，一年四季不消**
- **性格**：冷、公事公办、不通人情。核心特质是**"算"**——他一辈子在算命数，算到后来**他最算不明白的是自己还能活几年**。
  - 明显缺陷：**他把愧疚藏在了流程里。** 他救她做的每一件事都要走一遍钦天监的正式程序——**因为走流程他就不用承认这是私心。**
- **欲望 vs 恐惧**
  - 欲望：**把灾从"移"变成"消"。** 这件事全天下只有他做得到。
  - 恐惧：**第十年回账那日，他只能眼看自己死。** 他不怕死，他怕"她知道是他害的"。
- **背景故事**
  1. 七岁那年他被人按着手，亲眼看着清空一个女孩的命格。**他记不清那人的脸，只记得那女孩的手指在他掌心划了一道。他记了十九年。**（第五部第 226 章揭晓：那只按头的手有六根指，是裴老夫人）
  2. 他十九岁上分命八十一，是**钦天监的旧例，第一次有人这么分**。他自己知道这不是救人，是**把死期切成八十一片，慢慢死**。
  3. 他买她，走了三道正式文书，落款写的是"钦天监采买"，**不是"裴府"**——因为走裴府的钱，就成了裴家的账。**他不肯让裴家欠她。**（第一优先级伏笔）
- **语言特征**
  - 长句、公文体、条目式（"此案有三处不合"）——**他一生都在写公文，只有对她说不成句**
  - 口头禅："照规矩。""归档。""这一笔，我记着。"
  - 生气时不改语气，只改称呼（忽然叫全名，是他最狠的时候）
  - **全书他对她说过最长的句子只有十九个字。**
- **成长弧线**
  - 起点：把愧疚包在公文里
  - 转折（第三部）：她发现讨命要从他身上扣 → **他第一次伪造归档**
  - 终点（第五部）：他改天象，把"移灾"改成了"消灾"——**他做的是把自己的命数当燃料，烧了十九年攒的那点，全烧了**
- **人物关系**
  - 姜梧（他买的人 / 他毁了她命格的人之子 / 他这辈子算不清的数）
  - 裴老夫人（他母亲 / 十九年前的当事人 / 到第五部才和解）
  - 沈度（他前任 / 教他书符的人 / 唯一敢跟他说"你错了"的人）
  - 姜三娘（把姜梧卖进裴府的人）
- **专属符号**：腕上那道符纸压出来的一圈痕。**全书不解释，直到第五部。**
- **宿命语录**：
  > "这一笔，我记着。"

## 姜三娘

- **基本信息**：四十余岁 / 人牙子 / 卖过姜梧两次的人
- **功能**：全书唯一的"正常人"。**她是唯一不为"命格""天象"这些事惊叹的人——因为她根本不信这些。** 她只认银子。**她给这本书提供了最世俗的爽点。**
- **外貌特征**：袖口永远有算盘珠子磨出的白印；走路比谁都快（她一辈子在赶集）
- **关键行为**
  - 她是唯一叫姜梧"梧丫头"的人
  - **她卖姜梧第二次时，收了裴府三十四两，转头就去给姜梧买了件棉衣**（第三部揭晓）
  - 她第九部上场：她手上有一份**买姜梧的原始契书**，上面写的价是**一两二钱**
- **弧线**：从"卖人的人"到"替她记着买她那一刻的人"。**她不赎罪，她只是记着。**

## 沈度

- **基本信息**：约五十岁 / 钦天监前任监正 / 已致仕
- **功能**：**第五部的钥匙，也是全书"天象是律例不是鬼神"这一层的唯一解释者。** 他不教姜梧任何东西，他只给她一句"你算得清，那你自己算"。
- **外貌特征**：左手常年戴着手套（他做过移灾，切了命纹）；眼睛不看她，只看天
- **关键行为**：他当年主张"移灾只作律例，不作神术"，被裴老夫人一党赶出钦天监。**他手里有当年的原始档——移灾的成例册，全书只有他知道还存在。**
- **宿命语录**：
  > "天不欠谁。欠人的是人。"

## 裴老夫人

- **基本信息**：五十四岁 / 裴家当家主母 / 十九年前的当事人 / **左手六根指（F-004，第一部 018 章门口与记忆线引出，第五部 226 章揭晓）**
- **功能**：全书真正的对手。**她没有一次动手，全程坐在屋里，用"规矩"杀人。**
- **关键行为**
  - 买姜梧是她的主意，裴鹤不知道
  - 第二部她揭穿"命格必须空"这件事
  - 第四部她做了她这辈子最狠的一件事：**她要姜梧自愿应灾**——因为"强移的灾不入册"
  - 第五部她认账：她十九年前按住那个孩子的头，是为了让她**活下来**（因为她当年也被人这样对待过）
- **弧线**："我是为了她活" → "我错了，我不求你原谅"。**她到死没得到原谅，也没打算要。**
