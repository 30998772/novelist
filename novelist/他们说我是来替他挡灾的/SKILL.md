# 本书专属 Skill：《他们说我是来替他挡灾的，我说是来收债的》

## 一、这本书是什么

- 类型：**女频古代言情 × 权谋 × 强情绪长篇**
- 体量：五部 × 50 章 = 250 章 × 2000 字 = **50 万字**
- 基调：**虐在过程，甜在结尾。** 部一爽、部三最痛、部四转机、部五收
- 视角：**双主角双视角交替**（姜梧 / 裴鹤），禁止连续三章同一视角
- 结局：HE。**全书只死一人**（裴鹤），死法是"命没了"，写得极安静
- 安全区：**无暴力施害、无流血、无比武、无复仇加害。** 对抗手段是书符、翻档、议罪、当庭

## 二、核心设定速查（三条铁律）

1. **移灾不消灾，只换人背。** 铁律一，全书重力。
2. **开口即死**：她心里若有一个明确心愿指向他，灾立刻入她身。**这是全书的语法。**
3. **空命格是唯一能装灾的容器**；井填满了就没有井。

## 三、本书的感情语法（最重要的一条）

> **她一开口求他活，灾就进她身。所以这本书的感情不是靠说出来的。**

- 她全书**只能开口说账**（"多少""这一笔""抵了""划掉"），因为账目语言不含指向
- 他对她**说过的最长一句话只有十九个字**（唯一一次在第 196 章）
- **"我爱你"三字全书零次**
- 她全书只用"我"字开头一次，在最后一句（"我讨完了"）

## 四、文风黑名单（出现即改）

- 一切"眸"字系
- 「眼中闪过一丝」「嘴角勾起一抹」「空气仿佛凝固」「五味杂陈」
- 排比句抒情喊口号
- 大段心理独白超 5 行必拆
- 「不是……不是……而是……」句式（每章最多 1 次）
- 「这就是……」结尾（全书最多 3 次）
- 「从前的我不曾想过」式回忆插叙
- 一切"神仙显灵"式描写（天象是**律例与档案**，不写鬼神）
- **"我爱你"三字**
- 任何祈愿句（指向他性命），**除了第 246 章那一次**
- 壁咚、扯衣领、压墙、咬耳、"你听我解释"
- 给"移灾"加任何光效/音效/法术描写——**只写笔、墨、纸、印、档**

## 五、对话纪律

- 她：极短，永远是账目语言，从不用"我"字开头
- 他：长句、公文体、条目式；对她说不成句
- 对话减称呼 80%，只在第一句和说话者转换时保留
- 两人吵架必须"难听但读者知道他们很好"：**每部至少三场**
- 用公文、批文、印、档、天象、命数制造张力，不用肢体

## 六、爽点纪律

- 全书**只死一人**。爽点来自：当场背完旧例册、一勺判词掀翻一堂、报出三百四十二笔、三万四千两赎身凭据
- **她没有法力、没有势力**，唯一的武器是：**她算得清所有人的账，包括天象的账**
- 每 10 章至少一个爽点；每 20 章至少一个情绪高点

## 七、虐点纪律

- **"他每救她一次，她离死近一寸"**——这个反直觉必须在每一部被读者接住
- 虐不靠误会，靠**两个人都知道，都不能说**
- 不可怜相。**她不哭**（全书写到第 230 章为止）
- 他的愧疚藏在流程里：救她的每一件事都要走一遍正式程序

## 八、伏笔登记制

- F-编号在 `章节大纲/总纲.md` 伏笔总表登记
- **全书伏笔必须在第五部全部回收**（第 201-250 章）
- 暗线 A-1 ~ A-8 同上

## 十、章节标题纪律

- 长度 ≤ 12 字
- 台词体 / 悬念体 / 反差体轮换
- 忌裸编号（正文文件命名除外）

## 十之二、对白密集章的特殊判定标准（本书专用）

本书是「账目推理 + 极短对白」，大量章节对白行占比 70%–90%。
通用 human-prose 判据（段均 60–180、引语独占行）在对白章会误判，因此本章为本书另立判据，
**对白占比 ≥ 50% 的章按本节判定，其余章按通用判据。**

**1. 字数**
唯一口径 `len(re.sub(r'\s','',t))`，范围 **3200–3800**，目标 3500。
（注意：`human-prose/reference/check.py` 默认仍是 3600–4000，须显式传 `--lo 3200 --hi 3800`。）

**2. 乒乓体判定（本书最高频的失败模式）**
通用规则只查「复读」，查不出乒乓。对白章必须另查：

- **相邻对白轮上限**：同一组连续对白轮次 ≤ 4。
  超过即判乒乓，必须合轮。解乒乓的三种手段（可混用）：
  1. **并段**：把 2–4 轮对白并进同一段落，行间不再空行；
  2. **入叙述**：说话人的动作、视线、物件、呼吸写进段落中间，
     让叙述句切在对白轮之间（不是把叙述堆在轮次之前或之后）；
  3. **并句**：同一说话人的相邻两句用 `……` 或逗号并成一句。

- **对白独占行**：叙述章要求独占行；对白章**不要求**。
  对白占比 ≥ 50% 的章，**必须**把部分对白并入段落——
  这是解乒乓的主要手段。全章独占行对白超过 70% 记为「偏碎」，> 85% 直接 FAIL。
  写法要求：并入时补说话人指示（`裴鹤说` / `她` / 名字），
  不用「他说」到底，且一段内不出现两个未标明的说话人。

- **空转应答**：仅由 `"嗯。"` `"是。"` `"什么。"` `"为什么。"` `"姑娘。"` `"监正。"`
  构成的独立段，单章 ≤ 3 处；每处必须带说话人的可观察反应（动作/视线/物件），
  否则判为填充，删除。
- **称谓裸引**：`"姜梧。"` `"监正。"` `"孙妈妈。"` 这类只有称谓的独立行，
  若前后无动作、无信息增量，合并进相邻对白。

**3. 段均（对白章改判）**
通用判据 60–180 在对白章不可用。本书对白章判据：

| 对白占比 | 段均合格区间 | 备注 |
|---|---|---|
| < 50% | 60–180 | 叙述为主，走通用判据 |
| 50%–70% | 40–100 | |
| ≥ 70% | **≥ 35** | 低于 35 判碎，须合轮 |

**硬底线：对白章段均不得低于 35，低于即 FAIL。**

**4. 排比/复读的合法与非法**
本书有意使用「同形重复」做变奏（如十八张纸、三百四十二笔、一千四百四十七次）。
合法条件（三条须同时满足）：

- 同一句式在单章内连续出现 **≤ 3 次**；
- 第 4 次起必须有一处**实质差异**（数目、物件、动作、时间至少变其一）；
- 变奏段之间必须插入非排比的叙述段作为分隔。

不满足即为「焊接」（check.py 会报 🔴 焊接），必须改写。

**5. 明喻密度与复现意象链（对白章不减配）**
对白章最容易丢质感。每章明喻 **≥ 3 个**，且必须落在对白之间的叙述句里，
不能是「她说。她比作……」式的外挂比喻。使用本书复现喻体：
`纸 / 印 / 瓦 / 灰 / 绳 / 门框 / 墨`。

复现意象链判据（两项须同时满足）：
- 章内出现的**母题种类 ≥ 3**；
- **母题密度 ≥ 8.0 次/千字**，或**母题总出现 ≥ 15 次**。

**为什么是「或」而不是只看密度**：密度按字数归一，会惩罚接近 3800 字上限的章。
实测第015章母题 8 种（全书最多），仅因篇幅 3797 字，密度只有 6.8，
按单一密度阈值会被误判为意象空缺。因此总量与密度任一达标即算通过。

统计母题时**必须**包含 `纸 / 印 / 瓦 / 绳 / 门框`。
只统计 `灰 / 霜 / 墨 / 屑 / 霉` 会漏掉本书最核心的四个母题，
使意象列大面积报空。

**6. 长句**
对白章长句要求下调：≥ 45 字的句子 **≥ 2 个**，可由叙述句承担，
**不要求对白行本身变长**（长对白会破坏本书的短促节奏）。

**7. 破折号**
≤ 8 个/章，且不得出现在对白行内部。

**8. 钩子**
对白章的章末钩子不能是最后一句对白，必须带一个**物证或动作**
（物件、账目数字、身体痕迹、方位），落在叙述上。
