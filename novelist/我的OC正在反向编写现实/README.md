# 《我的 OC 正在反向编写现实》

## 项目说明

扑街网文作者纪辞发现，自己三年前弃稿的 OC 长明正在反向编写他的现实——灵感是被投喂的、记忆是灯油、人生是番外。当他拼死夺回执笔权时，才发现造物主悖论的全貌：他创造的角色，正在创造他。

## 基本信息

- **类型**：造物主悖论 × 叙事悬疑
- **篇幅**：140 章，四部（第一部 37 章 / 第二部 28 章 / 第三部 36 章 / 第四部 39 章），每章约 3500 字
- **视角**：第一人称「我」（纪辞）
- **基调**：恐怖悬疑，无恋爱，无打怪

## 结局基调

**双重悲剧结构**：

1. **物理悲剧**：世界排异不可逆，长明必须回到永夜之国
2. **存在主义悲剧**：长明发现自己的灵感来源于一个真实存在但已去世的人。他选择回去不是因为"不能活"，而是因为"不愿用别人的命换自己的命"

**开放式收尾**：长明选择回去（悲剧），但两人通过书信保持联系、纪辞等待重逢。最后一个意象：灯灭了，但光还在——只要我还在写，灯就还亮着。
