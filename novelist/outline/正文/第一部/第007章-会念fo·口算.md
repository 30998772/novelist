# 卷一 幼儿园

# 第007章 会念fo·口算

先说一件受气的事。

同桌找我借橡皮，我借了——我的橡皮向来好借，跟铅笔一样。她接过去，顺手抄起我的本子，把我写了半页的拼音，从最后一个字开始，倒着往回擦。

我说："你不能这样。"声音不大，还带着商量。

她擦得更起劲了，橡皮屑吹得满天飞，一边擦一边笑，笑声越来越大。我盯着那半页白花花的纸，火从心口往上顶，顶到嗓子眼，又被我咽了回去。最后我是举手找的老师。老师批评了她，让她道歉，事情就算过去了。

回座位的路上我算明白了一件事：一味退让换不来尊重。你退一步，有人就当你好欺负；你再退一步，她能把你的整个本子擦干净。

翻身是在拼音课上。

那天老师教韵母，f 和 o 碰在一起，成了"fo"。教室里顿时热闹了：有人念成"喔"，有人念成"屋"，还有人干脆喊"佛"。老师念一遍，底下歪一遍，越纠越乱。

轮到我。我站起来，清清楚楚念了一声："fo。"

教室静了一下。老师愣了愣，说：再来一遍。我又念了一遍。她点点头，冲全班说：都听见了吧？就这么念。跟我读——

"fo——"满教室的声音，跟着我一个人走。

那节课的后半段，我站在讲台边上领读。老师有事出去了，临走指了我一下：你带着念。我拿着教鞭——其实就是根细竹棍——点一个音，大家念一个音。底下鸦雀无声，念错了的，我用竹棍一敲桌面，那人就红着脸重念。

那一刻我忽然想起滑轮场上的末排，想起镜子里只剩小半个肩膀的自己。

原来脸不是只有一种挣法。跳不好舞，念得好"fo"；挤不进前排，站得住讲台。

数学这块阵地，是我一寸一寸自己攒出来的。

老师出十以内加减法，别人掰手指头，我的答案已经出口了；二十以内的进退位，班里算得又快又对的拢共两三个人，我是其中一个。老师偶尔拿难题试我，我报了答案，她追问怎么想的，我说不上来——不是不肯说，是真说不出来。脑子里有个地方，题目一进去，答案自己就转出来了，像那双滑轮鞋上了脚，门道自己往外冒。

我从不主动显摆。考好了，卷子折起来塞进书包底层；有人问分数，就说还行。数字这东西跟人不一样：它不看脸色，不记仇，也不会今天跟你好、明天把你的本子擦干净。一道题摆在哪儿，谁来做都是一个理。

老师喜欢我。她把我叫上讲台对全班说："看看人家。"底下几十双眼睛齐刷刷看过来，有服气的，也有不服气的。我不在乎哪一种——被服气比被喜欢有用，这个道理，我是吃过亏才懂的。

奶奶在家提过一回："丫头念书还行。"顿了顿又补一句："再行，也是人家丫头。"

这话没头没尾，我也没接。反正卷子是我自己考的，"fo"是我自己会念的，这些账都记在我自己名下，谁也划不走。

多年后回头看，幼儿园这一程像在攒家底：一截铅笔头，一双滑轮鞋，一套光碟，一个"fo"，一脑子算不错的数。东西都不大，可件件写着我自己的名字。

只是那时候我还不知道，攒下的这些东西，马上就要派上大用场了——因为离开的日子，到了。
