# 《废稿》总纲 · 伏笔登记表

## 总纲（一句话）

高二生白砚在三个不断拼接的世界（校园/古镇凶案/末日）间挣扎改命，最终发现所谓世界线、轮回、命运皆是假象——三段故事只是同一部小说被推翻三次的废稿，他的全部挣扎只是"排列作废的文字"；而他选择清醒地留在自己拼出的完美世界里，并在剧本之外刻下两个字：别认。

## 三幕

1. 卷一（001–013）绝望宿命线 A→B→C：日常藏 BUG → 封镇连环案与"分段"实感 → 白蚀灭世；卷末解锁"翻页"
2. 卷二（014–026）重生救赎线 B→A→C：带记忆破案救人的狂喜 → 完美校园的假圆满 → 修正力碾压，确认"剧情写死"
3. 卷三（027–035）真相破局线 C→B→A：稿纸之海贯通全谜题 → B 线诡计闭环+首次改文本成功 → 拼出完美终焉日常（伪大结局）
4. 终局（036–040）Meta 反转：定格乱码 → 页脚删除记录 → 三版废稿真相 → 「别认」→ 编者的选择
