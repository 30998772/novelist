# 第037章 页脚

翘边的地方，在城市的东郊。

白砚走了很久。凝固的世界里没有车可坐，他穿过一座又一座琥珀般的街景，走过婚宴的霓虹、夜班的岗亭、亮着灯却无人等候的公交站。越靠近东郊，天空的"纸色"越明显——那层均匀的微黄像陈年的宣纸，而漫天的字符雨在头顶缓缓流淌，无声无息。

最后，他停在了江边。

天与江相接的地方，"幕布"垂到了水面。近了才看清：那不是幕布，是纸。一整面望不到边的、微微泛黄的纸，从天上垂直地落下来，浸进江水里。江水碰到纸缘，就凝住了，像照片里的大海。

纸面上有字。

极小的字，密密麻麻，成行成列，像一份打印出来的清单。白砚走近，眯起眼睛，一行一行读下去——

最上方是一行稍大的标注：

**v0.3-A**

下面紧跟着几行小字：

**状态：已废弃**
**合并记录：v0.1 / v0.2 / v0.3 → 本版**
**修订人：（空白）**

再往下，是一条长得看不到头的列表。每一行的格式都一样——

**第004章：断层（删除于v0.2）**
**第009章：分段的镇（删除于v0.3）**
**人物：周雨（整线移除）**
**人物：沈砚生（更名重写）**
**场景：外婆家的石榴树（保留）**
**场景：初三转学生（未采用）**

一条一条，一条一条。

白砚的手指抚过那些字，指尖发抖。他看见了被偷走的周三——原来那一章真的存在过，编号第004，删除于某个他不知道的时刻；他看见了周雨——蓝色日记里苏晚同桌的那个名字，整条命运线被连根拔起；他看见了自己经历过的每一个夜晚、每一个清晨，在这里都有编号，有版本，有存废的批注。

有几条批注看得他眼眶发热：

**场景：疤脸顾让名（v0.3）——作者批：这段写的时候难受。保留素材。**

**人物：沈砚生——原型出自旧稿，勿再删。**

**场景：外婆家的石榴树（保留）**

**场景：初三转学生（未采用）**

还有一条，就挂在列表中段，墨色比别的都淡：

**人物：白砚（三版皆现）——备注：此人是意外。**

此人是意外。

白砚盯着这五个字看了很久。不知道为什么，这五个字竟让他生出一点近乎荒诞的安慰——原来连"他"都不是计划的一部分。他是这份文档里的一个 bug，一个笔误，一个被反复重写也没能抹干净的意外。

意外好啊。他想。意外是不听安排的。

这不是天空。

这是页脚。一本书的页脚。

而他此刻站在的，是他自己这本"书"的最边缘处——世界的装订线外。

"已废弃。"他轻声念出那三个字，喉咙干涩得发疼。

所以末日是什么？白蚀是什么？他挣扎了两世、跨越三稿、拼上一切换来的这场大胜——在这个页脚的记法里，只是"v0.3-A"这个版本号后面的一个标签而已。

废弃。作废。不要了。

就像抽屉深处任何一份写坏的东西。

白砚靠着纸墙缓缓滑坐在地上。江风——不，这里没有风，只有那种纸张特有的、干燥的寂静——他抱着膝盖坐着，忽然笑了一声，笑声在死寂里显得格外突兀。

然后他看见了列表的最底端。

所有条目的下面，最后一行，墨迹还新得发亮，仿佛刚刚写上去：

**终章：删除中……**

删除中。

正在进行时。

他猛地抬头。头顶的天幕上，那场字符组成的雨还在流淌，而江对岸、城市后方、世界的一切方向——极远极远的边缘处，泛起了一圈极淡的白。

白色的边界正在合拢。这一次不是要吞掉某座镇子、某座城市——

是要删掉"终章"。删掉这个被他亲手修订、重新装订、刚刚抵达完美的整个世界。

进度无从知晓。但白砚知道一件事：从"终章"两个字浮现到现在，已经过去了一个多小时。

一个多小时里，这个世界一动没动。

不是因为定格有多美。

是因为——它已经在被擦除了。声音先没了，然后是时间，接下来会是颜色、形状、记忆……最后是存在本身。

白砚站起来，仰头望着那面高不见顶的纸墙，望着墙上那份浩浩荡荡的存废清单，忽然问出了声：

"为什么要现在？"

没有人回答。当然没有。

但他鬼使神差地，把自己的手按在了页脚的那行小字上——

**合并记录：v0.1 / v0.2 / v0.3 → 本版**

**修订人：（空白）**

修订人。

后面是个空格。一个还没来得及填上的空格。

白砚盯着那个空格看了很久很久。然后他做了一件此后再也没有回头路的事——

他从口袋里摸出了那支笔杆上刻着禾苗的笔。
