# 第3章 沉默的父亲

从青川回临州，林知遥把车开得很慢。

高速上车不多，她却没有开定速巡航。方向盘握在手里，指节发白。副驾座位上放着透明文件袋，里面是民政局出具的查询回执。

回执只有两页。纸很薄，她捏在手里，却觉得压手。

小唐的话又在耳边响起。

"证是真的。"

"字号00217，钢印位置对，经办人签章也对。"

"但档案里的照片，不是您母亲。"

她当时盯着屏幕看了很久。电子档案是2008年补录的，原始纸质台账在2003年搬迁时遗失。屏幕上那张新娘的照片，脸更圆一些，眉眼浓，颧骨高，左边耳垂上有一颗很小的痣。

那不是母亲。

母亲唇角有一颗极淡的痣。她看了三十年，绝不会认错。

出租车——不，她自己开的车——在老巷口停下。巷子窄，车开不进去。林知遥把车停好，拎着文件袋往里走。

院门半开着。

林国栋坐在院子里，膝上铺着一张旧报纸。他面前倒着一把木椅子，椅腿拆下来，榫头露在外面，缠着发黑的麻绳。

他退休以后就开始修东西。邻居家的板凳，巷口的收音机，厨房漏水的龙头，他都修。母亲在世时常说，他恨不得把日子一寸寸拧回原样。

林知遥站在门口，看见父亲把砂纸按在椅腿上，来回打磨。

木粉落在他指缝里。

"回来了。"林国栋没有抬头。

"嗯。"

她走进院子，把文件袋放在旁边的小矮凳上。矮凳上有一只搪瓷缸，茶水已经凉透。

"爸。"

"先喝口水。"

"我去了青川县民政局。"

砂纸的声音停了一下。

林国栋说："路上累不累？"

"他们查了档案。"

林国栋没有接话。他伸手把一块翘起的木皮按回去，按得很慢。

林知遥在他对面站定。

"结婚证是真的。"

"嗯。"

"档案也是真的。"

"嗯。"

"但档案里的照片，不是我妈。"

院子里安静下来。巷口有人骑车经过，铃铛响了两声，又远了。

林国栋的手停在椅腿上。他没有看她。

过了很久，他把手里的砂纸放下，拍了拍膝上的木粉。

"你妈嫁给我的时候，就叫陈月娥。"

林知遥盯着他。

"那1992年的结婚证上，为什么写苏婉？"

林国栋拿起一块干布，擦手上的灰。

"那时候登记不规范。写错了。"

"写错？"

"乡下登记，很多字都是代写的。"

"名字写错，不会连照片都换。"

林国栋擦手的动作慢下来。

林知遥把文件袋打开，抽出那两页回执。

"爸，我看过档案。照片是另一个人。脸不一样，眉骨不一样，耳朵形状也不一样。"

她尽量让自己的声音平。

"如果是登记员写错名字，那为什么档案里的照片也不是她？"

林国栋不说话。

"民政局的人说，原始纸质档案在2003年搬迁时遗失了，现存只有电子补录。补录依据是当年留存的底卡和存根。"

"那时候管理松。"

"管理再松，也不会把一个人换成另一个人。"

林国栋把干布叠好，放在一边。

"知遥。"

"你告诉我，苏婉是谁？"

林国栋抬起头。他的眼睛被下午的光照得很浅，眼白里有细细的红丝。

他没有回答。

他重新拿起砂纸，按在椅腿上。

沙，沙，沙。

声音很轻，却很稳。

林知遥站在原地，手指慢慢收紧。

"这把椅子是你妈陪嫁的。"林国栋说，"腿松了，不修会摔人。"

林知遥看着他。

她忽然意识到，父亲不是没听懂。他听懂了每一个字。他只是把话堵在椅子腿下面，用木粉和砂纸盖住。

"爸。"

"你去歇着。"林国栋说，"晚上我煮粥。"

林知遥没有再问。

她拿起文件袋，转身进了屋。

屋里光线暗。

她站在门口，等眼睛适应了一会儿。客厅正中的墙上挂着母亲的遗像。照片上的陈月娥头发梳得整齐，嘴角有一点笑，像是被人提醒后才露出来的。

林知遥把窗帘拉开一半，让光进来。

她走到五斗柜前，拉开最下面的抽屉。

抽屉里有一只铁皮盒。盒子边缘生了锈，盖子上印着牡丹花。母亲生前把家里所有重要证件都放在这里。

林知遥把铁皮盒抱到桌上。

她没有急着打开。

她先去卫生间洗了手，擦干，又从抽屉里找出一副干净的一次性手套。这是她做尽职调查时养成的习惯。纸面纤维会留下指纹和汗渍，时间久了会发黄。

她以前觉得这些习惯属于工作。

现在她发现，工作正在反过来拆她的家。

她坐回桌前，打开铁皮盒。

证件按母亲的习惯分成几叠。最上面是房产证，中间是户口簿和身份证，最下面是病历和死亡证明。

林知遥拿出手机，打开相机，先拍了一遍原状。

然后她把证件一样一样取出来，按顺序排在桌面上。

第一样，户口簿。

户主林国栋。妻，陈月娥。迁入日期，1990年9月。服务处所，临州棉纺厂。

母亲确实在棉纺厂做过工。她小时候去过厂区澡堂，也去过母亲宿舍。宿舍楼下有一排白杨树，夏天全是蝉叫。

第二样，母亲身份证。

号码、姓名、出生日期，全是陈月娥。照片上的女人方下巴，唇角有一颗极淡的痣。

第三样，死亡证明。

陈月娥，女，1965年生，2024年10月17日因病去世。

林知遥的目光在这一行停了片刻。

她想起殡仪馆那天的白炽灯，想起母亲手背上的青筋，想起医生让她签字时，她写下的每一个笔画。

那时候她没有怀疑过母亲的名字。

没有人会怀疑自己母亲的名字。

她把死亡证明轻轻放到一边。

第四样，她开始找父母的结婚证。

她翻了一遍。

没有。

她又翻了一遍。

房产证下面，户口簿下面，病历下面，死亡证明下面。铁皮盒的每一个角落。

没有结婚证。

林知遥的手停在半空。

她忽然意识到一件事。

她三十二岁。

她见过父母的户口簿，见过母亲的身份证，见过自己的出生证明。

但她从来没有见过父母的结婚证。

从来没有。

她一直以为它存在。就像她一直以为母亲叫陈月娥，一直以为母亲没有娘家，一直以为这个家的一切都理所当然。

可铁皮盒里没有。

唯一一本结婚证，是她在相册夹层里找到的那本。

1992年3月18日。

林国栋，苏婉。

林知遥坐在桌前，很久没有动。

屋里很静。院子里传来父亲敲椅子的声音。

咚。

咚。

咚。

像在修一个松动的榫头。也像在把什么钉回原位。

她低头，继续翻。

第五样，她的出生医学证明。

纸已经泛黄，边角发软。上面盖着临州市妇幼保健院的章。

林知遥把台灯拉近。

她先整体看了一遍。

出生医学证明是手写体。父亲一栏写着林国栋，字迹偏瘦，墨色均匀。母亲一栏写着陈月娥，字迹比父亲那一栏略大。

她拿出放大镜。

放大镜是母亲以前用来缝衣服认针眼的。林知遥小时候见母亲用它穿过线，没想到有一天会用它看母亲的名字。

她把放大镜贴近纸面。

"陈"字第一笔露出边缘。

墨色比周围深。

不是深很多，只深一点。像同一支笔蘸了太饱的墨，又像纸面被处理过，吃墨更重。

林知遥屏住呼吸。

她继续看"月"字。

"月"的横折起笔处压着另一道短横。那道短横很浅，被新墨盖住，只在放大镜下露出一截断口。

再看"娥"。

女字旁的一撇尾部有细微分叉。纸面不是平整的，有极轻的凹凸，像被人用刀片刮过，又用硬物压平。

林知遥把手机的手电打开，从侧面照向纸面。

光一斜，纸纤维立刻显出差别。

那三个字底下，有旧字的痕迹。

不是涂黑，也不是划线更正。有人把原来的字迹尽量去掉，再在上面写新字。做得很小心，但没有做干净。

旧字的轮廓从新墨下面透出来。

第一笔像横，下面有撇。

不是"陈"。

林知遥的手指开始发凉。

她把放大镜移过去，一点一点辨认。

横，竖，撇。

草字头。

苏。

她停了几秒。

继续往下。

"婉"字的笔画更复杂，残留也更少。女字旁还在，右边宛的上半部分只剩一道弯钩。但那道弯钩的弧度，和她记忆里母亲偶尔签下的名字重合在一起。

母亲很少签名。

母亲只在家长会签到时写过名字。那时候写的是陈月娥。

可出生证明上最初的墨迹，像是苏婉。

林知遥坐直身体。

如果结婚证底档里的苏婉不是笔误。

如果出生证明上的陈月娥是后来改上去的。

那么她从出生开始，就站在一份被改过的关系里。

她的母亲叫陈月娥。

可纸上最初的母亲，叫苏婉。

林知遥拿出手机，关掉手电，打开相机。

她先拍出生证明正面。

再拍侧光。

再拍微距。

她拿了一张白纸放在旁边做比例，又打开时间水印。每拍一张，她都会检查放大后的细节，确认墨痕和纸面凹凸没有遗漏。

拍完以后，她把照片存进加密相册，又备份到云端。

这是律师的本能。

证据要先固定，再谈情绪。

她把出生证明放回原处，按原来的顺序压在户口簿下面。

铁皮盒盖上时发出一声轻响。

林知遥坐在桌前，没有立刻起身。

她拿出纸和笔，开始列清单。

一，青川县民政局1992年婚姻登记档案：姓名苏婉，照片陌生女人。原始纸质档案遗失，现存电子补录。

二，临州老宅证件：母亲所有身份材料均为陈月娥。

三，父母结婚证：铁皮盒内不存在。唯一一本结婚证为1992年苏婉名下。

四，出生医学证明：母亲一栏有修改痕迹，底层字迹疑似苏婉。

五，待查：临州棉纺厂人事档案。

六，待查：临州市妇幼保健院1992年分娩记录。

笔尖停在第六条上。

1992年。

她出生在1992年冬天。结婚证是1992年3月18日。

如果医院还有原始记录，也许能查到产妇入院时登记的名字。

林知遥把笔放下。

窗外的天暗下来。院子里的父亲还在修椅子。木头的味道从门缝里飘进来，混着旧茶和铁锈味。

她想起小时候，家里什么东西坏了，父亲都不扔。收音机坏了，他拆开后盖，拿电烙铁点一点。椅子坏了，他拿胶和麻绳缠一缠。母亲笑他，说东西修多了会老。

父亲说，修一修，还能用。

林知遥现在才明白，有些东西修得太久，连原来的形状都看不出来了。

她起身去厨房，准备煮一碗面。

水刚开，手机响了。

屏幕上是一个陌生号码。

归属地：临州。

她看了一眼院子里。林国栋背对着屋门，正弯腰给椅腿上胶。

她按下接听。

"喂。"

电话那头沉默了半秒。

"林知遥？"

男声很低，语速不快。

她愣了一下。

这个声音她听过很多年。大学阶梯教室，图书馆走廊，深夜从采访现场打回来的电话。三年没听，仍然一下子把某些旧东西翻了出来。

"周也。"她说。

"是我。"

林知遥没有立刻说话。

周也是她大学同学，前男友。毕业后去了省报深度部，常年在外地跑。他们分手三年了。分手那天没有吵架，只有一句话没有说完。

她记得他说，等你不想再把自己关起来的时候，给我打电话。

她后来没有打。

"你怎么有我号码？"她问。

"问了赵桐。"

赵桐是他们共同的大学同学，现在在临州市二中教书。

"有事？"林知遥说。

"我回临州了。"周也说，"在做一个户籍纠纷的选题。听说你母亲去世了，想见一面。"

林知遥看向厨房锅里的水。

水汽升上来，模糊了窗玻璃。

"不必了。"她说。

"就半小时。"

"周也，我们没什么好说的。"

"不是为了我们。"

他的声音没有变，还是那样直接，不绕弯子。

"我在查一个案子。"周也说，"跟青川县有关。"

林知遥的手指微微一紧。

"这跟我没关系。"

"1995年的。"

锅里的水翻滚起来，面汤扑了一下，浇在灶台上，发出嗤的一声。

林知遥没有去关火。

1995年。

那个年份像一根针，扎进她脑子里。

青川县。1995年。

结婚证是1992年。她出生在1992年冬天。那1995年发生了什么？

她不知道。

可周也说出这个年份的时候，她心里某个地方忽然塌了一块。

电话里，周也没有催她。

过了几秒，他说："我不是来叙旧。"

林知遥听见自己的声音。

"在哪儿见？"

周也报了一个地址。

她没有记住。

耳边只剩下那个年份。

1995年。
