# 作者语言手册

> 这本书的声音。写任何一章前读一遍。
> 目标：读者读完能认出「这是这本书」，而不是「这是网文」。

---

## 一、核心意象系统：缝

**这个世界是一件缝坏的衣服。** 规则是线，判定是针脚，维护者是缝线的人。

> ⚠️ **注意：「缝」既是物象也是字面。** 书里世界的裂口本来就叫裂缝、接缝。
> 也就是说**物象和实物是同一件事**——不是在裂缝旁边再添一层「布面的缝」。
> 两种含义叠在一起会撞车，读起来语义糊掉。
> 用法：**世界本身的裂口直接写「缝」，不必再翻译成「布面的缝」。**
> 只有在写人的手感、动作、态度时才用布料那一层。
>
> **密度上限：单章叙述段「缝」不超过 40/万字。** 超了就是口癖，不是意象。
>
> ⚠️ **密度上限对全部物象一视同仁**，不只是「缝」：下面八行的每一个
> （缝/针脚、线头、灰、呼吸、手、底座、**河床**、**桥**），
> 单章叙述段出现次数均**不超过 40/万字**。**045 一章之内「河床／闸门／坝／水」统治全章，
> 已是该物象的一部变奏形态，不得在任何一章把它当通喻批量复制**——它之所以合法，
> 是因为它被登记为物象；一旦退化成「像水一样／像桥一样」的通用比喻，就该删。

这条线在书里已经存在，只是没被贯彻：
- ch009 苏清然把赵擎的剑看成**一根缝衣针**
- ch028「不切断，不对抗。**抚平**。」——全书论点，三短句
- ch094 陆寻把 NPC 和玩家的意识**缝进同一条规则**，「比补一件破衣难得多」
- ch122 他给自己袖口缝三针，线是从鞋带上拆的，**针脚歪**
- ch064 沈墨留下的话：「规则要是没人看管，**会自己长出牙来**」

### 八个复现物象（每章至少用一个，不要硬塞）

列名与内容以 `SKILL.md`「核心意象系统：缝」的表为准，两处必须同步。
四部变奏 = 一部（断）/ 二部（中间态）/ 三部（高潮）/ 四部（终局）。

| 物象 | 一部（断） | 二部（中间态） | 三部（高潮） | 四部（终局） |
|---|---|---|---|---|
| **缝 / 针脚** | 断的、外露、扎手 | 抚平：不硬拉 | 把整片天缝起来，缝时自己在散 | 缝好了，不再需要缝线的人 |
| **线头** | 垂着、乱着、没人管 | 有人按住 | 灰走成一条线断在脚面 | 有人剪断、打结、留着教别人 |
| **灰** | 洗不掉，标在手上 | 落成渠，可以铺路 | 第一次托住鞋底 | 洗得掉了，但记得洗过 |
| **呼吸** | 规则在喘，喘得很难 | 学会顺着它下手 | 平稳到听不见，那一下很重 | 稳到不用去听，只剩它还在 |
| **手** | 拉紧、按平、打结 | 摸得出纹理走向 | 只按住，不动 | 传给下一个人 |
| **底座** | 歪了半度 | 一枚一枚校准 | 补天时全部重钉 | 不需要了，规则自己长牙 |
| **河床**（045 登记，此前为伏笔式使用） | 底下是石头，规则不决定水往哪流，只让它不漫得到处都是——**还在修**：「别去筑坝。去修河。」 | 河道被自己人改窄改宽，水开始自己找路；一次洪水冲垮一段旧床，靠人重新夯 | 补天＝给整条河重铺床底；他站在床上把最后一段夯平，夯完自己塌下去一点（130 补天、永久失去能力） | 河床自己会长：不再需要有人修了，规则像水一样自己找缝走——「稳到不用去听」的河 |
| **桥**（045 登记，此前为伏笔式使用） | **缺一座**：「它缺一个桥。玩家和NPC之间要有一座，规则和自由之间也要有一座。」桥两端还没有人敢站上去 | 两端开始有人来回走；桥面还是陆寻一个人铺的，走的人多了以后他就不再数谁过没过 | 桥断过一次，也被人接上过一次；最难的不是造桥，是**明知道对面有人也不确定自己算不算那个人** | 桥不归谁。陆寻站在桥上也只是个过路的，桥自己认得每一个走过去的人 |

**变奏规则：同一个物象，在不同部里必须是不同状态的。** 第七缝、第三缝、第七缝，读起来是三样东西。

> **「河床」「桥」的登记时点（2026-10-03 裁定）**：045 是它们**第一次以物象身份登记**的位置，
> 但**一部此前的用法一律保留**——`025:29`「又回到自己的河里」、`025:59`「跟水一样」、
> `028:55`「搭桥需要材料」、`034:11`「刻痕像干涸的河床」、`036:56`「泛滥的正在吞并别的水域」
> 属于**伏笔式使用**：字面先行，物象身份后补，这是本书刻意的写法，不是违规。
>
> **区分标准**：伏笔式使用**只借词、不承担主题**（说一句就走，不解释，不回响）；
> 一旦某个物象开始**承担主题**（被人物反复引用、被论坛复述、承载章末论点），
> 它才算「已登记」，从那一刻起适用完整的四部变奏要求。
> `045` 是「河床」「桥」跨过这条线的地方——045:58 的河床被论坛复述成了公共台词。
>
> ⚠️ 反过来，若某章只是借词却把主题压在它身上（如 034:11 把「干涸的河床」写进爽点栏），
> 那是**提前承担主题**，应改写——判据是「这句之后有没有人重复它」，不是「它是不是那八个词之一」。

## 一之二、判例：字面裂口与布面针脚不得同段叠车

**规则：同一段里不得同时出现字面裂口与布面针脚。
若必须出现，先写裂口，隔一段再落针脚。**

为什么：字面裂口（缝＝世界的破口）与布面针脚（缝＝衣服上的线迹）是同一条意象的两种指称。
一段里把两层叠满，读者必须同时装两个坐标系，句子会当场糊掉——
这不是加密度，是**语义撞车**。

### 反例（`正文/第一部/第045章-河床.md` 045:15）

> ✗「……这一次布满了裂纹，缝里透出微弱的金光。**裂缝的边沿都翻着，翻口上没有针脚，一针都没缝回去**。」

一句话之内叠了三层：字面裂口（裂纹／裂缝）+ 布面针脚（针脚／一针都没缝回去）+ 缝合动作（缝回去）。
三层全满，等于零层。**删掉后半句只留前半句，意思不减，信息量反而更冷。**

### 正例写法
- 只写裂口，不提针脚：`翻口朝上张着，金光从底下漏上来。`（读者自己会想到缝）
- 要写针脚，就**另起一段**，并且只写针脚：`翻口上没有针脚。`

### 已评估保留：045:67-70「石头缝过吗。」四句元对话

> 「石头缝过吗。」「缝过。」……「现在没人去碰那些针脚。」……「所以要有人去按。」

**经评估予以保留，不删。** 理由：
1. 它是全批评价最高的意象段落之一——把「缝」落在**一块石头上**（河床的组成物），
   从此「缝」不再是比喻，而是这个世界的实际材料；
2. 四句问答一次性完成全部主题：物证的来历（缝过）→ 现状（没人碰）→ 机理（水会泡松）→ 结论（要有人去按）；
   删任何一句，主题就缺一环；
3. 它已被前几轮改稿**按备份逐字恢复过**，再删等于回退已定的稿。

⚠️ 但它成立的前提是 **045:15 那处叠车必须先修**——
先有 15 行的冷、只到 67 行才把「缝」交出去，两者是递进关系；15 行若已经把三层说满，
67 行再来一次就只是重复（该冲突已登记在 `跨章问题清单.md` X-52）。

## 二、句法：必须有长句

现状是硬伤：**句子中位 10 字，50% 的句子 ≤10 字，>25 字的只占 10%。** 全书一个音量。

### 要写的句子

写「松开手以后，灰从袖口上一粒一粒往下掉，掉到桌沿上停住，又被风推到了地上」，
不写「灰往下掉。风把它推到地上。」

**规则：**
1. 每章至少 2 个长句（45 字以上），用来**展开**——把一个瞬间摊开成过程
2. 长句必须有**内部节拍**：用逗号串起 3 个动作，让读者读中间时被绊一下
3. 长句之后必须跟一个短句。**长短对比才出层次**，全是短句只会平
4. 短句留白用：**「然后就没事情了。」这类句子是有效的**，但一章不超过三处

### 参照
```
他伸过手。没有够到。

那三步的距离后来他老想起。苏清然说那不是他的错。陈胖说谁都没办法。赵擎说别犯傻。
```
第二个句子是长句，列举了三个人三种说法，三个都不解决问题。第一个是短句。**长短成对使用。**

## 三、术语必须还原成物象

**现状：全书「规则」1551 次，其中 764 次在叙述段。** 一半的时候它是设定名词，不是画面。

### 改法

| 不要 | 要 |
|---|---|
| 规则松弛了 | 某样绷了很久的东西松了半分 |
| 判定失效 | 针脚没有咬住 |
| 规则网络稳定 | 布面不再往下坠 |
| 精神负荷很高 | 他脑子里的那根线绷到发白 |
| 规则在呼吸 | 整块布在极轻地起伏 |
| 负载溢出 | 线从布上脱出来 |

**规则：叙述段里每出现一次「规则」「判定」「参数」，问自己「这件事看得见的样子是什么」。** 能换就换。
对白和系统面板里**可以保留原词**——那是人物在说，不是我在说。

## 四、比喻：必须复现

**现状：456 处比喻，喻体几乎全不重复。读完一章记不住一个。**

### 规则
1. 一章最多 2 个比喻（现在 3 个/章，但要改的是质量不是数量）
2. **同一个物象在同一本书里只做一次比喻**，之后一律直陈。比喻是标记，用一次就作废
3. 喻体必须来自这本书自己的世界：线、针脚、绷紧的布、脱开的线头、翻过来的破面、**河床、坝、桥**
4. **禁止通喻**：不像雨、不像刀、不像野兽。像什么像多了等于没写

### 要做
选 3-5 个喻体，在关键章节复现，让它们互相呼应。例如：
- 断口「像从布上撕下来的一块，**毛边还挂着一半的线**」（ch028 已有）
- 同一块断口在 ch128 再出现时，变成「毛边已经干了，线头脆了，一碰就掉」

## 五、禁止清单

| 禁止 | 原因 |
|---|---|
| 叙述里用「规则」「判定」「参数」当名词 | 是设定词不是画面。见第三节 |
| 比喻超过 2 个/章 | 密度过高会把每段写成合格样板 |
| 通喻（像雨像刀像野兽） | 无信息量 |
| 同段内字面裂口与布面针脚叠车 | 三层叠满等于零层。见「一之二」判例 |
| 作者替读者解释情绪 | 写筷子横在碗口上，不写「他心里五味杂陈」 |
| 章末点题、升华、总结 | 停在动作或物证上 |
| 排比三连（十七、十七、十七） | 只有声音和情绪可以三连 |
| 功能词堆叠（了/着/的 大量） | 句子要靠实词推进 |
| 每段都完美收束 | 允许话没说完就转场 |

## 六、仍然保留的（去 AI 感成果，不要弄丢）

- 人物有废话、答非所问、闭嘴
- 小动作归属人物，不归属场景
- 只留陆寻限知视角，他人内心 0 处
- 论坛块就是论坛，不干净
- 允许失败和不完整

## 七、交付自查

- [ ] 有没有 2 个以上 45 字以上的长句，且内部有节拍？
- [ ] 长句后面有没有跟短句？
- [ ] 「规则/判定/参数」在叙述段里还有没有能换成物象的？
- [ ] 本章的物象在四部里是不是新的状态，还是重复了上一部的状态？
- [ ] 「河床」「桥」是不是被当成了通用比喻（像水一样／像桥一样）？是就删。
- [ ] 有没有哪一段同时写了字面裂口和布面针脚？（见「一之二」判例）
- [ ] 比喻有没有超 2 个？喻体是不是这本书自己的世界？
- [ ] 章末停在动作或物证上？
