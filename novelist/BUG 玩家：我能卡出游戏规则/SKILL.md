# 《全服都以为我是废稿》创作规范

## 类型定位
反套路全息网游爽文。核心爽点：**别人遵守规则，我定义规则**。
第一部四幕结构（001-012 觉醒 / 013-024 扬名 / 025-036 扩张 / 037-047 抉择），47 章。
全书四部（47+51+35+20），共 153 章，约 52.8 万字。

## 视角与人设纪律
- 第三人称限知，跟随陆寻；每章至少一次"他人反应镜头"（围观/论坛/频道/反派内部）做震惊放大器。
- **他人内心 0 处。** 陆寻*猜*别人在想什么合法（他可能猜错）。
- 陆寻台词短、冷、狠，禁止长篇装逼独白；他的狂体现在行动里。
- 苏清然弧光：惋惜→疑惑→震撼→抉择→信任。她不是花瓶，是"守规矩的顶级强者"，与主角天赋天然对立互补（F-004）。**在营六年，十二岁入营，十八岁三冠**（全书统一）。
- 反派智商在线：天穹的每一步围剿都有利益逻辑；官方 AI【衡】不是蠢系统，是制衡程序（**不得叫"仲裁者"或"制衡者"**）。
- **霜华是女性**，用「她」。
- 人物小动作归属人物，不归属场景：陆寻**不蹲**（仅极限场景），陈胖蹲，赵铁山看火擦铁，苏清然压平对齐摆正。

## 金手指细则（全书锁死，不得自相矛盾）
- 天赋【规则偏移】：触发后产生 **0.01 秒规则真空**——目标判定被悬置（等级压制/锁定/惩罚/掉落/buff 存续/传送/仇恨/死亡结算……皆可）。
- 无属性加成、无攻击技能、**无位移**；真空只能"让判定失效"，不能直接造伤害。伤害靠操作、地形、普攻与心理战。
- 真空可**叠加**（F-001 主线成长线）。**但绝不可写成持续数秒的物理定格**——0.01 秒就是 0.01 秒。
- 代价：精神负荷随叠加层数递增；后期被【衡】针对性校验干扰（15 章）。
- **陆寻全书只有这一个天赋。** 不得写成"两种天赋"。

## 核心意象系统：缝
**这个世界是一件缝坏的衣服。规则是线，判定是针脚，维护者是缝线的人。**

六个复现物象，各有跨四部的状态变奏：
| 物象 | 一部（断） | 二部（中间态） | 三部（高潮） | 四部（终局） |
|---|---|---|---|---|
| 缝/针脚 | 断的、外露、扎手 | 抚平：不硬拉 | 把整片天缝起来，缝时自己在散 | 缝好了，不再需要缝线的人 |
| 线头 | 垂着、乱着、没人管 | 有人按住 | 灰走成一条线断在脚面 | 有人剪断、打结、留着教别人 |
| 灰 | 洗不掉，标在手上 | 落成渠，可以铺路 | 第一次托住鞋底 | 洗得掉了，但记得洗过 |
| 呼吸 | 规则在喘，喘得很难 | 学会顺着它下手 | 平稳到听不见，那一下很重 | 稳到不用去听，只剩它还在 |
| 手 | 拉紧、按平、打结 | 摸得出纹理走向 | 只按住，不动 | 传给下一个人 |
| 底座 | 歪了半度 | 一枚一枚校准 | 补天时全部重钉 | 不需要了，规则自己长牙 |

⚠️ **「缝」既是物象也是字面**（世界的裂口本来就叫裂缝）。**不要在字面裂缝旁边再添一层「布面的缝」**——
两种含义叠在一起会语义撞车。世界的裂口直接写「缝」，只有写人的手感、动作、态度时才用布料那一层。
⚠️ **密度上限：单章叙述段「缝」不超过 40/万字。** 超了是口癖，不是意象。
⚠️ **比喻每章 ≤2，且喻体只能来自这本书的世界**（线、针脚、绷紧的布、脱开的线头、翻过来的破面）。
**禁止通喻**（像雨像刀像野兽），读者读完记不住。

## 句法
- **必须有两种音量。** 现状风险是全书一个音量（句子中位 10 字、50% ≤10 字）。
- 每章至少 2 个 **45 字以上的长句**用来展开瞬间，内部用逗号串 3 个动作形成节拍。
- **长句后必须紧跟短句。** 长短对比才出层次。
- 叙述段**≤200 字**（否则超过 5 个渲染行）。

## 「没劲」判读（命中即改）

> 指标全绿、逻辑自洽、句子通顺，仍可能读着没劲。以下六条是可操作的判据。
> 详见 `没劲判读规范.md`。

**判废线（直接删改）**
1. **空物件清点**——一句/一段里并列多个废弃、无人管的物件，表达同一个意思。说一次够了。
   > ✗「石台短了半分……没人垫。」「刻字被盖……没人扫。」「灰积了几十年……没人扫。」
2. **机械三连**——`X。Y。Z。` 三句字数相近结构同构。
   > ✗「修复程序。一个载体。一个被预设了使命的存在。」
   **例外**：声音和情绪可以三连（十七、十七、十七），**叙事不能**。
3. **叙述者预告内心**——叙述者说「他在想 X」，而下一段就是把 X 展示出来。
   **修法**：删掉预告，直接进内容。读者要自己得到的乐趣，不要先说。
4. **隐喻压过事实**——比喻本身成了信息，读者要停下来想这个比喻。
   > ✗「怪物会自己往坑里跳。系统给的东西，它自己不知道危险。」← 这是格言不是比喻

**闷读线（累积判定）**
5. **没有阻力**——连续三段以上没有一件事是难的：没有成本、没有风险、没有失败的可能。
   *检查法*：问「这段里，主角如果什么都不做会怎样？」答案是「没区别」，就是闷的。
6. **事件代替体验**——读者**知道**发生了什么，但**没有经历**它。多见于设定讲解、面板汇总、战果罗列。
   *修法*：不写数值本身，写他看到数值时的具体动作或念头。

**两条不要误伤**
- **安静不等于闷。** 允许整章几乎无事发生。判据是**有没有人在承受什么**，不是有没有出事。
- **短句不等于碎。**「他没动。」单独成段是留白，不是复读。

**每章自查**
- [ ] 有没有并列的废弃物件在说同一件事？
- [ ] 有没有叙事性的 `X。Y。Z。` 同构三连？
- [ ] 有没有「他在想 X」而下一段就展示 X？
- [ ] 有没有需要读者停下来想的比喻？
- [ ] 连续三段，主角不做任何事也不会怎样？
- [ ] 有没有只罗列结果/数值而没有过程的段落？
- [ ] 允许**判定"这一章不闷、不动"**——精准确认比再洗一遍重要。

## 每章统一爽点公式
规则压制 → 众人嘲讽 → 系统判定锁死 → 主角触发真空 → 破格反杀 → 全员震惊 → 埋新伏笔。
章尾必须留钩子（悬念/威胁/反转任选其一），**停在动作或物证上，不升华不点题不总结**。

## 硬指标（脚本可验）

> **本书口径（2026-10-02 定，覆盖上级 skill 的数值）**
> 字数一律按 `len(re.sub(r'\s','',text))` 计（**含标点、去空白**），
> 范围 **3400-3800**（2026-10-02 二次修订）。
> 上级 novelist.md 写的是 3200-3800；本书从 3800-4600 收到 3400-3800，理由见下。
> ⚠️ **不要用 4000+ 的惯例反推范围**。本书 `书名与简介.md` 里的平台建议是：番茄 1500-2000、
> 起点 2000-3000、飞卢 1500-2000——**没有一个大到 4000**。正文 4000+ 是历史遗留（当时是按
> "正文长 → 拆章工具切成番茄 1664"设计的），不是目标。
> 含标点 3400-3800 ≈ 纯汉字 2800-3100，兼容起点直发；番茄仍走 `拆章工具.py`。
> **不要用纯汉字数判本书字数**，也不要把 3200-3800 套到含标点口径上。
> 验证：`python3 -c "import re;print(len(re.sub(r'\s','',open('正文/第一部/第001章-全服最废天赋.md',encoding='utf-8').read())))"`

- 字数 **3400-3800**（含标点；番茄版拆章后 1900-2300）
- 禁用词 **6 个**：微微、轻轻、缓缓、某种、仿佛、似乎
  （⚠️ **「像是」不是禁用词**——上级 01:19 版已删除，理由：比喻是意象系统的原料，
  一刀切禁掉会让 prose-scoring 意象维度永远无法达标。改为按「比喻纪律」管）
- 破折号 ≤2 处/章
- **明喻 ≤6 个/章**（不是"每万字"，也不是 2 个）；同章内同一喻体不得重复；
  喻体种数/总数 < 0.7 → 判定为无意象系统；跨章复现 ≥3 次即算意象，**不因重复扣分**
- 对白按体裁分档（本书 = **标准章回**档）：引语行占比 **25%-40%**，全章 <6 处判废
- 正文禁用加粗符 `**`；半角逗号 0
- 唯一句占比 ≥0.55（novelist.md 判废线）
- **叙述段均 ≥35 字**（⚠️ 只算叙述段，**不含**系统面板 `【】`、论坛引用块 `>`、纯引语行。
  本书面板密集，全书均值 45 个面板/章，按旧口径平均会系统性误判——见 `跨章问题清单.md` X-55）
- 段落 ≤200 字
- 禁忌设定 0：高维存在 / 创世者测试 / 多世界联盟 / 仲裁者 / 制衡者
- 缝合章 0（human-prose 第六节：一章内塞同一剧情两个版本）
- 批量替换疤 0（human-prose 第六节：处所短语 + 光杆人称）

## 风格黑名单
- 禁止大段设定说明堆砌，设定必须藏在冲突与反应里。
- 禁止圣母、禁止主角解释自己、禁止反派废话超过三句。
- 禁止作者替读者解释情绪（写筷子横在碗口上，不写"心里五味杂陈"）。
- 禁止章末升华、点题、金句、对仗。
- 系统文本用【】；论坛/频道用引用块；数据面板可用缩进块。
- 数字面板用阿拉伯数字，叙述用中文数字。
- 论坛块就保持论坛的样子，不干净是对的。
