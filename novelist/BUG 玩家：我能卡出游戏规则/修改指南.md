# 《BUG 玩家：我能卡出游戏规则》修改指南

## 三大核心问题与修复方案

## 问题一：人物弧光不足——陆寻需要"成长"而非"变强"

### 诊断
陆寻从第1章到第200章性格几乎没有变化，始终只是"更淡定"。SKILL.md明确提到"逐渐失去的人性"但执行不足。

### 修复方案：五阶段人性侵蚀弧线

| 阶段 | 章节范围 | 表现 | 具体手法 |
|------|----------|------|----------|
| ①好奇 | 001-012 | 对规则的纯粹探索欲 | 保留现有写法 |
| ②上瘾 | 013-024 | 开始享受"卡BUG"本身，不只是为了自保 | 增加"明知可以不用但用了"的情节 |
| ③异化 | 025-050 | 看世界的眼光变了——人变成"判定集合" | 增加他无意识分析他人判定的细节 |
| ④恐惧 | 051-100 | 意识到自己正在失去什么 | 增加对"人性流失"的恐惧和挣扎 |
| ⑤回归 | 101-200 | 在"神性"与"人性"之间找到平衡 | 用陈胖/苏清然/赵擎等人把他"拉回来" |

### 关键修改点

1. **第001章**：增加一个细节——陆寻在面板上看到灰色问号时，第一反应不是"这有什么用"，而是"这东西在看我"。暗示他与规则的共生关系从一开始就不对劲。

2. **第021章（冻结全世界）**：在冻结三秒的描写之后，增加一个细节——陆寻恢复意识后，发现自己无法立刻"共情"那些静止的人。他看着那枚悬空的金币，第一反应不是"壮观"，而是"判定中断导致物理引擎失效"。他把自己吓了一跳。

3. **第042章（陆寻的选择）**：在"成功编写第一条完整规则"的爽点之后，增加代价——他发现自己编写规则时，用的是和系统一样的"语言"，而不是人类的思维方式。他开始分不清自己是在"创造"还是在"被创造"。

4. **第101章（维护者的第一天）**：增加一个细节——陆寻修复规则时，发现自己能"感受"到规则的"疼痛"。他修好一道裂缝，远处的NPC铁匠突然打了个寒颤。他开始怀疑：自己修的是"规则"还是"生命"？

5. **第125章（规则之心融合）**：强化"自我丧失"的恐惧。融合过程中，他看到的不仅是记忆，还有"规则视角"——他同时以"系统"和"陆寻"两个身份审视自己，发现"陆寻"这个身份正在被"系统"消化。

6. **第200章（终章）**：呼应开头。陆寻说"规则学会了呼吸"，但补充一句只有苏清然能听懂的话："我也学会了。"——他指的是自己重新学会了"作为人"的呼吸。

## 问题二：后期AI腔严重——第三部后文笔退化

### 诊断
从第101章起，大量"他的意识""光芒""网络""维度"等抽象词汇堆叠，场景感减弱，说明文增多。

### 修复原则

| 禁止 | 替代 |
|------|------|
| "他的意识沉入规则网络" | 具体感官：冰凉、失重、耳鸣、视野分裂 |
| "两团光芒并肩悬浮" | 具体画面：像两盏被风吹歪的灯笼 |
| "规则稳定指数97.3%" | 用角色反应代替数据：陈胖的包子蒸笼不再乱跳 |
| "他感受到了那种力量" | 具体体感：后槽牙发酸、指尖发麻、像吞了冰块 |
| "新的挑战即将到来" | 具体画面：裂缝里伸出一只手指、钟声少敲了一下 |

### 每章必须有的"三个具体"
1. **一个感官细节**：声音/气味/温度/触感（不能只有视觉）
2. **一个生活化比喻**：用日常经验比喻超常现象
3. **一个意外细节**：打破读者预期的微小反常

### 对话修复原则
- 每个角色必须有可辨识的语言特征
- 禁止所有角色都用"……"作为省略
- 陈胖的台词要带"吃"的比喻
- 赵擎的台词要短、硬、带军旅腔
- 苏清然的台词要克制但有余温
- 白慕鸿的台词要优雅中带刺

## 批量修改检查清单

> 2026-09-30 替换。此前的清单要求「每章必须有生活化比喻 / 非视觉感官 / 意外细节 /
> 无用细节 / 人性波动」，已被**作废**——那套规则本身是 AI 味的来源，机械执行会
> 把每段都写成合格样板。下面是这八轮实际执行的规范。

### 一、可量化的硬线（用脚本扫）
- [ ] 字数 3200-3800（番茄版 1250-2100）
- [ ] 禁用词 0：微微 / 轻轻 / 缓缓 / 某种 / 仿佛 / 似乎 / 那一刻
- [ ] 破折号 ≤2 处/章（实测全书 0.76 处/章），且没有一处是「挂补充说明」
- [ ] 比喻 ≤3 处/章（实测 2.9 处/万字），且必须是**该人物会用的**比喻
- [ ] 对话密度 ≤30 行/千字（第四部实测 26.4）
- [ ] 最长连续正文对话 ≤8 行（论坛灌水例外）
- [ ] 标题零重复；文件名与首行标题 100% 同步
- [ ] 半角逗号 0；编辑残留/思考批注 0
- [ ] 禁忌设定 0：高维存在 / 创世者测试 / 多世界联盟

### 二、真正决定质量的几条（脚本扫不出来）
- [ ] **不许作者替读者解释情绪。** 不写「他心里五味杂陈」，写他把筷子横在碗口上没往下夹。
- [ ] **不许点题、不许金句、不许对仗。** 章末不升华。
- [ ] **禁伪精确数字。** 「0.8%的好感」比「他有点在意」更假。
- [ ] **人物要有废话。** 允许答非所问、被打断、闭嘴、说到一半咽回去。
- [ ] **允许失败和不完整。** 刚写完的东西可以看着别扭。
- [ ] **每段不必完美收束。** 允许话没说完就转场。

### 三、人物小动作的归属
小动作属于**人物**，不属于场景。不要给场景配动作。

| 陆寻 | 站着、观察、走动、等 | 蹲下（仅第116、133章极限场景）、摩挲、掸灰、理衣角 |

| 路人 | 保留 | — |
