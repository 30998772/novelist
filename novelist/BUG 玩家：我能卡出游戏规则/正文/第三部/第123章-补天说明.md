# 第123章 补天说明

第二天，陆寻去了世界最底层。维护者权限里有一扇他一直没推过的门，位置在世界底层往下的第九层，比任何锚点都深。门上没有锁，只有一行灰色小字。

```
/* archive.creator
   访问不需要权限。
   需要的只是走到这里。
*/
```

门是虚掩的。推开的时候没有声音，只有一层极淡的灰扑到袖口上。他没有拂，让它留在那儿。

里面是一片虚空。没有墙，没有地板，头顶和脚下都是同一层灰。灰里有无数光点在漂，大的有拳头，小的要凑近才看得清，每一个都在慢慢自转。

空气是凉的，带着一股老式机房才有的味道。塑料壳烤过头的甜味，混着灰尘和一点点臭氧。这味道他熟。他上高中以前在网吧后厨打杂的时候，见过一模一样的一屋子机器。

他伸手碰了最近的一个光点。光点摊开，变成一段影像。

一个年轻人坐在电脑前。头发一绺压着一绺，眼白里全是红血丝。桌上摆着一排空咖啡罐，罐口都干了，只剩一圈褐色的印。屏幕的蓝光把他整张脸照成一种不健康的颜色。

"第三十几次平衡测试，又失败了。"

他对着录音说话，声音哑得不像二十几岁的人。

"规则与人之间的平衡点，还是找不到。"

陆寻认得这张脸。织律者徽记的记忆残像里见过。沈墨。

"他们说我在做游戏。"沈墨对着录音说，"我做的不是游戏。我做的是一个证明。"

"规则和人，本来不该是死的对头。规则应该护人。可现实里的规则全在吃人。法律、制度、门槛、评分，都是规则。这些规则让有话语权的人定规矩，让没话语权的人照着办。"

他停了一下，端起一个空罐子，发现是空的，又放下。

"我想造一个世界。规则在那儿是盾，不是刀。谁都动不了谁。最弱的那一个，也被规则护着。"

"我知道这不现实。"他最后说，"平衡点是有的，只是我没找到。"

影像没有立刻散。画面定格在一个很小的动作上：沈墨伸手去够另一个咖啡罐，够到了，捏了一下，瘪的。他把它放回那一排空罐子中间，位置摆得整整齐齐。

然后他对着镜头说了一句没头没尾的话。

"今天楼下便利店的收银员跟一个插队的人吵起来了。"

"排队的是七个人，吵了四分钟，最后收银员说算了，你们都付钱吧。"

"我站在后面想，这不就是我想做的那个东西吗。有人吵，有人先讲道理，讲不通了有人让一步，让完大家都还能走。"

"我把这段写进引擎里了。写在最底层，上面的人看不见。"

影像散开。陆寻的手还停在半空。

他站在那片灰里，肩膀松了一下。他自己没察觉。他往前走了一步，低头看脚。虚空里没有地，他的鞋底虚虚地踩着，可他还是踩出了那个姿势。

```
/* 维护者不是规则的看守。
   维护者是平衡的执行体。
   执行体必须有偏移量。
   偏移量必须来自人。
   原因见 /balance/pigeonhole.md
*/
```

他伸手碰了第二个光点。影像里的沈墨老了。头发白了一半，颧骨凸出来，衬衫领子空了一圈。病号服搭在椅背上，笔记本搁在膝盖上，散热口呼呼地吹着风，吹得他手背上那层皮一直在动。镜头架在一摞病历上，位置比人还高一点。他坐下的时候要往下瞄一眼镜头。桌上摆着一个塑料杯子，杯里是水，水上浮着一片没泡开的药片。药片转了两圈，卡在杯壁上，贴着透明的一线泡着。

他伸手把药片按下去。指尖压到水面，片子转过来又立住，他顺着杯壁往下推，推到底，等它自己沉。按了三次才按进去。

"医生说还有三个月。"他说，语气平得像在读日志，"三个月做不完平衡点。"

"但够把框架收尾。"

"我会在世界底层留一个补天程序。等规则开始崩解，需要一个人用自己的力量，把平衡点重新撑起来。"

他停下来，摸了一下膝盖上的散热口。散热口的塑料烫手，他把手缩回来，在病号服上蹭了蹭。

"这里我要写清楚，不后人踩坑。"

他把笔记本往膝盖上挪了挪，屏幕的角度歪了，用小指勾住机身扶正。

"前几条是我给自己写的。有的不是。"

```
/* 补天说明

0. 今天下雨。走廊东头那盏灯坏了，报了两次。
      这行不算在说明里。

1. 补天的人必须是「人」。
      不是程序。不是规则本身。
      因为只有人知道人要什么。
      程序知道人要什么？程序只知道人「声明」什么。

（上一行我打了个引号没配对。改。）

2. 补天消耗的是补天者自己的力量。
      会耗尽。
      耗尽之后他是普通人，没有例外。
      补天不能续，也不能转让，中途停了就是前功尽弃。

3. 我不知道会是谁走到这一步。
      走到这一步的时候，希望有人在旁边。
      不是让他别去。是让他回来的时候有地方回。

4. 麻烦在旁边那个人告诉他：
      规则是工具。别拿它当信仰。
      告诉他他是一个人。

再写一遍：
      规则是工具。让他知道自己是一个人。
      怕前一条太轻了。这条不轻。这条留着。

5. 补写：
      写这行的时候我在ICU，手抖，"人"字写错了三次。
      错的那两个在下面的废稿堆里，别捡。

6. 算了。5 那条不算。

7. 走廊的灯还是没修。管这个的姓吴。
      吴师傅人不坏，就是慢。

8. 补天的人。
      补天的人。
      （重复了。留着。）

9. 如果你能读到这儿，前面那些大概都不用我说了。
      我本来想说很多。写不动了。
*/
```

影像散了。沈墨没念这段。他把这段敲进去，一个字一个字敲，敲到第三句停下来，把光标退回上一行改了个词，再往下敲；敲完他把整段选中，复制，粘贴进最底下那份文件的头部，让它当注释留在那里。

陆寻在灰里站了很久。他忽然想起自己刚才在灰里站着，数了一次附近能看见的光点。数到第九颗的时候数乱了，从头数，还是乱。

他第三次从头数，数到一半又停了。他停下来是因为想起觉醒日之前，他数过一次键盘缝里的灰，数出一个数，记了很多年。

那个数是多少，他想不起来了。他把两只手撑在膝盖上，在灰里坐了下去。

那些光点在他四周慢慢转着，一颗都不肯先说话。他伸手去摸其中一颗。

没有反应。他又摸了一颗。

没有反应。第三颗光点在他右手边一臂远。

他抬手。过去够不到。他往前挪了半个身位，指尖还是差着一截。他又挪，坐姿从盘腿变成跪撑，膝盖压在虚空里，压出一个膝盖的形状，那块地方比别处凉。

够不到。他把手收回来，看了一眼自己的手。普通的手。指甲缝里有灰。

他又抬手，碰第三颗光点。没有影像。

一行字浮在灰里。灰色，小的，跟觉醒日那天他面板最底行那句一模一样。

```
规则是工具，不是信仰。记住你是一个人。
```

陆寻看着它。他伸手在那行字上抹了一下。指尖沾了一点灰。他把手指翻过来，让那点灰落回原处。落到一半他改了主意，用拇指按住，按在那行字下面。他把那点灰搓开，闻了闻。和这房间一样的味道，塑料，尘，臭氧。

面板在视野右下角亮了一下。他没看。然后还是看了。

```
人性参数  31.1
维护者权限  已归档 · 不可撤销
```

"不可撤销"四个字是红的。

他盯着这四个字想了几秒。他还没补天，还没交出任何东西，权限已经先写上了"不可撤销"。

沈墨在补天说明第二条里写过：补天不能续，不能转让。同一批注释，两处口径。

一处的对象是补天。一处的对象是他。

他关掉面板，往门口走。

他正要走，指尖碰到的那行字滑了一下。下面多出了一行。

不是沈墨的笔迹。字体更小，颜色更淡，淡到几乎是那层灰的一部分。

```
/* 这行不是 creator 写的。
   写它的人也不知道自己是谁。
   只知道该有人在。
   ——归档时多出来的。别问。*/
```

陆寻盯着"别问"那两个字。世界底层没有别人。这个档案从封存到今天，只进来过两个人。一个已经死了。他把这行字记进脑子里，然后退出去，顺手把门带上。门在他背后合拢。系统跳了一行提示：

```
归档访问结束。
本次读取对象：3
目录内实际条目：4
说明：无。
```

三对四。他记着自己碰了三颗：影像、影像、一行字。

多出来的那一颗，他从头到尾没有碰到。他没有回头去数。

---

出来的时候，苏清然在入口等他。她没问他在里面看到了什么。她走过来，牵住他的手。

"你的手是凉的。"

"嗯。"

"我给你捂捂。"

她把他的手捧在手心里搓了搓。搓了一会儿觉得不对，换成贴在自己脖子上。颈侧有脉搏，跳得比手背暖，贴上去之后她自己的呼吸也慢下来，慢到他能跟着她一起数完一整轮。

他低头看着她低下去的头顶。这个人等了四十分钟，站着，没有坐下来。

"清然。"

"嗯？"

"规则是工具，不是信仰。"他说，"记住我是一个人。"

她抬起头。

"你说什么？"

"档案里的。他留给所有后来的人。"

她看了他两秒，笑了。

"好。我记住了。"

"记住什么。"

"你是一个人。"她说，"一个会害怕、会软弱、会说'我害怕失去你'的人。"

"嗯。"

"我喜欢这样的你。"

他看着她。频道响了。织律者公会频道，同一个提示音在两秒内响了六次。

「老大你人呢！食堂出大事了！」

「陈胖的包子蒸笼自己跳起来了，六个盖子，离地三寸，我端着一整屉稀饭没敢动」

「我看到了，我腿软」

「不是吧，我们食堂的蒸汽管道昨天刚修好」

「这世界是不是要完了」

「别慌，」陆寻打了五个字上去，「我在，五分钟后到。」

发完他把频道关掉。往外走的路上，公共论坛的推送顶到了他眼前。发帖时间比频道还早两分钟，标题被人改过一次。

「[已锁定] 官方公告：昨夜世界边缘光柱为维护作业，非活动，请勿聚集」

「顶帖：所以公告等于没公告」

「我昨晚在光柱正下方扫地，扫把直接立起来了，扫帚毛全部朝上。我干了八年保洁没见过这种事」

「我们公会那六个新人在里面练级，被光照到以后经验涨了三倍，其中一个的'治疗量不足'居然被判定为'充足'」

「楼上那个是不是充钱充的」

「充了三千。现在我怀疑是给充了三千的那个角色发补偿」

「不是补偿，那游戏不是按钱算的」

「不是按钱算的你怎么在这儿跟我吵」

「因为你有三千我」

「你那是首充送的」

「首充也是充」

「我上个月充了二百」

「你这个我记不清。你别说了。」

「我为什么不能说」

「你一说我又想充了」

「上面别聊充值了，正事呢」

「什么是正事」

「就是刚才那个光柱啊」

「我说了我不知道。我就是在光柱底下扫地的」

「那你怕不怕」

「怕」

「怕什么」

「怕扫帚立起来以后再倒下来砸我脑袋」

「……」

「你们聊完了吗，我要去倒垃圾了」

底下又有人回：

「那这世界有人一直在修？我们这些玩家算什么」

「楼上别问了」

「为什么不能问」

「因为问完你会希望自己没问」

陆寻把论坛关了。五分钟后他会站在食堂门口，看着一屉包子发呆，会在陈胖的追问里说"设备老化"。

陈胖不会信。他会端着蒸笼跟过来，问"设备老化能让人经验涨三倍吗"，问"能让人把'治疗量不足'判成'充足'吗"，问"老陆你是不是又干了什么"。

陆寻会摇头。档案里那行"别问"，他不会说。

少算的那一颗，他也不会说。他走到食堂门口，停下。

门里飘出来一股热气，混着酵母和糖的味道。有人在里面喊了一声"来了来了，让一下"。

他站着没动。他想吃一个苹果。这念头来得很没道理。他现在没有手可以拿，也没有地方拿。

他伸手推门。
