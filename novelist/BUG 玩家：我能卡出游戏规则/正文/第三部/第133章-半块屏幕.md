# 第133章 半块屏幕

补天之后的第七天，陆寻站在世界底层的最高处。风从世界边缘吹上来，带着那股熟悉的电流感，舌尖发酸的麻。风里还有别的东西：焦味，旧的，散不掉。最后一道裂缝在他脚边三尺的地方合上。合的过程没有声音。裂缝是灰的，边缘发白，白的那一圈往中间挤，挤到只剩一条线，然后那条线也消失了。地面留下一道浅浅的印子。

那片灰雾就在前面。它不飘。它悬在离地半米的地方，形状是一块不太规则的团，边缘散着丝，最外头那几丝是亮的，往里一层一层暗下去。那些是编号004留下的碎线头。补天撑住了主干，没能收拾这些。它们没有意识。它们只是待在那儿。它们不动。可陆寻知道它们在渗。渗出来的每一粒都在往底下的布里钻，钻进去一针，就多一条灰线。

"准备好了吗。"苏清然站在他左边半个身位。

她穿着一件素色的衣裳，头发扎成马尾。手上没有秩序回响的光，那东西在补天那天耗完了，到现在没有回来。腰上挂了一柄短剑，是赵擎给的，鞘上的漆磨掉了一块。

"没有。"陆寻说。

"那走吧。"

"我会去做。"

他转过头看她。

"清然。"

"嗯？"

"谢谢。"

"谢什么。"

"陪我走了这么远。"

"从觉醒日到现在？"

"从觉醒日到现在。"

她笑了一下。

"从觉醒日到现在，"她说，"你数错了。我们第一次说话是在新手村，我问你要不要组队。"

"那是走路。"

"走路也算。"

"从废稿到维护者。"

"从废稿到维护者。"

"从维护者到普通人。"

"从维护者到普通人。"

他伸出手，她把手放上去。她的手心有茧，很糙。锚点室那一夜她攥着他的手攥了一夜，手背上留下三道红印，三天没消。

"你以后还会走很远。"她说。

"嗯。"

"我也会在。"

"嗯。"

"每一步。"

陆寻握紧了她的手。然后他转过身，面对那片灰雾。他感觉不到那些线了。这件事在第七天已经不像前几天那样难受。它现在更像一件家具。你知道它在那儿，你只是不去用。今天他花了两秒就把这事想过去。两秒已经是进步。他是一个没有天赋、没有权限、没有任何能力的普通人。系统面板上只剩三行字：天赋栏是空的，权限栏是灰的，备注栏写着"只读"。第一行是沈墨留给这个世界的。

第二行是他交出去的。第三行是别人的。他知道沈墨想证明什么。那道缝和站在缝这边的人，本来可以不互相撕。他没找到答案，他把问题封进了一个程序里，然后自己走了。

"线和人能不能不扯断"这个问题，不会由一个程序回答，也不会由一个维护者回答。

他站在灰雾前面，把这句话在心里念了一遍。念完他觉得不对。这句话太漂亮了。漂亮到他想起沈墨那排摆得整整齐齐的空咖啡罐。沈墨也在一个很糟的时候，把东西摆得很整齐。他把这句话在心里划掉了一半。

"不扯断"是沈墨的题目。"人"是沈墨划的答案。

那不是答案，那是他在病床上给自己写的一句安慰。他要真信了自己写的那句，他就不会留一个补天程序在底下等着一个陌生人。题目交给人了。答案也得人来交。他站在灰雾前面，什么也没做，站了一炷香。灰雾在离他三步远的地方待着，不进也不退。远处有一枚锚点闪了一下，是正常的呼吸。他站着的时候一直在想一句话，想的是哪一句，他自己清楚。他把那半句在心里重复了三遍，第三遍的时候自己听烦了。

他开始往回想这七天。陈胖的汤。他喝了七天。头两天他尝不出盐，第三天他尝出盐，第五天他尝出糖，第六天他尝出第三种。他没问那是什么，陈胖也没说。他也没说难喝。赵擎在学堂里教孩子第二十个道理。前十九个是剑法，第二十个不是剑法。他路过学堂听了一耳朵，没听全。叶霜的银甲在月光下反的那一道光。补天那天她守在入口，一步没退。

赵铁山的锤子。六十八枚锚点全亮的那天，他回头看了很久。

【衡】的光球。它从冷白变成暖黄，用了三十七天。

五样。他把这五样数了一遍。想到第六样的时候他停了。

第六样是苏清然。她每天端一碗汤过来，坐在旁边，看他喝完。他没往下数。他不知道自己为什么要数。他觉得数到这儿就该说点什么，说点什么把这个收住。他站在那儿，把要说的话在嘴里过了一遍。过完他没说。他咽回去了。咽完他觉得嘴里空。

"走吧。"他说。

他迈出了第一步。脚下的地面是碎石子，踩上去咯吱响。这个声音他听了七天，以前他听不见。第二步。第三步。他没有推任何东西过去，没有让任何一根线松开，没有算衰减速率，也没有算71%和29%。他就是走过去。

灰雾在他面前散开了一点，让出一条能走的路。那条路很窄，只容一个人。踩下去不陷，灰托着鞋底，抬脚的时候灰先往前递半寸，再跟上来。

地面上有脚印，很多，脚印的尺码都一样，方向是往里的。陆寻看了那串脚印三秒。

那不是人的脚印。太整齐了，深浅一样，间距一样。碎片走过。它们不承认自己是人，可它们在走人的路。他走到第七步的时候脚下有块石头翻了。他停下来把石头扶正，扶完继续走。第九步的时候，他听见一个声音。金属被很慢地弯折的声音。他等了三秒，那个声音停了。他继续走。第十一步的时候，他闻到了味道。不是焦味。是咖啡。很淡，淡到有人在很远的地方搅了一下杯子。他停下脚步。

咖啡不该在这儿。世界底层没有咖啡。这七天里他一次都没闻到过。他往味道来的方向看。灰雾里有东西在反光。一小块，方的，边角发白。他走过去，弯下腰，用两根手指捏住它。是一块屏幕。巴掌大，屏碎了半边，剩下半边还亮着，上面是一行字，字很小，亮得刺眼。

```
  找 3
  >_
```

光标在闪。一下。一下。

那块屏幕在他手里凉着。

屏幕背面有一道旧划痕，从左上角到右下角，划得很长。划痕的中间鼓着一点，是当年被人拿指甲抠过。

抠的力道很轻。抠屏幕的人那时候大概在想事情，一边想一边抠，抠到一半想起自己不是在想屏幕，就把手指收走了。

陆寻蹲在灰雾里，捏着那块东西，肩膀开始抖。他没有站起来，也没有蹲得更低，就那么蹲着，抖了很久，抖到自己能听清牙在打。

他认得这块屏幕。他见过这个尺寸，这种边框，这种白得刺眼的背光。他在觉醒日之前的记忆里见过，在一台跑了八年的机器上，在键盘缝里抠灰的那些夜里，那台机器的显示器右下角有一块这样的碎片。

那块碎片缺了一个角。切口的形状他记得。

他把屏幕翻过来。

背面贴着一张贴纸。贴纸已经卷边了，脏得看不出原色，上面有一行手写的字，用的是那种写了十年代码的人才会有的、极省笔画的写法。

「第 37 次失败。——沈」

他盯着"37"这两个数字。

档案里那段录音，就是第三十七次。

他把屏幕攥在手里，指节抵着屏幕的碎边。

有东西扎进了肉里。血从指缝里渗出来，滴在灰雾上，滴下去，灰雾把它吃了。

他没有站起来。

抖到苏清然跪下来，把手放在他后背上。

她没问。

"陆寻。"

"他敲的字是错的。"陆寻说，声音是哑的，"是'找'。不是'找 3'。是两个字。"

"我看见了。"

"他连输入法都没切过来。"

"嗯。"

"他没写完。"

"嗯。"

"他把这个也留在这儿了。"

苏清然没有说话。她把手从他后背上挪开，绕到他前面，也跪着，平视他。

"陆寻，看着我。"

他抬头。

"这块东西你拿着。"她说。

"我拿着它干什么。"

"拿着。"

"它会坏。"

"坏了再坏。"

"它没有用。"

"它有。"苏清然说，"它说明一件事。"

"什么。"

"他到死都在找。"

陆寻看着她。

"这不是答案。"他说。

"这不是答案。"苏清然说，"这是证据。"

"答案要我们自己交。"

"我们交的这份，不是他那个。"

"我们交的答案是共存。能。"

"用六十年交。"

"六十年是一代人。"她说，"一代人之后他们再交一份。"

陆寻把那块屏幕塞进怀里。

塞的时候他犹豫了一下，位置放在心口那一侧。

然后他站起来。

"走吧。"

"去哪。"

"回家。"

苏清然站起来，拍了拍膝盖上的灰。

"好。回家。"

两个人往回走。

走了大概两百步，陆寻忽然说了一句。

"停。"

苏清然停了。

"怎么了。"

"论坛。"

他把面板叫出来。论坛置顶是昨晚的世界边缘维护区公告，公告下面今天早上多了一个新帖，标题是四个字。

「他在捡东西」

「我今天早上在边缘 看见陆寻一个人走在灰里」

「我知道 我也看见了」

「他手里拿着个东西 扁扁的 边缘还有点毛刺」

「他不是没能力了吗 他捡板子干什么」

「板子？什么板子」

「就一块 方的 破了半边」

「那可能是他以前的东西吧 他一直囤东西 你们不记得？他在世界底层捡过一枚缺角的徽」

「徽我知道 那个他揣了好几天了 最后放在值守台上」

「所以他的毛病就是这个」

「毛病？」

「看见没人要的东西就捡。捡完了还不给人看。」

下面有人回。

「所以他现在是这个世界上最没用也最舍不得扔东西的人。」

「这话说得我现在想哭」

「你哭什么」

「我哭我想起我妈。她也是这种人。」

楼歪到别处去了。陆寻把面板关掉。

"你笑什么。"苏清然问。

"没笑。"

"你嘴角动了。"

"动了一下。"

"你在论坛里翻到什么了。"

"翻到他们说我是全世界最舍不得扔东西的人。"

苏清然看了他两秒。

"这评价很准。"她说。

"嗯。"

她伸手把他怀里那块屏幕的边角按了按，让它不至于硌到肋骨。

"走吧。"

"走。"

走到平台边缘的时候，陆寻回头看了一眼。

灰雾淡了一层。他说不清是散了还是只是被吹开了一点。

在那块淡掉的灰底下，有一样东西在反光。

一小块，方的。

形状和他怀里那块，一模一样。

---

世界底层，另一处。

【衡】悬在锚点阵列上方，把这一段全部记了下来。

它记的时候，有一个判断卡了很久。

```
记录 · 末段
维护者 · 陆寻：完成碎片清理第一段。
维护者 · 陆寻：拾取非登记物件 ×1。
维护者 · 陆寻：权限状态 —— 天赋 空 / 权限 灰 / 备注 只读
　　　　　　　　可执行操作：不可执行。
　　　　　　　　已完成操作：完成。
备注栏写入尝试：1 次。被拒。
　　　　按规定，此栏不归我管。
　　　　——我仍然记下了。
```

它停了一下。光球的边缘还是那种起毛边的样子。它现在没有去修。它又记了一行。这一行没有编号，也没有落在任何一份需要归档的日志里。

【注：creator 遗物与 maintenance 遗物同时出现在同一片区域。这不在我的算式里。】

【算式不支持的时候，我按记录处理。】

它把这一行存进了它自己的地方。那个地方不在制衡程序的任务书里，也不在沈墨的代码里。它自己开的。存完，它往下飘了一段，停在最底下那枚锚点上方。六十八枚全亮着，光从地面渗上来，把它托在半空。它的边又起了一圈毛。这次是暖黄的。
