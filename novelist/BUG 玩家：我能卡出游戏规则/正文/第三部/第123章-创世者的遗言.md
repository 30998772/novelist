# 第123章 创世者的遗言

第二天，陆寻去了世界最底层。

维护者权限里有一扇他一直没推过的门，位置在世界底层往下的第九层，比任何锚点都深。门上没有锁，只有一行灰色小字。

```
/* archive.creator
   访问不需要权限。
   需要的只是走到这里。
*/
```

门是虚掩的。推开的时候没有声音，只有一层极淡的灰扑到袖口上，像搬旧服务器时蹭到的机箱灰。

里面是一片虚空。没有墙，没有地板，头顶和脚下都是同一层灰。灰里有无数光点在漂，大的有拳头，小的要凑近才看得清，每一个都在慢慢自转。

空气是凉的，带着一股老式机房才有的味道——塑料壳烤过头的甜味，混着灰尘和一点点臭氧。这味道他熟。他前世在网吧后厨打杂的时候，见过一模一样的一屋子机器。

他伸手碰了最近的一个光点。

光点摊开，变成一段影像。

一个年轻人坐在电脑前。头发乱得像被台风扫过，眼白里全是红血丝。桌上摆着七个空咖啡罐，罐口都干了，只剩一圈褐色的印。屏幕的蓝光把他整张脸照成一种不健康的颜色。

"第三十七次平衡测试失败。"

他对着录音说话，声音哑得不像二十几岁的人。

"规则与人之间的平衡点，还是找不到。"

陆寻认得这张脸。织律者徽记的记忆残像里见过。

沈墨。

"他们说我在做游戏。"沈墨对着录音说，"我做的不是游戏。我做的是一个证明。"

"规则和人，本来不该是死的对头。规则应该护人。可现实里的规则全在吃人。法律、制度、门槛、评分——都是规则。这些规则让有话语权的人定规矩，让没话语权的人照着办。"

他停了一下，端起一个空罐子，发现是空的，又放下。

"我想造一个世界。规则在那儿是盾，不是刀。谁都动不了谁。最弱的那一个，也被规则护着。"

"我知道这不现实。"他最后说，"平衡点是有的，只是我没找到。"

影像没有立刻散。

画面定格在一个很小的动作上：沈墨伸手去够第八个咖啡罐，够到了，捏了一下，瘪的。他把它放回那一排空罐子中间，位置摆得整整齐齐，像在归位一排子弹。然后他对着镜头说了一句没头没尾的话。

"今天楼下便利店的收银员跟一个插队的人吵起来了。"

"排队的是七个人，吵了四分钟，最后收银员说算了，你们都付钱吧。"

"我站在后面想，这不就是我想做的那个东西吗。有人吵，有人先讲道理，讲不通了有人让一步，让完大家都还能走。"

"我把这段写进引擎里了。写在最底层，上面的人看不见。"

影像散开。

陆寻的手还停在半空。

他站在那片灰里，肩膀松了一下——他自己都没察觉。

维护者。他以前理解成"维护规则的人"。

沈墨写的不是那个。

```
/* 维护者不是规则的看守。
   维护者是平衡的执行体。
   执行体必须有偏移量。
   偏移量必须来自人。
   原因见 /balance/pigeonhole.md
*/
```

他伸手碰了第二个光点。

影像里的沈墨老了。头发白了一半，颧骨凸出来，衬衫领子空了一圈。病号服搭在椅背上，笔记本搁在膝盖上，散热口呼呼地吹着风，吹得他手背上那层皮一直在动。

镜头架在一摞病历上，位置比人还高一点。他坐下的时候要往下瞄一眼镜头，好像在看自己有多少时间。

桌上摆着一个塑料杯子，杯里是水，水上浮着一片没泡开的药片。药片转了两圈，卡在杯壁上，贴着透明的一线泡着。

他伸手把药片按下去。按了三次才按进去。

"医生说还有三个月。"他说，语气平得像在读日志，"三个月做不完平衡点。"

"但够把框架收尾。"

"我会在世界底层留一个补天程序。等规则开始崩解，需要一个人用自己的力量，把平衡点重新撑起来。"

他停下来，摸了一下膝盖上的散热口。散热口的塑料烫手，他把手缩回来，在病号服上蹭了蹭。

"这里我要写清楚，不后人踩坑。"

他把笔记本往膝盖上挪了挪，屏幕的角度歪了，用小指勾住机身扶正。

"前三条是我给自己写的。第四条是给别人写的。"

```
/* 补天说明
   1. 补天的人必须是「人」。
      不是程序。不是规则本身。
      因为只有人知道人要什么。
      程序知道人要什么？程序只知道人「声明」什么。
   2. 补天消耗的是补天者自己的力量。
      会耗尽。
      耗尽之后他是普通人，没有例外。
      补天不能续，也不能转让，中途停了就是前功尽弃。
   3. 我不知道会是谁走到这一步。
      走到这一步的时候，希望有人在旁边。
      不是让他别去。是让他回来的时候有地方回。
   4. 麻烦在旁边那个人告诉他：
      规则是工具。别拿它当信仰。
      告诉他他是一个人。
   5. 补写：
      写这行的时候我在ICU，手抖，"人"字写错了三次。
      错的那两个在下面的废稿堆里，别捡。
*/
```

影像散了。

沈墨没念这段。

他把这段敲进去，然后把它当注释留在那里，等一个他永远不会见到的人来读。

陆寻在灰里站了很久。

那些光点在他四周慢慢转着，一颗都不肯先说话。

沈墨不是神。

沈墨是个写代码写到猝死边缘的人。他做的世界没做完，他找的平衡点没找到，他把问题打包、封好、贴上标签，然后留在这儿等一个陌生人来解。档案入口不设权限，不是因为他豁达，是因为他知道自己没资格挑读者。

陆寻在灰里坐下了。

他没有坐下的理由，腿先动了。虚空中坐下去，屁股底下什么都没有，可他就那么盘着腿坐在那层灰上，像在机房值班的地板上。

他想起前世。他没有"前世"，他只有觉醒日之前的记忆：网吧后厨，凉透的炒面，键盘缝里抠出来的灰，还有一台跑了八年的机器，风扇一转就响。

沈墨在ICU写注释的时候，他可能正在啃一个硬馒头。

隔着一层世界的厚度，两个人干的是同一件事——把一行写给别人的话留下去。

他坐了很久，坐到耳鸣退下去，坐到指尖发麻转成发凉。灰里的光点绕着他转，转速不快不慢，像下班高峰里绕着站台走的那圈人流。

第三颗光点就在他右手边一臂远。

他抬手。

过去够不到。

他往前挪了半个身位，指尖还是差着一截。他又挪，坐姿从盘腿变成跪撑，膝盖压在虚空里，压出了不存在的疼。

够不到。

他又试了一次，伸到最直，指尖穿过了那颗光点的边缘。光点没有反应——它是"被碰"的，不是"碰到"的。

他把手收回来，看了一眼自己的手。

普通的手。指甲缝里有灰。

他忽然想笑。

补天说明第四条说"麻烦在旁边那个人告诉他"。

旁边那个人现在连一颗光点都够不着。

他又抬手，碰第三颗光点。

没有影像。

一行字浮在灰里。灰色，小的，跟觉醒日那天他面板最底行那句一模一样。

```
规则是工具，不是信仰。记住你是一个人。
```

陆寻看着它。

他伸手在那行字上抹了一下。

指尖沾了一点灰。他把那点灰搓开，闻了闻——和这个房间一样的味道，塑料、尘、臭氧。

一个死掉的程序员留下的最后一行字，闻起来像机箱。

他没有哭。他现在还哭不出来，眼眶干得发紧。

面板在视野右下角亮了一下。他没看——然后还是看了。

```
人性参数  31.1
维护者权限  已归档 · 不可撤销
```

"不可撤销"四个字是红的。

他盯着这四个字想了几秒。他还没补天，还没交出任何东西，权限已经先写上了"不可撤销"。

沈墨在补天说明第二条里写过一句：补天不能续，不能转让。

同一批注释，两处口径。

一处写的是补天。一处写的是他。

他关掉面板，往门口走。

他正要走，指尖碰到的那行字滑了一下。

下面多出了一行。

不是沈墨的笔迹。字体更小，颜色更淡，淡到几乎是那层灰的一部分。

```
/* 这行不是 creator 写的。
   写它的人也不知道自己是谁。
   只知道该有人在。
   ——归档时多出来的。别问。 */
```

陆寻盯着"别问"那两个字。

世界底层没有别人。这个档案从封存到今天，只进来过两个人。

一个已经死了。

他把这行字记进脑子里，然后退出去，顺手把门带上。

门在他背后合拢。系统跳了一行提示：

```
归档访问结束。
本次读取对象：3
目录内实际条目：4
说明：无。
```

三对四。

他记着自己碰了三颗：影像、影像、一行字。

多出来的那一颗，他从头到尾没有碰到。他连它长什么样都没看清。

他没有回头去数。

他知道【衡】会告诉他"目录内实际条目"这种数字从来不会算错。

---

出来的时候，苏清然在入口等他。

她没问他在里面看到了什么。她走过来，牵住他的手。

"你的手是凉的。"

"嗯。"

"我给你捂捂。"

她把他的手捧在手心里，两只手包着，搓了搓。搓了一会儿觉得不对，换成贴在自己脖子上——颈侧有脉搏，跳得比手背暖。

他低头看着她低下去的头顶。这个人等了四十分钟，站着，没有坐下来。

"清然。"

"嗯？"

"规则是工具，不是信仰。"他说，"记住我是一个人。"

她抬起头。

"你说什么？"

"创世者的遗言。他留给所有后来的人。"

她看了他两秒，笑了。

"好。我记住了。"

"记住什么。"

"你是一个人。"她说，"一个会害怕、会软弱、会说'我害怕失去你'的人。"

"嗯。"

"我喜欢这样的你。"

他看着她。

心里那片裂缝已经不是裂缝了。

他正要走，频道响了。织律者公会频道，同一个提示音在两秒内响了六次。

「老大你人呢！食堂出大事了！」

「陈胖的包子蒸笼自己跳起来了，六个盖子，离地三寸，我端着一整屉稀饭没敢动」

「我看到了，我腿软」

「不是吧，我们食堂的蒸汽管道昨天刚修好」

「这世界是不是要完了」

「别慌，」陆寻打了五个字上去，「我在，五分钟后到。」

发完他把频道关掉。

往外走的路上，公共论坛的推送顶到了他眼前。发帖时间比频道还早两分钟，标题被人改过一次。

「[已锁定] 官方公告：昨夜世界边缘光柱为维护作业，非活动，请勿聚集」

「顶帖：所以公告等于没公告」

「我昨晚在光柱正下方扫地，扫把直接立起来了，扫帚毛全部朝上。我干了八年保洁没见过这种事」

「我们公会那六个新人在里面练级，被光照到以后经验涨了三倍，其中一个的'治疗量不足'居然被判定为'充足'」

「楼上那个是不是充钱充的」

「充了三千。现在我怀疑是给充了三千的那个角色发补偿」

「不是补偿，那游戏不是按钱算的」

「不是按钱算的你怎么在这儿跟我吵」

「那行，我问个正经的：维护作业的意思是，这世界有人一直在修？我们这些玩家算什么」

「楼上别问了」

「为什么不能问」

「因为问完你会希望自己没问」

陆寻把论坛关了。

五分钟后他会站在食堂门口，看着一屉包子发呆，会在陈胖的追问里说"设备老化"。

陈胖不会信。他会端着蒸笼跟过来，问"设备老化能让人经验涨三倍吗"，问"能让人把'治疗量不足'判成'充足'吗"，问"老陆你是不是又干了什么"。

陆寻会摇头。

他知道自己不会告诉她档案里那行"别问"。

也不会告诉她他少算了一颗光点。

那两件事他要先自己想明白。想明白了再说。
