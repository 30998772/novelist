# 第129章 最后的考验

世界底层的崩解比预想的快。

陆寻站在中央的时候，脚下的锚点阵列已经暗了大半。那些他花了无数心血钉下去的规则节点，此刻像被人从内部啃噬，一点一点地熄灭。

熄灭是有先后的。第七枚最先暗，因为他钉得最深，用的力量最大。然后是第三枚、第二枚。第五枚到现在还亮着，亮得很勉强，光在它表面上一抖一抖，像一盏接触不良的灯。

第五枚在灭之前先亮了一下。那一下比它整个存活期都亮。

```
锚点阵列 · 实时
有效    2 / 31
衰减速率  0.05 枚/秒
预计全面崩溃  T-41:37
```

"四十一小时三十七分。"【衡】说。

"够了。"

"够什么。"

"够我做完。"

【衡】没有回应。它悬在阵列上方两米，光球压得很低——它这几天一直压得很低。

"你算过误差吗。"它说。

"算过。最坏情况多两小时。"

"最坏情况你补不完。"

"那就取最好的。"

"最好的情况是你补完之后，规则只稳定六十年。"

"六十年够很多人出生。"陆寻说。

他抬头看头顶那片虚假的星空。

那些星星是假的，每一颗都是一个规则节点的投影。节点在，星星就亮；节点灭，星星就掉。

现在它们在掉。

一颗一颗往下坠，拖着一条很短的亮尾。掉到一半亮尾就断，断成几截，像被人从中间剪开的线。

他数了数这一分钟掉了七颗。

三十七颗。

"开始吧。"

"等一下。"【衡】说。

"说。"

"你确定要一次性全放出来。"【衡】说，"你上次这么做是在第二层深渊。你那次在椅子上坐了十一个小时。"

"这次多久。"

"这次我不知道。"

"那更好。"

"陆寻。"

"嗯。"

"我算过你的精神负荷曲线。"【衡】说，"释放过程一旦开始，中途停止的损失是继续的三倍。"

"我知道。"

"我建议你分批释放。八次，每次留一成。"

"八次要多花三小时。"

"三小时买一个能中途退出的机会。"

"我不是要退出的机会。"陆寻说，"我要三小时以后这个世界还在。"

他没有再看它。

频道响了。四条消息挤在一起进来。

「老大呢！昨晚到现在没消息」

「地表在抖，从三点开始就没停过，我家冰箱上的东西全滑下来了」

「论坛已经炸了，有人说世界要没了」

「我这儿三十七个人在线，十一个在挂机」

陆寻看了三秒，回了四个字。

「我在补。都好。」

发完他补了一句。

「陈胖，饭别送下来了。」

频道那边停了两秒。

「……那送哪儿去」

「世界底层。」

「哪层」

「最下面那层。」

频道静了很久。然后跳出来一条，是叶霜。

「我去接。」

苏清然扭头看了他一眼。他摇头。

"你现在下去，"他说，"你会想替我挡。"

"我就是要替你挡。"

"所以我不要你下去。"陆寻说，"我要你在我看得见的地方。"

她抿着嘴，把频道关了。

"开始吧。"他说。

他松开苏清然的手。

松开的那一下，他感觉到她的手在他掌心里抖了一下。

他回过头。

她看着他，眼睛很亮。

"我在这里。"她说，"我哪儿也不去。"

"锚点别去碰。等我说第三枚再按。"

"第三枚？"

"第三枚是第一枚崩的。"陆寻说，"它最弱，也最听话。秩序回响打进去，它会先响应。"

"你怎么知道。"

"因为我钉它的时候多钉了一下。"

苏清然愣住。

"你多钉了一下？"

"嗯。"

"为什么。"

"因为当时我算过，第三枚是整个阵列里最可能被优先回收的一个。"陆寻说，"多钉的那一下会让它多撑二十秒。二十秒不多。够你抓住。"

"你什么时候多钉的。"

"三个月前。"

苏清然没说话。

"我那时候觉得你不会需要。"陆寻说，"我是留着以防万一。"

他闭上眼睛。

规则偏移启动。

不是触发。是释放。触发是点一根火柴，释放是把一整桶油泼出去。

力量从他身体里往外走。

最先走的是手。指尖开始麻，麻完是指节，指节麻完是手腕。麻过的地方没有感觉了，像有人把他的胳膊一节一节卸下来。

然后是牙根。

他咬着后槽牙，腮帮子酸得发疼——这是他这几天认出来的一样东西。疼还在，说明他还在。

他把全部的力量推出去。

那道光从他的位置冲出去，扫过地面，扫过三十一枚锚点，扫过整个世界底层。它不像水，水是有方向的；它更像声音，压过一切，把别的声音都推到很远的地方去。

他听不见了。

锚点重新亮了。

不是稳住。是重生。

第三枚最先响应——它抖了两下，然后整根亮透。第五枚跟着亮。第九枚亮的时候发出一声"叮"，那个声音他听不见，可他知道，因为第九枚的振动传到了他的脚底。

【规则锚点 · 正在重铸】

世界底层的裂缝，一条一条地，开始愈合。

他能感觉到自己变轻。

不是飘起来那种轻。是有人从他身上一层一层地撕走东西。

血从手指里被抽出去，温度从四肢里被抽出去。骨头缝里那种往外冒的冷被抽走之后，剩下的地方是空的。

他站不住了。

膝盖先弯。

"陆寻！"

苏清然的声音从很远的地方过来。他听得见每个字，可那声音像隔着水。

她冲到他前面，双手按在锚点上。秩序回响的光从她脚底涌上来，托住了他正在往下垮的身体。

托住的是膝盖以上。

"别松手。"她说，"我托着你。"

"清然——"

"别说话。专心补天。"

她的脸已经白得像纸。光从她指尖涌出来，一半稳锚点，一半往上托他。

她在干两个人的活。

"停。"

"不停。"

"你的秩序回响撑不了四十二小时。"

"撑一个小时就行。"

"一个小时以后呢。"

"一个小时以后你补完了。"她说，"我就倒了，倒了也没事。"

她的鼻子里渗出血来了。她用手背抹了一下，抹完继续按。

陆寻看着她。

他想伸手把她拉开。他算过：他现在抬手中断，锚点会在三秒内掉到临界值；他继续补下去，她会一直撑到他补完。

两套算式，两个答案，两个都不成立。

第三套。

他把手按到她手背上。

"你干什么。"

"托我。"他说，"用秩序回响托我一个人，比托两个人省力。"

"……"

"三秒之内我说的话你不用信。"他说，"三秒之后你信。"

"我是定规矩的人。"

"你是守人的人。"陆寻说，"守人的人不守规矩。"

他闭上眼，把剩下的力量往前推。

第三套算式里，锚点把冲突折算出来的冲击，71%分给了秩序回响那一侧。

他把自己那份吃满了。

视野边缘炸开一片黑。

不是噪点了。噪点是点，现在是整块的黑，从外往里压。他看见苏清然的手背在黑里发白，血管一根一根全浮出来，颜色已经不是青也不是灰，是一种接近纸的颜色。

"陆寻。"

"第七枚。"

"什么。"

"按第七枚。"

她的手指抖了一下，往右挪了一段，按下去。

第七枚亮了。

光亮得整片空间都白了。

陆寻在那一瞬感觉到了规则偏移正在离开他。

不是一点一点。是抽。

像拔掉一根插在墙上的水管。

```
规则偏移
真空时长  0.010 → 0.008 → 0.005 → 0.003
天赋定义  正在被重写……
```

真空时长在往下掉。

0.01秒是他从觉醒日到今天所有的资本。它掉到0.001秒，他就什么都破不了了。

他看着那串数字往下走。

他心里没有舍不得。他只在心里跟一个东西说了句谢谢——谢谢它陪他走了这么久，从一百分之一的概率被人笑成废稿，到今天还在替他顶住半个世界的重量。

规则偏移的光在他身体里闪了最后一下。

灭了。

---

世界底层安静了一瞬。

这次的安静和校准协议停掉时不一样。那次是有人按了暂停。这次是有人把机器修好了。

空气里那股焦味散到最后剩下一点臭氧，一点金属。

裂缝没有了。

三十一枚锚点全亮着，光从地面渗上来，把底层照成一片温的、发黄的亮。

陆寻往下倒。

不是摔倒。是所有东西都从他身上撤走以后，剩下的那个空壳自己塌了。

苏清然接住了他。

她的秩序回响已经耗完，接住他用的是纯粹的人的力气。两个人一起摔在地上。

"陆寻！"

他睁开眼。

她跪在他旁边，头发散了半边，脸上又是血又是汗，睫毛在抖。

他看着她。

他想抬手替她擦一下，手抬到一半就落回去了。

"你鼻子。"他说。

"什么。"

"在流血。"

"我知道。"

"你没擦。"

"擦不擦都一样。"她用袖子抹了一把，抹完那道血痕还在，从鼻翼拖到下巴，"两只手都得按着。"

陆寻看着她。

她按在锚点上的手指，每一根都在抖。抖得连锚点顶面那层光都跟着晃。

"苏清然。"

"别说这个。"她把脸转开一点，"我按我的。"

"成功了吗。"他问。

"成功了。"她说，眼泪掉下来，"你做到了。"

"我感觉不到规则了。"

"嗯。"

"感觉不到锚点。"

"嗯。"

"感觉不到力量。"

"嗯。"

"我变成普通人了。"

她用力点了一下头，点得太快，血从鼻子里又涌出来一截。

"普通挺好的。"他说。

然后他闭上了眼睛。

他这一觉可能睡很久。久到醒来的时候，什么都该有人替他记着。

---

【衡】飘过来。

它的光球在暖黄里，边缘还是那种起毛边的样子。

"他成功了。"它说。

"嗯。"苏清然说。

"他失去了所有能力。"

"嗯。"

"他现在是普通人。"

"嗯。"

"他的系统面板上还剩三行字。"【衡】说，"天赋栏是空的。权限栏是灰的。"

"嗯。"

"第三行是备注栏。"

苏清然抬起头。

"备注栏怎么了。"

"只读。"【衡】说，"他填过一行，弹回去了。"

"他填的什么。"

"我记录了。但我不能告诉你，因为那栏不归我管。"

苏清然看着它。

"你们两个。"她说。

"什么。"

"一个写了注释不留编号，一个填了字填不进去。"她说，"我认识的人里，最不会说话的两个，都在憋着。"

"她。"

"谢谢。"

"不客气。"【衡】说，"这是我作为朋友能做的事。"

它往前飘了半米，停住。

"苏清然。"

"嗯。"

"谢谢你选了他。"

"我没选。"苏清然说，"他本来就是人，我只是没让他把这件事忘了。"

"那我们两个想的一样。"

"那你们两个以后少憋着。"

【衡】的光球抖了一下。

"这句我不知道该不该记录。"

"记。"

"为什么。"

"因为它不是数据。"

它记了。

---

世界底层入口处，四个人站着。

他们感觉到了那场"震动"停了。从凌晨开始，那震动就没停过——脚下的地砖每隔几分钟嗡一下，像楼上有人在拖家具。现在停了。

"停了。"赵擎说。

"成了？"陈胖问。

"成了。"

叶霜往前走了半步，又停住。

"他呢。"

赵铁山没说话。他把手放在腰后的锤子上，握了很久。

"他变成普通人了。"他最后说。

四个人站着，很久没人开口。

陈胖手里还提着一个饭盒，铝的，边角磕得发亮。他一直提着，从昨晚提到现在。

"走。"他说。

"去哪儿。"

"接他回家。"

他先动的。他迈开腿的时候饭盒撞在胯上，"当"了一声。

叶霜跟上。赵擎跟上。赵铁山最后走，走之前回头看了一眼锚点阵列。

三十一枚，全亮。

四个人朝着那片光走进去。朝着他们的朋友走进去。

---

补天结束后的第九分钟，公共论坛已经数不清帖子了。

有人在世界边缘贴了张照片：自治城的街面，地砖裂着，缝里有暖黄的光往上冒。

「我住二楼，我看见地板在往上鼓」

「然后有人把楼敲回来，我抱着孩子从楼梯跑的」

「重点是底下在补，补完了地还在鼓」

楼往下滚得飞快。滚到某一层，走向变了。

「这次没锁帖。上次光柱那次，官方十分钟就锁了。这次过了二十分钟，一个字都没删」

「也可能是意味着不需要管了」

「前面贴的治安官公告，编号0041。到现在没有0042」

「我懂我意思了」

「我们公司在二十七楼，电梯停了，走下去要四十分钟」

「我在等它停。刚才晃了三下，现在不晃了」

「不晃了才可怕。之前它一天晃三回，现在一下都不晃」

这条回复被顶到很后面，可它下面的回复数量比整页加起来都多。

「我爸在工地干了一辈子。他说最好的时候是终于不用再补漏那天。」

「我爸说的是不漏就是好。」

「你俩别打了。」

陆寻躺在地上，看不到这些。论坛他都关着。

他现在能听见的只有三样：自己吸气的声音，苏清然手指压在锚点上的摩擦声，还有自己心口里那个一下一下的、很沉的响。

那个响比跳得慢。

他以前不知道自己的心跳能这么慢。

慢到他在数：一下，两下，三下。数到第七下他放弃了，因为数它本身就要花力气。

他闭上眼。

黑暗里有一点暖黄色的光在晃。

他知道那是【衡】。它没有走，就悬在那儿。

他想跟它说句话。他张嘴，发不出声音。

那就不说了。

那行它在档案里多写出来的、没有编号的注，他自己记着呢。
