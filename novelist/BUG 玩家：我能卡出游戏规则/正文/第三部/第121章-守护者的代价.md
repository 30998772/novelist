# 第121章 守护者的代价

世界底层的锚点室没有窗。

陆寻能听见的东西有四样：自己的耳鸣，锚点阵列运转的低频，头顶换气扇的风，还有苏清然每次呼吸末尾那一点湿。

她两分钟前咳过一次，压着嗓子压下去的。他听出来了。

空气里全是臭氧味，混着新拆包装的塑料薄膜味。嘴里发苦。他咬着后槽牙，用牙根那道硬味把苦顶回去。

七枚锚点排成一列，插在房间中央的地面上，每枚露出半米，顶面磨得发亮。

第四枚正在暗。

```
锚点阵列 · 实时
已稳定      4 / 7
衰减速率    0.03 枚/秒
秩序回响负荷 78%
承载源      单
```

单。

苏清然的右手按在第四枚锚点顶面，掌心贴着冷灰的金属。秩序回响的光从她指缝里往外渗，把她手背上的血管一根一根顶起来。

陆寻是靠另一种东西感觉到她的。

不是规则感知。那部分他快摸不到了。是更靠里的一根线，从他心里那片裂缝穿过去，一直连到她指尖那团光。她每加一分力，那根线就绷一分。

"够了。"他说，"你超负荷了。"

"还早。"

"78%了。"

"还早。"

她的声音平得像在报站名。

他把面板叫出来，找那份档案。编号005佚名的档案里有完整记录，写得比他见过的任何一份病历都细。

```
意识同化征象 · 005 佚名
一、手背浅层血管隆起
二、指甲根部灰化
三、言语停顿间隔缩短（失去迟疑）
四、对疼痛反应迟滞
五、认知中"人"条目权重下降
五、不可逆
```

第五条被系统自己划掉了，划痕很新。陆寻盯了两秒。

"苏清然。"

"别说话。让我专心。"

他闭了嘴。

他站着没动。他先看的其实不是血管。

他看的是她的手在抖。抖得不大，一下一下，频率很稳。

他站着看她手背上那几根顶起来的血管，看了大概三分钟。三分钟里换气扇转了十几圈。

他右手的鞋带松了。他没去系。他站着看了一会儿，觉得那根带子一直在那儿晃。

"你的手。"

"别看。"

"我不是关心。"

"那你看什么。"

"我看血管。"

她没接话。

他就这么站着又看了两分钟。什么也没发生。锚点室外面有人走过，脚步声从门口飘过去，走了。

他忽然想起自己今天早上那杯水没喝完，还搁在值守台上。他已经忘了那杯水放了多久。

"喝口水。"他说。

"不喝。"

"喝一口。"

"我喝了要分神。"

"那你喝。"

"……"

"我喝。"他说，"我替你喝。"

她笑了一声，笑完那只手抖得更厉害。

"你别闹。"她说，"我不闹。你让我专心。"

第四枚锚点重新亮起来。光从她掌心底下渗开，衰减速率往下掉。

```
已稳定      4 / 7
衰减速率    0.01 枚/秒
秩序回响负荷 86%
```

她的脸在肉眼看得出的速度里失去血色。先是嘴唇，然后是脸颊，最后是耳廓。

陆寻站在原地，两只手垂在身侧。

他以前没有"做不了"的时候。规则偏移能卡掉等级压制、锁定、死亡结算、掉落。0.01秒真空一开，就没有他破不了的判定。

他把那根松了的鞋带终于系上了。系的时候他背对着她。她没回头。

系完他才转过来。

"你脸色不好。"他说。

"我没事。"

"你在说谎。"

"嗯。"她说，"我在说谎。"

她承认得太干脆，反倒把他噎住。

"为什么。"他问，"代价你比我清楚。"

"因为你也付。"她说，"你付人性，我付意识。"

"这两样不一样重。"

"哪儿不一样。"

"我说不清。"

"那你就别分。"她说，"分不清的东西，你分到最后会算到自己头上。"

"不一样。"

"哪里不一样。"

"我付的是我自己的。你付的，是因为我。"

苏清然的手抖了一下，锚点的光跟着抽了一抽。

"你说得对。"她说，"是因为你。可你以前为我做的事，哪一件问过我同不同意。"

他没接。

面板跳了一行新数据，把他的注意力拽走半秒。

```
已稳定      5 / 7
秩序回响负荷 93%
```

五枚了。第四枚刚刚才稳住。他抬头看那排钢钉，从左往右数一遍：五个亮的，两个暗的。没多没少。

面板把数跳过去了。

他想开口问【衡】，话到嘴边又咽回去。

这个念头冒出来的时候他自己愣了一下。不想让任何人知道世界底层少报了一行数据，这念头本身就不像他。

他的私人频道和织律者公会频道同时响了一声。公会频道里全是人。

「老大你在底下吗」

「我在锚点房外面站了二十分钟了 门缝底下全是热气 插电水壶烧开那种」

「四十分钟了 我焖了壶面」

「别打扰」

「我就说一句 刚才整座城的地砖一起响了一下 我鞋底都麻了」

「他回了吗」

「没有」

「那就是别打扰」

「你们先吃 我在楼道里坐着」

「我这面坨了 坨了也能吃」

陆寻把频道关掉。他没回。现在回一个字都会让她分神。

论坛那边也炸了。有人在世界边缘拍到一张照片，标题是"这游戏半夜放烟花？"，图里是自治城上空一道竖直的白色光柱，从地底穿到云层。评论区吵成一锅粥。

「那不是烟花 那是有人在地底下按住了整个服务器」

「楼主你清醒一点」

「我清醒得很 我们区从来没见过这种bug 要么是活动 要么是有人把世界的地基给顶开了」

「顶开了我第一个跑」

「别跑 我刚从锚点房那条路绕过去 路面全是裂纹 宽的能塞进去一只手」

「跑也没用 我家那栋楼的电梯从刚才起就只下不上」

「我家 也是」

「物业群已经吵了两百条了 全在问是不是地震」

「物业说的是煤气泄漏」

「煤气泄漏放烟花呢」

「那我们小区物业是真有文化」

【衡】在房间另一头悬着，光球压得很低，几乎贴着地面。它没说话，也没记录，只在负荷跳到97%的时候往前飘了半米。

陆寻看了它一眼。

它注意到他在看，把光球又往下压了一点。

这一压没有意义。屋里已经没那么亮了，它压不压都一样。它压完了就不动了。

第五枚暗下去的时候，室内温度跟着掉了下去。陆寻后颈的汗一下变凉，黏住皮肤。

"还差两枚。"她说。

"停。"

"还差两枚。"

"苏清然。"

"你来。"她说，"我退半格，你接。"

"我的力量接进去，人性参数会跌破三十。"

"我知道。"

"【衡】会启动强制校准。"

"那也要接。"

"不行。"

她终于转过头看他。眼睛红了一圈，眼神稳得吓人。

"陆寻，你上次拦我，是在坠星崖。我没听。"

"那次不一样。"

"哪次都一样。"她说，"你想护着我，可你护的方式是让我替你扛。"

房间安静下来。换气扇转了一圈，扇叶刮到壳子，发出一声细响。

他低头看了看她的鞋。她今天穿的是那双补天用的旧靴，鞋头磨得起了毛。她进这间屋之前换了鞋，换得很急，一只鞋的鞋跟还踩着。

他没提。

陆寻看着她的手。

"我来算。"

"你算。"

"两个人同时注入。"

面板又跳了一行。

```
已稳定      5 / 7
秩序回响负荷 99%
承载源      单
承载源      单
```

两个承载源，两个"单"。

数据自己打架了。陆寻盯着那两行看了三秒。

锚点室的门从外面响了一下。

没人推。可能是风，可能是外面那个人走路碰到了门。

两个人都没回头。

第三下响过以后，就没有了。

锚点判不出承载源。它会同时收下两份力量，再按运算规则把冲突那部分折算成冲击，直接作用在两个承载者身上。

"第三套也不行。"他说。

"三套都不行。"

"那你就看着我烧。"

"我不是。"

"你就是这样。"她说，"你的办法永远是算。你算完告诉我结果，然后你自己去承担结果。"

她的声音第一次抬高了半格。

"我不是要承担结果。"陆寻说，"我是要。"

"你要什么。"

他张了张嘴，没出声。

"我不知道。"他说。

"那就一起。"她说。

"一起会被夹。"

"被夹总比一个人在外面站着强。"

她抬起手，掌心朝上。

"我数三下。"

"苏清然。"

"三下。"

陆寻把手放上去。

锚点阵列在他们脚下嗡起来，那声音从脚底往上走，震得他牙根发酸。

两个承载源并进去的瞬间，第四枚锚点顶面炸开一圈白得刺眼的光。

苏清然的手在他掌心里猛地一沉。

痛从那个接触点冲上来，冲进他的手腕、前臂、肩膀，一路顶到后脑。他耳鸣盖过了所有声音。视野边缘开始出噪点，一粒一粒的黑点，像老式电视没信号时的那种雪花。

```
承载冲突 · 折算中
冲击量  0.34
分配    承载源A 71% / 承载源B 29%
```

他被分到了七成。

他要的就是这个。

他把牙根咬死，把噪点顶到视野外侧，开口的时候声音平得连他自己都意外。

"接着。"

"陆寻。"

"第五枚，稳住。"

第五枚亮起来。

第六枚跟着亮。

```
已稳定      6 / 7
秩序回响负荷 121%
承载冲突    持续中
```

超载了。超载的数值直接挂在她身上。

她小臂上浮起来的血管开始变色。从青到灰，从灰到一种说不清的白。

苏清然咬住了下唇。血珠子渗出来，她咽了一下。

"清然。"

"别说。"

"你咬破了。"

"我说了别说。"她的声音从牙缝里挤出来，"你一说话我就想听，我一走神冲突量就往上跳。"

陆寻闭上了嘴。

他把另一只手也压上去，两只手把她一只手包住。锚点要折算就折算，冲他来就行。

她想抽手。他没让她抽。

噪点糊住了他半边视野。

第七枚。

光从地面顶起来，穿过他们交叠的手指，从指缝里溢出来。

他把那根松了的鞋带终于系上了。系的时候他背对着她。她没回头。

系完他才转过来。

"你脸色不好。"他说。

只有她的手。

凉的。在发抖。是一个"人"。

那根线在他心里被拽到最紧，然后断了。

他额头上的汗一下涌出来，顺着鼻梁滴下去，滴在她手背上。

他的手猛地收紧。

他收得太紧，指节压在她手背上，压出一道白印。过一会儿那印子才消。

"苏清然。"

"嗯？"

"我害怕。"

她愣住了。

"我害怕你受伤。"他说，"我害怕你因为我受伤。我害怕我护不住你。我害怕。"

声音断了。

他低下头，额头抵在她手背上。

"我害怕失去你。"

苏清然的眼泪掉了下来。

一滴，砸在他手背上。

温的。

他愣了一下。他已经很久没摸到过温的东西。

他把手翻过来，让那滴东西流到掌心里，然后合上手指。

锚点的光猛地亮了一下。第七枚从亮变成刺眼，房间里的空气一瞬间被烤出焦味，臭氧之外又多了另一层。

面板跳了一行字。

```
人性参数  30.0 → 31.1
```

陆寻没看。

他额头抵着她的手背，听见她的声音从很远的地方过来，很轻，还带着抖。

"陆寻，你回来了一点。"

"嗯。"

"就一点。"

"够用了。"

她的手反过来握住他，力气小得几乎感觉不到，可她没松。

---

【衡】在房间另一头看着这一切。

它的光球闪了很久。

【记录。】

【人性参数：31.1。】

【上升0.1。】

【原因：未知。】

它又闪了一下。

【不。】

【原因：已知。】

【她。】

记录写完，它没有像往常那样归档。

它在那份记录上又停了一会儿。

停完，它把光球往后撤了半米，重新压到贴地的位置。

光球往前飘了两米，停在陆寻和苏清然交叠的手上方三寸处。

然后它做了一件没有任何指令要求它做的事。

它在记录末尾多写了一行。这一行没有编号。

【注：她哭的时候，人类心率会升高。】
