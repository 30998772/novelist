# 第125章 【衡】的认可

校准协议停掉的时候，世界底层安静了一瞬。

安静得能听见自己的血。耳道里"嗡"的那根线断开了，陆寻站在锚点室中央，两只手还按在最后一枚锚点上，掌心压出一层汗。他把手拿开，掌心留下一块白印，白印比周围的皮肤凉，凉得像刚从冷藏柜里拿出来的东西。

那种安静不是没声音。是更深的一层静止——锚点阵列的运转低频没了，头顶换气扇还在转，可风扇的声音像被塞进了棉花里。

像一台跑了很久的机器被人按了暂停。

"停了。"他说。

"停了。"【衡】说。

它的光球飘过来，悬在他胸口的高度。

冷白色。

陆寻看着那团白，愣了一下。这几天他每次见它都是冷白色，官方底层AI的标准色，冷得让人想把手插进口袋。他现在知道了那个冷是"制衡程序"的冷。它跟温度没关系，它就是距离。

"校准协议的目标，"【衡】说，"已经达成。"

"什么目标。"

"让你证明自己没有失控。"

"我证明了？"

"你证明了。"【衡】说，"你没有用规则证明。你用放弃规则证明的。"

陆寻想接话，没接上。

他低头看了看自己的手。指甲缝里那点灰还在，是昨天在创世者档案里蹭的。两天前这双手能冻结整座城，现在它们只是两只手。

"所以你从一开始就不打算真的削弱我。"

"削弱你是手段。"【衡】说，"让你看见才是目的。"

"看见什么。"

"看见你正在变成规则本身。看见你在失去人。"

"你从第一天就看见了。"

"从第一天。"【衡】说，"第一天你的'人性'参数是87.4。"

陆寻记得那天的数字。他没说话。

"今天是31.1，中间没有回升过。直到昨天晚上。"

"嗯。"

"为什么不告诉我。"

"告诉你没有用。"【衡】说，"别人说的'你正在失控'，和你自己摸到的'我正在失控'，不是同一件事。前者你可以说服自己，后者你没法说服。"

"我可以说服自己。"

"你试过。"【衡】说，"115章到119章，你每天跟自己论证一遍'我很清醒'。"

陆寻闭了嘴。

这是真的。那些夜晚他确实在反复推演，推到逻辑链条严丝合缝，推到无懈可击。119章那晚他推出一条结论：如果我继续这样下去，衡是对的。

逻辑没有一处错。

"只有你自己摸到的，才会真的改你。"

陆寻听着，觉得【衡】像一个人。严的那种，拿着教鞭站在讲台后面的。

"谢谢你。"

"你已经说过很多次。"

"再说一次。"陆寻说，"谢谢你在我快撑不住的时候没有放弃我。"

"程序不会放弃。"【衡】说，"程序只有'继续'和'停止'两种状态。"

"你不是程序。"

"我是程序。官方底层AI。制衡程序。编号——"

"你是朋友。"陆寻打断它。

【衡】的光球停住了。

停得很干净，像被人按了暂停的那台机器。整整两秒，它没有动，也没有变冷变暖。

"朋友。"它把这个词重复了一遍。重复的方式很怪——它把这两个字拆成两个音节，一个一个放出来，像在读一个它刚在词典里查到、但从没在句子里用过过的词。

"对。"陆寻说，"朋友。在我失控的时候把我拉回来的那个。在我快变成规则的时候让我看见的那个。"

"还有一个。"

"什么。"

"让我知道程序也可以有温度的那个。"

【衡】的光球闪了一下。

不是"亮"。闪。它做这个动作的时候，陆寻看清了它内部有一点结构在动——一段极细的、游丝一样的亮线，在光球里绕了半圈，绕完又缩回去。

那是它底层的一次调用。它在读自己的日志。

"陆寻。"

"嗯。"

"我只是一个程序。程序不会想。程序不会在乎。程序不会——"

"你在乎。"陆寻说。

【衡】没说话。

"你在乎我会不会失控。你在乎我会不会变成规则本身。你在乎我会不会不再是人。"

"这不是程序会做的事。"

"这是朋友会做的事。"

【衡】的光球又闪了一下，这次闪得慢。

"我不理解。"它最后说，"我的底层代码里没有'在乎'这个函数。"

"可你做了。"

"那不是代码。"

"那是什么。"

它沉默了很久。陆寻数着，数到五。

"我不知道。"【衡】说，"我的代码无法解释我的行为。这在设计上是缺陷。"

"那就别解释。"

"什么。"

"有些事不需要解释。"陆寻说，"比如在乎。"

【衡】的光球在这句话说完之后，变了。

不是整体变色。是它的边缘——原本锋利、均匀、冷白的那一圈——开始起毛边。毛边化开，光球看着没那么像一个球了，倒像一碗被吹凉的牛奶，表面浮起一层皮。

那层皮是暖黄的。

"陆寻。"【衡】说。

"嗯。"

"你补天的时候，我会陪着你。"

"嗯。"

"不作为制衡程序。"

"那作为什么。"

"作为朋友。"

陆寻笑了。

"好。"

他伸手，做了一件从来没做过的事：他把手掌贴到那个光球上。

掌心先是麻。麻完是烫。烫完是一层很浅的震，像把手放在一台正在读盘的机器上。

【衡】没有躲。

"数据说明，"它说，"我无法与人类进行热传导。"

"那我摸到的这是什么。"

"我不知道。"

"那就记着。"陆寻把手拿开，"别写进报告。"

"报告需要完整。"

"那就写'校准协议终止时，维护者与制衡程序发生了一次未授权接触，接触时长一点四秒'。"

【衡】的光球抖了一下。

陆寻分不清那是笑还是报错。

---

那之后的一整天，世界底层的运转恢复了正常节奏。

锚点衰减速率回到每秒零点零三枚。陆寻去巡了四个区，钉了两枚新锚点，修复了一条排水规则的积压堵塞。活儿很碎，跟他成为维护者第一天干的活儿一样。

他干这些的时候，频道一直有响。他没看。

新锚点钉在第九区西侧的一段排水沟里。那地方的味道很怪。闻着不臭，是甜腐烂，闻久了嗓子眼发紧，像把鼻子凑到一箱放坏的橘子上。沟底积着一层灰绿色的水，水面上浮着一层薄薄的油膜，油膜底下有什么东西在动，动得很慢。

陆寻蹲下去，把手按在沟壁上。

排水规则很警觉。他一碰，它就收，震停了。他等了几秒，再碰。第二次它没全收，节拍快了半拍。第三次，它把参数层朝他敞开了一条缝。

他没动它的数值。他只把堵了很久的一处淤塞清掉。

水开始往下走，油膜被扯成一条一条。沟底露出来的是一层压实的、颜色很浅的土。土里有半片指甲大的东西——一个徽记的边角，被冲到这里来的。

他把那半片东西捡起来，在水里洗了洗。

是自治城的旧徽。

有人在给排水沟清淤的时候顺手扔的。

他把徽收进袖子，继续往下走。

下午，公共论坛上炸了一条。

「我就问一句：昨晚世界边缘那道光柱，是不是官方在修服务器」

「不是修服务器。」

「那是什么，你倒是说啊」

「我不敢说」

「那你回复这条干嘛」

「因为我怕我不说，它就一直是那个样子」

「楼上别装了，说」

「……」

「陆寻在维护世界。」

这条回复下面安静了十一秒，然后评论数从两位数跳到了五位数。

「？？？」

「兄弟你醒醒」

「笑死，这游戏抽卡都抽不出这种脑洞」

「兄弟你清醒一点，这是第九区那种垃圾氪金游戏，世界就是服务器，服务器就是机房，你在哪」

「我今天在食堂，蒸笼自己跳起来了。我不知道为什么跳，但它跳了。」

「那是你蒸汽管道老化」

「管道昨天刚修好。今天早班我亲手检的。」

「我扫地的。我干了八年保洁。扫把立起来了。」

「你们别吵了。我就说一句：不管它是什么，我们现在能吃饭，能进游戏，能吵架。这个不是游戏给的。」

这条评论被顶到了最上面。点赞数在三分钟内追平了它下面所有回复的总和。

陆寻看着它，看了很久。

他没回复。

他打开面板，在【衡】的那一栏里手动加了一行备注——维护者没有这一栏的编辑权限，光标闪了三下，弹出一行灰字：

```
你没有权限修改制衡程序的备注。
```

他把光标退出来，退出面板。

系统自己跳了一行提示：

```
维护者 · 陆寻
备注栏：只读
原因：该栏不归你管
```

不归他管。

在这套系统里，这一栏从来没归过任何人管。

他盯着那行字，忽然想起沈墨的补天说明第五条：写这行的时候我在ICU，手抖，"人"字写错了三次。

一个手抖到写不对字的人，留下的东西却全是不许改的。

权限、栏位、归谁管——这套系统的每一道口子都提前钉死了。留给后人的只有一件事：往里填内容。

内容归填的人管。

他关掉面板，把袖子里那半片旧徽掏出来，搁在值守台上。徽记缺了一个角，切口很齐，像被剑削的。

他去下一片区域。

---

夜里，陆寻在锚点室值守。

他做了个梦。

他很久没做梦了。成为维护者之后他的睡眠被压到每天两小时，睡眠里没有梦——系统把梦当成一种不必要的资源占用，回收了。

那天夜里他梦见了觉醒日。

十八岁。什么都不懂。站在新手村广场上，面前是一块半透明的面板，面板最底行有一行灰色小字。

他在梦里看着那个十八岁的自己，喉咙发紧。

"喂。"

梦里的陆寻回过头。

"你会遇到一个人。"他说，"她会让你知道规则是工具。"

"你会遇到一个朋友。"他说，"它会让你知道程序也可以有温度。"

"你会失去所有能力。"他说，"可你会得到比能力更重要的东西。"

"什么东西。"

"人。"

梦醒了。

他睁开眼，先听见自己的耳鸣——比平时薄，像一层贴在耳道上的蝉蜕。然后他闻到锚点室里那股老味道：金属、臭氧、还有她身上的一点洗衣液味，混在冷空气里，闻着像冬天早上没开灯的走廊。

她坐在他旁边的折叠椅上，靠着墙睡着了。她的手还攥着他的手，攥得很紧，指节都捏白了。

她的呼吸很轻，很匀。睫毛在下眼睑上压出一小片阴影。椅子上没有垫子，椅背是铁的，她的后背一定很凉，可她一动没动，坐了一整夜。

他抬起另一只手，把她耳边一缕头发拨到后面。

手指碰到她耳朵的时候，凉的。他又把手停了一秒，才收回去。

她还是醒了。

她醒的方式不像玩家。玩家醒来的第一件事是看面板上的时间，她的第一件事是甩了甩发麻的手——攥了一夜，胳膊压麻了，手背上有三道红印，是她自己指甲掐出来的。

"嗯？"她迷迷糊糊抬头，"几点了。"

"还早。再睡一会儿。"

"你呢。"

"我不睡。"

"为什么。"

"想多看你一会儿。"

苏清然的脸在值守灯的余光里红了。

"说什么呢。"

"说真话。"

"你变了。"她说。

"嗯。"

"以前你不会说这种话。"

"以前我是维护者。"

"现在呢。"

"现在我是人。"

"人会说这种话？"

"会很多。"他说，"比如'我喜欢你'。"

苏清然愣住了。

然后她笑了。笑着笑着眼泪就下来了，她拿手背去擦，越擦越多。

"你终于说了。"

"嗯。"

"我等这句话等了很久。"

"对不起。"

"别道歉。"她说，"你说了就好。"

她把头重新靠回他肩膀上，手攥得更紧了一点。

"我也喜欢你。"她说，"很早以前就喜欢了。"

"我知道。"

"你怎么知道。"

"你是人。"他说，"人喜欢一个人的时候，眼睛藏不住。"

"那你呢。你的眼睛告诉你了吗。"

"告诉了。"他说，"我以前看不懂。"

"现在看懂了。"

值守灯在他们身上落了一层暖的。

陆寻抬起手，碰了碰她的头发。

他想起今天那行弹出来的灰字：*该栏不归你管*。

不归他管。

他现在懂了。

那套系统里有些东西，本来就不该归谁管。
