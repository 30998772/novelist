# 第141章 裂缝深处

裂缝深处没有光。

不是"暗"。暗还有暗的层次，这里的光是直接没有。灰色光点到了这个深度就不再亮，它们只是悬着，一动不动，像一屋子闭上的眼睛。

陆寻伸出手，碰了最近的那一个。

凉的。比地底的土还凉。指腹压上去，它往回弹了一点，弹完又停住。

苏清然在他身后半步："它没推我们。"

"它没力气推了。"陆寻说，"它们从补天那天起就在推。推了三年。"

"那它们为什么还在这儿？"

"因为它们没地方去。"

他没有解释更多。他往前走了。

脚下的地变了。

岩石还是岩石，可踩上去的反馈不对。抬脚的时候鞋底会多粘半秒，像拔出一块吸了水的海绵。他把步子放慢，从每一步多耗的那半秒里找规律——第三步和第七步粘得最久，第五步最轻。

第三步和第七步的间距，正好是一个立方的边。

这地方的空间是软的。

软到有弹性。

"清然。"他说，"报个数。"

"什么？"

"我走一步，你报一次我的位置。"

"……好。一。"

"二。"

"二。"

"三。"

"三——"苏清然的声音停住了，"三的位置比二远了半步。"

"四。"

"四。"

"五。"

"五。"

"六。"陆寻停下，"你刚才说三比二远半步。"

"对。"

"可我走第三步的时候，地面的粘滞和第五步一样。"陆寻回头，"这地方的距离在骗人。它把我们往里挪，不给挪的量走。"

苏清然蹲下来，把掌心按在岩面上。

"这里的时间比外面慢。"她说，"慢多少我不知道。我数你的脚步，你走的六步，我这边只走了五步的量。"

"慢多少？"

"外面过去六秒，这里过去五秒。"苏清然抬起头，"一年如果这么差，进去三年就是出来两年。"

陆寻没接话。

三年。她用三秒算出了三年。

他把这件事记在心里的那本新账上，然后继续往前。

---

越往里，光点越密。

它们悬在四周，不动，也不让路。

走到第三百步左右，陆寻停了。

前面出现一道墙。

半透明的，从地面一直顶到看不见的高处。它不发光，靠着后面更深处的灰，才显出一道竖直的边。

第二道墙在十步外。

第三道在二十步外。

三道墙平行排开，把路堵成一条通道。

"它们来了。"陆寻说。

"我来。"赵擎从队伍左侧上前，木剑出鞘。

他没有冲。他先站着看了三秒，看那墙的边，看墙面上有没有波纹。

然后他吐了一口气，从鼻子里出的。

"陆先生。"他说，"这东西压不坏。我要把它切开，得找缝。"

"有缝吗？"

"有。"赵擎把剑尖抬起来，指着墙面上靠下三尺的位置，"那儿每四秒会往回弹一次。弹的时候有个瞬间它薄得像纸。"

"四秒？"

"我数过了。"

陆寻看了一眼手表。手表是他自己买的，三块钱，指针走得比别处慢一点。

他在心里数了四个四秒。

"等那个瞬间。"

赵擎没有答。他收剑，退了两步，右脚后跟抵住一块凸起的石头——那是他自己找的支点，从进来到现在，他一直在地面上一块一块地找。

第四次回弹。

他出剑。

木剑从下往上撩，切进那个瞬间。

墙裂了。

裂口没有碎片飞出来，也没有声音。墙只是从中间分开，向两侧退，退的过程像一块布被人从中间抽走了一根线，退得很整齐。

第一道墙让开了。

【衡】把通道画面推到每个人的面板上。

「现场记录已接通。」它说，「在场三十五人，无人掉队，无人受伤。数据念一遍。」

```
    地表温度：12℃
    缝内温度：-3℃
    缝内重力系数：0.94
    缝内时间流速：0.83（相对地表）
    距地表完全闭合：19分钟
```

陆寻的喉结滚了一下。

地表上是另一场安静。

自治城的告示牌前围了几百个人。城主府把【衡】播出来的数据抄成了三份大字，用糨糊刷在墙上：地表十二度，缝内零下三，重力零点九四。

最底下那行红字写的是"距地表完全闭合：19分钟"。

有人在念。念一遍，围观的人就往前挤一挤。

「所以现在是零下三度，他穿的那身破外套。」

「陈胖带锅了。」

「陈胖带的是锅。」

「我说他带锅去地底。」

「你耳朵是装饰品吗，他带锅是因为要给伤员炖汤。」

「零下三度炖汤。」

「零下三度炖汤。」

「四十分钟前织律者还发了个帖子，问能不能给陈胖的锅做保温处理。有人回他：你先把人带出来再说。他回了两个字：能带。」

「他现在是不是在缝里。」

「能带。」

告示牌前没有一个人走开。城主府的人劝了三次，三次都被同一句话顶回来——"到点了没?"

陈胖的锅，在三百里外的一个侧帐里架着，火烧得很小。

---

"走慢点。"

赵擎回头："慢？"

"【衡】说碎片密度在上升，速率和我们的推进速度成正比。"陆寻说，"我们走得越快，它挤得越凶。硬冲，我们会在通道里被夹成两段。"

"那慢到什么时候？"

"慢到它挤不动。"陆寻看着前面那道墙，"它挡我们，是为了不让我们到核心里去。它越急，我们越不能急。"

"你从哪儿看出来的？"

"它第一道墙没往我身上挤。"陆寻说，"它挤的是路，不是人。它要的是时间。"

"走。"赵擎收剑，"第二道在十步外，还有两次回弹。"

他走在最前面。第二道墙他用了同样的方式，等、同一个瞬间、从同一个角度切进去。第三道他没有等回弹——他改成在墙面最厚的地方贴地一扫，横扫。

"这招不对。"他自己说，"这招慢了三秒，但稳。稳比快要紧。"

他一刀切完，扶着木剑喘了两下。

木剑的剑刃上多了一道灰白的印。

陆寻走过去，用指腹擦了一下那道印。

灰是温的。

"它们在挡。"他说，"因为我们再往前走一步，就到它们的窝了。"

"能判断它们的密度吗？"赵擎问，"我需要知道下一刀往哪儿切。"

【衡】的数字弹出来：

```
    屏障密度：1.7g/m³（标准值0.9）
    回弹周期：4.0s
    最薄处厚度：3.2cm
    【备注】最薄处位置随机，非固定
```

"最薄处是随机的。"赵擎把剑举起来，"那我得每一刀都重新找。"

"找三次。"陆寻说，"三次找不到就退，别硬切第三刀。"

"为什么是三次？"

"因为你的手在第三次会抖。"陆寻说，"我看出来了。你握剑的虎口在发白。"

---

外圈。

陈胖的嘴一直没合上。

碎片从缝里溢出来，一颗一颗，大的有指甲盖，小的只有米粒。它们的轨迹没有规律，全靠碰撞乱飞，撞到人就往肉里钻。

陈胖张嘴。

"噗。"

一颗。

"噗噗。"

七颗。

他嚼了两下，眉头皱起来。

"什么味儿？"赵铁山在旁边问。

"像……"陈胖又吞了一口，噎得直翻白眼，硬咽下去，"像放了三年的粉笔，泡过水，晒干，再泡一遍。"

"你形容得还挺具体。"

"废话。"陈胖抹了下嘴，"我是厨师。我这辈子嘴里过的东西比你见过的多。"

他张开嘴等下一批，等得脖子酸，就半蹲下去，把嘴张成个"O"型等。

这一等就是二十几颗。

他脖子撑不住，头一歪，咳了半分钟，扶着赵铁山的锤柄才站起来。

"铁山哥，"他喘着说，"下次给我做个支架。铁的。带弹簧那种。"

"我打铁的，不是打家具的。"

"你打铁的还不是给人做饭吃。"

赵铁山没接这句。他把锤举起来，对着缝边一块松了的岩壁砸下去。

"当"的一声，岩壁往里沉了两寸。

地面的震顺着锤柄传到他手腕上，再顺着腕骨传到肩，肩一沉，锤再落。

他一锤一锤地敲，每一锤的间隔一样长。敲了二十来下，那块岩壁传回来的声音变了——从"空"变成"实"，像敲一块实心的砖。

"这块行了。"他说。

他往旁边挪三步，换了个位置重新举锤。

"你怎么不歇。"陈胖一边嚼一边问。

"歇不了。"赵铁山说，"我这一块敲实了，下一块松了，整片都会走。"

---

裂缝更深处，陆寻和苏清然站到了通道尽头。

那里悬着一个东西。

一颗灰色的球，直径大概到膝盖，悬在空处。周围所有的光点都在往它身上飘，飘到跟前就停下，贴上去，贴成一圈毛边。

球不亮。可它周围有一圈很慢的起伏——像一块面团在慢慢醒。

"核心。"苏清然说。

"核心。"陆寻说，"很安静。"

他伸出手。

指尖离球还有一寸时，他停住了。

他发现一件事：光点不怕他。

从进来到现在，所有光点对他都没有反应。不推，不挤，不挡。它们只在赵擎切墙的时候才动。

它们认得他。

它们认得的东西在他身上——他当维护者那三年里留下的东西。

他没有犹豫，把手按了上去。

温的。

和赵擎剑刃上那道灰印一个温度。

---

然后那团"存在感"挤进了他的脑子。

那团存在感比语言更老——像有人在很远的地方拍了一下墙，墙这边的空气动了一下。

它说了三句话。

第一句：你们来了。

"嗯。"陆寻说，"我们来了。"

第二句：你们要修我们。

"送你们。"陆寻说。

第三句没有成句。它停在半途，像一句被咽回去的话。

陆寻等着。

它又试了一次。

陆寻听懂了。

它问的是：修好了，你们还在吗。

"在。"陆寻说，"我会一直在。"

"我们都会。"

他等着它再问。它不问了。

它只是在他手心里一下一下地起伏。

一下，一下。

比心跳慢。

像一个人在睡梦里呼吸。

陆寻站在那儿，手按着，等了大概六十秒。

他不知道自己为什么数了六十秒。数完他才想：这是以前等系统刷新读数的节奏。

他把这个念头按下去。

"清然。"他说，"我要开始送了。"

"我扶着你。"

陆寻把手往下压。

那颗灰色的球在他掌心里开始散。

散得很慢，慢到他能看清每一颗光尘离开的顺序：先是表面那层毛边松开，然后是外圈，最后是中心。中心散到一半时，整条通道里所有的光点同时向内收了一步——朝着他手心的方向收。

收完，它们停住。

没有爆，没有涌，没有推。

整条通道安静了大概五秒。

然后，通道上方传来一声很长的响。

岩石在位移。听不见，只有整条通道的顶往下压，压得很慢，压得矮了三尺。

"它要合。"苏清然说，"缝在合。"

"它在合。"陆寻说，"它不想让人待在缝里。"

他抽手。

掌心是空的。灰色的球没有了。

通道顶还在往下压。远处有石头从壁上掉下来，砸在地上，砸出的声在通道里绕了两圈才散。

"走。"他说，"往回走。快。"

"清然。"

---

往回跑的那三十秒，陆寻回头看了三次。

第一次，看那道被赵擎切开的墙口——三道墙都在愈合，切口从两边往中间挤。

第二次，看通道壁上——灰光点散了七成，剩下的开始往岩层里钻，钻进去就不再出来。岩壁的灰在退，像退潮。

第三次，他看自己的手。

掌心有一块印记。

灰色的，圆的，中间一道细缝。

它像一只闭上的眼睛。

他把手指攥起来。印记没有消失，攥紧了更清晰，隔着掌纹都能摸到一点凸起。

苏清然在他前面跑，跑出七八步才发现他慢了。

她倒回来，一把抓住他的手腕。

"陆寻！"

"跑。"

"你的手怎么了！"

"出去再说！"

他们冲出通道口的时候，头顶塌下来。

赵擎的第三道墙正好被合拢的岩层砸中，整面墙被压成一团淡灰色的雾，散得很快。

"进来了多少？"赵擎抹了一把脸。

"一个。"陆寻弯腰撑着膝盖喘气，"一个核心。它答应走了。"

"答应？"陈胖从外圈跑过来，嘴还没擦，"它会说话？"

"它没说话。"

"那就是没说话。"陈胖说，"可我吃了三十多颗，每一颗都在喊。"

陆寻看着他。

"喊什么？"

"疼。"陈胖擦了擦嘴，声音低下去，"每一颗都在喊'疼'。"

陆寻直起身。

他的后槽牙在发酸，从咬肌一路酸到耳根。这三天他每天只睡两小时，站着的时候膝盖会抖——抖他自己看得见，别人看不见。

他伸手按了一下腮帮，把酸压下去。

面板在视野右下角自己弹了一行：

```
    【体力储备】21%
    【警告】低于15%时，判断误差将超过可接受范围
    ┊
```

只到21%，没有更多说明。

他记得三年前这行字后面还跟着一句"建议摄入糖分"。现在那句话没了。

"走吧。"他说。

风从缝里往外吹，吹在他脸上。这一次风是热的。

热风里有一点焦味，像谁在很远的地方烧了纸。

地平线上，那片灰色的天，正在一寸一寸退。

退得比来的时候慢。

苏清然看着他的手。

"这是什么？"

陆寻没答。

他把手翻过来。

印记闭得更紧了一点。

就在这时候，缝的最深处——就在那片灰色退下去的地方——有什么东西翻了个身。

整个地面震了一下。

苏清然手里的水壶盖被震落，滚到土坡下面去了。

缝没有再合。

它张开了半寸。

半寸里透出来的不是光。

是更深的灰。
