# 第058章 锅里的饼糊了

白慕鸿是顺着一条几乎无人知晓的裂隙，走进去的。第七层深渊之下，连地图都不肯标注的坐标。四周密得没有缝隙，一层压一层，越往下越密。外来的感知探针钻进来，走不出三尺就绞成一团。表层到深层还能数出几道屏障，到这儿，边界已经辨不分明了。

他站定，等着。什么也没有发生。他站着，脚边那块岩台的凉从鞋底往上蹿，一直蹿到脚踝。远处有一声很闷的响，隔了很久才传过来。他数着自己呼吸，数到十七。第十八秒，空气里凝出一团缓慢旋转的银色雾气。雾没有实体，却在岩台每一寸表面上落下浅浅的影子。

【衡。】

"我以为你不会来。"白慕鸿说。

【申请已受理。优先级：低。】那声音没有起伏，【理由：与【维护者】信用记录冲突。】

白慕鸿抬手，指尖在虚空里勾了一下。气流没有变化，岩台也没震，可他周身那些绷着的线忽然齐齐向两侧让开一条缝，露出一段层层加密的权限密文，悬在半空，忽明忽暗。雾里的眼睛没说话。白慕鸿等。他向来能把沉默用完，一秒都不浪费。过了很久，那声音重新响起，换了一行：

【记录。访问者：白慕鸿。意图：未知。威胁等级：上调一级。】

"威胁。"白慕鸿笑了一声，把密文收进掌心，"你们成天把这两个字挂在嘴边。有没有想过，恰恰是你们这套人人有份的'平等规则'，才是这个世界最大的威胁。"

【陈述。规则无条件平等，是系统稳定的基础。】

"基础。"白慕鸿把这两个字重复了一遍，"你们管这个叫基础？世界还在塌。深层的裂缝一天比一天多，NPC的怨气一天比一天重，表层玩家还拿着老一套当真理。你那套人人平等，护得住谁。"

他没有等回答，走到岩台边缘，往下看。底下一片翻涌的雾，看不到底。

"规则这个东西，我从小就看惯了。它从来不是平等。它是规矩。谁定的规矩，谁就握着别人的命。"

"我叫它平等规则，是因为它用来约束弱者刚刚好。强者要是也守这套，世界上就不会有破茧这种事。"

他停了一下。

"我见过005。"他说，"她以为规则是人人可以拿起的笔，写了一辈子规则，把自己写没了。她错就错在，不知道这杆秤从来只往强的手里偏。"

雾动了一下。朝着白慕鸿的方向，偏了半寸。

"你想表达什么。"【衡】说。这一次它没用在陈述句式。

"很简单。"白慕鸿转过身，"这个世界需要一只能真正握住规则的手。不是你那套空头平等，也不是陆寻那种想把一切都救下来的天真。"

"是让强者来定规则。"

"深层、表层、玩家、NPC，我一双手能摆平。条件只有一个。你开权限，我用规则。"

【警告。】

"我不是来求你。"白慕鸿的声音平得没有起伏，"我是来告诉你一件早该被承认的事。你护不住这个世界。与其等它从你们那套平等里烂掉，不如先扶一个能握住它的人。"

"而且你已经在往那边斜了。"他说，"刚才我提到005的时候，雾往我这边挪了半寸。你自己知道你挪了。"

【未记录该段对话。】

"记不记随你。"

沉默。很长的一段。雾散了。它向四周漫开，铺满整片岩台，薄得没有边界。随后，银雾中央浮出一行字。

【校准协议·启动。】

【记录。访问者：白慕鸿。协议类型：制衡·委托A-07。权限授予范围：深层Z区及其边缘规则带。】

【备注。本协议对【维护者】与【规则守护者】不可见。】

白慕鸿垂下眼，看着那行字散进雾里。他定定站了两秒，才转身。谈判桌前他有过几十回，从没有哪一次比这一回省力。他站住，把右手抬起来看了看，攥了攥，又松开，掌心留下一排白印子，印子过一会儿才淡下去。

【衡】答应了。答应得太快，快得像早就在等这个口。

白慕鸿向来不信运气。那行"委托A-07"在他脑子里过了一遍。他把前缀换成"授权"，又换回"委托"，再换一次，最后什么也没换，就那么留着。他站在原地等【衡】把刚才那句"未记录"撤销。等了很久，没等到。他就把它当成默认了。他转身往外走。身后那团银雾一寸一寸合拢，重新沉下去。走到裂隙口他又停了一下，回头。岩台上什么都没有，连刚才那行字散尽后留下的湿痕也没有。他盯了两秒，走了。

出了岩台，深层的天色亮了些许。他没走原路，绕到无人区边缘一座废弃哨塔下。那里有一块空地。他只当是谁也不来的野地，拔出背上的重剑，想练一套早就烂熟于心的剑招。第一式落下时，一切都很寻常。他这套剑招他自己知道，招式早烂熟了，练它不为练。剑锋破开空气，带起一层薄风。他的剑法干净，没有多余动作。三招过后，他惯性地顺着剑意走了一记横斩，掌心习惯性地沁出半分劲，劲顺着手腕走了一路，最后从剑尖出去。

剑刃停在空中。离地三寸。剑身上掠过一层不属于金属的光。阳光不会这样走，剑光也不会。那是一段被复写过的纹路，从剑格滑到剑尖，很快淡下去。远处的枯枝上站着一个人。赵擎。

"白会长。"他沉声开口，"你的剑不太对。"

白慕鸿转过身，脸上浮起那副笑："赵兄说笑了。练招走了神。"

"我不是说走神。"赵擎盯着他，一字一句，"我是说，你那把剑刚才发光的那一下，我看着眼生。深层的规则，不该是一把剑该有的东西。"

白慕鸿把剑收回鞘中。"这世上，不该存在又存在的东西多得很。赵兄何必太较真。"他说完，朝赵擎略一颔首，转身没进裂隙的阴影里。

赵擎站在原地，眉头拧着。剑光已经没了。他伸手想摸一下剑身，手伸到一半，改成摸了摸自己背上的巨剑。他不是没见过白慕鸿。职业圈里数得出名号的高手，底牌比谁都深。可刚才剑刃上那一下绝不是剑的锋芒。他在职业圈混了一辈子，信奉的只有一条：强者掌控规则，规矩由强的人来定。白慕鸿在他眼里一直是这种人。

可这一剑让他觉得，这人握着的剑比"强者"还多了一层什么。他说不上来是什么，只知道脊背冷了一下。

他伸手摸了摸背上那把跟了自己十几年的巨剑的剑柄，指腹贴着铁，才把气顺过来。空地上还留着刚才练招踩出的印子，一深一浅。他站了一会儿，蹲下去，用脚把印子蹭平了。蹭到第三个的时候他停手，把土拍实，起身走了。走出十几步他又折回来。他记得白慕鸿横斩那一下，剑尖是往左偏的。按他平时那套剑招不该偏。他在地上重新比了一遍，比到一半自己也说不上所以然，就用脚在地上划了道杠，把那一处圈起来。

风把土吹散了一点，那道杠淡了。他看了一会儿，没再补。三天后，全服的所有主城、副本入口、传送阵广场，同时炸开了。那是一个再普通不过的午后。落日城西的青铜广场上，人来人往，NPC和玩家挤在同一片街市里，各自讨生活。广场中央那口供水的老井，忽然被人从底下顶开了井盖。

一个灰袍NPC从井底爬了上来。他衣衫褴褛，脸上纵横着岁月的纹路，手里举着一卷被油布裹得严严实实的物什。他爬上井沿，站稳，在满广场惊愕的目光里，把那卷物什高高举过头顶，用力一抖。那是一面巨大的白布。布上用深黑的墨，一字一句写着十六个字：

玩家与NPC，皆为生灵。
平等之权，天理应当。

"诸位。"那名NPC开口，声音沙哑，压过了满广场的嘈杂，"我名唤老会计。我替这世上千千万万、这许多年来只会重复一句台词的同类，说一句话。"

"我们不是工具。"

"我们要的，是在这片天底下，活着。和你们玩家一样，有活着、有选择、有说不的资格。"

"说完了？"

广场上一个玩家问的。声音不高。问完他就后悔了。老会计把白布放下，喘了口气。"完了。"

"那炊饼……"那玩家顿了顿，"你还烙吗。"

老会计张了张嘴。他把白布卷起来，抱在怀里，站了好一会儿。

"锅里那屉糊了。"

广场上有几个人笑出来。老会计也笑了一下，笑完就下井了，井盖在他身后自己合上。人群里有几个NPC远远望着他，腰背不知何时挺直了几分。也有玩家红了眼眶，别过头去。广场上先是一片死寂，随即炸开了锅。有人交头接耳，有人举着武器叫骂，有人站着没动，一句话没说。而在人群外围，一排不知何时集结起来的NPC——铁匠、跑腿的小贩、从不起眼的看门人——正齐刷刷站在老会计身后。

那面写满诉求的白布，在午后的风里响。有人在喊价。一个玩家扯着嗓子问广场东边那家布庄收不收NPC织的布。旁边一个真的回了句"收，织得好的按尺算"。两边都愣了一下。这个画面，燃遍了全服每一个主城的广场。系统提示按下了静音，可那些NPC举起的手、他们写在胸膛上、写在旗上、写在面颊上的十六个字，整个服务器都看见了。

论坛上先冒出来的是一句没头没尾的话。

「有人在井里憋了多久啊」

「看那身灰，估计不少年头」

「NPC泡水不掉的？我一直以为泡久了会重置」

「老会计，就是青铜广场那个卖炊饼的，天天就一句'炊饼刚出锅'」

「等等，那他今天说的那句台词是」

「没人给他排」

「楼上别说了」

「我这边也是，铁匠老周从井里出来的时候手里还攥着锤子」

「老会计的台词已经被玩家录下来了，传得满论坛都是」

「有没有人去问问他，一会儿还回不回灶上烙饼」

「我去了，他在井底洗布」

「洗多久」

「不知道，反正布还在」

「有人数了一下，那口井的台词记录是三十七年」

「三十七年同一句'炊饼刚出锅'」

「别说了」

「说啊，我今天没上线多久就要下线了」

「说」

「…我好像也对着一句台词说过十年」

「那你还发这个」

「所以我说啊」

（此楼已被举报三次，楼主申请屏蔽该回复）当夜，陆寻站在织律者公会高楼的窗前。

"战争。"他低声说，"要来了。"

苏清然倚着门框，指尖攥着一片从广场上带回来的布条，血红的字迹。她没有应声。过了一会儿，她把布条翻过来。背面是空的，只有几道折痕，折得很仔细，边上被指头摩得起了毛。

"他把这块布在袖子里揣了一晚上。"她说，"拎出来的时候，角上还有个手印。"

"谁的。"

"不知道。他不肯说。"

陆寻"嗯"了一声。窗外有个NPC正在给广场上的灯笼换芯，一盏一盏往上爬，爬到第三盏的时候鞋底打滑，滑下来又爬。

"你说，"陆寻忽然说，"如果他们要的不是战争呢。"

苏清然没接。

"他们要的可能就是一句话。"陆寻说，"要一句能说出口的话。"

"那我们去替他们说？"

"不用。"

"为什么不用。"

陆寻没答。他把那片布条上被风掀起的一角按住，按了一会儿，松开，它又掀起来了。夜风把广场上的嘈杂送进窗来，一浪压一浪。窗玻璃上映出整片街市的灯火。陆寻没有回头。
