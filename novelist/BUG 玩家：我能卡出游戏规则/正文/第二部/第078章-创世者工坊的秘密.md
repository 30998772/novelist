# 第078章 创世者工坊的秘密

战争的第十二天，陆寻收到了一条神秘的消息。

那条消息没有经过任何通讯系统，直接出现在他的意识中。

陆寻警觉地睁开眼。能绕过所有通讯频道、直接把信息写进他意识里的存在，他只想到一个。可这一次，消息的格式是标准的系统提示。

【系统提示：检测到隐藏区域解锁。创世者工坊已开放。坐标已标记至您的地图。】

"创世者工坊。"陆寻皱眉。

【创世者工坊：沈墨在创建这个世界时使用的工作室。包含修改世界基础规则的工具。危险等级：SSS。】

"沈墨。"陆寻默念着这个名字。第四位传承者，关于他的记录极少。

修改世界基础规则的工具：如果能得到它，或许就能彻底结束这场战争。

"苏清然，陈胖。"他召集了核心成员，"我要去一个地方。"

"去哪儿。"陈胖问。他的黑眼圈比之前更重了。

"创世者工坊。沈墨的工作室。"

苏清然皱眉："现在就走。战争还没结束。"

"正因为战争还没结束，我才要去。只有得到创世者工坊的力量，才能真正结束这一切。"

苏清然盯着他看了几秒，忽然道："如果工坊里有结束战争的办法，为什么沈墨自己不用。"

这个问题让帐篷里安静了一瞬。

"所以我要亲自去看看答案。"陆寻说。

陈胖犹豫了一下："但是陆寻，这边的战斗怎么办。我们群龙无首的话。"

"你来。"陆寻说，"我相信你。"

陈胖愣住了："我。"

"你是我见过最聪明的战术家。"陆寻说，"你对数据的敏感度，对战局的判断力，比任何人都强。这场战斗交给你，我放心。"

陈胖的眼眶红了一圈，很快又被他抹了回去。他吸了口气，把腰板挺直。

陆寻难得地多说了几句："真空锚点还剩七个能用，B线的伤兵不要排第一班。还有，要是天穹放终焉之火，就把人撤进三号区，别心疼工事。"

"知道了知道了，你什么时候变得这么啰嗦。"陈胖摆摆手，声音却有些发哽。

"好。"他说，"我会守住的。"

陆寻点了点头，然后看向苏清然："你跟我一起去。"

苏清然点头："好。"

她跟着他走出帐篷，走了三步又停下，回头把帐篷的帘子压好，压了两道。

陈胖在里面没吭声。帘子压完，那边才传出一句："走吧。"

两人消失在了夜色中。

创世者工坊位于游戏世界的最深处，一个从未被玩家发现的隐藏区域。它藏在数字之海的最底层，被无数的防火墙和数据加密保护着，像一枚沉在最深海底、几百年没人碰过的锈锚。

路上并不太平。第三层防火墙是一道活体规则墙，会主动撕咬一切靠近的数据，锋利的丝线贴着他们的衣角擦过去，留下一条条焦黑的印子；第五层是记忆迷宫，闯入者会看见自己最不愿回想的画面。陆寻靠规则偏移硬生生卡掉两道关卡，苏清然则用规则同化安抚那些躁动的防火墙程序，像驯服一群恶犬——指尖贴着丝线一寸一寸顺过去，直到那些发烫的敌意一圈一圈地软下来。

记忆迷宫里，陆寻看见的是新手村的那条泥路。雨夜，昏黄的路灯，一个卖药水的NPC朝他用力挥手。画面只持续了一瞬，就被他亲手掐灭了。撕开幻象的时候，他的指尖不易察觉地抖了一下。

苏清然什么都没问，只是走过来，与他并肩。

最后一段路，两人是踩着一段废弃的旧版本地形走过的。脚下的山川还是许多年前的样子，边缘处不断剥落成光屑，坠入无尽的黑暗深处。

陆寻和苏清然穿过重重障碍，终于来到了工坊的入口。

那是一扇巨大的金属门，高约十米，宽约五米，上面刻满了复杂的符文。那些符文在黑暗中散发着微弱的光芒，明暗交替，一起一伏，像一扇门在均匀地呼吸。锈迹从门轴一路爬到门心，又在符文的纹路边缘干裂卷起——这扇门，不知道在这片黑暗里站了多少年。

"这些符文，"苏清然伸手触碰，指尖刚沾上，那圈符文就像受了惊，齐齐亮了一下，"是规则的具现化。每一条符文都代表着一条规则：重力、时间、空间、生命、死亡，它们交织在一起，形成了这扇门。门上的锈和灰，是年月替它们盖的被子。"

"门在筛选来访者。"她收回手，"它刚才读了我的权限。"

"结果。"

"我们被允许进入。"她顿了顿，"但门说，上一位访客，已经是很多年前了。"

"能打开吗。"陆寻问。

"能。"苏清然闭上眼睛，规则同化的力量在她体内涌动。

她伸出手，掌心贴上金属门。

嗡。

门轴咬住了她的指尖。疼，像按住了一块烧红的铁。她没松手。

符文顺着她的掌纹一格一格亮过去，然后门开了。开得很慢，慢到她能数清门轴转了多少圈——整整四十七圈。这扇门上一次开，是四十七圈之前。

一股沉寂了不知多少年的空气从门缝里涌出来，带着金属与旧纸张混合的味道。

门后，是一个巨大的空间。

无数的机器、屏幕、工具整齐地排列着，像一座搬走了一半的仓库：架子还在，货全没了。空气中的尘埃被门推开的那股风惊起，在光柱里上下翻找落点。气味是金属、机油和干涸墨水搅在一起的，涩，压嗓。

这是时间的味道。不新鲜，是密封了很久又开过一次的旧气。

苏清然的脚步声在这里格外清晰，一步一声，都被空旷的空间接住、放大。她走过一排排沉默的机器，那些蒙尘的屏幕依次亮起微光，像沉睡的哨兵认出了来人，一盏接一盏地睁眼，却没有一个惊动这片沉寂。

工坊深处有一张积灰的工作台，上面摆着半杯早已凝固的茶、几页写满涂改痕迹的草稿纸，还有一枚磨得发亮的六面骰子。椅背上还搭着一件外套，落满了灰，肩线依然挺括。

茶杯里的茶冻成了琥珀色的一块，杯壁上挂着一道水痕——水痕的上沿已经干掉发白了，说明这杯水倒下去之后，没人喝。

草稿纸上的字迹潦草而用力，有几处划破了纸背，笔尖把整张纸都戳得坑坑洼洼。桌角还压着一颗螺丝钉，旁边一小摊水渍，水渍已经干成白边。写这些字的人拧着眉头，一边写一边拆过机器。

苏清然拿起其中一页，轻声念出上面的一行小字："规则应当公平，否则宁可不写。"

落款处只有一个编号：004。

"六面骰。"她把那枚骰子托在掌心。六个面上各刻着一个编号，001到006，唯独没有007。

"传承者的名录。"陆寻的声音压得很低。

骰子底部的棱上还刻着一行极小的字：掷出我的人，已经不在场了。

在这时【衡】开口："沈墨离开之前，把工坊的权限拆成了三份。一份交给了那扇门，一份封进了这支骰子。至于第三份。"

它停住了。

"在哪里。"

"如果我能说，你们就不会是第一批活着走进来的访客了。"

"这就是创世者工坊。"陆寻走进去，四处张望。

他的目光被一个巨大的屏幕吸引。

屏幕从地面一直立到屋顶，上面滚动着无数的数据和代码，那是这个世界的底层结构。

字迹密得反光。陆寻看了十秒，眼睛开始发涩，泪腺自己往外挤。他抬手用袖子擦了一把，擦完还接着看。

每一条代码都是一条河流，无数条河流汇在一起，就成了这个世界。这片星河此刻正对着他一个人静静地淌，淌得连个水花都没有。

他忽然想去便利店。走了一整天的路，脚底那双鞋的鞋垫已经压平了，站在货架前会不觉得累。这念头冒出来的时候他自己都愣了——他正站在这个世界的源代码前面。

有几条支流在"发烧"：战争留下的规则创口还没愈合，代码在那里打着旋，泛起一圈圈浑浊的浪，冒出细密的杂音。陆寻不用靠近，凭意识就能定位每一处伤口的坐标——那一处的光是焦黑泛暗红的，隔着整面屏幕都认得出。

他数了一遍。

十七处。

前线的战报从来没一次提到过这个数字。

"这是，"陆寻瞪大了眼睛。

"世界的源代码。"苏清然走到他身边，"沈墨就是用这些代码创造了整个寰宇神域。重力、时间、空间、生命、死亡，所有的规则都在这里。"

她抬头看屏幕，看了一会儿，忽然说："这里只有代码。"

"什么？"

"没有注释。"她指着屏幕右下角一块空白，"这么大一片，一条注释都没有。沈墨给全世界写了几百万行代码，一句没写。"

陆寻看着那块空白。一个把自己编进世界的人，给自己留了整整一屏的沉默。

陆寻盯着屏幕，眼中闪烁着复杂的光芒。

他下意识地想用规则偏移去碰其中一条支流，指尖刚起势就被苏清然按住了手腕。

"在这里，每一次试探都是真刀真枪。"她摇头。

"如果能修改这些代码，"他低声说，"就能改变这个世界的规则。"

"但是你必须小心。"苏清然说，"任何错误的修改，都可能导致世界崩溃。这个世界是精密的，每一条规则都相互关联，牵一发而动全身。"

陆寻点了点头。

他开始在工坊中搜索，寻找可以修改世界的工具。

最终，他在一个角落里发现了一个古老的装置。

那是一个巨大的机器，高约三米，整体形状是一枚巨大的笔尖。机器的表面布满了锈迹和划痕，但它的核心部分却散发着微弱的光芒。那是创世之光，是创造世界的力量。

"创世之笔。"苏清然把声音压到只够两人听见，"传说中，沈墨就是用这支笔创造了这个世界。它是创造规则的工具。"她顿了顿，"握住它的人，握的是整个世界的笔山墨海。"

陆寻伸出手，握住了那支笔。

笔身冰凉，凉得他小臂起了一层疙瘩。重量更过分——他抬了三次才把它端平，端平之后手腕开始抖，抖得停不下来。这分量像端着一整块地板砖，还是悬空的。

笔杆上密密麻麻全是划痕，一层压一层，压了不知多少年。每一道刻痕里都嵌着灰。灰下面还有更早的划痕，一道压一道，数不清。有人在这里握过、放下、再握起，反复了很多次。

那股力量顺着掌心的划痕往里钻。

陆寻听见自己太阳穴在跳，一下一下，跳得比外面的代码河流还快。信息不是涌进来的，是砸进来的：每一条规则的结构、每一个节点的位置、每一条代码的含义，一口气全塞进他的颅腔，塞不进去的就硬挤。

他的鼻血流下来了。



【衡】的声音头一回带上了一丝近似于紧张的东西："放下它，或者做好觉悟。这支笔每写下一个字，都要以世界的基础架构为墨。你们脚下这个世界，经不起几次挥霍。"

陆寻的手没有松开。

"我感觉到了。"陆寻说，"我能感觉到这个世界的每一条规则，每一个节点。它们交织成一张巨大的网，形成了这个世界。"

"还有你的精神负荷。"苏清然说，"已经接近极限了。要是现在动笔。"

"我知道。"陆寻打断她，"但是我没有选择。"

苏清然看着他，忽然想起白慕鸿转述过的一句话：这个人从不解释自己，但他的每一步都踩在自己说过的话上。

她没有再劝。她只是走到他身侧半步的位置站定。从今往后，他写下的每一个字，都有她来守。

他闭上眼睛，握紧创世之笔。笔尖悬在半空，映出他眼底跳动的光。
