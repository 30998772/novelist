# 第068章 够得着的水囊

风停了很久。屋顶上的铁皮还在响，一下一下。陆寻已经分不清站了多久。脚底板的知觉早就没了，只剩鞋底硌在碎砖上的那种钝痛。远处有鸟叫了一声，又断了。这地方的鸟不叫。被风暴剖开的主街横在脚底，半面城墙斜插在乱石里，墙缝间嵌着一格一格的熄灭的光丝。空气里有焦灰味，混着铁锈，混着一股说不清的凉。陆寻在断墙边站了一夜。

后半夜他试着靠墙歇一会儿，墙硌得慌。他换了个肩，又换回来。整整一夜里，他一共回头看过两次。两次都是听见身后有人想走近，又退回去的脚步声。第三次没听见有人来。他还是回了头。没有人赶他走，也没有人敢上前。救援早就停了。统计的人一趟一趟来，在瓦砾间低声数着什么。有人蹲下去数完，手指在瓦砾上写个数字，写完用袖子抹掉，再往上挪一格继续数。写完就抹。他听得见那些数字：救出来的，没救出来的，还有至今对不上名字的。

他试着伸手。伸到一半又放下了。规则偏移扫过整片废墟，一寸一寸，从东往西。从前他一个念头，就能让一整座城停下来三秒。可这会儿，那些人被风暴吞下去的时候，他就在三步之外，他伸过手，没有够到。而现在，扫描线扫过的地方，全部是平的。没有回应，没有光。

从前他从不觉得"无力"这两个字，跟自己沾得上边。他一路赢过来，靠的从来都是"还有办法"四个字。

【扫描完成。区域内无存活规则单元。无响应。】

远处有两个人在低声说话。

"再扫一遍吧，仪器说没有，人在这儿站着呢。"

"仪器不会错。"

"那我问你，人呢。"

对方没答。无。他又扫了一遍。同样的结果。他把提示关掉了。他从前调规则，卡判定，改参数，靠的都是这个世界递过来的一双手。他一直以为那双手是他的。昨夜发现那是借的。他试着把这件事想得更具体些：那双手是谁的，他以前从没问过。现在也问不了。他试着不去想那个瞬间。后面那半段他很熟，熟到能背：他正在同时处理两处，一处偏了，他先去补那处，等他反应过来补错了，再回头已经晚了。有时候是在结算队列里，有时候是在仲裁队列里。

他把这件事在心里翻来覆去想了半夜，翻到最后还是那一句：早半秒呢。

他把那块瓦砾在脚边翻了翻，翻出一个烧变形的铁牌，牌子上压着编号。他读了两遍，把牌扣在掌心。

"扫过的区域，"他对着空气说，"我全记着。"

没东西接话。远处那两个人走了。没有早半秒。风暴从缺口倒卷回来时，他正被另一道裂口的信号绊住。他以为自己能同时护住两条线，结果一条都没有护住。等他拔足跑回去，那条街已经没了。有人从光里朝他伸过一次手，很快又被抹平。整夜里反复把他惊醒的，都是那截被风抽空的手，和那句喊着他名字的声音。

他清楚自己丢了什么，也清楚一件都捞不回来。他没有跪，也没有哭。哭要力气，他现在连生气的力气都得省着使。他想骂一句。想了两句，都没骂出来。他在断墙边坐了一会儿，又站起来。站了一会儿，又坐下。身后传来踩碎瓦砾的声响。陈胖在他三步之外停住，没再往前。他在那儿站了一会儿，跺了跺脚，才从怀里掏出油纸包，隔着三步的路程递过来："陆哥，吃口东西吧。包子还热。"

陆寻没有回头。包子的味还是飘过来了。猪肉大葱。凉透之后那层油凝在纸上，一块一块。他昨晚也吃的是这个，那会儿嫌咸。陈胖也不催，把包子收回去，在断墙上坐下。坐下去的时候他哎了一声，屁股底下是块碎砖。他没挪地方。两人隔着三步。他脸上还沾着灰，眼圈发青。昨夜他扯着嗓子协调救援，把声音吼哑了。他压着喉咙开口。"统计那边我盯着呢。从这片废墟里捞出来的活人，一共二十六个，全安置在断桥底下，验过伤，吃得下东西。没找着的，我叫他们慢慢对，对到对上为止。"

他没敢提叶霜。那只油纸包，是他一路揣在怀里跑过来的，半道上摔了一跤都没撒手。风从废墟那头吹过来。陈胖摸出保温杯，拧开，自己喝了一口，呛得直咳嗽。他连咳嗽都捂着嘴，不敢出声。嚼了两口包子，他终于开口，声音沙得厉害："陆哥，你别太难过了。你不是神，你是人。神才不会为了死了的人，在废墟里站一整夜哩。会疼，会走不动，会舍不得。你站在这儿，已经比他们全都强了。"

他说到一半，顿了顿，声音放得更轻："断桥底下有个守着孩子的NPC，自己伤成那样，还在给小孩系扣子。陆哥，你守的那些人，有人替你接着在守。"陆寻的肩膀动了一下，幅度很小。断墙上的碎灰跟着落了薄薄一层。陈胖又说："论坛上那些人说话难听，你别看。明天我就带人去删，一个都不留。"

"别删。"

"啊？"

"他们说的有一句对的。"

陈胖张了张嘴，没接上话。他低头去抠油纸包的边角，抠了两下没抠开。没有人笑。他自己也没笑，低头把剩下半个包子塞回嘴里，赌气似的，两口吃完。过了好一会儿，他闷闷地说："其实我过来的时候，不知道该说什么。天没亮我就蹲在路口，把能说的话都想了一遍，没有一句对得起你站的这一夜。"他咽了口唾沫，"后来我就想，你平时话也不多，我坐这儿，不说话也行。你知道你还剩一个兄弟，活的，还在。这就够了。"

陆寻终于回过头，看了他一眼。两个人谁也没说话。有个统计的人从瓦砾那头过来，手里捏着一支断掉的粉笔，蹲下写了个数，写完抹掉，起身走了。他走过去的时候鞋底踩碎了一块瓦，脚下一滑，扶了一下墙。陈胖被他看得先是一愣，鼻尖一酸，赶紧用袖子胡乱抹了一把脸，正想再挤出一句话。余光里，断墙另一头，有个身影走了上来。赵铁山。陈胖顺着他的目光认出来人，紧绷了一夜的肩膀悄悄塌下去一点："赵叔也守了一夜了。我去送水，他把自己的水全让给了伤员。"

老铁匠提着一柄短锤，从塌了半边的铁匠铺那边，一步一步走过来。他没走近，在陈胖身后站定，把锤柄往地上一支，就那么站着。他一句话也不说。他大概比谁都明白，这种时候，说什么都是轻的。他就站着。手背上有血，是昨夜在瓦砾里扒人时划的口子，他不包，也不喊疼，一双老眼在晨光里眯着，慢慢扫过整片废墟。

过了一会儿，他弯下腰，从砖缝里拣起一枚烧黑了的小铁钉，在掌心掂了掂，收进腰间的布囊里。拣完他没直起身，在那儿蹲了一阵，看着地上的砖。那布囊已经鼓了一半，鼓得布都发亮。他又解下腰间那只旧水囊，放在断墙边，摆在陆寻伸手就够得着的位置，然后退开半步。他学不会说安慰的话，就留下这一口能喝的水。然后他转过身，朝铁匠铺的方向，一步一步走了回去。

始终没有说一个字。

"赵叔。"陈胖小声喊了一句，"你水都给了，你喝什么。"

老铁匠没回头，也没停，只把手往身后摆了一下。

"他摆手的意思是，"陈胖转过头看陆寻，"他不渴。"

陆寻没说话。陈胖望着那道背影走远，张了张嘴，什么也没说出来。他往兜里摸了摸，摸出那半个硬饼，咬不动，又塞回去。陈胖把保温杯的盖子拧上，又拧开。他一直没喝。陆寻却在这时抬起了手。他也不知道自己为什么要再扫一遍。大概是赵铁山弯下腰的那个动作，勾住了他脑子里什么东西。感知顺着指尖重新沉下去，扎进脚底的废墟，穿过一层又一层焦黑的残骸，一直往深里去。他找了那一整夜，却没敢往深里找。

他碰到了什么。很远的地方，有一粒极细的光，浮了上来。它没有形状，没有声音，却带着一丝几乎察觉不到的暖意。陆寻第一反应是残响。风暴过后，旧数据回光返照，这种东西他见过，散得快，他告诉自己别去接，接了就是给了自己一个假念头。可那一粒光没有散。它浮在那儿，一格一格地稳着。风从上面压下来，它矮了一截，随即又顶回去。顶了整夜。陆寻的手开始抖。抖得不听使唤，跟泡了凉水以后拿不稳筷子一个样。他把另一只手也压上去，压不住。

"陆哥？"陈胖察觉不对，凑了过来，"你、你别吓我，你看到什么了。"

他手上还有半个包子，捏着，没敢咬。

"有东西。"陆寻说。声音很低，低得像在说给自己听，"这下面。有东西。"

他把感知再往深处推。那一粒光牵出第二粒、第三粒。一小簇一小簇地亮起来。亮得很慢。它们残缺，破碎，彼此不搭话。可它们都在。那是规则留下的印记，是那些被风暴撕碎卷走、却没散干净的最后一点渣。它们没有死透。他蹲在原地辨认了一会儿，认出了几缕熟悉的气息。有一团还带着铁砧上的余温；有一团细细的、缠着药草香。更远处还有十七团更淡的光，各带着一点不同的小习惯。有人总把账目记在心上。有人爱蹲在桥头的石像边发呆。有人怀里还揣着半张烧了边的糖醋排骨的方子。

每一个，他都叫得出名字。其中有一团认出了他。陆寻的呼吸猛地断在胸口。那团碎片碰到他的感知，往下沉了一下。就一下。点头也用不了这么大力气。他整个人跪了下去，把掌心贴紧焦土。那天午后柜台后面那个一直擦着同一只药瓶的女人，笑起来眼角三道细纹。他记得的。

"叶霜。"他说。

碎片没有回应。他几乎要缩回手。，一道声线从感知的尽头浮起来，隔着很厚很厚的水，一字一字，往他胸口里钻：

"……下面……还有……"

沙哑。断续。几乎要被一团嗡鸣的杂音吞没。陆寻收紧了手指。

"叶霜！"他喊，"你说的下面是。"

话音没落，那声音就在杂音里一截一截地断了。信号断了。他把那只手从焦土上拿开，掌心沾了一层黑，搓不掉。

"陆哥？"陈胖蹲在他身边，大气都不敢出，"刚、刚才那声音，是叶霜姐？她说了什么？"

"再叫一次。"陆寻说。

"陆哥，声音传不下去的。"

"我知道。"

"那我陪你叫。"

陆寻没拦他。陈胖趴到裂缝边上，扯着嗓子喊了两声叶霜，喊完自己先红了眼睛。陆寻没有说话。他把那句话压在喉咙底下，一个字一个字地，放回心里。下面。还有。她没说别的话。就这四个字。就在他的脚下。陈胖在他背后小声问了一句要不要叫人来。陆寻没听见，也没答。

他在那儿又唤了几遍。声音在底下传不远，出去一截就散了。碎片再没出声。一颗一颗熄回去，沉进焦土，重新安静。方向他不会认错，就在脚下这片黑下去的地方。陆寻慢慢站起来。晨光越过断墙，落在他手背那几道泛着冷光的裂纹上。他低头望向脚边那道被风暴剖开的、黑得看不见底的裂缝，他站着没动。他朝裂缝的方向，迈出了第一步。鞋底在焦土上打滑，他换了个脚。

身后，陈胖慌慌张张地站起来。他绊了一下，膝盖磕在砖上，磕完又跑。："陆哥？陆哥你去哪儿。你等等我啊。"陆寻没有停下。废墟之上，风又起了。这回带着一点湿气。裂缝深处，很远很远的地方，有一粒几乎看不见的光。隔着重重废墟，一闪。一闪。
