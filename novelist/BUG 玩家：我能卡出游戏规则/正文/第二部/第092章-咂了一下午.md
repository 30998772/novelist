
# 第092章 咂了一下午

那枚护符在陆寻书桌上躺了快半个月。灰扑扑的，巴掌大，正面刻着几道弯弯曲曲的纹路，乍一看就是一截开了裂的旧东西。陈胖那天在废墟里刨它出来，沾了一手的灰，献宝似的递过去："老大，这玩意儿看着邪门，上面全是你不认识的字。"陆寻接过来看了看。那些纹路不属于寰宇神域现存的任何一种文字体系，笔画细得像针尖，隐隐流动着微光。他试着用精神力探进去。石沉大海。精神力撞上去那一下，他后槽牙咬紧了。
护符本身没有抵抗，反倒是他探进去的那一截精神力被抹平了，抽出来的时候已经不成形，摊在感知里一摊，边界找不回来。
他甩了两下手，才把那股发木的感觉甩掉。
"有意思，但暂时破不开。"他把护符收进怀里，"放我这儿，改天研究。"
半个月里发生了太多事。陆寻成了新的维护者，决心修复NPC意识，在第二层深渊里找回了叶霜、林姐他们的意识碎片。那些碎片以规则残影的形态沉睡着。清早的风从窗缝钻进来，带着秩序之城特有的铁锈和草灰气。陆寻把护符翻出来看了两眼，指尖描过细纹。半个月前废墟那天，铁锹磕在硬物上发出"当"的一声，哑得奇怪。
他试过更深的探法。所有的路都走到"进一步"这三个字上就卡住了，连同他自己的精神力一起卡住。
"残影有了，缺的是一把钥匙。"陆寻盯着摊开的光点残影，声音沉下去，"它们缺一个共同的锚点。没它，我没法把散乱的信息拼回去。"
苏清然站在他身侧，指尖的规则纹理扫过那些残影："是缺一个坐标。这个世界的所有NPC都该有一个共同的根。只要能碰到那个根。"
"就能顺着它，把每盏灯重新点亮。"
陆寻说这话时没抬头。在场的人都听懂了：能想的办法都试遍了。叶霜的残影在他掌心里颤上一颤，边界往外鼓了鼓，又缩回去，硬是不肯真正聚拢成型。
"这些残影是忘了回家的路。"陆寻收回手，"他们记得自己是谁，却不记得自己从哪儿来。"
那东西落进掌心就再没离开过他。夜里睡不着，他把灯拧暗，对着窗缝漏进来的一道月光，翻来覆去地看。纹路在暗处会显出一层极淡的荧光，一明一暗，频率很稳。他试着用指尖一点一点描过去，描到某处时指尖会发麻，麻意一直蹿到胳膊肘。
他掐灭灯，改用精神力描。麻的位置一模一样。从那天起，每天清早他都把护符翻出来看两眼，描完就收进怀里。这件事他没跟任何人说。桌上摊着的正事排着队等他处理，他一件也没落下，只是每天清早会先腾出三分钟。今天这护符摆在桌上。屋里没人说话。苏清然在翻昨天没批完的一叠表格，翻了三张，一张也没批。窗开着，一只不知道什么鸟落在窗台上叫了两声，又飞走了。赵擎靠着柱子换了个脚站，站完把剑在地上杵了一下。
陆寻伸手把护符往前推了半寸，又收回来。推到一半停了。
"你们先说。"他忽然道，"它要不是我想的那个东西怎么办。"
"那就再放半个月。"苏清然头也没抬。
"半个月以后还不是。"
"那就一直放。"
陈胖嚼着半根卤鸡腿，腮帮子鼓得老高，油滋滋的嘴角沾着碎肉："那到底去哪儿找这个根啊？"没人回答。陆寻沉默了一会儿，伸手从怀里把那枚旧护符摸了出来。
"我在想这个。"
陈胖噎了一下，把鸡腿从嘴里抽出来："你不是说破不开吗？"
"破不开封印。"陆寻把护符举到光下，"可它跟NPC意识有关。沈墨留下的底层信息里没有它，可它的气息跟世界的根很像。就差一层壳。"
"那就硬砸开。"赵擎抱着剑，"我出一剑。"
"不了。封印对攻击和窥探都免疫。越用力它越往里锁。"
屋子里安静了一瞬。陈胖盯着那枚护符看了很久，忽然开口："……要不，让我试试？"所有人的目光都转过来。
"得了吧胖子。"赵擎挑眉，"你那铁胃还能啃得动护符？"
"我不是要啃护符！"陈胖脸一下子涨红，"我是说，那个封印认的是'力量'，剑也好精神力也好，带着攻击或者探究的意图，它都给你挡回来。可我的【铁胃】不是攻击啊。"
他把那枚护符拿起来放在掌心掂了掂。
"我天赋的判定是'消化'。系统判的是'它能不能被我吃掉、有没有营养'。它认的是'有没有营养'，不认'是不是封印'。"
陆寻的目光定住了。
"你是说，你想把它吃了？"苏清然问。
"不是整个吃。"陈胖挠挠头，声音低落下去，"我试过绕着它啃，密封层跟里面的芯是分开的。那层壳……"
他掰着手指头。
"我在嘴边咂巴了两下，好像能尝出点东西，咸不拉几的，像隔夜汤上结的油皮。"
"那你就咂呗。"赵擎说。
"我咂了。"陈胖说，"我咂了一下午。"
"有味儿吗。"
"有个屁。"
他顿了顿，闷声道："我想把那层油皮吸溜掉。里面的芯，说不定就能露出来。"
屋子里静了整整三秒。然后赵擎先笑了："行啊胖子，这么多年，总算听见你那铁胃干点正事了。"
陆寻没有笑。他走过去，把护符放回陈胖手心。
"小心点。封印下面如果真是创世者的信息，它可能是活的。"
"放心。"陈胖眼睛一眯，"我这辈子最擅长的，就是对付活的东西。"
"你上回也是这么说的。"
"上回那锅是馊的，不算。"
"那上上回。"
"上上回是酸笋。"陈胖顿了顿，"……那回也不算。"
"上上上回。"
"上上上回那锅我喝了。"陈胖把鸡腿骨头上最后一点肉啃干净，"真挺好的。我念了四年。"
陈胖把护符举到嘴边的时候，满屋子人都屏住了呼吸。他喉结一动，做了个吞咽的动作。系统随即弹出一行判定。【铁胃·消化判定：检测到可分解的'能量外壳'，是否执行消化？】。搁往常这种提示他闭眼就点了确定。这次他在心里说了句：执行。
几秒后，他整张圆脸皱成一团。
"嘶。"他倒吸一口凉气，干呕了两下，"咸的。真他娘的咸。跟一把老盐巴糊嗓子眼里似的。"
他一张嘴，蒸腾起一小团淡灰色的雾，那雾还没散开就被判定重新纳了回去。他咂咂嘴，表情认真起来："咦，不对……这味道，怪。"
"怎么了？"苏清然追问。
"它……有温度。"陈胖的声音低下去，"饭菜那种热是烫嘴的。这个像有人把手焐了许久的温，捂在脸上。"
他原本只打着试试的主意，此刻却让什么东西勾住了，二话不说又凑上去，咕咚咕咚连吸了两大口。那两口的动静比头一口大得多，护符表面腾起一层漩涡，笼着淡淡光晕。苏清然把灯往他脸侧挪了半寸。
"你的嘴唇在发紫。"
陈胖没听见。他这会儿的表情，陆寻见过。跟他在食堂连吃三碗免费汤时一模一样，眼睛发直，腮帮子鼓着，明明已经撑到不行，还不肯放下勺子。
"够了够了！"陆寻脸色一变，伸手去拦，话音还没落——
咔嚓一声。护符表面那层顽固至极的封印壳，在他这个被嘲笑了多年的废天赋面前，整块裂开，顺着缝隙一片片剥落，露出底下暗金色的本体。屋里的空气静到了极点。陈胖还保持着吸第二口的姿势，嘴张着，没吸上第三口。他自己先愣了，抬手抹了把嘴，问了句谁都没想到的话：
"……完了吗？"
那些细如针尖的纹路，此刻在暗金色的基底上一条一条亮了起来。亮到一定程度，纹路竟从护符表面浮起，悬在空气里，拼成的字又扭来扭去重组了好几次，才终于落定：
【规则载体·创世者信息 · 归属：沈墨】
陆寻的呼吸顿了一拍。那行字并没有就此停止。有个声音借护符当留声机，落进他的意识。声线很平，隔着一层什么传过来的，可每个字落地时都带起一阵电流擦过皮肤的酥麻，从后颈一路麻到指尖。屋里的灯在这时候全灭了一瞬。一瞬而已，众人都没动。
"……如果你能看到这里，说明世界的根还在。我记得每一个被我看成'活物'的存在。他们的来处，他们的名字，他们最初被点燃时的那点火苗。这把钥匙连的是每一个NPC的出处。别丢了它。替我，把他们带回家。"
声音消失之后，护符表面的纹路安定下来，收敛成一枚温润的、暗金色的印记。陆寻站在原地，很久没有说话。他低头看着掌心的护符，又看看面前那些星星点点的残影。叶霜的，林姐的，还有成百上千个等在那里不肯散去的名字。他抬手，让护符与其中一团残影相触。那团几乎要散成碎光的残影猛地一颤，轮廓清晰了几分。
"看。"陆寻的声音压得极低，"这就是锚点。顺着它，每一处残影都能找到自己的出处，把出处接上，把缺的记忆填回来……他们不是死数据。"
"他们知道自己不是吗。"苏清然问。
"不知道。"
"那他们凭什么信。"
陆寻没答。他把护符又翻了一面，背面也有一层纹路，之前没注意到。
"少废话，快试！"陈胖在旁边嚷，"我嘴还咸着呢。"
陆寻没理他。他又试了一次。这次更稳，护符贴上去以后他没有立刻拿开。
"看这个。"他忽然说。
那团残影里，一个模糊的轮廓慢慢坐了起来。
"……叶霜？"苏清然的声音抬高了。
陆寻把手收回来。
"还不行。"他说，"刚才那一下只是把门推开了一条缝。"
"那要多久。"
"两天。"
"两天？"陈胖叫起来，"我这边嘴还是咸的。"
"那就多喝点水。"陆寻说。
他把护符收进贴着心口的暗袋，拍了拍。屋里先是安静，随即爆发出一阵压到极低的欢呼。赵擎一巴掌拍在陈胖后背上，把他拍得一个趔趄。
"好样的胖子！"
"疼疼疼！"陈胖揉着后背，"先说好，我这半层封印的灰都咽进去了，回头得让苏清然给我炖锅汤补补。这辈子的盐分，都交代在这破护符上了。"
苏清然没理他。她在看自己刚才挪过的那半寸灯。
"那半寸灯，"陈胖说，"你挪它干嘛。"
"看他脸。"
"看他脸你直说啊。"陈胖捂着脸，"我以为你要照我。"
"你脸上有光。"
"那是我油。"
陆寻看着陈胖那副没正经的模样，笑了。他想起高一那年，陈胖抢到最后一份鸡腿，掰成两半塞给他一半，说"你正长身体呢"；想起围杀之后，他爬过两道墙来陪自己喝酒。外面那些人对陈胖的看法从没变过。
"胖子。"
"啊？"
"你那天问，去哪儿找那把根。"
"嗯。"
陆寻把那枚暗金色的护符压在心口，看着他。陈胖愣了一瞬。然后他咧开嘴，笑得眼睛都弯成缝："嗨，我一直说嘛。天塌下来，我铁胃先垫两口。这不，连创世者的壳也顺手给垫了。"窗外，秩序之城的灯火一盏接一盏亮起来。陆寻把手按在心口。
"明天开始，"他说，"替他们把家点亮。"
