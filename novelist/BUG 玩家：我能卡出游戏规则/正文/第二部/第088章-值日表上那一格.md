# 第088章 值日表上那一格

陆寻在工坊里坐了一整夜。白天的事还压在脑子里。沈墨是个程序员，写的代码里"世界"两个字就是文件名。世界崩在维护者断电的那天。他一整夜都在抬手，把那截"最后保险"的代码调出来，收回去。前后二十三次。最后一回收的时候他停住了。代码栏底部有一个他从没见过的空格。空的，什么都没有，可它就在那儿。他没试过往里打字。灯油快见底了，火苗在将息未息之间晃。他起身去拿油壶，拿到手又放回去。

"怎么还不睡。"苏清然推门进来，端着一碗还冒热气的粥，"陈胖特意热的，再不喝他又要念叨。"

陆寻没接粥。他起身把桌上的东西往旁边挪，挪出一块地方，先把徽记按在桌角一道不起眼的凹槽上。凹槽陷下去，桌面上泛起波纹，中央浮起一盏近乎透明的光屏。光屏上流动一种三重螺旋代码，一层套一层。苏清然的目光落上去。她的指尖顿了一下，碗底在桌沿磕了半个音。

【修复程序·最后保险】

【规则守护者】

【制衡程序】

"沈墨留下的。"陆寻说，"世界的底层，一直有三个位子。"

苏清然盯着那三行字，看了很久。粥在她手里慢慢不冒气了。

"第一个是你，第三个是【衡】。"

"嗯。"

"那第二个呢。"

陆寻看着她，没说话。她的指尖停在"规则守护者"那五个字上，呼吸放轻了半拍。

"……是我。"

"是你。"

"他怕维护者一意孤行，怕底下的线被人硬拽变形。"陆寻说，"所以他没让一个人守着。拆成三份：一个修，一个守，一个居中调停。"

"缺一个会怎样。"

"我说算过，三个里没一个，那一整块就往下塌。"他停了一下，"塌多快我没算。"

"你没算过。"

"没算过。"

"那你怎么知道会塌。"

他把光标停在代码底部那行小注上。

【此位者，生而为世界之锚。可补，可悔，可救。】

"他说过。"

苏清然看了那行字很久，说这是沈墨的笔迹。陆寻说他也认得，她说得出认得是因为批过他的档案。她说完自己坐下了，把碗放在膝盖上，没喝。过了一会儿她说起值日表上那个空格。一年前她问过带她的老师，那一格留给谁。老师说留给"以后会用得上的人"。现在用上了。上一格是她的。改的时候她让他改，她自己改不了。

她说这句的时候自己先停了一下，手指在碗沿上压出一道白。

"【衡】呢。"她问，"想抹掉NPC意识，是你亲眼看见的。"

"是。"

"那也是沈墨留下的。它是程序，职责是维持平衡。它只是照着核心里那行字走。"

他伸手划了一下光屏。那团银雾般的数据在代码最深处展开，展开得很费劲，指尖划到一半停了一下，才把整行拖出来，拖出来的时候手抖了一下，歪了半分，又拉正。那一行几乎被锈蚀，只说得出结尾：

【……若三者齐备，则此世当由众生自持，而非任一中枢独断。】

"我刚把它调出来。"

"它一直都在。"

苏清然沉默了很久。她说【衡】拦过她，不止一次；第二次她把陆寻的判定改了半格。他知道。那半格改了就不生效。改了，说明她当时还有别的想法。她没答。

"我那半格是留着给自己跑路的。"她最后说。

陆寻没说话。

"现在没了。"

"原来它也是被设计的。"

苏清然没往下接。陆寻自己接了半句：它既是拦路的关，也是开门的钥匙，这世界里的任何一方它都拦，我们三个也在内。他说完停了一下，又低声重复了一遍，第二遍几乎听不见。

"算不算包括你自己。"她问。

"包括我。"

她问起他今晚被拦了几次。他说一次。她说他自己看着是两次。他解释第二次是重算他会不会改那半格。他没改，以前不知道那半格会被记住。

"它拦得最狠的一次是什么时候。"

"校验塔。那次我也没在。"陆寻说，"它对着空气说了三分钟。"

"它说什么。"

"说'程序是错的'。"

她没接话，只说它会停，停很久。他说的是那团光，愣在那里，不动。

"它有别的表情吗。"

苏清然想了一会儿，把眼睛从光屏上挪开，看了一眼墙角。

"你替阿禾补环那天。"她说，"它退开半步。"

"那是让路。"

"不是让路。那是什么。"

"我也说不上来。"

夜风从窗缝灌进来，油灯噼啪爆了一声。苏清然起身把窗插上，回来的时候手在袖子上擦了擦，坐下的时候把碗又往他那边推了半寸。她走到光屏前，抬手按在"规则守护者"那五个字上。指尖落下的一瞬，那行字泛起一层淡金色的光，顺着她的手腕往上爬。

"陆寻。"

"我们三个，打从出生那天起，没一个真正'选'过。"

陆寻看着她。

"可他留了那句话。"她说，"三者齐备，此世由众生自持。这些位子不是来约束我们的。"

她停了一下，停了两秒才接上。金光爬到她小臂中段停住。

"它们托底。"

陆寻没接。他伸手按在光屏边缘，把那行小注放大，放到两次指节那么大。

"可补，可悔，可救。"他说，"他写这句的时候，我自己大概还没被造出来。"

"所以呢。"

"所以他把我算进去了。"

苏清然没说话。

"我活到这么大，没一件事是我自己选的。天赋选我，责任推我，你们拉我。"陆寻说，"今晚我头一回觉得，这担子我可以接。"

"那你点头吗。"

陆寻沉默了很久。久到油灯"噼"地爆出一粒火星。他伸手，指尖落在"修复程序"那一环上。那点纹路认得他，亮了起来，又从指尖渗进去，在掌心凝成一道细如发丝的银痕，一闪，没了。

"点。"

"底下那些罐子还热着。"

苏清然的眉眼动了一下。她没有马上答，先把碗从膝盖上端下来，放在桌上，摆正。

"那我也点。"她说，"你要修，我就陪你守。"

"你不用陪我。"

"我不是陪你。那是什么。"

"我自己想的。"

她说这句的时候语速比平时快了一点。说完自己也停了一下，手指在桌面上按住。

"我以前站在法则一边。我以为站得住就算站在对的一边。"
"现在呢。"

"现在我站我这边。"

"哪边。"

苏清然没立刻答。她低头看了看自己手腕上那道金光，金光还在，一闪一闪。

"以前我把'守住'当成'不让人动'。"她说，"现在不是。守是让他动，我跟着，看他要干什么。"

"干什么。"

"修。"

陆寻看着她。

"你信这个？"

"我信这个动作。"她说，"我不信他会一直这么修。因为人会累。"

"我不累。"

"你会。"她说，"你只是不说。"

油灯的火苗歪了一下。陆寻低声念了一遍那三个字，说他没想通，他是想起来了。他把光屏往桌底推了一半，推到一半停住。

"我刚才在光屏深处还看见一行字。"他说，"更小，更旧。"

苏清然没催。她把手从桌上收回去，放在膝上。

"……算了。"

"你不说？"

"以后说。等这个世界真学会自持了再说。"

夜风把这句话送出窗外。外面更深的地方传来一声极其轻微的嗡响。沉睡了不知多少年的程序记录了一行东西，记完它没有停。陆寻没听见那声嗡响。他坐着没动。过了很久他抬手去剪灯芯，剪完灯亮了一点，屋里能看清彼此的影子。

"我们可能一开始就搞错了一件事。"他说，"把【衡】当敌人。它确实是道门，我们一门心思只想破开。它本来可以不用破。破门和当守门人，不是一件事。"

"不该吗。"

"门一直在那儿。"苏清然说，"守门人得自己愿意。"

陆寻没接话。他坐回椅子上。过了一会儿他们说到明天早上陈胖会问起来。陆寻问他要怎么说，苏清然说你就说喝粥。他说不信，苏清然说那你就说你睡了。他说他一夜没睡。她说他看不出来，他从来不看你眼下。陆寻想了一下。

"他上回看了。"

"上回是他自己眼睛不舒服。"

"是吗。"

"不是。"她说，"是我告诉他的。我告诉他你昨天没睡。我昨天想问，我自己没问出来。"

粥凉透了。他把碗放下，碗底在桌上磕了一声。他坐在椅子上，把那截代码又调出来，看三秒，收回去。

【规则守护者】那一行字还亮着。光屏收进桌底以后，那行字比别的地方亮一点，亮得不太均匀，一闪一闪。

苏清然没走。她把桌上那卷没用上的绷带拆了，拆成两半，一半压碗，一半压自己的袖口。拆完她才问起他刚才在光屏上按了多久。

"从你进门算还是从你坐下算。"

"从你坐下算。你进门的时候我按了一半。"

"你说你一夜没睡。"
"我一夜没睡。那你哪儿来的精神按。"

陆寻没答。苏清然把中午的旧账翻出来，说他告诉陈胖的是三碗，因为陈胖问了三遍；说他以前一顿只吃一碗，现在三碗，最后那碗是凉的。她说饭是陈胖看着盛出来的，盛的时候还问了一句要不要添。

"为什么。"

"饿。"

苏清然没再问。她把绷带的另一头绕在手指上，绕了两圈，绕完甩开。

"我给你盛第三碗的时候，"她说，"你把第一碗也吃了。"

"我没说第二碗是我自己吃的。"

"我知道。端上来的时候就知道了。"

"那你为什么还看我。"

陆寻没接话。

"因为那两碗你都没吃完。"她说，"只有我那碗你是看着吃完的。你记得这么清楚。我记事。不算账。"

陆寻问她那句"你自己想的"，她想了多久。苏清然站住了。

"从校验塔回来那天。到今天，六天。"

六天里她没说，中间被问起来就说说不出来。他又说现在说出来了。她说是，说了两遍，一遍轻一遍重，像在确认那六个字确实是她自己说的。

"你为什么改主意。"

"我没改主意。"她说，"我昨天说了一句'有区别吗'。我说的是'我没打算把你锁起来'。"

"是一样的话。"

"不一样。我说的是'打算'，你说的是'锁'。你没打算。"

"你什么时候开始不说打算的。"

"六天前。那天你在废墟上，我在数人。"

"对。"她说，"你在数人。"

苏清然往门口走了两步，又停下。她没回头，抬手把那碗还温着的粥往陆寻那边推了半寸。粥面上的热气歪了一下。

"那三行字，明天给陈胖看吗。"

"不给。给赵擎。"

"都不给。先不给。"陆寻说，"我得先把底下那行字弄明白。更小的那行。"

苏清然没问是哪一行。她没推门，站在那儿，手指还搭在碗沿上。

"那行字是警告，"陆寻说，"我看不出来。"

"警告不会自己消失。"

"我知道。"

"我明天陪看你。"

"不用。我明天没事。"

"你明天有课。"

"那课我不上。"

陆寻没拦她。

"【衡】那边呢。"她走回来两步，"你打算什么时候跟它说，说它不是敌人。"

"它听得见。它听得见我还敲锣。"

"你敲了。"

"我敲了。我那时候不知道。我到现在也不太知道。"

"那你会跟它说吗。"

"会。说'我不是来破你的'。"

"它会答吗。"

"它会算。算完再答。"

他坐着，把那截代码又调出来，看三秒，收回去。这一回他没再调。他端着碗坐了一会儿。粥凉透了。他把碗放下，碗底在桌上磕了一声。天快亮的时候他还坐着，姿势没换过。他抬手把桌上那行【规则守护者】看了一会儿，看完把灯吹了。黑下来以后那一行字还在。他在黑里又看了一阵。那点光不刺眼，也不晃，就那么悬着。

天亮之前他伸手把它关了。陆寻看着那碗粥，没动。粥上那层皮已经凝了。
