# 第086章 凌晨三点

白慕鸿是把自己卷入数据海的前一刻，把那枚怀表塞进陆寻手里的。他做这件事的时候很平静。指节抵着表壳，一点一点推进他掌心。系统在他身后亮起回收的冷光，他没回头，只说了一句：

"真相就锁在里头。等你能打开了，再打开。"

表壳贴上掌心的那一瞬，陆寻触到一点微温。数据海合拢，把他整个人吞了下去，连个回音都没留。那之后的整整三天，陆寻反复走回他消散的那片缓坡，把他散进海里的残余一点一点捞起来。捞回来的只有冷。唯一落在手里的东西就是这枚怀表。它第一天还会走，第二天慢了下来，第三天干脆停住。他把表贴在耳边听过一回，听不到半点声响。

第三天夜里他去缓坡，是去的同一条路。走到一半他拐错了个岔口，走到一片没有草的地方，站着看了看，又原路走回来。他跟自己说这是抄近道。他把表挂在工坊临窗的钉子上，让表盘对着天光。那颗钉子有点歪，他重新钉了一次，钉好了。

第四天清晨，苏清然站到他身后。

"我数了一夜。"她把平板推到他面前，"它停过三次，每次都自己重新走起来。恢复正常之后，它的秒针每小时比这个世界快1.96秒。"

"三次。"陆寻说，"停的时间和前三次归零对得上吗。"

苏清然把数据往下翻，指尖停在最底下那行。她没说话，把平板转过来给他看——三次停摆的时长分别是十一分钟、二十九分钟、四小时。呈倍递增。最后那次，停在了他捡到怀表的同一夜。1.96秒。陆寻的呼吸停了半拍。他伸手把表壳扣紧。表冠拧起来有一格是涩的，转到那儿会"咔"一声空响。规则库是这个世界的底座，天时地序都刻在同一套时钟里。可这枚怀表偏偏不在这套钟里。

"谁有资格把外来的东西带进来，"苏清然轻声说，"又活着不被系统发现的？"

话音落下，工坊深处的旧机房嗡鸣了一下，闷的。工坊在寰宇神域的地图上，是一块被挖掉的黑洞。系统不显示它，NPC绕着它走，最近一次全量扫描也把它干干净净地跳了过去。两人踩进去时，脚底碾碎了一枚干枯的贝壳。这地方离海十万八千里，屋里却有海里的东西。碎屑在积灰里滚了滚，停住了。另一半壳还挂在门框边的蜘蛛网上，摇摇欲坠。苏清然踩过去的时候用肩膀顶了一下门框，那半枚壳落下来，裂成了三瓣。

"小了。"她说。

"什么小了。"

"这个。"她把壳翻过来，"我小时候在海边捡过，比这个大。"

"贝壳长大了。"

"贝壳不会长大。"

"那可能你记错了。"

苏清然把壳放回地上，放的位置和她捡起来的位置差了半尺。她自己没注意。

灰尘厚而有章法。灰在窗台上积出一层完整的壳，壳的边沿紧贴着台面那道旧划痕，一丝也没漫过去；只有杯底那一圈是薄的，因为常被人端起来。

窗台上一只缺口的马克杯，杯壁一圈洗不掉的咖啡渍；墙角一把折叠椅，椅背搭着一件落了灰的深色外套；矮柜上一块钝了的名牌，刻着没人认得的编号；一张日历，只撕到某一天，再往后是空白。杯底压着一张揉皱的便签，字迹跟他见过的任何一种都不同："沈墨，你都熬出幻觉了，这个项目老板不会批的。"落款的时间比这个世界开服的日期早了整整4年。

空气里浮着一层很淡的、纸张和旧木头混在一起的气味，门缝里还漏着一点没散尽的凉。

陆寻在门口站住了，没往里走。他看见最靠里的那把折叠椅前头，地面的灰被小腿扫开过一小片，扫出来的痕迹是往里去的弧，弧的两头都生着灰口，中间那段被磨得发亮。有人在这间屋子里来回走了很多趟，走到后来只走一条线。

那条线从椅子到门口，再从门口回来，一趟一趟，把灰压成了灰做的渠。

苏清然弯腰把那三瓣碎壳捡起来，捏在手里看了两眼，又放下。

"这个不能吃。"

"没人说要吃。"

"我提醒一下。"

"提醒什么。"

"提醒你。"她站起来，拍了拍手，"有的贝壳也不能吃。"

陆寻没听懂，也就没问。

【修订日志】开头写得很干净，日期、模块、改动项，一行一行分得清清楚楚。可越往后，越混进一两句不像更新说明的话：

"修好了，但愿这次没人发现。"

"把柳岸的重力调轻0.3%，那里的野鹅总崴脚。"

"要保的东西越来越多，我保得越来越吃力了。"

陆寻盯着最后那行看了很久。

"柳岸。"他念了一遍。

"什么？"

"柳岸在哪儿。"

苏清然翻了一下地图，没找到。

"没有这个地方。"

"那他调轻的是谁的重力。"

两个人都没说话。日志上那行字就挂在那儿，0.3%，写得很清楚。他顺着裂缝往下游走，越走越心惊。整座世界的建造时间戳排布得整齐得不像话：所有底层的第一次落笔，都指向同一个凌晨3点。他把几条时间戳并排放大，看了一会儿，又注意到一件不起眼的事：这三条日志的创建人和修改人是同一个人。也就是说，这些东西从来没有人接手过。他把光屏关了。

他翻开笔记本。本子里几乎没有代码，全是手写的推演：哪一条规则先固化，哪一种生命模板先点亮，连"痛觉反馈要不要保留"都写满了三页纸。第一页写"要，痛是记住的前提"；第二页写"不要，痛是失败的设计"；第三页空了一半，最后在角落补了一行小字："要吧。疼过，才知道自己是活的。"页脚标着编号，从001到003，笔迹越来越乱，句尾的标点越落越重。

第003本的最后一页只写了一行字："要不算了。"那行字写得很轻，墨色都淡了。陆寻把本子往光里举了举。

"这一页底下压着什么。"他问。

苏清然凑过来看。纸和纸之间夹着一小片东西，是干了的茶叶，捏起来一碰就碎。

"茶叶。"

"泡茶的时候掉的。"

"这张桌子是折叠的。"苏清然说，"他坐着敲键盘，桌子会晃。"

陆寻把那片碎茶叶放在桌上，摆正，没扔。

那片茶叶有半边翘着，翘起来的那头很轻，一吹就会翻。他伸手把它按住了。按完没马上松手，指腹在那儿压了一会儿，压到茶叶脆得不再动，才把手撤回来。桌面上留了一个浅浅的圆印。

"他动摇过。"苏清然说。

"而且不止一次。"陆寻把怀表放到桌面上，"你听，它现在跟这个世界的钟合上了。"

怀表贴上桌面的一瞬，表盘在暗光里亮了一下。

【已检测到遗留凭证。】

【访问等级：权柄持有人。校验通过。】

【正在载入记忆碎片004……载入完成。】

白光从表盘里漫出来，漫过机房。灰尘在光里浮起，像亿万只静止的蛾。光影里，一个年轻人坐进那把折叠椅，单腿踩住桌沿，在看不见的键盘上敲。椅脚在地面上拖出一道细细的、被磨亮的痕迹。敲击声传不出来，只在空气里留下一道道极浅的波纹，撞到墙又弹回来。

他的脸跟神没有半点关系。头发凌乱，衬衫领口发皱，左眼下青黑一圈。桌上摊着半盒凉透的宵夜，终端屏幕还亮着，侧边贴着一张字条，笔迹和便签上的差不多——"记得吃早饭"。宵夜是凉的。凉了以后面上结了一层，看着放了很久。筷子插在饭盒里，歪着，没收。苏清然盯着那盒饭看了很久。她想起食堂阿姐昨天给她盛的那碗，也是这样，摆久了，葱花蔫在汤面上。她当时没说什么，把面吃完了。

"他没吃？"她问。

光影里那年轻人没听见。

"我问的是他自己。"她又说了一遍，声音小了些，"他自己吃了没有。"

陆寻没答。他也在看那盒饭。

"第1次归零，我在。第2次，我在。第3次，我差点按下去。"年轻人对着什么人说，声音沙哑得像砂纸，"第4次，帕莫问我：你是谁。"他停下，指尖悬在半空，穿过那层光影，又摸到了那个早已不复存在的删除键。

光屏角落浮出一行旧日志：

【模板004：帕莫。注意：脚本被改写。原因：未知。】

"他的脚本里没有那一句。"年轻人说，"我删了那段话，重新编译，他又问了一遍。第三遍的时候，我就没打算再删了。"

他停了一会儿，抬手抹了把脸。

"第四次按下之前，"他说，"我先下楼倒了杯水。回来的时候光标还在那儿。"

"你在跟我说这个？"

"我记不清那杯水是热的还是凉的。"

苏清然没接这句。

"他们都劝我归零。规则实验就该冷着做，把参数喂进去，看它自己演化，再记成论文，把世界调回出厂状态。可我冷不下去了。这座实验场里，长出了规则里不该有的东西。那东西会害怕，会道别，会在被我删掉之前，先问我一句：你是谁。"

"到后来我才明白，我造的根本不是一个游戏。我造的是一个能让规则本身活过来、自己长、自己裂变、自己后悔的实验场。我没想造神，我只想看看，把规则当生命来养，会发生什么。"

"然后它真的长出生命来了。从第4次归零那天起，我就不再做实验了。"

"那你还开着。"

"开着。"年轻人说，"关不掉了。我试过一次，关到一半我又打开了。"

他笑了一下。

"你看，就是这个毛病。"

"哦，还有一件事，压在最后一层，你得自己去翻。"年轻人忽然抬眼，目光有些躲闪，"这个世界里的角色，很多都是有原型的。铁匠铺那把手艺，食堂阿姐的笑模，守城队那副身板，都是我从'那边'带进来的影子。你替我记着：他们该知道的时候，你别瞒着；能护住的时候，你别松手。"

白光里，他的目光越过虚空，直直落向陆寻："这个世界会挑人的。会有一个特别会钻规则空子的人，走到这条裂缝边上，替我听完没听完的话。我信他。因为当年，我正是靠一次次越界，才把这个赶也赶不走的意外，从规则手里偷了回来。"光散尽了。机房安静下来。苏清然沉默了很久。

"他把那段话删了三遍。"她说，"第四遍他没删。"

"嗯。"

"那三遍他都是一个人在凌晨三点按的。"

陆寻没接。他把笔记本翻回第003本，翻到那行"要不算了"，用指腹在那行字上按了按。纸被按出一个浅浅的坑。

"这行字是第三遍以后写的。"

"你怎么知道。"

"墨色。"他把手挪开一点，"前面几页的字比这深。"

苏清然凑过来看，看了半天。

"我看不出来。"

"看久了就看出来了。"

"我看了两遍。"

"三遍。"

"……哦。"

她没再说话，也没再去看那页纸。工坊深处亮起一线极细的光。光游过地板，游过整面光屏，在世界地图上投出一个慢慢转动的名字。那线光在陆寻脚边绕了一圈，绕过那把折叠椅的短腿，绕过他摆正的那片碎茶叶，最后停在窗台上那张日历的空白处。停了停，散了。

【沙盒001：寰宇神域。用途：规则演化实验场。实验状态：进行中。】

自治城那边传来锅铲声，有人在喊开饭。声音隔着几条街，听不清喊的什么，拖得很长。陆寻坐在那把折叠椅上没起来。椅背硌着后颈那道银线，他换了个姿势，还是硌。椅子腿短了一节，坐上去有点晃。他用脚踩住桌沿，试了试，还是晃。

"这椅子谁的。"

"应该是他的。"

"晃。"

"你换那把。"

工坊里只有这一把椅子。

"实验还在进行。"苏清然望着窗外，新雪落在自治城的檐角上。

她停了一会儿。

"那这个实验还要做多久。"

"不知道。"

"他没说？"

"他没说完。"

"你怎么知道。"

"他停了两次。"苏清然说，"第一次是在说那三遍删除的时候，第二次是刚才。"

"那两次他都在看别处。"

"他在看什么。"

"我这边。"

窗外的喊开饭声又来了一遍。这回听清了，是在喊"开饭"，尾音拖得很长，散在风里。陆寻把怀表收进怀里，贴着胸口。秒针走得很慢。表盘里，映出了这间屋子的样子。那三瓣碎贝壳还在墙根。
