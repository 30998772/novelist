# 第021章 冻结全世界

倒计时最后一小时，陆寻上线了。

他直接出现在中央擂台，三天前赵擎跪着的地方。全服蹲守的主播疯了一样涌向岚风城广场，直播间人数以史无前例的速度突破五千万。

有老玩家翻出三天前的直播截图对比，连地面的裂缝位置都一样。

"来了来了来了！！"
"最后一小时！BUG哥最后的高光！"
"五千万了！平台服务器在冒烟！"
"快看天穹的人！全员到齐啊这是"
"等等，他们怎么不动手？就围着？"
"动手？还用得着动手吗？倒计时归零系统自己会收拾他！"

天穹全员倾巢而出，白慕鸿亲自带队，将擂台围得水泄不通。这一次他们不需要动手，只需要等倒计时归零，看系统把这个人"修正"掉。

"NULL。"白慕鸿的声音响彻广场，"何必呢？一小时后一切都会结束。"

"是啊。"陆寻站在擂台中央，抬起手，"所以赶在这之前——"

广场上的哄笑声小了些。

有人察觉到不对劲了。这个人太镇定了。一个即将被世界抹除的人，不应该有这种眼神。

"我想先还你们一笔账。"

广场安静了两秒，随即哄笑四起。

"还账？"天穹的人群里有人嗤笑，"一个死人还什么账？"

笑声不大，却很整齐。

只有白慕鸿没有笑。他的手，已经按在了剑柄上。

【全域修正倒计时：00:41:17】

四十分钟，两千四百六十秒。

对天穹是等待处刑的煎熬，对观众是吃瓜的黄金时段。对某个人来说，这是最后一段可以自由呼吸的规则空气。

他深吸一口气，擦掉鼻血。擦完低头看了一眼手背，血把袖口染湿了一小块。他把袖子往上撸了一截，闭上了眼。

人群边缘，苏清然没有往前挤。她隔着整圈人海看着那个擦鼻血的身影，嘴唇动了动，没出声。

她的指尖在袖口里按住一枚纽扣大的符石。这是两人提前商量好的配合：一旦他的意识在下潜里散掉、拽不回来，她就在外面捏碎这颗石头，用"秩序回响"把他从深海边缘捞回来。

符石被她捏出了一道浅印。她把拇指挪开一点，换了个地方捏。

他在擂台上坐下来，腿一盘，像在教室后排等老师点名的样子。天穹的人往前压了一步，看见他坐下，又都停住了。

四十分钟。他要在这四十分钟里，做一件人类玩家从未做过的事。

计划很简单：把真空叠加到覆盖整座城市，冻结所有系统进程。在那段绝对静止的时间里，他还账、翻底牌、看清这个世界的真面目。

三秒。他只需要三秒。

为什么是三秒？

清单第137页写着他全部的计算：全域修正程序的装载窗口是0.7秒；规则域重写的临界震荡持续1.2秒；而人类意识从"看见"到"理解"需要0.5秒。

三个数字相加，再留出0.6秒的余量。

至于那件事是什么：

全世界只有一个人知道。

陆寻闭上眼。

广场上五千万人屏住呼吸。天穹的包围圈往前压了半步。

擂台的石缝里有几粒沙，被风推着挪了半寸，挪到缝口卡住，就卡在那儿。

倒计时的数字在每个人的视野角落跳动：00:11:59，00:11:58……

这十一分钟里，大部分人什么都没做。有人把手机举高拍屏，有人蹲下来系鞋带，系完了又站起来。天穹的队伍往前挪了两步，挪完就不动了。有个小孩被挤哭了，哭到一半就没人理他，他自己也不哭了。

十一分钟就这么过去。

没人知道，这将是这个世界的规则最后一次完整运转的十一分钟。

意识下沉、下沉、再下沉，越过面板，越过技能层，潜入这个世界的规则底层。

下沉到一半的时候，什么也没发生。黑暗里没有声音，也没有上下。有一条线擦着他的手背飘过去，他没去抓；还有一条在他眼前停了很久，最后自己走了。

十米，光线消失，玩家的世界沉在头顶变成一片模糊的亮斑。百米，精神负荷开始挤压思维。千米，绝对的黑暗里只剩下那些线，亿万条流动的线。

无数条纵横交错的线：等级的线、伤害的线、判定的线。每一条线上，都有他能撕开的洞。

一条街道的"存在"需要上万条规则共同维持：石板的硬度、光照的角度、行人的碰撞体积、声音的传播衰减。

以前他一次只能撕一个。

那四十八小时里，他把叠加练到了极致。精神负荷顶到极限的时候，他发现了一件事：

叠加层数没有上限。上限只是他的精神力。

发现这件事是在第三十九个小时。那天他躺在黑暗里，叠加失败，躺着没动，就在想：为什么会有上限。

想来想去，天赋那一栏从来没变过。变的只有他自己还剩多少。

而现在，他要把成千上万个"洞"，同时撕开在整座城市的规则之上。

【全域修正倒计时：00:12:00】

十二分钟。

陆寻睁开双眼，瞳孔深处有金色的数据流一闪而过。

开始。

没有惊天动地的起手式。

他只是把四十八小时练出的东西，一次性铺开。

第一千个洞出现在城东的居民区。第一万个洞爬满了中央大道。数量过十万的时候，整座城市的规则结构开始出现细密的震颤。

鼻血已经流到了下巴，一滴一滴砸在擂台的石板上。血在石头上摊开，被广场上那层浮尘黏住，颜色发黑。

视野里的世界在褪色，听觉在消失，他靠着一个念头钉在原地：

再撑一下。就一下。

十万条判定在同一瞬间被悬置。他的鼻血喷涌而出，意识的海岸线被潮水彻底淹没，他在窒息的最深处死死撑住。

负荷早已突破理论极限。

按照他自己记录的数据，超过一万两千层的叠加会导致意识解体。而现在是十万层。

他脑子里反复滚过一个画面：新手村外那块老石头，陈胖红着的眼睛。苏清然掐进掌心的指甲。还有那个追皮球的孩子被母亲捂住的"眼睛"。

他没想过自己撑不撑得住。

有半分钟，他什么也没做。真的什么也没做。规则线在身侧一根一根地流过去，他让它们流。那半分钟他不在任何地方，卡在两个地方中间，脑子里空着，只听见自己的心跳，一下，又一下。

五千万观众看见的是：

岚风城的天，忽然静止了。飞艇停在半空，旗帜僵在风里，NPC的吆喝声卡在一个音节上。

铁匠的锤子悬落一半，火星凝固在空气里。酒馆门口，说书人的折扇停在展开的瞬间。

卖花的妇人举着花的手臂还举着。她等的那个人正从街那头走来，走得很慢，一步一步，也停了。

满城玩家的技能栏、血条、buff图标，全部变成了灰色。

没有黑屏，没有卡顿，也没有任何系统崩溃的征兆。色彩还在，声音没了。

一枚抛向空中的金币凝在半空，币面上的反光定格住了。那金币是人群里某个玩家抛的，他本来想用它表达对NULL的嘲讽。

酒馆二楼，一个正单膝跪地向女友求婚的玩家跪到一半，戒指盒停在半空。

广场角那个卖糖画的老人NPC，勺子悬在糖浆将滴未滴的一刻。一滴蜜在空气里拉出细长透明的丝。

广场喷泉的水珠悬在半空。一只鸽子保持着展翅的姿势钉在空中，羽毛上的水汽凝成细小的霜粒。

白慕鸿拔剑的动作停在一半，剑刃出鞘七寸。

而擂台中央，陆寻还站着。全世界的静止画面里，只有他是动的。

五千万人的直播间里，弹幕也停了。没人想发。所有进程都被冻结了，包括他们手里的终端。

转播席上，无数主播的麦克风张着，半天发不出一个字。有个主播把水杯举到嘴边，举着没喝。

除了一个方向：岚风城地下九层，那片数据海域依然在黑暗中奔涌。

消息是随着那三秒的解冻才炸开的。

全球玩家的论坛挤到几乎瘫痪：

「我的角色不动了！我在岚风城！隔着屏幕都能看见那条线上的杠！」

「被冻住的偏偏只有那么一座城、那么一瞬间，谁在吹牛」

「回看了八遍录屏，不是卡顿。卡顿的人眼睛会眨，这些一个都没眨」

「我这边一帧一帧拉的，那个卖糖画的，糖拉了多长一根丝，你们自己看截图」

「我室友说主播在他面前挥手，挥了十几秒才放下来，他还笑主播演得不像」

「有个傻子在广场上给鸽子喂面包，鸽子停了，面包还捏在他手里」

三秒钟后一切恢复。

这三秒后来被整个游戏圈称为"神域静止事件"。

【全域广播·最高权限·紧急插播】
【警告！检测到大规模规则悬置！】
【范围：岚风城全区。】
【状态：所有系统进程挂起。】
【预计恢复：无法计算。】

九亿玩家看着这行字，脊背发凉。

地下九层，【衡】的核心警报响成一片。

`【紧急事件：全域规则进程被外部挂起。】`
`【影响：岚风城 4,712,393 名在线玩家，全部系统功能失效。】`
`【原因分析中……】`
`【原因：目标将 0.01 秒真空叠加至 1,048,576 层，覆盖城市级规则域。】`

1048576。

二进制的2的20次方。

【衡】反复核对了十七遍这个数值，每一遍都得出同样的结论：这不是失控的暴走，是一次瞄准过的操作。

`【……百万层。】`
`【重新评估：目标不是僭越者。】`
`【目标是——】`

评估结论卡在这里。固件给出的选项有三个：僭越者、漏洞、病毒。三个都不对。它得造一个新词条才能归档。而它造好这个词之前，三秒已经到了。

对悬停在世界底层的陆寻来说，这三秒被拉得很长。第一件事，看清全域修正程序的装载路径。第二件事，在修正程序的核心逻辑里，留下自己的标记。第三件，去见一个"东西"。

三秒结束。

世界重新运转。金币落地，鸽子飞走，喷泉的水珠碎成一片水雾。

有一个小孩被挤醒了，哇地哭出来。他旁边的人正在哭另一个。谁也没空管他。

陆寻站在擂台上，鼻血顺着下巴往下滴。他看着恢复喧嚣的广场，看着那些重新动弹的人。他们尖叫、欢呼、抱在一起发抖。

他脑子里冒出来的第一句话是：判定恢复，物理引擎重启，NPC行为树重新加载。

然后他抬起头，看见了那枚金币。

它正从半空往下掉。慢。三秒的静止给它留下了额外的重量，现在它每落一寸都要走完整个世界的物理流程。

他伸出手去接。

手伸到一半就停住了。他自己也不知道为什么伸那一下。

金币落在石板上，弹了两下，骨碌碌滚进人群的脚缝里。抛币那人正搂着同伴的肩膀喊什么，压根没看它一眼。

陆寻的手指还举在半空。他没收。

苏清然挤过人群走到擂台边，抬头看他。

她没问他刚才做了什么。她脱下披风，绕上他的肩。

"先下来。"她说。

陆寻没有动。他低头看着自己搭在披风上的手。

刚才那三秒里有四百万人被按停在原地，其中多少人替他挨了那三秒，他算得出来。

数字算得出来。
