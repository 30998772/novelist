# 番茄版拆章说明

## 一句话
`拆章工具.py` 把 `正文/` 的 153 章 × 3320 字，按段落边界切成 **306 章 × 1664 字**，
符合番茄 1500-2000 字/章的建议。

**项目里只保留 `正文/` 一个版本。** 需要番茄版时执行 `python3 拆章工具.py` 现生成：

```
python3 拆章工具.py      # 生成正文_番茄版/（306 章）
```

工具**完全幂等**，脚本内已嵌入 153 条手工标题，重跑结果逐字节一致。

## 怎么用
| 平台 | 用哪版 | 说明 |
|---|---|---|
| 起点 | `正文/` | 3320 字/章，起点偏能吃长章，且标题是完整的手工标题 |
| 番茄 / 七猫 / 飞卢 | 先跑 `python3 拆章工具.py` | 306 章，均 1664 字，落在建议区间 |

原稿全在，不用重做。

## 切分规则
不是按字数硬砍，是**按段落边界切**：
1. 优先落在「空行后的第一个非对白叙述段」开头——也就是场景转折处
2. 次选任何段落边界上最接近对半分的位置
3. 目标半章 1550 字，容许区间 1250-2100

**306 章的下半段没有一章是以对白或面板开头的**（0/153），说明没有把对话从中间劈开。

## 标题
前半段沿用原题的 `（上）`，后半段 153 章**逐章手工起名**。

### 为什么不用自动提取
第一版想从正文首段自动提取 2-5 字短语，产出全是垃圾：

> 差异藏在 / 白慕鸿瞳 / 对不起我 / 陆寻把三 / 苏清然盯 / 赵擎低头看 / 她笑了他看

这些是从句和被切碎的词组，不是标题。**结论：能用规则算出来的东西不要假装能自动生成；中文短标题只能靠读懂那一段再起。**

### 实际做法
读完每章下半段的前 5 段，提取该段真正的落点——**具体物件、有来历的数字、人物说出的一句笨话、一个反常动作**。三类都用了：

| 类型 | 例 |
|---|---|
| 物件/痕迹 | 终端黑屏、凶手那栏、磨白的扶手、抠屏幕的人、那把扳手 |
| 具体数字 | 执裁十五年、五十五万、三千四百二十七、四十一秒、第七只空匣 |
| 人物原话 | 我不值、我不计算（→我是撞出来的）、真他娘的咸、随便问 |
| 反常动作 | 蹲麻了、没走近、折了三次、平票、没踩那道缝 |

后半章标题**不使用「（下）」**，全部独立。全书 306 个标题零重复。

### 重复消解
初稿有两组撞名，各改一个：
- 「最后保险」×2 → 066 **留下的那段**（沈墨留保险）/ 194 **挂上了名字**（仲裁者宣布协议）
- 「规则对话」×2 → 072 **意识注入**（首次注入触发）/ 108 **坐下来**（对话比感知难在哪）

另修一处笔误：300 **四个十一秒** → **四十一秒**（正文是「你举着它四十一秒的时候」）。
