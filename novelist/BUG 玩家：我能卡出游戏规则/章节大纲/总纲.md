# 《BUG 玩家：我能卡出游戏规则》全书总纲

一句话：全民全息游戏时代，少年抽到全服唯一的"废稿"天赋，却发现它能卡掉游戏的一切规则——别人在规则里玩，他把规则当玩具。

## 核心主题

**主题句**：规则是工具，不是信仰。记住你是一个人。

**主题阐释**：
- 规则之上，是"人"。没有规则的"人"是混乱，没有"人"的规则是压迫。
- 特例不是天赋，是选择。所谓特例，就是规则为自己保留的一点例外——而"例外"，是"人"。
- 守护世界，不是靠超能力，而是靠"人"的意志。

**主题发展弧线**：
| 部 | 主题阶段 | 核心问题 |
|----|----------|----------|
| 第一部 | 规则是什么？ | 规则可以被打破吗？ |
| 第二部 | 打破规则的代价 | 打破规则后，我们还是"人"吗？ |
| 第三部 | 规则之上是什么？ | 守护世界，是否必须牺牲"人"？ |
| 第四部 | 没有规则，如何守护？ | 普通人也能守护世界吗？ |

## 核心逻辑
规则压制 → 众人嘲讽 → 判定锁死 → 触发真空 → 破格反杀 → 埋新伏笔。

## 关键设定存档

- **特例单位编号体系（全书统一，两套编号互不相同）**：
  - **传承序列（织律者/特例单位传承）**：001林渊、002楚瑶、003周铮、004沈墨（=创世者）、005佚名、006叶霜（=当世NPC叶霜乃006的当代觉醒，同一存在）。**第七位（064空匣）由陆寻承接**。
  - **系统NULL编号（当世登记）**：NULL-01 = 陆寻（全域唯一特例单位，第一部024定ID为NULL）；NULL-02 = 白慕鸿（第二位特例单位，天赋规则复制，081揭示）。
  - **白慕鸿无"候选007"号**：他仅作为落选/退选者目睹过005佚名终考（080），与传承序列第七位无关。
- 天赋触发：意念锁定目标判定瞬间 → 0.01 秒规则真空（该判定悬置失效）。
- 真空不能造伤害，只能让"判定失效"；伤害靠操作与普攻。
- 叠加层数越高精神负荷越大；冻结全城 3 秒是当前极限（021）。
- **能力终点**：Lv7「规则补天者」是最终等级。130章"补天"后陆寻永久失去能力，此后不再升级，第四部以普通人身份行动。
- **Lv4规则编写限制：编写的新规则必须有载体（武器/道具/媒介/特定空间锚点），不能凭空生效。载体品质决定规则持续时间和作用范围。**
- 【衡】的格式化台词风格：【警告。】【记录。】【校准协议·启动。】
- **灰色光点本质**：创世者残留权限衰变时产生的"疤痕组织"——世界的自我保护机制。它们没有意识，但会本能地抵抗修复行为。不是外部敌人，而是世界老化的自然现象。
