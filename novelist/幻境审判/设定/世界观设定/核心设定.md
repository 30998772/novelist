# 幻境审判 核心设定（三层标注版）

> 本文件按三层结构分写：**认知层**（角色/一刷读者相信的）、**真相层**（二刷读者发现的）、**自白层**（三刷读者解码的）。
> 写作时正文只呈现认知层；真相层靠漏风；自白层靠名称学与结构暗示。任何一处"跨层直给"，都是漏风。

---

## 一、世界观概述
### 认知层
幻境是独立于现实的异空间，在特定条件下降临于封闭场所。它不受物理法则约束，以参与者的记忆、情感与罪孽为素材，构建审判场景。幻境的本质是"人心镜照"——它不制造恐惧，只放大恐惧；不虚构罪行，只重现真相。

### 真相层
幻境并非"外部力量降临"，而是林昭远潜意识构建的审判场。它以林昭远的记忆为唯一素材，把一个人的十七种罪孽，伪装成十七个人的群像审判。所有规则的制定者与执行者，都是同一个设计者——林昭远的良知。

### 自白层
全书 = 林昭远苏醒后、出书前，将自己昏迷三分钟内的幻境经历写成的手记。幻境、笔记本、读者手中的书，三者同一。读者拿到的每个审判场景，都是自白书的一个章节。

## 二、降临机制
### 认知层
| 要素 | 说明 |
|------|------|
| 触发条件 | 封闭空间内存在"共业纠缠"（多人因同一事件/同一链条产生因果纠葛） |
| 降临标志 | 所有电子钟同时定格23:59且不跳动；门窗自动封闭；手机信号归零 |
| 持续时间 | 以审判完所有"核心参与者"为终点 |
| 脱离方式 | 完成审判（轻度：记忆整合后苏醒；重度：死亡后意识消散） |

### 真相层
- "共业纠缠" = 林昭远一人的多面愧疚聚在不散的因果里。
- 降临的瞬间 = 林昭远昏迷的瞬间（当天16:44倒下、16:47苏醒）。所谓"审判全程"，耗时仅三分钟。
- "所有人被审判完" = 林昭远逐一承认自己的每一面人格。认完即醒。

### 自白层
"23:59"是自白书扉页标下的时刻——不是作者醒来时的现实时刻，而是他给自己审判设定的"开场钟"。时间倒序＝自白书回读自己的罪史。最后一章标题"00:00"是**罪的零点（象征），非物理午夜**——0与∞同源，罪的起点也是书的起点；现实侧的时间刻度是16:44→16:47。

## 三、空间规则
### 认知层
- 主场景固定：枫城第七中学
- 每个参与者进入独立"审判间"
- 走廊公告栏实时更新每个人的审判状态
- 每晚零点，未完成者被拖入"联合幻境"

### 真相层
- 七个空间全在同一个意识子宫里：教学楼=人格、操场=记忆、旧图书馆=良知、浴室=罪。
- 公告栏 = 林昭远笔记本的"目录页"——每一条状态都是他某一面人格的存亡记录。
- "联合幻境" = 所有投影在同一场庭审里同时受审（013章庭审文体）。

### 自白层
空间的数量与形状暗示人格的数量。读者若数清每个场景，就能数出林昭远承认的人格总数。

## 四、审判分级
### 认知层
| 等级 | 名称 | 风险 | 典型案例 |
|------|------|------|----------|
| Ⅰ | 轻度审判 | 无生命危险，反复撕开记忆 | 座位风波（林薇）、棉花路（林昭远） |
| Ⅱ | 重度审判 | 真实死亡（意识消散，现实中骤停） | 无尽回廊·恶犬、浴室·水鬼 |

### 真相层
- 分级标准不是"做了多坏的事"，而是"林昭远允许自己认出哪一部分自己"。
- 轻度审判 = 他允许自己"看到但不当回事"的人格（林薇、周勉）。
- 重度审判 = 他被良知逼着必须"承认死亡"的人格（17名他亲手"杀死"的穷学生、许白）。
- "现实中心脏骤停" = 林昭远昏迷，而非他人。醒来时监护仪显示他曾停跳三分钟。

### 自白层
轻与重的分野，就是林昭远在自白书里愿意署名的程度。越是回避署名的，审判越重。

## 五、审判流程
### 认知层
```
1. 召唤：叩门声 / 视线边缘白色丝状物 / 短信"该还了。"
2. 入审：被吸入独立审判间 / 审判官（良知凝聚的人形）宣布罪状
3. 回溯：轻度循环播放记忆 / 重度以第一人称体验受害者经历
4. 裁决：承认并接受真相→审判间崩塌→回归现实；试图隐瞒→无限循环直至崩溃
```

### 真相层
- 审判官=良知=林昭远自己→所以始终看不清脸。
- "以第一人称体验受害者经历"=林昭远体验自己施加给他的穷学生的痛苦。
- "无限循环直至崩溃"=他昏迷的三分钟内被拖延成无限长的三分钟。

### 自白层
流程本身是写作流程：召唤（提笔）→入审（回忆）→回溯（写）→裁决（署名/不署名）。全书即"拒不署名的记忆被良知逐条逼着署名"的记录。

## 六、特殊规则
### 认知层
| 规则 | 认知层描述 |
|------|-----------|
| 旁观者效应 | 多人共罪时审判"共享"，一人受审其余相关者同步观看 |
| 记忆污染 | 经历审判者遗忘一部分记忆，同时获得一部分受害者的记忆 |
| 棉花媒介 | 幻境实体媒介是棉花；棉花越多审判越重；棉花缠身=罪孽执行中 |
| 时间债务 | 幻境中撒谎/逃避会"欠下时间"，现实里突然衰老对应时长 |

### 真相层
| 规则 | 真相层解释 |
|------|-----------|
| 旁观者效应 | "旁观者"=林昭远愧疚注视的化身（N-09）。整个教室的围观者，都是"我"在看自己 |
| 记忆污染 | 林昭远撬取了自己记忆里被埋藏的部分来补全审判素材；遗忘的是罪，获得的是痛 |
| 棉花媒介 | 苏棉（苏醒）、许白（洁白）、棉花田（罪现场）同字系——棉花=他的"罪与可能的同体" |
| 时间债务 | 废弃规则，正文不呈现（原型设定残留，已从伏笔表中剔除，仅存认知层供人物对话引用一句） |

### 自白层
此处故意保留"时间债务"一条不回收——如同自白书里有个"没写完的注脚"，暗示作者本打算审判自己"欠下的时间"，最终良知决定不让它成真。这是留给三刷读者的一个未解之谜（作者拒绝为它署名）。

**时间债务＝全书唯一允许的文本内未回收项（自指式例外）**：
- 它的"不回收"本身就是符号——审判的终点是"苏醒那一刻"，苏醒发生在书页之外，所以这笔债只能由"放下书的人"来还。欠下的时间，属于读过它的人。
- 红线纪律同步固化：除"时间债务"外，全书29条伏笔一律执行"埋设→漏风→回收"闭环；此项为唯一豁免，且豁免理由在自白层成文可查（评审闭环）。
- 认知层仅保留人物对话里的一句引用（"你欠的账，时间会找你要"），正文不展开、不回收，三刷读者自行解码。

## 七、棉花事件（共业核心·三层真相）
### 认知层（正文呈现版）
> 三年前枫城第七中学以"劳动实践课"名义组织学生采摘郊县合作棉田的棉花，学校统一售卖用作"班级活动经费"。班主任王德明与收购商赖皮陈勾结，把学生辛苦采摘的棉花以极低统购价卖给赖皮陈，赖皮陈再以市场价转卖，差价二人私分。学生中有人知情、有人沉默、有人受害。

### 真相层
- 真正的记账员、真正主导的是**林昭远**（学生，负责记账）。他操控棉价，侵吞差价。
- 王德明是被"安排"出来的挡箭牌——他名字"德明"的反讽，即"被强行安上不德之名"。
- 苏棉的举报信被林昭远截下、替换。
- 许白（真实存在的女生）追问真相，被林昭远构陷"偷改账单"、逼其转学。她父亲陈建辉（棉田技术员）为女伸冤，被栽赃为"地主同谋"，沦为案板上被指定的人名。
- 十七名穷学生的辛劳与家计，是林昭远用账本葬送的。

## 八、主角特殊性（自我认知 vs 真相）
### 认知层
林昭远是"后知后觉的目击者"：当年记账时隐约察觉价格不公但选择沉默。他不是施害者，却是关键知情不报者。

### 真相层
他是唯一操纵者。他的"沉默之罪"是被良知处罚的借口——真相是"操纵之罪"。整场审判都建立在"我明明知道，却假装不知道"的自欺之上。

### 自白层
他的特殊性，在于他是全书唯一"在场却不肯署名"的书写者。读者读完整本，是在读一个人的忏悔如何从一个谎言开始，被迫弯回原点。
