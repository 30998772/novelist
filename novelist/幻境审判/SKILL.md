# 本书专属 Skill：《幻境审判》

## 一、这本书是什么

- 类型：**校园惊悚** × 幻境审判 × 群像悲剧 × **叙述性诡计**
- 总基调：惊悚、绝望、救赎。**审判的不是罪行，是心魔**
- 核心卖点：**三刷三故事**
  - 一刷：校园群像惊悚剧
  - 二刷：诡计揭示本（死者无名、审判官无脸、挚友全知、苏棉不对视、时间倒流）
  - 三刷：自白书（全书=林昭远醒来后写下的忏悔录，书名出自主角之笔）
- 结构：15章 × 3500字 ≈ 5.25万字
- 视角：**第一人称"我"（林昭远）——不可靠叙事**

## 〇、三层写作纪律（全书最高机密）

> 本规则凌驾于其他所有写作规则之上。正文只呈现「认知层」；「真相层」靠漏风；「自白层」靠名称学与结构暗示。任何一处"跨层直给"＝漏风，可能毁掉二刷三刷体验。
> 附加「四读」纪律（超额层）：正文永不出现"读者""你翻开"等打破第四面墙词汇；指认只落在封面凹印、015书名浮现与"该还了"的收束处，由读者自己完成。详见 章节大纲/总纲.md 写作红线第4条。

### 最高红线（013章前禁止跨层直给）
- ❌ 禁止出现"投影""分身""人格分裂""潜意识""幻境其实是……""真相是……"等上帝视角词汇
- ❌ 禁止任何"其实""原来""直到后来我才明白"式回溯解释（**013除外**，且需在卡片允许范围内；014/015是回落章，更需警惕会泄露的反观口吻）
- ✅ 允许：回忆性闪回、物证细节、数量异常、名字空白、侧写——这些是"漏风"

### 三刷暗语（只能埋，不能说）
- 名称学（苏棉=苏醒的棉 / 许白=被允诺的洁白 / 王德明反讽 / 陈建辉=秩序父亲 / 何眉=为何注视 / 林小满=圆满记忆）——靠名字本身暗示，不注释
- 书名浮现、短信双关、"为什么你能自由走动"——靠复现频率暗示
- 开篇不一致点（时间倒卷）——靠每章错一处细节暗示

## 三、文风与纪律

### 文风要求
- 第一人称，主角是后知后觉的目击者（表面）
- 前半段营造"普通校园"错觉，逐步揭示异常
- 恐惧感通过环境描写与人物反应传递，不靠"好可怕"直说
- 每个角色"死亡"都要有冲击力（冲击力=读者以为失去同窗的痛）

### 节奏纪律
- 第1章：信任建立，首个钩子
- 第2-3章：恐怖升级，死亡降临
- 第4-6章：主角个人审判，真相倒灌
- 第7-9章：规则全明，反击受挫
- 第10-12章：集结决战，人数谜团
- 第13章：终极反转（最高点，庭审文体）
- 第14-15章：现实回落，环形闭合

### 字数铁律
- 每章 3500 中字符（**计数口径：正文非空白字符，含中文标点，不含标题/分隔线；浮动 3200-3800**）
- 写完后必须验证字数（以非空白字符计）
- 纯汉字数（不含标点）应 ≥ 2900，作为辅助校验口径

## 四、AI 痕迹防控细则（量化可验证）

### 禁用词黑名单（全书禁用）
`眼中闪过一丝 / 嘴角勾起一抹弧度 / 空气仿佛凝固 / 时间仿佛静止 / 那一刻 / 仿佛(禁)/ 似乎(禁) / 命运般 / 灵魂深处 / 内心最深处 / 嘴角 / 眸子 / 心尖 / 颤了颤 / 呼吸一滞 / 无声叹息 / 某种情绪 / 说不清道不明 / 眼泪在眼眶里打转 / 血往上涌 / 凉到头顶 / 头皮发麻 / 倒吸一口凉气 / 喉头一紧 / 眼眶一热 / 狠狠攥紧 / 目光深邃`

### 比喻纪律（判据定义：明喻=像/如/如同；暗喻=是/成/成了；拟人=物作人）
- 每 500 字比喻总数（明喻+暗喻+拟人）≤ 2；单段 ≤ 1。
- 比喻必须来自**本文意象库**（棉花/雾/水/声音/账目/合影/撕口/手指），不得借用 AI 常见意象（海洋/星辰/宇宙/时间洪流/潮水）。
- 禁止三连排比（"风是……风是……风其实是……"）超过 2 连。
- 计数时不计入熟语引用（如"哭也不是"），只计修辞性比喻。

### 金句收尾禁令
- 章末钩子的最后一句话：**必须是一个事件/一个画面/一句台词**，禁止警句式收尾
- 示例✅："他咽了口唾沫，把手机按亮。屏幕上显示：消息已读。"
- 反例❌："时间的河流终将冲刷一切，而我，只能站在原地。"

### 对话纪律
- 每个角色对话可辨识（对照档案语言特征）
- 删除寒暄废话；对话至少推动剧情或刻画人物之一
- 主角"我"的内心独白不得超过每章 8 行

### 第三人称退出纪律（014章后）
- 014章结尾起允许"我"退出叙述（第三人称旁观），这是故意的结构切换，不允许更早出现
