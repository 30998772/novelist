# 第066章 雨季的书香
六月的雨，说来就来了。
那天早上还是晴天，太阳从东边的山头上冒出来，把整个老城区都照得亮亮堂堂的。可到了中午，天色忽然暗了下来，像有人在天上泼了一盆墨。云层越积越厚，越压越低，空气里弥漫着一股潮湿的泥土气息。
然后，雨就落下来了。
不是春天那种细细密密的雨，是夏天的雨。大的，急的，重的。雨点打在屋顶上，打在窗户上，打在青石板上，发出噼里啪啦的响声。
陆栖站在文献馆的门口，望着雨幕中的天井。雨水从屋檐上落下来，连成一道道透明的瀑布，把天井变成了一面巨大的镜子。
她转身走回大厅。
大厅里轻手轻脚的。林越在写一份新的报告。关于南枝文献馆长期保护方案的。他已经写了三个月，改了无数稿，还在写。苏晚在给孩子们准备"灵的故事角"的道具。她用纸壳做了一些小玩偶，有雪团，有纸屑灵，有围裙灵。
雨越下越大。
陆栖走到二楼古籍区，开始巡查。雨季是文献馆最脆弱的季节。潮湿的空气会让书页发霉，会让书架变形，会让那些脆弱的灵变得躁动不安。她每一排书架都仔细地看，每一本书都用手地碰了一下，感受它们的湿度。

《未刊诗草》还在那里。她伸手碰了碰封皮，感觉到了一种很轻很轻的凉意。不是书凉了，是灵的气息变弱了。雨季里，灵的气息会变弱。
"阿棠，"她轻声说，"下雨了。你还好吗？"
书页后面传来一阵极轻很轻的暖意。比平时弱了很多，可还在。
她翻开最后一页。那行字还在。"我看到了。"下面是她写的"阿棠，我们的工作，被看见了。"
"雨停了，我就好了。"
那行字她看了很久。
"阿棠，"她轻声说，"雨停了，你就好了。"
书页后面的暖意变亮了一点。
她合上书，打开除湿机。机器发出嗡嗡的声音，把潮湿的空气吸进去，把干燥的空气吐出来。她又在书架旁边放了几包干燥剂，把窗户开了一条缝。
她转身走回一楼。
苏晚走过来，说："陆栖，雨季里，那些灵。它们会怎么样？"
陆栖说，"它们会不舒服。有些灵会变得更安静，有些灵会变得更躁动。"
苏晚说，"那我们怎么帮它们？"
陆栖说，"保持干燥，保持安静，不要打扰它们。等雨停了，它们就会恢复。"
苏晚说，"好。"
她走回儿童阅览室，继续做她的玩偶。
林越走过来，说："陆栖，雨季里，那些旧照片和旧档案。需要特别保护吗？"
陆栖说，"需要。把它们放在干燥的地方，不要受潮。"
林越说，"好。我把它们搬到二楼的干燥柜里。"
她开始搬运那些旧照片和旧档案。一箱一箱地从照片收藏区搬到二楼的干燥柜里。箱子很重，可她搬得很稳，一步一步，踏踏实实的。
雨还在下。
陆栖走到借阅台前面，坐下来，盯着窗外的雨幕。她想起顾松年说过的一句话："雨季是文献馆最脆弱的时候，也是最考验守馆人的时候。"
她想起自己刚来那年，也是雨季。那时候她什么都不懂，不知道雨季要除湿。有一天，她打开一本古籍，发现书页上长了一层绿色的霉斑。她吓坏了，跑去问顾松年。顾松年走过来，看了看书，说："没关系，清理一下就好了。"她拿出一把软毛刷，地刷掉霉斑，然后用吸水纸把书页一张一张地吸干，最后把书放在通风的地方晾干。整个过程，顾松年的手很稳，很慢，像在照顾一个生病的孩子。
她记住了这句话。后来，每一个雨季，她都会格外仔细地巡查每一排书架，每一本书。
现在，林越也在做这些事。他搬着箱子，从一楼到二楼，从二楼到一楼，来来回回，不嫌麻烦，不嫌累。
雨小了一些。
苏晚从儿童阅览室走出来，手里拿着一个纸壳玩偶——是雪团。白绒绒的一团，裹着一条小绒毯。
苏晚说，"陆栖，你看，我做的雪团。"
陆栖接过玩偶，看了看。玩偶做得不太像。比例不对，颜色也不对。可它有一种说不出的可爱，像一个孩子画的画，虽然不准确，却很有生命力。
陆栖说，"很好。"
苏晚说，"真的？"
陆栖说，"真的。"
苏晚说，"那我继续做。我还想做纸屑灵、围裙灵、乐谱灵——"
她掰着手指头数，数着数着，笑了。
苏晚说，"太多了，做不完。"
陆栖说，"慢慢做。不急。"
苏晚说，"好。"
窗外的雨还在下，比刚才小了一些。
她想起阿棠说过的一句话：""
循环往复，生生不息。
她转身走回大厅。
大厅里很安静，书架齐齐整整，桌上一杯茉莉花茶，绿台灯亮着暖黄的光。
林越把最后一箱旧照片搬上了二楼。他走下来的时候，额头上冒着汗。
林越说，"搬完了。所有的旧照片和旧档案，都在二楼的干燥柜里了。"
陆栖说，"好。"
林越说，"陆栖，雨季一般持续多久？"
陆栖说，"一个月左右。"
林越说，"那这一个月，我们每天都巡查？"
陆栖说，"对。"
林越说，"好。我跟你一起。"
窗外的雨小了一些。天色亮了一点。远处的山在雨雾中若隐若现，像一幅被水晕开了的水墨画。
陆栖走到窗边，端详着窗外的雨幕。
雪团从绘本区滚了出来。它滚到书架最上层，把自己裹在绒毯里，只露出两只黑豆眼。它不喜欢雨。雨天的空气太冷了，它的绒毯不够暖。可它没有缩在柜顶上。它滚到书架最上层，从那里往下看，瞅着陆栖巡查书架。
它没有飘到陆栖的肩膀上。它飘到雪团旁边，薄薄的一片，在绒毯的一角停住了。
雪团低头看了看纸屑灵。
纸屑灵不再颤抖了。
两个灵静悄悄地待在书架最上层，一个白绒绒的，一个薄薄的，共享着一条绒毯的一角，望着陆栖巡查书架。
窗外的雨还在下。
围裙灵飘到古籍区，停在《家常菜谱汇编》旁边，伸出看不见的手，一下一下地扇着那几页书。

字典老先生从工具书那一排探出半个身子，把《新华字典》往外面推了半寸，让干燥的空气能碰到书页。它推完就缩回去了。

板书灵从墙角的粉笔灰里钻出来，在黑板上写了两个字：雨季。写完它仰着头看屋檐。

日记灵李晓禾趴在陆栖肩上，在本子上写了一行字：今天雨大，四个人都在。

窗外的雨还在下。
最后一页上，那行字还在。"雨停了，我就好了。"
她提笔，在那行字底下添了一行小字：
"阿棠，雨会停的。"
书页后面传来一阵极轻极轻的暖意。那种暖光更亮了，书页后头那个灵，大概在笑着。
书合上了，她走到窗边。
她想，砖还湿着，走出去会滑。
沈念来了。
她每个月来一次，每次来都带着一个笔记本。今天她带来了一样东西。一把钥匙。
沈念说，这是太爷爷房间的钥匙。我在老家里找到的。我想把它放在馆里的展览区。和太爷爷的照片、太爷爷的笔记本放在一起。
陆栖接过钥匙。钥匙很旧了，铜绿斑斑，可还能用。
陆栖说，"好。"
沈念说，这把钥匙，能打开那扇门吗？
陆栖说，"能。"
沈念说，我想试试。
陆栖带着沈念走到二楼古籍区，走到书柜后面的小门前。她把钥匙插进锁孔，地一转。
咔嗒。
门开了。
沈念站在门口，望着那个小房间。房间里还是那张桌子、那把椅子、那盏灯。桌上放着一本翻开的书，书页已经发黄了。
沈念说，太爷爷走的最后一晚，是不是就坐在这里？
陆栖说，"是。"
沈念说，她在看什么书？
陆栖走过去，看了看那本翻开的书。书的封面上写着三个字：《未刊诗草》。
陆栖说，"她在看阿棠的诗集。"
沈念沉默了很久。
沈念说，他到死都在等她。
陆栖说，"对。她到死都在等她。"
窗外的雨还在下。
