# 第025章 林晓颂的成长

林晓颂值了一个月的晚班。

这一个月里，她把馆里每个区域的灯都认全了。绘本区那盏夜灯是暖黄色的，灯罩磨了一半，要往左拧半圈才最亮。二楼走廊尽头那盏壁灯装得太高，换灯泡的时候得踩凳子，她头一回换，踩空了一级，差点摔下来，后来记住了——那级踏板松了，要踩旁边那根横杠。三楼书房的台灯最老，灯绳是棉线编的，拉的时候要轻轻的，一使劲就断，断了得重新打结，她打过三回，每一回都比上一回好看些。

这一个月里，雪团开始认得她的脚步声。

雪团是绘本区的小灵，缩在第二层书架的缝隙里，裹着一页画当毯子。刚来馆里的头两个月，林晓颂每次走近，它就把身子往缝隙里缩，只露出半个圆滚滚的后脑勺。后来她每天傍晚来绘本区开灯，脚步声轻轻的，踩在木地板上不响，可雪团还是缩着。再后来，她每次开灯之前会先敲两下书架，"笃笃"两声，不大不小。敲了十来天之后，她再走近的时候，雪团不缩了。它把小脑袋从缝隙里探出来，看她拧灯、擦灯罩、把歪了的绘本一本本摆正。再后来，她还没走到绘本区，雪团就提前从缝隙里钻出来，蹲在书架边上等她了。

林晓颂把这件事跟陆栖说了。陆栖正在办公室里翻一本旧目录册，听完点了点头，说："它记住你的脚步声了。"

"脚步声也能记住？"

"能。"陆栖翻了一页，"雪团怕风，脚步声重了它当是风来了。你走路轻，它听久了就知道不是风。"

林晓颂想了想，又问："那陆老师您的脚步声，它也记得吗？"

"记得。"陆栖说，"它记得的比我以为的多。有一回我重感冒，脚步声比平时沉，它就缩回去了，缩了一整个晚上。第二天我好了，脚步声轻了，它才出来。"

林晓颂没再问。她回到绘本区，蹲在雪团旁边，看它把那页画毯子拉了拉。画毯子上画的是半棵柳树，绿色已经褪成了黄绿，可雪团还是裹得紧紧的。她伸手想帮它把毯子角掖好，雪团"嗖"一下缩回缝隙里去了。

她把手收回来，笑了笑。她想，慢慢来。

这一个月里，她也学会了看馆里的天气。

不是看窗外的天，是看馆里各处的"气候"。绘本区朝北，冬天冷，夏天凉，春秋最舒服，可一到换季就起潮，绘本的封面容易卷。旧课本区朝东，日头晒得足，纸页干得快，可日头太猛了纸又会脆，得拉半帘挡光。二楼的古籍区最讲究，温度和湿度都不能大动，墙上那台老除湿机嗡嗡响了一整个冬天，春天停了几天，又得开起来，不然角落里那排明刻本会返潮。

林晓颂把这些都记在自己的小本子上。她的本子比方小远的大一号，写得也比他密。本子前面几页是陆栖教她的修书手法——怎么配纸，怎么穿线，怎么用糨糊。后面几页是她自己摸索出来的规律——绘本区周三最安静，适合补封面；旧课本区周五下午有学校组织来参观，得提前把易碎的书收到高处。

她翻本子的时候，手指上还沾着糨糊。糨糊是自己调的，用的是面粉和白醋，比例是陆栖告诉她的——面粉一勺，白醋半勺，温水调开，小火熬到起泡。她头一回调，水加多了，糊出来的东西稀得像米汤，粘不住纸。第二回水少了，熬成了面疙瘩。第三回才勉强成形，可还是比陆栖调的粗。陆栖调出来的糨糊是半透明的，抹在纸上几乎看不出来，只留一点淡淡的麦香。她调出来的，白花花一层，干了以后像补丁。

"不急。"陆栖说，"我头一回调糨糊，调了十来回才成。"

"十回？"

"十回。"陆栖说，"顾老还嫌我浪费面粉。"

林晓颂笑了。她想，原来陆老师也有过手笨的时候。她以前总觉得陆栖什么都会，修书、认灵、松土、调糨糊，好像天生就会似的。如今才知道，那些本事都是从一次次手笨里磨出来的。

这一个月里，她还学会了跟馆里几只熟悉的灵相处。

说是"相处"，其实是她单方面的。她看不见它们，可她能从书页的动静里感觉到它们。借阅册灵她认得最熟——那本被翻圆了角的蓝布册子，摊开在借阅台上，风大了会自己翻页。起初她以为是风，关了几回窗，册子还是翻，她才明白不是风。后来她摸出了一个规律：每回有读者认真借完书，走的时候，那册子就自己"哗啦"翻过一页，像在替谁记上一笔。

她把这事说给陆栖听。陆栖说："你摸到它高兴的时候了。它从前见过几百个人的人生，都借它记着。如今还有人借书，它就觉得还没被忘干净。"

"那我怎么跟它打招呼？"

"不用打招呼。"陆栖说，"你每天把借阅台擦干净，把册子摆正，它就知道了。"

林晓颂照做了。每天下班前，她把借阅台擦一遍，把蓝布册子摆正，压好镇纸。她做这些的时候，册子安安静静的，可她总觉得自己擦台子的时候，册子的纸页会松一松，不再那么绷着。

旧课本区还有一只灰扑扑的小影子，她认不出来，只感觉它喜欢待在窗台上。每回傍晚，日头斜进窗户，那影子就蹲在窗台边上，看外面的巷子。林晓颂不知道它叫什么，只觉得它像在等谁。她不敢惊动它，只在窗台角放了一杯水，天天换新鲜的。有一天她放水的时候，窗台上的窗帘轻轻动了一下，像有一阵极轻的风，从她手边绕过。

她蹲在那里，心里忽然涌上一阵说不清的暖。她想，她虽然看不见它们，可它们知道她来了。

这天傍晚，林晓颂在旧课本区整理新到的捐赠书。这批书是城南一所小学淘汰下来的旧课本，纸页泛黄，书角卷着，有的封面还画着小人的涂鸦。她一本一本地翻，看有没有虫蛀的、有没有缺页的，该修的修，该登记的登记。

翻到第四摞的时候，她翻出一本不一样的书。

那是一册手抄的古诗选，毛笔字，写在竖格的稿纸上。字迹端正，一笔一画都用过心，不像随手写的。稿纸已经泛黄了，边角起了毛，可字迹还很清晰。她翻了翻，一共二十三页，每页抄两首诗，都是五言绝句。最后一首是王维的《竹里馆》，写完之后，空白处多了一行小字："一九七四年秋，抄于灯下。"

她把那册诗选捧在手里，看了一会儿。她虽然看不见灵，可她能感觉到一种说不清的东西——像这册书在微微发热，不是太阳晒的那种热，是从纸里往外渗的、带着一点点脉搏的热。她把书贴在耳边，听见了一种极细微的声音，像有人在翻纸页，又像有人在轻声念诗。

她抱着书去找陆栖。陆栖在办公室里，正对着台灯翻一本旧档案。林晓颂把诗选放在她面前，说："陆老师，这本好像不太一样。"

陆栖放下档案，拿起诗选。她翻了几页，手指停在那行"一九七四年秋，抄于灯下"的小字上。她把书凑近台灯，看了一会儿，说："这是个有灵的。"

"什么灵？"

"诗灵。"陆栖说，"抄诗的人把心思一笔一笔写进纸里，写得久了，纸就有了记性。这册诗抄了二十三页，每一笔都是认认真真写的，记性就深了。"

"那它……想要什么？"

陆栖把书合上，放在桌上。她看着那册泛黄的诗选，沉默了一会儿，说："它想被人读。"

林晓颂点了点头。她蹲在桌边，又把诗选翻开，翻到第一页。第一页抄的是《鹿柴》："空山不见人，但闻人语响。返景入深林，复照青苔上。"她一个字一个字地读，读得很慢，读完抬头看陆栖。

"一九七四年的晚上，有人点着灯把这首诗抄下来。"林晓颂说，"他不知道多少年后会有人读，可他还是抄了。"她顿了顿，"我要是那个抄诗的人，我大概也愿意有人读。不读我抄的字，就是知道曾有人，在灯下认认真真做过这件小事。"

陆栖看着她："你想到了这一层，就比许多只看见'旧书'两个字的人强了。"

"那我把它放到古诗区去，"林晓颂说，"让它不孤单。"

"你决定。"

林晓颂捧着诗选去了古诗区。她在书架上找到一个靠里的位置，旁边是一排线装的旧诗集，纸页都比这册手抄本老。她把手抄本放进去，让它靠在一本《唐诗三百首》旁边。放好之后，她又蹲下看了一会儿——她看不见灵，可她总觉得，那册诗选放进这排书架的时候，纸面上的光好像亮了一点点。

她站起来，拍了拍手上的灰。回去的路上，她经过绘本区，看见雪团蹲在书架边上等她。她蹲下来，雪团没有缩，只是把那页画毯子又裹紧了一些。

"你也听到了？"林晓颂轻声问。

雪团没有回答。可它把小脑袋转了转，朝古诗区的方向看了一眼。

林晓颂笑了。她伸出手，这一回雪团没有缩。她的指尖碰到了那页画毯子——凉凉的，毛茸茸的，像一层薄薄的雾。她赶紧把手收回来，怕自己手重，惊了它。

"我走了。"她说，"明天再来看你。"

雪团缩回缝隙里，把自己团成一个雪白的绒球。林晓颂站起来，关了绘本区的灯。临走前，她回头看了一眼——缝隙里，两点亮晶晶的小光，像两颗很小很小的星。

她走出馆门的时候，天已经黑透了。路灯亮着，把她的影子拉得很长。她裹紧围巾，走在回家的路上，脚步声踩在水泥路上，一下一下的。她想，今天的灯都关好了，雪团也安稳了，那册诗选在古诗区也找到了伴。她今天做的事不多，可每一件都做完了，做踏实了。

走到巷口的时候，她忽然想起陆栖说过的一句话："守馆不是守着楼，是守着楼里每一个会冷的角落。"她从前觉得这话太大了，不好接。今天她站在古诗区，把一册手抄诗选放进书架的时候，忽然觉得，这话其实不大——大到一栋楼，小到一个书架格子，都是"角落"。你把每一个格子都照顾到了，这栋楼就不冷了。

走过小公园的时候，她在路灯底下站了一会儿。树影疏疏地落下来，风从叶间穿过，凉凉的。她想，自己来馆里快半年了。半年前她第一天上班，什么都不会，连调糨糊都能调出三回废料；半年后她认得每一区的脾气，摸得懂借阅册灵高兴不高兴，能把一册旧书安放到它该在的地方。这半年没什么惊心动魄的事，就是一天一天地来馆，一天一天地把小事做周全。可就是这"一天一天"，让她变了人样。

她加快脚步往家走。口袋里的小本子硌着大腿，本子上今天多了一行字：三月十五，收到手抄诗选一册，一九七四年抄本，已放古诗区。古诗区湿度正常，待观察。

她到家的时候，妈在灶房热粥。她洗了手，帮着端碗，坐下吃饭。粥是红薯粥，甜丝丝的。她喝粥的时候，手指上还有一点糨糊的痕迹，洗了三遍也没洗掉。她看着那点白，笑了笑，低头接着喝。

睡前她把小本子翻到第一页，看了看自己入职第一天写的那行字："今天第一天来馆，什么都不会。"她翻到最后一页，看了看今天写的那一行。然后她把本子合上，放在枕头边。

窗外的风很轻，吹得窗帘微微动。她闭上眼睛，想起雪团蹲在书架边等她的样子——那个小小的、雪白的、裹着画毯子的身影，已经在她脑子里住了下来。她想，明天傍晚去绘本区的时候，脚步声再轻一点。再轻一点。
