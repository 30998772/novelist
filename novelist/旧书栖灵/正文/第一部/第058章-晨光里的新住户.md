# 第058章 晨光里的新住户

那天早上陆栖到馆的时候六点差一刻。天已经白透了，巷子里有人推着车过去，轮子压在青石板的缝上，一压一响。她开门的时候手上沾了雨水，前一天夜里下过一场，天井的石板到早上还是湿的。

她上楼放下包，下楼去查漏。走到大厅中央她停住了。

靠墙那排旧书架的最底层，多了一本书。

不是她放的。也不是谁捐的——她昨天擦那一排的时候看过，最里侧那一格是空的，架板上没有灰。现在那一格里躺着一本书，位置很正，书脊朝着过道。

她蹲下来。

是一本日记本，很小，只有巴掌大。封面是淡蓝色的布面，上面印着一朵小雏菊，花瓣褪成了灰白，只剩轮廓。封面上有一个小小的铜扣，已经发绿。边角磨毛了，纸页泛黄，翻口的地方起了细毛。

她伸手碰封面。一阵暖意从指尖上来，很弱，弱得像一口气，可它确确实实在那儿。

她把日记本拿起来，翻开。

第一页写着一行字，歪歪扭扭，笔画收不住：

"今天是开学第一天。我好开心。"

底下画了一朵小花，五片花瓣，涂成黄的。旁边画了一个太阳，圆圆的。

她翻到第二页。

"今天下雨了。妈妈没有来接我。我自己走回家的。淋湿了。可是我没有哭。"

旁边画了一把伞，伞面上有一只兔子。

再往下。"今天老师表扬我了。说我写字写得好。我高兴了一整天。""今天我和小美吵架了。她不跟我玩了。我好难过。""今天爸爸给我买了一本新书。《安徒生童话》。好厚啊。我要看很久很久。"

"今天我在图书馆里看了一下午的书。图书馆好安静啊。我喜欢这种安静。"

第五页有一段长一点的话：

"我最喜欢图书馆了。图书馆里有好多好多书。每一本书里都住着一个人。我翻开书，那些人就醒过来了。他们跟我说话，跟我说故事。我不孤单了。"

底下画了一栋楼，楼顶上画了一棵大树。楼门口画了一个小人，举着一本书。

她看着那幅画。那个小人大概就是这本日记本的主人。他画的那栋楼是南枝文献馆，他把书举得很高。

她继续翻。

"今天我又去图书馆了。我找到了一本新的书。书里有一个小女孩，她住在一个旧旧的楼里，楼里有好多好多看不见的邻居。小女孩每天都去看它们，给它们留灯，给它们泡茶。我好羡慕那个小女孩啊。我也想住在那样的楼里。"

她把这一页翻回去重看了一遍。小孩子写的是这栋楼里的事。那些看不见的邻居，那盏留着的灯，那杯每天换的茶。

她又往下翻了三页。

"今天图书馆里来了一个新的阿姨。她很瘦，头发乱糟糟的。她坐在窗边看书，看得很认真。我偷偷看了她一眼。她好像在跟书说话。"

"今天那个阿姨又来了。她给书浇水了。书旁边有一盆绿萝。她浇水的时候，绿萝的叶子抖了一下。"

"今天那个阿姨在修书。她修得好慢好仔细。她修完了，把书放在书架上，朝书嗯了一下。我觉得那个阿姨好温柔啊。"

她把本子往下挪了挪。这一页的下角有一个很小的手印，油墨的，是小孩按手印按的。

最后一页只有一行字，笔画比前面的工整一些：

"如果有一天我走了，我会变成一本书。我会住在图书馆里，等着有人来翻开我。"

底下没有画。

她把日记本合上，放在膝盖上，把手掌盖在封面上，就那么靠着书架坐在地上。地砖是凉的，凉气透过裤子渗上来。她没有换姿势。

她坐了一会儿。地砖缝里嵌着一点灰，她用指甲剔出来，剔成一小堆。站起来的时候膝盖有一阵麻，她扶着书架站直，把日记本抱到怀里。

她抱着本子上楼。

她要把它挪到二楼去。《未刊诗草》在古籍区最里侧第二架，那个架子上还有位置。她抱着本子走到楼梯中段，停下来。

挪书要动两样东西：格位卡的编号，索书号。

她抱着本子退回去，先去柜台翻《住户登记册》。从头翻到尾，没有这一条。她又翻《入藏登记》，从民国三十五年那一页翻到今年，也没有。没有编号，没有来源，没有谁填过的字。

她从抽屉里取出一张空白的格位卡。卡是硬的，一面印好三栏：名称、来源、索书号。三栏的格宽是印死的。

名称一栏她写：蓝布面日记本，童笔，字三百余。

来源一栏她停住了。

她抬头看那一排旧书架。每一格的卡片都在，编号连着号，三栏填满。她这一格要填一张。索书号她自己编得起，工具书区的号段她闭着眼睛也能接着往下数。来源编不出来。查不到捐赠人，查不到旧藏登记，查不到有人把它抱进这扇门。

她在来源那一栏写了两个字：不详。

写完她自己看了一会儿，把卡片放回抽屉，换了一张。

第二张她把来源那一栏空着。三栏填了两栏，第三栏底下留一块白。空着的卡插不进那一排——那一排卡片的编号是连着的，中间少一张，后面的人按号找，找到了断掉。

她在空白的第三栏底下写了一行小字：待编。

这一张插得进去了。她把它插在那一格的架板上，牌面朝外，编号那一栏填的是这一格原有的号。

编索书号这件事她以前做过十几次。索书号不是写在卡片上的，是贴在书脊下面的一条纸签，签用牛皮纸裁的，一格宽，写蓝黑墨。工具书区最末那一条她昨天核过，末号是一六二。她拿着本子去数架上的书脊，数到架尾那一本，那一条签是新的，纸色比别的浅，是她上个月刚裁的。

问题出在这儿。索书号要有地方贴。日记本是布面的，封面只有一朵褪色的小雏菊，铜扣在正中间，左下角有一小块磨白的皮。她捏着那块皮看了半天：签贴上去，正面要露出铜扣；贴到底下，书放不平，一放就翻。

她最后没有贴。她把卡上的索书号那一栏填了一个临时号，前头加一个"临"字。填完她把笔尖在墨水瓶口刮了两下，笔尖刮到瓶壁，吱的一声。等笔尖不滴了才把卡插回去。

那块磨白的皮上什么都没有。

上午她拿着这张卡去问了管理员。

"待编的东西，索书号怎么算。"

"不算。"管理员说，"临时的号不进借阅册。有人在借阅册上找这本，找不到。"

"那要等多久。"

"等来源补上。"管理员把卡推回来，"来源补不上就一直临。"

"一直临是什么意思。"

管理员看了她一眼："意思是它一直在这一格，你在卡片上写什么它就在什么。"

陆栖把卡拿回来，插回那一格。她本来是想把它挪到二楼去的。卡插回原格以后，她就没有再下楼去拿日记本。

她在《开馆闭馆登记》的备注栏里写了一行。这一栏只够七个字。她写了六个：

住户一，待编。

那本日记本就在她楼上。她没有再去动它。

她下楼端了一杯茉莉花茶，放在那一格旁边的架板上。杯子是小白瓷的，刚泡的，杯口浮着一层热气。她放的时候把杯底在架板上磕了一下，试温度，烫。她又等了半分钟，等那层热气散薄了，才把杯子往里推了推，推到不碍事的地方。

放完她在那儿站着看了一会儿。日记本的布面在晨光里显出绒的纹路。她想，那孩子的日记里写过一楼、二楼、三楼，写过天窗、槐树、楼梯，写过他坐在哪个角落看见她。他写了那么多地方，唯独没有写过这一格的架板底下。

六点半，第一个读者到馆。中年男人，抱着一摞地方志，进门先问能不能在阅览室看。她给他倒了水。他在阅览室坐下翻了二十分钟，忽然隔着桌子问她，你们这个馆里最老的是哪本。

她说了《未刊诗草》。他记下来在本子上写，写的时候她过去添茶，看见他在那四个字底下画了一道横线。

"这书我借过。"他说，"二十五年前，大学的时候。那书里夹着一片干叶子，不知道现在还在不在。"

她说这个她不知道。她也没说她后来在树上见过的那道刻痕。她只说，您要是想知道，翻到扉页看看。男人真去翻了。他翻到扉页看了很久，说上面有字，被人刻过，刻得很浅，看不太清。

"看不清就对了。"她说。

男人愣了一下，问为什么。她说，这书怕人看清。男人笑了笑，把书合上，说这话有点意思。

临走的时候他问，那个空着的架子上写什么。她说，空着。他哦了一声，把地方志抱起来，站了一会儿才走。

他走后她把地方志搬上二楼。搬完她站在楼梯上歇了一会儿，第十三级那块地方她踩了一下，木头闷闷地响。

傍晚她关窗。一楼两扇，二楼三扇，三楼两扇，天井后头那扇小的。她一扇一扇插上插销，插到底要往上提一下再往里推。关到二楼最里侧那扇的时候她停了一下。这扇窗她从来不关，风要进来，风进来阿棠才出得来。今天她还是关了。

关完她站在窗前看了一会儿，又把窗推开一条缝。窗框卡了一下，她用手托住，撑到一指宽。她把手放在窗框下沿那道旧灰上，抹了一把，抹下一层灰白的粉，粉沾在指头上，她在外套上蹭掉。

她拉开门，台阶上有两个青苔的印子，间距短，落得重，一个在前一个在后，往巷子那头去了。她站在门口看。印子被露水泡得很快，淡下去，最后只剩下两道浅绿的痕。

她回屋，翻开借阅登记册，摊在柜台上。今天这一页还没有人登记。她在页脚补了一行：本馆新增住户一名，蓝布面日记本，索书号临字零零三。

写完她把笔搁下，又把这一行划掉了。临字号不能上借阅册。她重写了一行：本馆新增住户一名，蓝布面日记本，待编。

她翻回前面几页。有几页被人拿铅笔写过极淡的一行，她以前没注意。她把册子凑到窗口的光底下看，写的是"某某年某月，某某还书，某某未还"。是前一任馆长的笔迹。那位老馆长也干过同样的事。

夜里闭馆，她下楼巡了一圈。大厅角落那一格，日记本还在原处，蓝布面朝上，铜扣朝着过道。它旁边是一杯不再冒气的茉莉花茶。

她蹲下来，把手指按在封面上。日记本里有一阵颤动，很轻。

她没有把手指挪开，也没有起身。

那一格的架板上插着两张卡。底下那张是老卡，编号连着号；上面那张是她今天新填的，第三栏底下写着"待编"。

两张卡挨在一起，中间没有别的。
