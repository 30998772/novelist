# 第004章 未写完的童诗

多是教辅和过期少年杂志。教辅按斤称过，卖废品嫌不够秤。杂志缺了封面封底，纸芯发潮，摸着黏手，一翻就往下掉屑末。箱底积了一层碎纸屑，脚踩上去发软，陷下去一点。陆栖一册一册登记，一本一行，行尾写箱号。写到第九箱她去接了杯水，回来时光斜过来一点，正照箱底那本薄本子。牛皮纸封面，圆珠笔写着"四年级二班，陈小满，《我的诗》"。

"陈小满"三个字映得发亮，笔画里的圆珠笔油还留着，油亮一层，摸上去有点涩，是新写上去没多久的那种亮。

她盯着看了两秒，先把它翻开了。牛皮纸封皮硬得硌手，边缘磨得起毛。翻的时候刮了一下指甲。本子一开，一支铅笔头模样的灵从纸页间探出脑袋。

它比馆里任何住户都小，也最旧。铅笔写的字会淡，靠字活着的灵也淡，它撑到今天还亮着一点。石墨蹭在指尖上是黑的，搓不掉。全凭那半页没等到评语的空白。纸是薄的那一种，透光，角上起毛。身子只有一截手指长，灰扑扑的，尖朝上，看了她两眼就缩回去。灰是粉的，一碰就散。

陆栖没有伸手去够。她把椅子往后挪半尺，让出一段刚刚好的距离，低下头，捏着书角假装翻封面。给小东西留退路，是跟它们打交道的第一课。

"……你是这本里的？"

它没动，笔尖抖了一下。陆栖说不是来收的，她登记完就走。那截铅笔从书缝里又探出来一点，笔尖朝着窗台的方向。它怕自己又不被看见。陆栖把本子带到窗边。翻之前先净了手，在水龙头底下搓了搓，指甲缝里的灰也冲掉。馆里有条不成文的规矩：碰来历不明的旧书先洗手。不为讲究，为的是手上不带一点急躁。

擦干时她用袖口蹭了两下。窗外的光刚刚好。她把本子斜举起来对着光看，没有虫蛀，没有水渍，只有孩子手汗浸出的、浅浅一圈圈的黄印。

被认真捧读过的纸和被随手丢着的纸，黄得都不一样。这本薄，捏在手里透光，纸背起了一层浅浅的毛。字里行间夹着拼音，还有橡皮戳破的洞。八岁孩子的手在纸上留过东西，纸记得。

第一首叫《云》。题目写在第一行正中间，笔画比正文粗，是小学生写大字题的那种用力。

"云是天空的被子，晚上盖住月亮，怕它着凉。"

念到一半她停住。诗下面有一行更小的字，是孩子自己改的。她嫌"被子"两字写起来太长，缩成"布"，旁边画了括号，括号里是划掉的原字。改得很认真，涂了又描，描得又粗又黑，描完还描。

铅笔灵从桌腿边探出半个身子。第二首是《外婆的手》。"外婆的手像老树皮，可是摸我脸的时候，比被子还暖。"

念到"比被子还暖"那句，陆栖把声音压低了。写这行孩子换过一次笔，前半截笔尖钝了，后半截的字深一些。第三首没写完，题目倒有了：《等妈妈回家》。题目下面空两行的位置，底下只一行。"我数到一百，楼道就会亮"。

空出来的那两行是留白，格子里的横线被反复描过，描得比别的行深。孩子本来还要写的。中间某页空白处还有一首，没题目。"爸爸的自行车会响铃，叮铃铃，全楼道都听得见。"字迹到这里停住，后面跟一大团涂改的黑疙瘩，橡皮戳破了一个三角形的洞。

陆栖把本子摊平在桌上，两只手压住两边。纸受潮又干，卷着的地方一松就往上翘。指尖压下去有点涩，像按住一片干叶。她拿镊子把卷起的纸角展平，又用软橡皮滚掉屑末，屑末粘在橡皮上，黑的。

再往后翻，全是空白，从第一首的位置一路留到本子末尾。纸面干净到发脆，指头划过去发涩。铅笔灵在空白页上挪来挪去，一会儿瞟瞟陆栖的脸色，一会儿把自己缩得更小。它太知道接下来的流程了：看两眼，合上，归档，从此落灰。每一次都从头盼起，盼到空白页，再从头落空。

那之后十九天，她每天下班前把本子摊在窗台上，翻到最后一页。铅笔灵挪到纸背那一面贴着。她隔着纸听，听不见，可她知道它在说什么。它说了十九遍同一句：

"我怕。"

第十九天她没有再问它怕什么。数不清也还是怕，那就不必问。陆栖把本子合上，走到书架前抽了两本《小学生作文选》。同一批捐来的，落款都是语文教研组。

再把陈小满那本摊开，对着光找。每首诗后面都有批注栏，同学作文里总有一两行红字。这个小本子的批注栏里只一个孤零零的字。阅。后面一个勾。那个勾打得很潦草，尾巴拖得老长，一看就是笔没停、手没抬，一秒钟一本的速度。铅笔灵的笔尖垂下去了。灰扑扑的身子往纸背上一贴，不动了。

"……阅。"陆栖对着那页念了一遍。

没有人接话。办公室里只有窗外麻雀在防盗网上蹦两下又飞走的动静。

"这个字是写给谁的？"

笔尖抬起来一点，又垂下去。陆栖没再问第二遍。她从登记簿夹层里抽出自己那份。《我的爱好》，半页，写她喜欢旧书店的味道。存了二十年，纸早发脆发薄，她捏着书角展开。

发下来的时候，批注栏里也是孤零零一个字，笔迹压得很实，一笔到位。她把那两页并排放在一起。陆栖把这个阅字认下来。是我的。

"这个比喻真好。天上的被子。"

铅笔灵猛地从纸页上弹起来，落下，又弹起来，笔尖朝上，抖着。

"《外婆的手》这首，"陆栖接着往下，声音放得很稳，"最后那句'比被子还暖'是真的。我小时候外婆也这样。你把她手上的感觉写出来了，这最难。"

它停在原处，仰着头看她，笔尖还在抖。门外有脚步。顾松年在门框那儿站住。

"你在读什么？"

"一本作文本。"陆栖没抬头，"清出来的旧书，捐的。"

"……这字体太小了。"

陆栖说，八岁写的。

"嗯。"

他直起身，摸了摸那支铅笔头，又看了看陆栖，什么也没问，转身出去了。门轴响了一下。陆栖在原地没动。隔着一道门，听见他在走廊里停了停，才走远。

"他把字挡住了。"她对那支铅笔说。

笔尖点了一下纸面，像应了一声。她找出馆里用的软铅笔，削尖，在扉页背面写评语。原本想拿红笔，转念换铅笔。

"小满同学：你的诗写得真好。尤其是'云是天空的被子'。请一定继续写下去。"

她写得很慢，每一笔都压进纸里，纸背凸起一道一道的痕。写到署名她停了一下，添了四个字：一个认真的读者。这四个字她想了很久。平时签名笔画连着写，快；这四个字她一笔一画断开写。

"这个'认真的'是我编的。"她把笔尖在砚台边上蹭了一下，"我二十年前也想要这么一句。"

铅笔灵没有动。陆栖把本子摊开，放到窗台的阳光里。字写得不算匀。笔画粗细不匀，有两处洇开了，是孩子下笔太重。末几行的墨积在纸的凹坑里，干了以后凸起来一道。写到"请一定继续写下去"那句时，笔尖悬了一会儿，悬出的墨尖已经干了，凝成一个硬粒。这孩子后来有没有继续写，她不知道。纸面上只有那一句，底下什么都没有。

它升起来，绕着陆栖转了三圈，一圈比一圈轻盈。第一圈贴着她的袖口。第二圈掠过她的发梢。第三圈冲上半空，在光柱里打了个旋，抖落一身细碎的亮。那点亮落在摊开的诗稿上，满纸歪歪扭扭的字都活了过来。

门被推开，木门轴吱呀一声。一个八九岁的男孩站在门口，书包带子攥在手里，攥出一圈印，他妈妈跟在后面。

"阿姨，那本《我的诗》我要借。"

陆栖的手还按在窗台上。这本是上午才从第九箱登记出来的，借阅卡空着。男孩走到桌边，两只手撑住桌沿，踮着脚往里看，指头抠着桌沿的漆，抠下一块。看到窗台上摊开那本，他把手伸过去。陆栖没拦，她要看他怎么拿。手背在身后攥着，等他先动。

男孩的手指在牛皮纸封面上停住，才捏住书脊往外抽，抽得极慢，怕扯封皮。抽出来抱在怀里，两只手在封面上摸了两下。

"这个我也要写吗。"他忽然问。他指的是扉页背面那行字。

"那是别人写给你的。"

男孩低头捏了捏那四个字，把本子抱得更紧些。铅笔灵在纸页间动了一下。它没有再亮，从那行字底下挪开，挪到靠书口的地方，缩成小团。陆栖隔着纸又听见，同一句。

馆里行规她背得出：来借的要还。她量了日子，应还日期写一个月后的今天，在借阅卡上写男孩的名字，何嘉，和班级。他妈妈在旁边签了押。她另取小纸让男孩按手印。印泥还是那个铁盒，盒沿糊了一圈干红。男孩按得太靠边，图案缺了一角。

借阅卡底下压着一张空白的登记卡，钢笔已经捏在手里。

另存。馆里没有这条规矩，可她认得。八岁那年她跟外婆去县图书馆，管理员把一本没人借的书锁进里间。登记卡上写"有灵，另存"，钢笔写的，写完在旁边画了一道竖线。她说不出那书为什么不能借。

可它怕。它说了十九遍。铅笔灵在书口又缩回去一点。陆栖把笔尖压在"借阅卡"三个字上，压得笔杆弯了一点。

笔杆弯成那样，登记卡上就该落字了。卡片就压在本子底下，钢笔还捏在手里。四个字而已：城西小学，拆迁捐赠，有灵，另存。填完这本不上架，锁进里间，钥匙交到她手上。

锁起来，这个孩子半年都摸不着它。摸不着它，它就在这一格里等着，等下一个把它抽出来的人。也可能等不到。有灵另存的书她没见过结局。八岁那年那本锁了十年，她后来路过，门牌换过，里头是什么没人告诉她。

陆栖把笔挪开了。挪开以后她把笔杆上压弯的那一段捋了捋，没捋直。她把卡放回本子后，合上。抽一张棉纸包两层，角上压实，用细麻绳系了个十字扣。绳子打结要打两遍，她系到第三遍才收紧。

包的时候她停了一下。别的灵被借出去过，借出去的还能回来：本子回到架上，灵就回来了。这一册要是过期不还，它连落脚的纸都没有。册子上只有应还日期，没有归还那一栏；过期了往后翻，还是过期。她把绳头压进纸层里，压了两道。

"一个月以内送回来。"她把本子递过去，"弄脏不要紧，角别折。"

男孩两手接住，抱在怀里跑出门。他妈妈在后面追着喊慢点。铅笔灵趴在那页空白上，跟着本子一起出了门。

她把那张空白登记卡对着窗光看。卡的下半截，纸背上有一道浅浅的凹。一头在纸边，一头收在正中。那截身子趴久了压出来的，一格一格的痕，凑近才看得见。

登记卡上"捐赠人"那栏，她握笔停了一会儿。那一栏本来该填陈小满。可她不知道陈小满现在多大，在哪个城市。清册上写的是"城西小学图书室"。

她把笔搁回笔架，笔尖朝外，搁得很正。那一栏空着，空格子比填满的显眼。她看了它一眼，没有补。借阅卡还压在桌角。何嘉，五年级三班，应还日期，一个月后的今天。

一个月以后的今天会来。到了那天，这本册子只有两个地方可以翻：架子，或者那个孩子的书包，没有第三处。卡上那一格填的是日期，不是能不能找回来。
