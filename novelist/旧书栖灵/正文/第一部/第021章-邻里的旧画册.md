# 第021章 邻里的旧画册

十一月初，街道办转来一批居民捐赠：几大册老相册和画册。旧城改造摸底时，几户老人家主动捐给馆里"存个念想"的。

陆栖整理的时候，相册灵们纷纷醒过来，一页页伸脖子。它们不是在吵架，是在争着介绍自己："看，这是我。""这是我姐。""看我看我。"跟单本书的灵不同，相册的灵是一群。每一页照片里都探出小小的脸来，叽叽喳喳，热闹得像过年。

她站在那里又看了半天，才反应过来自己有点手足无措，不知道该先招呼谁。

陆栖蹲在纸箱边上，一本一本地翻。有的保存得好，颜色鲜艳；有的受潮发黄发霉，边角卷翘。她托着书底翻开，两指捏着页角往上抬，不敢硬掰。有的照片里的人她认识。顾松年年轻时的模样，馆里老馆长的身影；有的照片里的人她不认识，可从他们穿着打扮和脸上表情，能猜出那是哪一年的事。

陆栖守在展厅里望着那些照片。有的褪了色，黑白变成灰白，可人脸还清晰。脸上的表情，有的在笑，有的在发呆，有的在认真地盯着镜头。每一张脸背后都有一个故事，每一个故事都值得被说出来。她想，这就是她做这件事的意义。让那些被遗忘的故事重新被说出来，让那些被遗忘的人重新被看见。

陆栖猛地想起小时候在外婆家翻老相册。外婆的相册也是这样，每一页她都认识，翻到某一页就停下来说到某一页就会停下来说："看，这是你妈小时候。"然后就开始讲一个她听了无数遍的故事。可她每次都不觉得厌，因为外婆讲故事的时候，脸上会发光。

他合上索引，放在相册旁边。两本册子并排躺在书架上，一本装着照片，一本装着名字。窗外的天已经黑了，路灯亮了起来，暖黄的光从窗子里照进来，落在书架上，落在那两本册子上。

陆栖跟顾松年商量后，在阅览区办了个小小展览，名字叫"小城记忆"。老照片翻拍放大，配上年份，展了一个月。

翻拍是个细致活。陆栖借来相机，一张一张对着自然光拍；模糊的不硬修，说明卡上写"岁月磨损，原样保留"。她拍得很慢，每一张都要找角度、调光线，有时候一张照片要拍五六遍才满意。

这些照片不只是影像，是时间的切片，每一张都定格了某一天的某一刻。那个瞬间的光线、那个人的表情，都藏在那张薄薄的纸里。她拍的不是照片，是时间本身。顾松年把说明卡全看了一遍，改了三个错别字，又添了一句话挂在展厅门口：

"如有认出亲人故旧者，请告知馆方，代为存念。"

就为门口这句话，一个月里有十几位老人跑来补信息：这是谁的媳妇，那是谁家的老三。展览越办越厚。不是照片多了，是照片背后的名字多了。可也有一册始终没有名字。

纸箱里所有捐赠清单都随箱交来了，清单上写着"南巷某某户""桥西王姓人家"，没有一个具体的名字。陆栖按清单上的地址一户户打电话，打了六天。第五天的时候，她拨到南巷那户，电话响了三声，一个女人接起来。

"哦，那箱相册啊。"女人说，"是我爹妈留下的。老人去年冬天走的，房子空了，社里让捐。"

"捐赠人登记的是谁？能补一个名字吗。"

"名字？"女人愣了一下，"我一时想不起来。那箱东西里有没有写着？"

陆栖看了一眼手里的清单。上面只有一串门牌号。

"我再找找。"她说，"找到了给您回话。"

挂了电话，她在笔记本上把那一行又抄了一遍。南巷，十七号。名字空着。照片在，人没了名字。这一栏永远是空的。

陆栖守在展厅里，望着来来往往的人。拄拐杖的、坐轮椅的、被儿孙搀着的，在这面照片墙前一张一张看。看到熟悉的面孔就停下来，指着照片说："这是我家老大。""这是隔壁王婶。""这是那年发大水，我们站在屋顶上拍的。"每说一句话，照片就活了一分，像一盏被重新点亮的灯。每多一个名字，照片就亮一分，像一盏被重新擦亮的灯。

有位坐轮椅的爷爷在供销社柜台的照片前停了半个钟头，指着玻璃罐里的水果糖："三分钱一颗。我给我妹买过。"

他妹妹就站在旁边，六十多岁的老太太了，笑着接话："哥，那颗糖是橘子味儿的，你骗我说是苹果味儿的。"

"苹果味儿的。"老头一口咬定。

"橘子味儿的。"老太太也一口咬定。

"你忘了，你那年才六岁。"

"我六岁我记得清清楚楚。"

陆栖在旁边听着。她低头去看那张照片。玻璃罐在柜台上是有的，罐子里的糖看得见——只有一团模糊的白糖纸印子，纸上什么字都没了。

她要是能翻出另一张、角度不同的一张，也许能看清罐子上贴的标签。可这册相册里只有这一张供销社。

她没有插话。这一刻谁也赢不了谁：照片不会作证，罐子早就不在了，柜台也拆了。只有两个人还站在这儿，各自攥着一份谁也核对不上的记忆。过了好一会儿，老头先松了口："橘子就橘子吧。"

"本来就是橘子。"老太太说。

两个人都拿手背按了按眼睛。

陆栖递了一张纸巾过去。老爷子接过来擦了擦眼睛，不好意思地笑了笑："老了，不中用了。可看到这些老东西，就忍不住。"她指着照片里的供销社柜台，声音低了下去："那时候日子苦，可心里踏实。一碗饭，一颗糖，就是一天。现在什么都有了，反而不知道该高兴什么了。"

照片泛黄，摄于几十年前的馆门口，纸角卷着毛边。一个半大的少年站在台阶下，仰头看这座楼，手里攥着什么东西。背面一行铅笔字，字迹稚嫩：

"许愿：希望妹妹的病快点好。"

少年攥着的，大概就是这张纸条。陆栖把照片翻过来又翻过去地看。少年的眉眼很淡，但那副仰头望楼的认真劲儿，隔着几十年都看得出。她拿着照片去了办公室，翻出登记卡的空表。

表格是死的。第一行"捐赠人姓名"，第二行"捐赠物品"，第三行"捐赠时间"，第四行"备注"。每一格都有字数上限，姓名那栏后面印着六个方格。她拿着笔，在第一个方格上停住。

她手上有姓。三户合捐的那一户姓陈，清单上写着"南巷某某户"。可清单从头到尾没有一个人的名字，只有一串门牌号。她可以在第一个方格里写"陈"。一个姓，占一格，后面五格空着。

她也可以写"陈氏"。写完看着更像那么回事，也更像在搪塞。两种她都试了一遍，都划掉了。她去找顾松年。

"这一栏填不出。"她把表推过去，"街道办给的清单只有门牌号。"

顾松年把老花镜推上去，看了半分钟。

"填'佚名'。"他说，"馆里老册子都这么填。"

"佚名。"她念了一遍。

"没人知道名字的，就写佚名。馆里老册子都这么填。"

陆栖看着那一栏。六个方格，填两个字，剩下四个空着。她知道这么填不会错。检查的人看见"佚名"会知道这不是漏填，是确实不知道。她把笔放下。

"那我填什么？"

"填你要填的。"

"备注栏有字数上限。"她指着表格背面那行小字，"四十个字。"

顾松年把表推回来，摘下眼镜。

"四十个字够写一句话。"他说，"不够写一个名字加一句话。"

陆栖把表拿回去，在办公桌前坐了很久。窗外天井的老槐树影子移过一格，又移过一格。最后她填了。第一行"捐赠人姓名"那栏，她写了两个字：待考。

底下"备注"栏，她写：捐自南巷某户。照片中的少年当年在此许愿，愿望是希望妹妹的病快点好。我们不知道他是谁，也不知道愿望实现了没有。但我们记得。四十二个字。超了两个。

她数了两遍，是四十二。她把"我们记得"挪到第二行。第二行还容得下四个字。第一行三十八个字，字数上限是四十。她把表格拿去给街道办的小刘。小刘接过去看了一眼，眉头皱了一下。

"'待考'？这个填法上报不了。上面要核名字。"

"那就先空着。"

"空着更不行。"小刘把表放下，"空格是漏填，待考是疑义。两种都退。"

陆栖站在那儿。

"那你要我填什么。"

小刘想了一会儿，说："你写'某佚名氏'，我给你报。名字那栏空着不算，'佚名'两个字算。"

他说得很实在。他不是为难她。他每年要往上交十二张这样的表，退回去要重填，退回去三回他就要挨一次说。陆栖点头。

她把表收回来，在"待考"那两个字上又停了一下。她把"待"字最后一笔拉长了一点，看着像"侍"，又改回"待"。然后她把小刘说的"佚名"添进备注栏最后：某佚名氏。添完一数。四十七个字。

她从"我们记得"里删掉"记"字。四十六。又删掉一个"们"。四十四。她停了一下，盯着那个"我"字看了几秒。这是展览，不是给后人写信。"我们记得"里的"我们"，本来就不该她一个人替。

她把"我们记得"整个划掉，改成：但有人记得。三十九个字。她把表交给小刘。小刘这回数了，没皱眉，签了个字，往下一个格子填去了。

表格收上去以后，陆栖在那张照片的说明卡上，用铅笔写了一行很小的字，写在"待考"那两个字底下：若有人认得，请告知馆方。

布展那天傍晚，她看见相册灵们都凑在那张照片周围，周正的，谁也不闹了。它们轻手轻脚围成一圈。那个抱着膝盖坐在照片上的、瘦瘦的少年影子抬起头来，朝她心里应了一下。不是道谢的意思。更像是确认，确认这件事，真的有人接住了。

陆栖想，这些相册灵和馆里其他灵不一样。别的灵守着一首诗、一支曲子，可相册灵守着一群人的脸。脸是最难记住的东西，也是最容易忘记的东西。可相册灵替人记着。记着每一个人年轻时的样子，记着每一个人笑起来的样子，记着每一个人站在镜头前的样子。

撤展那天，几位老人结伴又来望了一眼。轮椅爷爷由妹妹搀着，把整面墙的照片从头看到尾，一张没落。看完他说了三个字：

"都在呢。"

展览结束后相册回到古籍区专架。陆栖把老人们口述的人物关系整理成一册"照片人物索引"，附进函套。厚厚一沓稿纸，写满城南半个世纪的人来人往。

她写到深夜，台灯的光晕落在稿纸上，照见那些密密麻麻的名字。有的名字她不认识，有的从来没听说过，可她还是一个一个写下来，一笔一画，端端正正。

顾松年翻了翻，给了句公道话："这可比我们的馆藏目录难编多了。"相册灵在函套里听着，把每一页都抚得平平整整。

陆栖把函套合上，放回书架上。她站在书架前，看着那盏灯，忽然觉得，这些相册和馆里的其她书不一样。它们不只是记录，是凭证。是证明那些人曾经存在过的凭证。只要有这些照片在，那些人就不会真的消失。它们终于安心了。被人看过了，被人记住了，名字被写下来了。

它们终于可以安安心心地回到函套里，回到那一页页泛黄的照片中间。往后再有人翻开相册，看到的不只是照片，还有照片背后的名字、故事和温度。对于一群灵来说，这就是最好的归宿。
