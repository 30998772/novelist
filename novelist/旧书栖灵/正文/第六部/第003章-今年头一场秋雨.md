# 第003章 今年头一场秋雨

林越来的那天，落了今年头一场秋雨。

雨不大，淅淅沥沥的，从早上一直下到午后。天井里的老槐树被雨洗了一遍，叶子绿得发亮，水珠沿着叶脉往下淌，滴在树根旁边的石头上。陆栖坐在一楼靠窗的位置，手里捧着一杯热茶，望着窗外的雨。茶是今年新晒的，头几道涩，后头才回上来一点甜。她喝了一口，又放下。

林越是下午到的。他今年五十九了，头发全白了，人瘦了不少，可精神还好。他进门的时候，手里提着一个布袋子，袋子里装着几个橘子和一盒绿豆糕。他把袋子放在桌上，说："路上买的，你尝尝。"

陆栖看了看那袋橘子，黄澄澄的，皮上还带着水珠。她拿了一个，剥开，橘瓣上冒着热气。她吃了一瓣，酸里带甜，味道不错。

"你吃了饭没有？"她问。

"吃了。来的路上吃的。"林越在她对面坐下来，把外套脱了搭在椅背上。他穿了一件灰色的毛衣，毛衣的袖口磨出了毛边。他扫了一眼窗外的雨，说："这雨下得正好。秋天不下几场雨，冬天就干得难受。"

陆栖应了一声。她又喝了一口茶，然后把茶杯推到林越面前："你也喝。"

林越端起茶杯，喝了一口。他喝茶的样子跟年轻时候不一样了——年轻的时候他喝茶快，一口一杯，如今他喝得慢，一小口一小口地抿，像是在品什么。

两个人就这么坐着，谁也没说话。窗外的雨声很轻，像有人在远处翻书。天井里的水缸沿上，雨水汇成一条细细的线，顺着缸壁往下流，流到地面上，渗进砖缝里。老槐树的影子倒映在水缸的水面上，被雨滴打得一颤一颤的，像一幅画，画里的树在风里摇。

林越先开了口："最近身体怎么样？"

"还行。"陆栖说。

"手还抖吗？"

"抖。比去年厉害了点。"

"吃药了没有？"林越顿了顿，又补了一句，"陆栖，你这辈子记性最好。我穿什么衣服，你记得清清楚楚。可你自己吃不吃药，你从来不在意。"

"吃了。"

林越盯着她的手。她的手搁在桌上，手指并拢，指尖有轻微的颤动。他没有伸手去握。他把手收回去，放在自己膝盖上。

"你呢？"陆栖问，"腿还疼不疼？"

"不怎么疼了。换了个药方，好多了。"林越把裤腿往上提了提，露出膝盖上一道旧疤，"去年摔的那一跤，留了个疤，阴天的时候会酸。"

"你小心点。"

"知道了。"

两个人又沉默了一会儿。窗外的雨渐渐小了，天边露出一线亮光，像是太阳要出来了。天井里的老槐树叶子上还挂着水珠，在那一缕阳光里，亮晶晶的。

"上礼拜有个读者来找我。"林越说。

"嗯。"

"六十几岁的男的，姓崔。他祖父在这儿当过管理员，民国年间。他自己翻了一个下午的旧照片，翻到最后抱着一本出来，说要复印。我问他复印哪张，他说哪张都不印，就是想看看清楚一点。"

"看清楚什么？"

"他自己也说不清。"林越笑了一下，"他说他在照片后头找一个人，找了一下午。人都认得，就那个没有。他说他祖父提过，家里有个姐姐，没结婚，抗战那几年在馆里帮忙管过书，后来没了。他想看看她长什么样。"

陆栖没有说话。

"我跟他说，你要真想知道，我可以查查旧职工名录。他说没有。"林越停了一下，"我后来翻了一下，那几年馆里就三个人，一个管理员，一个学徒，还有一个姓崔的姑娘。名录上写着'崔明玉'，后面没有别的。"

雨声在这时候又大了一点。

"那个男的后来怎么样？"

"他道了谢，走了。"林越说，"走到门口又回头，问我能不能把那本相册先留着，别上架。我说我查查。查了三天，没找着这本。"

陆栖把茶杯端起来，发现是空的，就又放下了。

"你该记一记。"她说。

"记什么？"

"崔明玉。"陆栖说，"哪怕只写一行，以后他再来问，你好答。"

林越"嗯"了一声，从口袋里摸出本子，翻开，写了几个字。他写字的时候左手压着本子，右手握笔，姿势有点别扭。写完他把本子转过来给她看。字迹歪歪扭扭，最后一个"玉"字的一横拖得很长。

"你这字不如从前了。"陆栖说。

"手抖。"林越把本子收回去，"你也好不到哪儿去。"

陆栖想反驳，可她低头看了一眼自己的手，没话说。

"你还记得崔明玉？"

"刚才你说了，我就记住了。"陆栖说，"我别的记不住，这种名字记得住。"

"为什么？"

"因为名字少。"她说，"三个字，一听就知道是个人。"

陆栖冷不丁说："你还记不记得，你刚来馆里的时候？"

林越愣了一下，然后笑了。他当然记得。那时候他三十出头，刚从别的单位调过来，接手南枝文献馆。他第一天来的时候，看见陆栖在旧书区翻书，满手的灰，头发上沾着纸屑，头也没抬，就说了一句："放那儿吧，我一会儿看。"他站在门口站了半分钟，才说："我是新来的馆长。"陆栖抬起头，看了他一眼，又低下头，说："哦。那你自己先转转。"

"你那时候可不怎么热情。"林越说。

"你现在也不热情。"陆栖说。

两个人都笑了。笑声很轻，在雨后的安静里，像两片叶子落在水面上。

林越打量着窗外，说："我在馆里待了三十八年了。三十八年，好像一眨眼的事。"

"你刚来的时候，馆里就我们两个。"陆栖说，"后来加了苏晚，再后来加了晓颂、小远、小明。人多了，事也多了，可楼还是这栋楼。"

"楼是这栋楼，可楼里的人换了好几拨了。"林越说，"顾先生走了，方先生走了，周先生走了。苏晚也退了。就你还在这儿。"

"你也在这儿。"陆栖说。

林越笑了笑，没接话。他端起茶杯，又喝了一口。茶已经凉了，他也没有在意。

两个人坐在那里，端详着窗外的天色一点一点地亮起来。雨停了，天井里的地面湿漉漉的，砖缝里冒着细细的水汽。

方小远从花园走进来，手里拎着一把剪子，剪子上沾着碎叶。他看见林越，打了声招呼："林伯，来了。"

"来了。"林越说，"桂花树长得怎么样？"

"好着呢。"方小远咧嘴笑了，"新叶子又长了两片。它扎根扎得快，明年说不定就能开花了。"

"那就好。"林越心里应了一下。

方小远走了之后，林越又坐了一会儿。他瞅着窗外那棵桂花树，冷不丁说："苏彻的女儿，上次来过没有？"

"来过。上个月来看过一次，说树长得好。"陆栖说。

"她一个人来的？"

"一个人。她爸走了之后，她一个人住。"陆栖顿了顿，"她每次来，都站在树旁边站一会儿，也不说话，就站着。"

林越沉默了一会儿，说："想爸爸了。"

"嗯。"

两个人又不说话了。窗外的阳光越来越亮，把天井照得通透。老槐树的影子缩到了树根底下。

陆栖数了数树上的叶子。春天她数过一回，那回数不清，密密麻麻，分不出个数。这回数得清一些，稀了。

她没有跟林越说这些。

午后，雨后的阳光暖洋洋的，照在人身上，有一种懒洋洋的舒服。林越站起来，说去院子里走走。陆栖说她也去。两个人一前一后走出馆门，走到天井里。地面还是湿的，踩上去软软的，鞋底沾了泥。林越走在前面，走得很慢，一步一步的，像是在数步子。陆栖跟在后面，也走得很慢。两个人的影子被阳光拉得很长，一前一后地印在湿漉漉的地面上。

走到老槐树底下的时候，林越停了下来。他抬头看了看树冠，叶子密密匝匝的，遮住了大半个天。阳光从叶子的缝隙里漏下来，碎成一地的金。他站了一会儿，说："这棵树，比我们年纪都大。"

"比这栋楼年纪都大。"陆栖说。

"你说它在想什么？"

陆栖看了他一眼："你什么时候也开始想这些了？"

"老了就爱想这些。"林越也笑了。

陆栖没有回答。她低头，看见了树根旁边露出来的一块石头。

林越也看见了，蹲下去摸了摸。"这石头，摸着暖。"

"石头晒了一天太阳，当然暖。"陆栖说。

"不是太阳的暖。"林越说，"是石头自己的暖。它在这儿待了这么多年，吸收了多少人的体温，早就暖了。"

陆栖没接话。林越的侧脸被阳光照着，鼻梁上有一道亮。

"你说话越来越像顾先生了。"她说。

"是吗？"林越转过头来瞅着她，"那我可不敢当。顾先生说的话，我到现在也没全听懂。"

"我也没全听懂。"陆栖说，"可我慢慢地，懂了一点。"

"懂了什么？"

陆栖想了想，说："懂了这栋楼。"

林越没有追问。

两个人在树底下站了很久。阳光从头顶漏下来，照着他们的白发。

傍晚的时候，他们回到馆里。进了旧书区，陆栖想再看一遍那排需要除虫的书。她从架子上抽出一本，翻开第一页，凑近了看——霉斑还在原来的位置，没有扩大。她拿铅笔在书脊上打了一个记号，笔尖刚碰到木头，手一抖，铅笔在书脊上划出一道歪斜的线，从上到下拉了半寸。

她把书放回去，重新抽出来。第二次，线还是歪的。

林越在旁边站着，没有伸手。

陆栖把那本书放回架上，插回去，插偏了一指宽，她用手指把书脊推齐，推了两次才推进去。

"还有多少本？"林越问。

"两百三十七。"

"一个人做要多久？"

"照今天这样，三个月。"

林越没说话。他弯腰从地上捡起铅笔，放回她手里的笔盒，然后走到架子另一头去了。

陆栖站在原地，握着那支铅笔。她握了一会儿，笔杆上留下了一点汗。她把笔放进兜里，出了旧书区。

林晓颂已经把晚饭准备好了——粥、咸菜、一碟炒青菜。三个人坐在办公室里吃，吃得很安静。林越吃粥的时候很慢，一小口一小口地，像是在品粥的味道。陆栖望着他吃，忽然说："你以后常来。"

林越抬起头，看了她一眼。

"常来坐坐。"陆栖说，"反正你也没什么事。"

林越笑了，说："好。"

吃完饭，林越要走了。陆栖送他到门口。门口那棵桂花树在暮色里站着，叶子上的水珠已经干了，枝条在晚风里微微摇晃。林越站在树旁边，回头看她。

"你进去吧。"他说，"外面凉。"

"你走慢点。"

"知道了。"

他转身走了。走了几步，他又回头，说："下周我再来。"

"好。"陆栖站在门口，看着他的背影在暮色里一点一点地变小，最后拐过巷口，看不见了。她把门带上。门闩落下去，在走廊里响了一声。

她回到办公室，坐在桌前。桌上的茶杯还在，茶已经凉透了。她端起来倒掉，重新泡了一杯。

她把茶杯放下，在笔记本上写了一行字：

"秋雨，林越来访。桂花树又长新叶。槐树今年叶子稀。"

写完，她看了看，又添了一句：

"他说石头是暖的。我想，是的。"

她站起来，走出办公室。月光出来了，照在老槐树上。

"晚安。"她说。

她踩着楼梯下楼，脚步声很轻，楼梯的吱呀声反而比脚步声还响。
