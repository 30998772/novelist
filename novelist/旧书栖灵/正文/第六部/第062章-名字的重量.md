# 第062章 名字的重量

冬至前两天，陆栖一大早就醒了。

天还没亮，窗外是灰蒙蒙的。他坐在床边，把棉鞋穿上，系好鞋带。手在抖，鞋带系了两次才系上。他站起来，走到桌前，把笔记本拿起来。笔记本是旧的，封面磨毛了边角，里面的纸页泛黄。他把笔记本揣进外套口袋里，走出家门。

路上没什么人。天冷，街上只有几个早起的人在走动，裹着厚棉衣，缩着脖子。他走得很慢，每一步都踩得很稳。他走到文献馆门口的时候，天刚蒙蒙亮。楼门关着，他从口袋里掏出钥匙，开了锁。钥匙插进锁孔的声音在寂静里显得很清脆。他推开门，走进去。

楼里很安静。木楼梯在脚下吱呀吱呀地响，每一步都踩得很稳。他走到二楼，走进办公室，坐下来。办公室的台灯还亮着——昨晚他走的时候忘了关。暖黄的光照在桌面上，照着桌上的笔记本。他把口袋里的笔记本拿出来，放在桌上，翻开。

他从第一页开始看。第一页是四十八年前写的，字迹工整，一笔一画。上面写着：

"雪团。绘本区小灵。怕冷。裹小绒毯。后得旧绒布斗篷。已远行。"

第二页：

"足音。木楼梯上的足音。民国教书先生。只有脚步声。已远行。"

第三页：

"乐谱灵。三十年未完的曲子。抱琴杆的轮廓。曲名《未完》。在。"

他一页一页地翻。每一页都是一个名字，一段注释。有些名字后面写着"在"，有些写着"已远行"。"在"的，他还看得见，摸得着，能跟它们说上几句话。"已远行"的，他只能在心里想想，翻翻笔记本，看看那些字迹。

他翻到最后一页。最后一页是他昨天写的——"旧书区。阅览室。四楼。天井。"他在每一条后面加了注释，字迹歪歪扭扭的。

他把笔记本合上，放在桌上。手放在笔记本上，感觉到纸页的温度——凉的，可又带着一丝从纸页深处渗出来的微温。

他坐了一会儿。窗外的天亮了一点，灰蒙蒙的天光从窗户里透进来，照在桌面上。他看着那光，看了一会儿。然后他站起来，走出办公室。

他去了旧书区。

旧书区的门没锁。他推开门，灯没开，只有窗外透进来的灰白天光。旧书架一排排地站着，书脊上的字在昏暗里模模糊糊的。他走到南墙靠里的那排架子前，站住了。

架子上有一本被墨水弄脏的书。墨点灵的书。他把手放在那本书上，感觉到那团墨水的温度。然后他从口袋里拿出笔记本，翻开，找到墨点灵那一页。

他看了看那页上的注释。"墨点灵。黑墨水。被泼掉的诗。等了三十七年。"他看完，把笔记本合上，揣回口袋里。

他走出旧书区，去了花园。

花园里很冷。冬天的花园没什么好看的，花都谢了，草都枯了，只有那棵老槐树还站着，光秃秃的枝桠在灰白的天光里伸着。花园的铁门半开着，门轴生了锈，推的时候吱呀一声。他走进去，脚踩在冻硬的泥地上，发出咔嚓咔嚓的响。他走到老槐树前，把手放在树干上。树干是凉的，可他感觉到那脉动——从树干深处传来的，很慢很慢的，像一颗很大的、很慢的心脏在跳动。

"我记得你。"他轻声说。

老槐树没有回应。枝桠在风里轻轻摇晃，沙沙的响。

他绕着老槐树走了一圈。树根扎在土里，周围的泥土裂开了几道缝，缝里长着几根枯草。他蹲下来，用手摸了摸那些枯草。草是干的，脆的，一碰就断。他把手从草上拿开，站起来。

他走出花园，走到天井里的石桌旁，坐下来。石桌上落了一层薄薄的雪，他用手抹了抹，把雪抹掉。桌面露出来了，青石的，凉的。他把手放在桌面上，感觉到石头的凉意从掌心传进来。他坐了一会儿，看着天井里的老槐树。老槐树光秃秃的站着，枝桠在风里轻轻摇晃。

他从口袋里拿出笔记本，翻开。他从第一页开始，一个名字一个名字地念。念得很慢，一个一个的，像数星星。

"雪团。"他念。"你怕冷。你裹着小绒毯。后来你有了斗篷。你第一次走出角落的那天，天上下着雪。你伸出手去接。雪花落在你的手指上，化了。你笑了。"

"足音。"他念。"你在木楼梯上走了很多年。民国的教书先生。你的脚步声很轻，很稳。你走的时候，楼梯吱呀吱呀地响。"

"乐谱灵。"他念。"你的曲子叫《未完》。你弹了很多年，一直没弹完。后来你弹完了。你把曲子改了名字。"

"字典老先生。"他念。"你帮人查字。你戴圆框眼镜，穿中山装。你把整架字典托付给了新的年轻人。你说：'查字的事，交给你了。'"

"借阅册灵。"他念。"你守了几百个人生的借阅记录。每一个名字，每一本书，你都记得。你随风远行了。你坐过的那个台子上，还留着你坐过的凹痕。"

"灯笼灵。"他念。"你守了两百年的街。你看着南枝镇从一条小街变成一个镇子。你说：'守街不守楼。'可你一直在文献馆门口亮着。"

"小禾。"他念。"你是日记灵。你叽叽喳喳的，像一只小鸟。你喜欢在日记本里写东西，写今天吃了什么糖，写了什么字，看见了什么花。"

"纸屑灵。"他念。"你是最脆弱的一页纸。你薄如一口气。后来你被接住了。"

"围裙灵。"他念。"你是菜谱之魂。你系着围裙。你从自卑到自信。"

"墨点灵。"他念。"你是那团黑墨水。你被泼掉了诗。你等了三十七年。我一直没帮上忙。"

他念完最后一个名字，把笔记本合上。他把笔记本放在膝盖上，手放在笔记本上，感觉到纸页的温度。他坐了一会儿，看着天井里的老槐树。老槐树光秃秃的站着，枝桠在风里轻轻摇晃。

他想起了昨天在旧书区看到的那本被墨水弄脏的书。那团墨水还在等。三十七年了，它还在等他把那首被泼掉的诗补回来。他一直没帮上忙。他不知道怎么帮。他只知道，那团墨水在等，他就不能忘。

他又想起了阿棠。阿棠的那首被涂掉的诗，他前些天在旧书区的诗抄里找到了半首。"我在风里等你，等你翻开——"后面被涂掉了。他还没有找到办法把那半首诗补全。他不知道阿棠想让他翻开什么。也许是一本书，也许是一个答案，也许是一个他还没有想到的东西。

他把这些事在心里过了一遍。然后他把笔记本翻开，在最后一页上加了一行字。字迹歪歪扭扭的，可每一笔都用了力：

"未完的事：墨点灵的诗。阿棠的半首诗。"

然后他站起来，走出天井，走进楼里。他走到二楼，走进办公室，坐下来。办公室的台灯还亮着，暖黄的光照在桌面上。他把笔记本放在桌上，翻开，在最后一页上写了几行字。字迹歪歪扭扭的，可每一笔都用了力：

"所有灵的名字，我都记得。它们的位子，我都记得。它们说过的话，我都记得。它们最后的样子，我都记得。"

他写完，合上笔记本，把笔放下。手在抖——帕金森的抖，手指头不听使唤。他等了半分钟，等那阵抖过去，才把手从笔上拿开。

他坐了一会儿。窗外的天已经亮了，阳光从窗户里透进来，照在桌面上。阳光是暖的，照在他的手上，照在笔记本上。他看着那光，看了一会儿。

然后林晓颂来了。她推开门，手里端着一碗粥。粥是小米粥，冒着热气，碗沿上搁了一双筷子。

"陆老师，吃早饭。"她说。

他接过碗，坐下来，慢慢喝。粥很稠，小米煮得烂，入口即化。林晓颂站在旁边，看着他喝。他喝了几口，放下碗，说："晓颂。"

"嗯。"

"你过来。"

林晓颂走过来，站在他旁边。他把笔记本翻开，翻到第一页。他指着第一页上的名字，说："你看。"

林晓颂低头看了看。第一页上写着"雪团"两个字，旁边是一小段注释。她看了看，又抬头看陆栖。

"这些名字，"他说，"你记不记得？"

林晓颂想了想，说："雪团。怕冷的小灵。裹小绒毯。后来有了斗篷。"

他点了点头。"你记得。"

"是您教我的。"林晓颂说，"您以前跟我说过。每一个灵的名字，都要记住。"

"对。"他说，"每一个灵的名字，都要记住。名字是灵的根。记住名字，灵就不会散。"

他把笔记本翻到最后一页，指了指最后那几行字。"你看。"

林晓颂低头看了看。最后一页上写着"所有灵的名字，我都记得"。她看了看，又抬头看陆栖。

"您都记得。"她说。

"都记得。"他说，"一个都不少。"

他把笔记本合上，放在桌上。手放在笔记本上，感觉到纸页的温度。他坐了一会儿，说："晓颂，你坐。"

林晓颂坐下来。她坐在他对面，看着他。他看着她，看了很久。她的脸他认得——林晓颂的脸，圆圆的，眉眼温柔。可他知道，再过一段时间，这张脸他会认不出来了。他会记得她的名字，记得她说话的声音，记得她端粥来的样子，可她的脸会变成一张模糊的、空白的纸。

这是代价。守馆人的代价。

他没有说这些。他只是说："你去忙吧。馆里的事，你管着就行。"

林晓颂站起来，走到门口。她停了一下，回头看了他一眼。她想说什么，又没说。她转身下楼了，脚步声在楼梯上一层一层地远下去。

陆栖一个人坐在办公室里。阳光从窗户里透进来，照在桌面上，照在笔记本上。他把手放在笔记本上，感觉到纸页的温度。他坐了一会儿，轻声说了一句话：

"都在呢。"

然后他关了台灯，站起来，走出办公室。楼梯吱呀吱呀地响，每一步都踩得很稳。他走到一楼，走出楼，走进花园。

花园里的阳光比楼里暖一些。他走到老槐树前，把手放在树干上。树干是凉的，可他感觉到那脉动——从树干深处传来的，很慢很慢的，像一颗很大的、很慢的心脏在跳动。一下。又一下。又一下。

他把手贴在树干上，闭上眼睛。他在心里把这些名字又念了一遍。念得很慢，一个一个的，像数星星。

念到最后一个名字的时候，他睁开眼睛。阳光照在老槐树的枝桠上，枝桠的影子投在地上，斑斑驳驳的。他看着那些影子，看了一会儿。

然后他把手从树干上拿开，转身走出花园。他走在天井里，脚步声在寂静里显得很轻。他走到楼门口，停了一下，回头看了一眼。楼在阳光里站着，旧旧的，暖暖的。灯光从窗户里透出来，暖黄的小小一团。他看了一会儿，转身走进阳光里。

他走在老街上，阳光照着他的脸，暖暖的。风来了，穿过老街的巷子，贴着他的脸颊走过去。他闭上眼睛，在心里默念了一遍那些名字——念得很慢，一个一个，像数星星。

念到最后一个名字的时候，他睁开眼睛。他继续走，走进阳光里。身后的楼越来越远，越来越小，最后变成一个小小的亮点，在阳光里亮着。

他知道，明天就是冬至前夜。后天就是冬至。后天，他要做最后一件事。他要为这栋楼里所有的灵，加固它们的记忆。他要让它们记得，有人来过，有人守过，有人把它们的名字记在了本子上。

他走在阳光里，心里很静。
