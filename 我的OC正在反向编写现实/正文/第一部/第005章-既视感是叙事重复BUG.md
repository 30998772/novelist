# 第005章 既视感是叙事重复BUG

备忘录事件之后，我开始记录。

不是记小说，是记"异常"。我建了一个文档，标题就叫《观察日志》，把每一件说不通的小事按日期记下来：时间、现象、当时的合理解释、解释的漏洞。像写实验报告，也像写怪谈素材——反正我是干这行的，这两样都熟。键盘敲击声在安静的房间里很清晰，嗒嗒嗒的，像雨点打在窗玻璃上。文档窗口的白光照着我的脸，映在对面衣柜的玻璃门上，模糊的，发青的。我习惯在写日志的时候把台灯调到最暗，因为屏幕的光已经够亮了，亮得能把房间里的黑暗逼到墙角。那些黑暗缩在衣柜旁边、床底下、窗帘的褶皱里，像一群安静的旁观者。

日志写到第九天，出现了一个新的高频条目：既视感。

以前我也偶尔有déjà vu，一年两三次那种，模糊的、软绵绵的，你知道那不是真的，只是大脑在跟你开个小玩笑。可那段时间，它一天能来五六次，而且强烈得吓人，强烈到让我在街上走着走着突然停下来。有时候是在走路的时候，脚刚迈出去，大脑忽然弹出一帧画面——"这一步我迈过"——然后整个人僵在原地，像被人按了暂停键。有时候是在跟人说话的时候，对方还没开口，我已经知道他下一句要说什么，甚至知道他说话时嘴角上翘的角度。

最典型的一次发生在便利店。

周三傍晚六点多，天色刚暗下来，路灯还没亮透。我推门进去，门铃叮咚响了两声——第一声是机械的，第二声是回音，嵌在便利店狭小的空间里，像两颗石子投进同一口井。收银台后面的小周抬头说"欢迎光临"。冷柜的风幕声嗡嗡嗡，收银机旁饭团的到期提示音"嘀——嘀——"，门口进来一个穿校服的学生，校服是蓝白相间的那种，很旧了，领口起了毛球——所有元素落位的瞬间，一股强烈的"这段我经历过"的感觉砸下来，砸得我站在原地动不了。我能感觉到自己的呼吸停了一拍，胸腔里像有什么东西卡住了。我能闻到便利店里各种食物混合的味道，关东煮的咸味，面包的甜味，还有冷柜里散发出的冷气，带着一点塑料味。货架上的商品排列得整整齐齐，标签朝着同一个方向，像一排等待检阅的士兵。

我知道接下来会发生什么：穿校服的学生会走到饮料柜第二层拿一瓶乌龙茶，然后小周会喊住他，说那瓶临期了换旁边那排。学生会犹豫一下，放回去，拿旁边那瓶。

三秒后，学生走向饮料柜。五秒后，小周开口。

一字不差。

我站在货架前面，手里捏着一包还没决定要不要买的饼干，看着现实在我眼前精确地重播一遍。鸡皮疙瘩从手臂爬到后颈，又从后颈爬回头皮。饼干包装袋在我手里发出轻微的沙沙声，我能感觉到塑料袋的光滑触感。我能听到自己的心跳，一下一下的，很快，很重。

还有更细的东西。那个学生的校服第二颗纽扣是松的，晃晃悠悠挂着线头——上一遍"播放"里也是这样。小周弯腰搬箱子的姿势、冷柜风幕声的间隔、甚至门口进来时门铃响了两声还是一声——全部严丝合缝。我能听到冷柜压缩机启动的嗡嗡声，低沉的，持续的。我能感觉到便利店地板的光滑，鞋底踩上去有点滑。

如果是普通的既视感，到这一步就该结束了。可这次不一样的是：重播结束后，又来了一遍。

同一个瞬间。同样的风幕声。同样的一句"欢迎光临"。学生第二次走向饮料柜。小周第二次开口。甚至连学生犹豫时手指在饮料瓶标签上划过的那个动作，都一模一样——指尖从上往下，划了大约两厘米，然后缩回来。

我在便利店门口站了整整一分钟，看着这套流程循环了三遍。第三遍的时候我开始数秒，心里默念：一、二、三——"欢迎光临"。一、二、三——学生走向饮料柜。一、二——小周开口。时间轴被钉死了，像一段被锁定循环播放的音频文件，进度条在同一个区间里来回跳。第四遍的时候，循环断了——学生的妈妈在门口喊他回家吃饭，声音尖锐，穿透力极强，像一把刀切开了一个不断重复的圆环。剧情岔开，世界若无其事地继续流淌。小周看见我还杵在门口，笑着问我："哥，你还好吧？脸都白了。"

我说没事，拿了瓶水结账走人。水是凉的，瓶壁上凝着水珠，我握在手里能感觉到冰凉从指尖渗进掌心。收银机吐出小票，小票的纸很薄，边缘有点割手。

走出便利店的时候我回头看了一眼。小周在收银台后面整理零钱，动作自然，表情正常，完全不记得刚才发生过什么——或者在他看来，刚才什么都没发生过。便利店的自动门缓缓关上，发出轻微的气压声。外面天已经黑透了，路灯的光是那种惨白的LED光，照在人脸上，把皮肤照得发青。街上的行人不多，三三两两的，各自低头走路，没人注意到一个在便利店门口站了一分钟的怪人。我能感觉到夜风的凉意，吹在脸上，带着一点灰尘的味道。远处有狗叫声，断断续续的。

回到家我用冷水洗了把脸，然后打开《观察日志》，手有点抖地把这一条记下来。水是凉的，泼在脸上的时候能感觉到皮肤收紧，毛孔一个个缩起来。我用毛巾擦脸，毛巾是旧的，纤维已经变硬，蹭在脸上有点扎。记完，我盯着屏幕上"重复三遍"四个字，一个此前一直绕着走的念头，第一次正面浮了上来。水龙头没关紧，一滴一滴往下淌，滴在水槽上，嗒，嗒，嗒，节奏和便利店冷柜的风幕声一样。我的手指搁在键盘上，指尖冰凉，敲字的时候能感觉到键帽的温度一点一点被体温焐热。

可如果它不是误报呢？

如果那种"我经历过"的感觉是真的呢？——我真的经历过，就在不久之前，只是经历完之后，有什么东西把那段"播放"撤回去了，重新来过。

写手都懂这个动作：写了五百字，觉得不对，Ctrl+A全选，Delete删除，重来。重来之后的新版本往往和旧版大差不差，因为底子是同一个思路。而人对自己删掉的旧稿是有残影的——有时候你会觉得某个段落"应该还有一句话"，那就是被删掉的话留下的坑。我能感觉到自己的呼吸变浅了，胸腔起伏，空气从鼻腔进入，带着一点干燥的凉意。房间里的空气很沉，闷闷的，像有什么东西压在头顶。

我当过六年的删除者。我知道删稿子的人是什么心态：不心疼。删得越狠，写得越好，这是行规。没有哪个写手会为一千个字举行葬礼。可那是因为删掉的只是文字，文字背后没有人。没有心跳，没有呼吸，没有指纹。

可如果被删的是世界呢？

如果这个世界也是一份稿子呢？

如果有人——或者有什么东西——正在反复修改这份稿子，删一段，重写一段？那么身处稿中的我，会不会在某些衔接不严的地方，感觉到上一版的余温？就像一栋翻新过的房子，墙壁刷了新漆，但如果你把耳朵贴上去，还能听到旧墙里水管的回声。

déjà vu不是记忆出错。

是缓存没清干净。

我把这个结论敲进日志，敲完最后一个句号，自己先笑了。荒唐。太荒唐了。一个写网文的扑街作者，把自己写进了一个正在被实时编辑的世界里，这件事荒唐的程度已经超出了正常人的认知边界。我能感觉到自己的嘴角在上扬，肌肉在牵动，但眼睛里没有笑意。屏幕上的光映在眼镜片上，变成两个小小的白色方块。

可是笑着笑着，我笑不下去了。

因为我发现自己在等。

等我写完这行字，保存，关掉文档的那一刻，我会不会觉得这一幕似曾相识？

我保存了。关掉了。

然后我在黑暗里坐着，一动不敢动。椅子的皮面被我捂出了汗，黏在后背上。房间里很安静，能听见自己的呼吸声，一吸一呼，节奏很浅。窗外偶尔有车驶过，车灯的光从窗帘缝隙里扫过，在墙上投出一道短暂的光影。冰箱的嗡嗡声从厨房传来，低沉的，持续的，像某种底噪。我能感觉到空气里的灰尘，吸进去的时候有点呛。我能听到自己心跳的声音，一下一下的，很规律，但那规律不是我的——那是一个正在被编写的段落的节奏。

因为我清清楚楚地记得，十分钟前我已经写过一版《观察日志》的这一条目了。措辞不一样，但意思一模一样——同样的便利店，同样的小周，同样的乌龙茶，同样的三遍循环，同样的结论。甚至那个"三遍循环"的措辞，上一版用的是"循环了三次"，这一版改成了"循环了三遍"，但内核一模一样——就像同一个人换了件衣服出门，五官没变，走路的姿势没变，连抬手的习惯都没变。

而我完全不记得，是什么时候删掉它的。我的回收站是空的，历史记录里没有删除操作。就好像那版文字从来没存在过——可它确实存在过，因为我记得自己写过。这种记忆和事实之间的裂缝，比既视感本身更让我害怕。既视感至少还能推给大脑出错，可一个记得自己写过、却找不到痕迹的文档，连推给谁都不知道。

或者——不是我删的。

是"它"在改稿。而我，只是稿子里的一个字。上一版的字，这一版还在，只是被重新描了一遍，墨迹更深了一点，笔画更重了一点。而我永远不会知道，上一版的这个字长什么样。就像一个人永远不会记得自己的前一个版本。

我低头看着自己的手。十根手指，十个指甲，指纹的螺纹一圈一圈的。我忽然很想知道：这些纹路是谁写的？是某个深夜敲键盘的我，还是某个更高处的存在，用一支看不见的笔，在我出生之前就把这些螺纹画好了？

我试着用右手的拇指去摸左手的食指指尖。指纹的纹路很细，要用很大的角度才能感觉到——像微缩的梯田，一层一层的，有沟有壑。这双手打过几十万字的小说，搬过三次家，做过无数次外卖文案，此刻它们搁在键盘上，微微发抖。它们是真实的。可是真实的就一定是"我"的吗？

这个问题没有答案。或者说，答案就藏在那些我读不出来的既视感里——那些我以为是错觉的东西，其实是上一版的我留下的指纹。它擦得干净文字，擦不干净痕迹。就像写手删掉旧稿之后，偶尔会在某个深夜突然想起一句被删掉的话，那句话不请自来，像一个不肯搬走的租客。

我低头看着日志文档，光标停在最后一行的句号后面，一闪一闪的。每闪三下，停一下。再闪三下，再停一下。像在等我写下去。又像在等我意识到什么。

窗外有风。路灯亮着。世界很正常。

可我知道，在某个我看不见的地方，有一支笔正在改我。
