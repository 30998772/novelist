## 项目概述

《裂隙余痕》是一部温柔致郁系怪谈大IP小说，核心卖点是**没有鬼怪，只有遗憾**。

- 正传：6部×60章=360章，126万字
- 番外：7本独立番外，147万字
- 总计：273万字

## 核心卖点

1. **无恶人设定**：所有怪异都源于遗憾，不是恶意
2. **专属符号系统**：每个角色都有独特记忆点
3. **宿命语录**：每人一句可出圈金句
4. **温柔治愈**：高级、好哭、辨识度爆炸
5. **无限延展**：正传完整+番外深挖，可连载多年

4. **世界观**：查看设定/世界观设定/了解核心规则
