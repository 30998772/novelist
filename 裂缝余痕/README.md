# 《裂隙余痕》小说创作资料库 -- 物语系列

## 项目概述

《裂隙余痕》是一部温柔致郁系怪谈大IP小说，核心卖点是**没有鬼怪，只有遗憾**。

- 正传：6卷×60章=360章，126万字
- 番外：7本独立番外，147万字
- 总计：273万字

## 核心卖点

1. **无恶人设定**：所有怪异都源于遗憾，不是恶意
2. **专属符号系统**：每个角色都有独特记忆点
3. **宿命语录**：每人一句可出圈金句
4. **温柔治愈**：高级、好哭、辨识度爆炸
5. **无限延展**：正传完整+番外深挖，可连载多年

## 使用说明

1. **写作前**：查看章节大纲/第X卷.md了解剧情走向
2. **写作时**：查看设定/第X卷角色.md了解角色状态
3. **角色塑造**：查看设定/角色设定/了解详细人设
4. **世界观**：查看设定/世界观设定/了解核心规则
5. **系列规划**：查看系列规划/了解后续发展
